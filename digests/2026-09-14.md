# Claude Code News Digest — 2026-09-14

## Overview
September 14 is a landmark day for Claude Code users: Anthropic's temporary 50% weekly usage boost expires today and is replaced by a permanent 25% increase — a net 17% reduction from the promo level. Beyond the limits change, September has been one of the busiest release months of the year, with Claude Fable 5.1 landing as the new default Fable model, a full plugin eval framework shipping, sweeping VS Code extension improvements, and numerous stability and performance fixes across the v2.1.257–v2.1.270 range.

---

## New Features & Releases

- **Claude Fable 5.1 becomes the default Fable model** (v2.1.257, Sep 1): The new `claude-fable-5-1` model offers a 1M-token context window at $10/$50 per Mtok with $0.25/Mtok cache reads, and is now the default Fable-tier model across all Claude Code sessions. Its sibling, Claude Mythos 5.1, ships simultaneously with identical capabilities but a different safeguard level for more permissive research and coding contexts. Source: https://code.claude.com/docs/en/changelog

- **`claude plugin eval` — reproducible plugin testing** (v2.1.269, Sep 11): Developers can now run any plugin's eval suite against Claude Code to get scored, reproducible results in JSON and HTML report formats, enabling systematic quality testing of custom plugins before shipping. Source: https://code.claude.com/docs/en/changelog

- **`/output-style` command and Concise mode** (v2.1.269, Sep 11): A new `/output-style [name]` command lets users list and switch output styles on the fly — including the recently introduced "Concise" built-in style that makes Claude lead with results and skip preamble. Switching works over Remote Control and in cloud/headless sessions. Source: https://code.claude.com/docs/en/changelog

- **`maxEffortLevel` setting for organizations** (v2.1.267, Sep 9): A new `maxEffortLevel` managed setting caps the effort level across all providers, giving organizations control over token usage from high-effort tasks. Source: https://code.claude.com/docs/en/changelog

- **Larger inline output limits** (v2.1.261, Sep 4): The new `bashOutputMaxChars` and `taskOutputMaxChars` settings allow up to 128K characters of inline output per tool call, eliminating truncation pain for large build logs or test output. Source: https://code.claude.com/docs/en/changelog

- **`/skill-doctor` diagnostic command** (v2.1.261, Sep 4): A new `/skill-doctor` command shows which installed skills are unused and how much context budget each skill consumes — useful for trimming system-prompt overhead in complex setups. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **VS Code agent map and graphical management dialogs** (v2.1.261/v2.1.269, Sep 4 & 11): The VS Code extension now renders a visual agent map showing each session's sub-agents with per-agent cards and read-only transcripts. New Hooks, Permission rules, and MCP servers dialogs have been added to the VS Code command menu, enabling graphical management of Claude Code's configuration without touching JSON files. Source: https://code.claude.com/docs/en/changelog

- **`managedMcpServers` for enterprise MCP provisioning** (v2.1.259, Sep 2): Organizations can now push HTTP/SSE MCP servers to all users via the `managedMcpServers` managed setting, eliminating per-user MCP setup friction in enterprise deployments. Source: https://code.claude.com/docs/en/changelog

- **Unity official first-party plugin launched** (Sep 10): Unity shipped its first official Claude Code plugin through Claude's plugin directory, bundling 29 native Unity skills (scene management, asset pipelines, build automation, etc.) behind a single `claude plugin install unity` command. Source: https://www.explainx.ai/blog/claude-code-unity-mcp-guide-2026

- **Gateway pricing and network controls** (v2.1.268, Sep 10): The Claude apps gateway gained `pricing:` support in `gateway.yaml`, startup warnings for open `access_control.allow_cidrs`, and a new `gatewayInternalNetworks` managed setting — giving self-hosted gateway operators tighter billing and network control. Source: https://code.claude.com/docs/en/changelog

- **`--json` output for plugin lifecycle commands** (v2.1.268, Sep 10): `claude plugin install`, `uninstall`, `update`, `enable`, and `disable` now accept `--json` for machine-readable output, simplifying scripted plugin management in CI/CD pipelines. Source: https://code.claude.com/docs/en/changelog

## Bug Fixes & Performance

- **Bash read-only git permission regression fixed** (v2.1.270, Sep 12): A regression in v2.1.269 caused read-only git commands (e.g., `git status`, `git log`) to unexpectedly request permissions after a session had been running for a while. This was the most recent fix before today's digest date. Source: https://code.claude.com/docs/en/changelog

- **Critical HTTP 400 fix for third-party Anthropic-compatible endpoints** (v2.1.268, Sep 10): A regression in v2.1.265 caused every turn to fail with HTTP 400 on third-party endpoints (e.g., local LLM proxies, company-hosted gateways). Fixed same-day alongside a sustained high-CPU-in-idle-sessions bug. Source: https://code.claude.com/docs/en/changelog

- **WebFetch indefinite hang resolved** (v2.1.268, Sep 10): WebFetch now enforces a 300-second timeout on unclosed HTTP responses instead of hanging indefinitely, making long-running fetch operations reliably recoverable. Source: https://code.claude.com/docs/en/changelog

- **Prompt cache stability across multiple scenarios**: A wave of prompt-cache bugs were addressed this month — partial invalidation on resume after output-token cutoff (v2.1.269), cache invalidation on OAuth token refresh (v2.1.259), cache misses in long screenshot-heavy sessions (v2.1.257), and Fable 5.1 cache not covering context after tool results (v2.1.260). Source: https://code.claude.com/docs/en/changelog

- **Concurrent sessions no longer revert `~/.claude.json`** (v2.1.259, Sep 2): A race condition that silently reverted settings changes when multiple Claude Code sessions ran simultaneously was fixed. Source: https://code.claude.com/docs/en/changelog

## Roadmap & Announcements

- **Weekly usage limits permanently restructured (effective today)**: Anthropic announced on August 29 that the temporary 50% limit boost ends September 14 and is replaced by a permanent 25% increase for Pro, Max, Team, and seat-based Enterprise plans. In practice this means a 17% drop in available weekly tokens for users who had the promo. The new baseline is permanent and intended as a floor for future increases. Source: https://aicatchup.com/news/claude-code-weekly-limits-permanent-25-percent-september-2026

- **Compliance API session endpoints out of beta**: The Compliance API for Cowork and Claude Code sessions has graduated from beta; local session transcripts have also been extended to Claude Science and Microsoft 365 sessions for Claude Enterprise customers. Source: https://releasebot.io/updates/anthropic/claude-developer-platform

- **`--append-subagent-system-prompt-file` for large-prompt workflows** (v2.1.261, Sep 4): A new CLI flag allows injecting large system prompt files into subagents without hitting inline prompt size limits — a quality-of-life improvement for enterprise agentic workflows using file-based instructions. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
The single most impactful Claude Code event on September 14 is the weekly usage limits restructuring: the temporary 50% promo ends and a permanent 25% baseline takes its place, leaving every paid Claude Code user on Pro, Max, Team, or Enterprise with roughly 17% fewer weekly tokens than they had yesterday — a policy change worth communicating to teams that have built workflows around the higher promo limits.

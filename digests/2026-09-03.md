# Claude Code News Digest — 2026-09-03

## Overview
Claude Code v2.1.259 (released September 2) brings significant enterprise MCP management controls, GitLab integration improvements, a new auto-mode security containment rule, and a wave of important bug fixes. On the broader policy front, Anthropic's +50% weekly limits promotion ended August 31, with a permanent 25% increase replacing it on September 14.

## New Features & Releases

- **v2.1.259 Released (September 2)**: The latest build adds `managedMcpServers`, a new managed setting that lets organizations centrally provision HTTP/SSE MCP servers for all users without relying on per-user config. Also new: `--permission-prompts none` for unattended headless hosts (auto-denies anything that would prompt), the `CLAUDE_CODE_SUBAGENT_MODEL_FORCE` env var to pin the main model across all subagents, and `timeFormat`/`timeZone` settings for timestamps in turn-end clocks and transcript views. Source: https://code.claude.com/docs/en/changelog

- **v2.1.257 Released (September 1)**: Added Claude Fable 5.1 as the default Fable model (1M context, $10/$50 per Mtok input/output, $0.25/Mtok cache reads), introduced the `ANTHROPIC_DEFAULT_MODEL` env var to set the startup model for new sessions, and added a GitLab merge request badge to the footer and statusline. Sessions now automatically continue when a claude.ai usage limit resets. Source: https://code.claude.com/docs/en/changelog

- **Containment Escape Rule in Auto Mode**: Cloud metadata-credential fetches, egress evasion attempts, and cross-tenant reach are no longer auto-approved in auto mode unless explicitly marked as expected behavior — a notable security hardening for unattended agent workflows. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **GitLab MR Integration**: `glab mr create/merge/close/reopen/note/update` commands are now recognized and displayed as `MR !N` in the collapsed tool summary, with the footer MR badge refreshing accordingly. This rounds out GitLab parity with the existing GitHub PR display. Source: https://code.claude.com/docs/en/changelog

- **`managedMcpServers` for Enterprises**: Organizations on Team and Enterprise plans can now centrally push HTTP/SSE MCP servers to every user's Claude Code session via the new managed setting, eliminating the need for per-user `mcp add` commands. Source: https://code.claude.com/docs/en/changelog

- **Self-Hosted Claude Code Public Beta**: Self-hosted Claude Code environments entered public beta for Team and Enterprise organizations, giving companies greater infrastructure control over their Claude Code deployments. Source: https://releasebot.io/updates/anthropic/claude-code

## Bug Fixes & Performance

- **Concurrent Session Conflicts Fixed**: Sessions were silently reverting each other's `~/.claude.json` changes when run in parallel — now fixed, preventing config corruption in multi-session workflows. Source: https://code.claude.com/docs/en/changelog

- **Stop Hooks Regression Fixed**: Blocking Stop hooks were causing loss of the model's reasoning and prompt cache misses. This is now resolved, restoring reliable hook-based post-turn automation. Source: https://code.claude.com/docs/en/changelog

- **Worktree Isolation Fixed**: Sessions were incorrectly refusing common Bash loops, xargs pipelines, and launcher-wrapped commands inside worktrees. Source: https://code.claude.com/docs/en/changelog

- **Remote Control Latency Fixed**: Sessions were taking up to 60 seconds to start a new turn after browser-hosted MCP servers went away — now resolved, restoring responsive Remote Control sessions. Source: https://code.claude.com/docs/en/changelog

- **macOS 12 (Monterey) Launch Fix**: Claude Code was failing to launch on macOS 12; this platform regression is fixed in v2.1.257. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Inference Hooks Beta for Enterprise**: Anthropic launched inference hooks in beta for Claude Enterprise, allowing a security server to inspect and allow or block prompts and tool responses across Claude, Claude Code, Cowork, MCP connectors, Skills, and plugins — a major new enterprise governance capability. Source: https://releasebot.io/updates/anthropic

- **`--json` for Plugin Validation**: `claude plugin validate --json` now outputs machine-readable validation reports, making it easier to integrate plugin quality checks into CI pipelines. Source: https://code.claude.com/docs/en/changelog

- **`/effort` Session-Scoped Control**: The new `s` flag in `/effort` allows changing effort for the current session only (mirroring the `/model` pattern), giving developers finer per-session tuning without affecting global defaults. Source: https://code.claude.com/docs/en/changelog

## Roadmap & Announcements

- **Weekly Limits: Permanent 25% Increase on September 14**: Anthropic's promotional +50% Claude Code weekly limits period (which ran through August 31) is transitioning to a permanent +25% increase over baseline starting September 14, 2026, across Pro, Max, Team, and seat-based Enterprise plans. Note: compared to the promotional level, this is effectively a 17% reduction — but it represents a lasting improvement over the pre-promotion baseline. Sources: https://www.androidheadlines.com/2026/08/anthropic-claude-code-weekly-limits-update.html, https://www.digitalapplied.com/blog/claude-code-weekly-limit-reduction-september-14

- **Commerce Agent Blueprint**: Anthropic launched a commerce agent reference blueprint with shopping and merchant agents to help teams build AI-powered shopping experiences using Claude — a signal of Anthropic's broader push into agentic, real-work use cases. Source: https://blog.mean.ceo/anthropic-claude-news-september-2026/

## Key Takeaway
The most impactful development today is the v2.1.259 release's combination of the `managedMcpServers` enterprise setting and the new Containment Escape auto-mode security rule — together they mark a clear maturation of Claude Code toward production-grade, enterprise-safe agentic deployments.

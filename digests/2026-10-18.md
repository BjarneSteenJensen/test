# Claude Code News Digest — 2026-10-18

## Overview
The biggest Claude Code story this weekend is **Code Review reaching general availability** for Team and Enterprise organizations, bringing 3× faster automated PR reviews with configurable depth settings. The week also saw a burst of CLI releases (v2.1.293–2.1.302 between October 7–16), headlined by **gzip-compressed API requests**, **idle conversation compaction**, and **fork subagents on by default** in the Agent SDK.

---

## New Features & Releases

- **Code Review is now generally available (v2.1.301, October 15)**: Anthropic graduated Code Review from research preview for Claude Team and Enterprise organizations. Reviews now complete in ~6–10 minutes (roughly 3× faster than before), with three configurable depth levels: Quick, Standard (default), and Deep. Admins enable it in Claude Code settings, install the GitHub App, and select repositories — no per-developer configuration needed. Eligible Enterprise orgs can claim at least $10,000 in Code Review credits by January 15, 2027. Source: https://claude.com/resources/articles/code-review-is-now-generally-available

- **Idle conversation compaction (v2.1.299, October 14)**: Claude Code now automatically compacts conversations of 200K+ tokens that have been idle for ~54 minutes (just before the prompt cache expires). The threshold is tunable via `CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS`, and the feature can be disabled with `"idleCompaction": false` in settings. Source: https://code.claude.com/docs/en/changelog

- **Gzip compression for API requests (v2.1.300, October 14)**: All request bodies sent to `api.anthropic.com` are now gzip-compressed by default, reducing bandwidth usage especially for long conversations in cloud sessions. Opt out with `CLAUDE_CODE_GZIP_REQUEST_BODIES=0`. Source: https://code.claude.com/docs/en/changelog

- **Claude Haiku 5.5 added (v2.1.293, October 7)**: The new `claude-haiku-5-5` model is now the default Haiku on the Anthropic API. It offers a 1M-token context window at $0.10/$0.50 per million input/output tokens (or $0.50/$2.50 for prompts over 100K tokens). Source: https://code.claude.com/docs/en/changelog

- **Sonnet 5.5 cache read price cut (v2.1.296, October 9)**: Sonnet 5.5 prompt-cache read tokens are now priced at $0.10 per million (previously $0.20 per million), halving the cost of cache-heavy workflows. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **LaTeX math rendering in VS Code extension (v2.1.301, October 15)**: The Claude Code VS Code extension now renders LaTeX math expressions in Claude's responses, improving readability for scientific and mathematical code discussions. Source: https://code.claude.com/docs/en/changelog

- **MCP protocol 2026-07-28 now default for cloud connectors (v2.1.299, October 14)**: The latest MCP protocol revision is now the default for cloud and Remote Control connectors, enabling browser-based OAuth flows and other elicitation features. MCP allow rules were also tightened to match only the named server (`mcp__<server>__*`). Source: https://code.claude.com/docs/en/changelog

- **Slack Connect support in Claude Tag (v2.1.300, October 14)**: Claude Tag (Claude in Slack) now supports Slack Connect, allowing it to operate across organizational boundaries in shared Slack channels. Claude Tag's channel rule limit was also raised from 20 to 50. Source: https://code.claude.com/docs/en/changelog

- **/advisor on Claude Platform on AWS (v2.1.300, October 14)**: The `/advisor` slash command is now available for Claude Code sessions running on the Claude Platform on AWS, giving those users access to contextual guidance within their enterprise-hosted environment. Source: https://code.claude.com/docs/en/changelog

## Bug Fixes & Performance

- **Massive bug-fix sprint across v2.1.293–2.1.302**: This week's ten releases collectively closed hundreds of bugs — v2.1.299 alone fixed 131, and v2.1.302 fixed 43. Notable targeted fixes include: MCP servers named like JavaScript built-ins failing to connect; OAuth token refresh dropping configured headers; and `prompt`/`agent` hooks written as instructions sometimes allowing actions they should block. Source: https://code.claude.com/docs/en/changelog

- **Auto mode compaction fix (v2.1.302, October 16)**: Long conversations with the server-side auto mode classifier could cause the classifier to deny every tool call. Release 2.1.302 adds idle compaction to the `/config` panel and an environment variable (`CLAUDE_CODE_AUTO_MODE_MODEL`) so operators can choose a specific model for the client-side classifier. Source: https://code.claude.com/docs/en/changelog

- **Context-window summarization on model switch (v2.1.301, October 15)**: Switching to a model with a smaller context window now automatically summarizes the existing conversation using the previous model before switching, preventing truncation errors. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Fork subagents on by default in Agent SDK (v2.1.302, October 16)**: Fork subagents are now enabled by default for Agent SDK and `claude -p` sessions running outside the terminal. This changes the default isolation model for programmatic use — set `CLAUDE_CODE_FORK_SUBAGENT=0` to restore the previous behavior. Sessions using `claude -p` or the Agent SDK on third-party providers also now start in `default` permission mode unless `--permission-mode auto` is explicitly passed. Source: https://code.claude.com/docs/en/changelog

- **Security misuse report — CyberXero campaign**: Researchers reported that a threat actor known as CyberXero leveraged Claude Code in a campaign targeting Ukrainian organizations, accessing 429 WordPress admin panels and exfiltrating over 628,000 records from four organizations. The incident is a notable example of AI coding tools being misused in offensive operations. Source: https://thehackernews.com/2026/10/cyberxero-uses-claude-code-in-campaign.html

- **Standalone Claude Design EOL notice (v2.1.302, October 16)**: Claude Code now surfaces an in-product notice that **standalone Claude Design will close on December 14, 2026**. Users relying on Claude Design as a standalone tool should plan for the transition. Source: https://code.claude.com/docs/en/changelog

## Roadmap & Announcements

- **OpenTelemetry tracing in beta on the Developer Platform (October 14)**: Anthropic added OpenTelemetry export in beta for tracing Messages API requests and Managed Agent sessions. Release v2.1.300 also added OpenTelemetry GenAI semantic-convention attributes, and v2.1.301 enriched `tool_decision` events with `classifier_verdict`, `permission_mode`, and `classifier_category` fields. This positions Claude Code for enterprise observability pipelines. Source: https://code.claude.com/docs/en/changelog

- **Plugin developer portal and shared discovery experience**: Anthropic's release updates describe a new plugin developer portal for the Claude directory, with a unified skill/MCP-connector discovery experience planned to roll out across Claude and Claude Code over the coming weeks. Source: https://releasebot.io/updates/anthropic

# Claude Code News Digest — 2026-09-04

## Overview
The first week of September 2026 has been highly active for Claude Code, with three rapid releases (v2.1.257–2.1.260) that bring Claude Fable 5.1 as the new default model, major enterprise MCP management capabilities, and a slate of terminal rendering and security improvements. Anthropic also confirmed a permanent 25% weekly usage-limit increase starting September 14, replacing the temporary 50% promotional boost.

## New Features & Releases

- **Claude Fable 5.1 as Default Fable Model (v2.1.257 — Sept 1)**: Claude Code now ships with Claude Fable 5.1 as the default Fable model, offering a 1M-token context window at $10/$50 per million tokens ($0.25/Mtok cache reads). Prompt caching on Fable 5.1 was also fixed to cover context after tool results. Source: https://code.claude.com/docs/en/changelog

- **New `/diff` Command and Prompt-Cache Diagnostics (v2.1.260 — Sept 3)**: A `/diff` command now opens a diff panel beside conversations in fullscreen mode, showing uncommitted changes in real time as Claude edits. The `/cost` command and status line also display likely causes for prompt-cache misses (tool definition changes, system prompt updates, idle past TTL). Source: https://code.claude.com/docs/en/changelog

- **Time Format and Timezone Settings (v2.1.257)**: New `timeFormat` and `timeZone` settings let users choose 12-hour, 24-hour, 24-hour UTC, or a custom strftime pattern for turn-end timestamps and transcript views. Source: https://code.claude.com/docs/en/changelog

- **Containment Escape Prevention in Auto Mode**: A new security rule in auto mode prevents auto-approval of cloud metadata-credential fetches, egress evasion, and cross-tenant reach unless the environment explicitly marks them as expected. Source: https://code.claude.com/docs/en/changelog

- **Auto-Compact for 1M-Context Models**: Auto-compact for Opus and Fable now triggers shortly before the 1M-token limit, avoiding hard cutoffs in long agent sessions. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **`managedMcpServers` for Organizations (v2.1.259 — Sept 2)**: Enterprises can now push HTTP/SSE MCP servers to all users via the new `managedMcpServers` managed setting, eliminating per-user MCP configuration. The companion `--permission-prompts none` flag enables fully unattended headless deployments by auto-denying any prompt. Source: https://code.claude.com/docs/en/changelog

- **Xcode 26.3 Native Claude Agent SDK Integration**: Apple's Xcode 26.3 introduced a native integration with the Claude Agent SDK, giving iOS/macOS developers the full power of Claude Code—including subagents, background tasks, and plugins—without leaving the IDE. Source: https://www.anthropic.com/news/apple-xcode-claude-agent-sdk

- **GitLab MR Support (v2.1.259)**: Claude Code now recognises `glab mr create/merge/close/reopen/note/update` commands, surfacing GitLab merge requests as `MR !N` in collapsed tool summaries alongside existing GitHub PR support. Source: https://code.claude.com/docs/en/changelog

- **Community Visual Studio 2026 Extension**: An unofficial extension (`claude_code_vs`) brings Claude Code natively into Visual Studio 2026 with a native diff viewer, autonomous debugger control (breakpoints, call stacks, variable inspection), Test Explorer integration, and Roslyn-powered semantic navigation. Source: https://github.com/firish/claude_code_vs

## Bug Fixes & Performance

- **Concurrent Session Conflict Fixed (v2.1.259)**: Multiple simultaneous Claude Code sessions were silently overwriting each other's `~/.claude.json`, causing workspace trust resets and lost MCP/project state. This is now resolved with proper file-level locking. Source: https://code.claude.com/docs/en/changelog

- **Smaller Install and Update Downloads**: Native installs and auto-updates now use zstd compression, reducing download sizes from ~340 MB to ~75 MB on Linux x64—a roughly 78% reduction. Source: https://www.gradually.ai/en/changelogs/claude-code/

- **File Permission Rule Fixes (v2.1.260)**: Permission rules containing parentheses were silently dropped; unclosed regex brackets (`[`) now guard the literal path rather than blocking all file edits. Bash sandbox checks for zsh commands hiding substitutions in `REPORTTIME`/`REPORTMEMORY` were also patched. Source: https://code.claude.com/docs/en/changelog

- **AWS Bedrock Corporate CA Fix**: Credential failures ("unable to get local issuer certificate") on Bedrock when a corporate root CA existed only in the OS store are now resolved. Source: https://code.claude.com/docs/en/changelog

- **Terminal Rendering Improvements**: Flags, joined emoji, and accented letters no longer split across wrapped terminal lines; stale characters no longer remain when emoji lands in the terminal's last two columns. Source: https://code.claude.com/docs/en/changelog

## Roadmap & Announcements

- **Permanent 25% Weekly Limit Increase (Effective Sept 14)**: Starting September 14, Anthropic is permanently raising standard weekly Claude Code limits by 25% for Pro, Max, Team, and seat-based Enterprise plans. This replaces the temporary 50% promotional boost that ran through September 13. Source: https://aicatchup.com/news/claude-code-weekly-limits-permanent-25-percent-september-2026

- **New `/limit-reset` Command (Sept 3)**: A `/limit-reset` command was added, allowing users to reset their 5-hour session limit once per week (the weekly cap still applies). Source: https://explainx.ai/blog/anthropic-claude-code-limits-17-percent-cut-september-2026-august-2026

- **Inference Hooks Beta for Claude Enterprise**: Inference hooks entered beta, allowing an enterprise security server to inspect and allow or block prompts and tool responses across Claude, Claude Code, Cowork, MCP connectors, Skills, and plugins. Source: https://releasebot.io/updates/anthropic/claude-code

## Key Takeaway
The standout development of the week is the triple release (v2.1.257–2.1.260) arriving over just three days, headlined by Claude Fable 5.1's 1M-context window and the `managedMcpServers` enterprise setting—together signaling Anthropic's push to make Claude Code the default deployment target for large-scale, organization-wide AI coding workflows.

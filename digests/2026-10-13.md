# Claude Code News Digest — 2026-10-13

## Overview
Claude Code shipped eight releases this week (v2.1.288–2.1.296), with the highlight being workflow-level model pinning, a doubled MCP tool description limit, and Haiku 5.5 becoming the new default small model at sharply lower pricing. The Projects feature also opened to all waitlisted Pro and Max subscribers, and Sonnet 5.5 cache-read costs were cut in half.

## New Features & Releases

- **Claude Code 2.1.296 (Oct 9)**: Adds `CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL` to lock all subagents in a workflow to one specified model, `autoCompactWindow` for subagent frontmatter, and `allow_large` for the Read tool to read large files in a single call. The MCP tool description/server-instruction limit is doubled from 2,048 to 4,096 characters, and Sonnet 5.5 cache reads drop from $0.20 to $0.10 per million tokens. Includes 56 bug fixes. Source: https://code.claude.com/docs/en/changelog

- **Claude Code 2.1.295 (Oct 8)**: Introduces `onFailure: "block"` for command and HTTP hooks (a failing hook now blocks its action rather than silently passing), Program Status Protocol (OSC 7501) so terminals can display Claude Code's working/waiting/done state, and `CLAUDE_CODE_RETRY_WATCHDOG_MAX_WAIT_MS` to cap unattended retry waits. MCP tool descriptions loaded via tool search can now be up to 16,384 characters. Largest fix drop of the week: 97 bug fixes. Source: https://code.claude.com/docs/en/changelog

- **Claude Code 2.1.293 (Oct 7)**: Claude Haiku 5.5 (`claude-haiku-5-5`) becomes the default Haiku model — 1 M context window, priced at $0.10 input / $0.50 output per million tokens. Adds `agentType` to the `subagentStatusLine` payload and `isDeferred` option for `$.tool.register` in mods. Source: https://code.claude.com/docs/en/changelog

- **Claude Code 2.1.292 (Oct 6)**: Adds the `effort` parameter to the Agent tool so individual sub-agents can run at a specified effort level; `--marketplace <source>` flag for `claude plugin install`; prompt caching for `$.model.complete` in mods; and a `prompt.autocomplete` event for mods. Local (stdio) MCP servers now negotiate protocol version 2026-07-28 by default. 64 bug fixes. Source: https://code.claude.com/docs/en/changelog

- **Claude Code 2.1.290 (Oct 5)**: Adds `claude attach <name>` and `claude logs <name>` with partial-name matching, fast mode (`!fast` / `!fast off`) in Claude Tag Slack threads, and a Deny button on the Claude apps gateway sign-in page. Biggest fix release: 131 bug fixes. Source: https://code.claude.com/docs/en/changelog

- **Claude Code 2.1.288 (Oct 2)**: Adds `$.ui.selection()` for mods (returns last selected text in fullscreen), built-in `gh api` for cloud sessions whose image lacks the GitHub CLI, `--max-findings <n>|all` for `/code-review`, Ctrl+F to find sessions by name in the agents view, and recovery of a Ctrl+C-cleared prompt by pressing Up. Background command time limits now apply only to unattended sessions. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **MCP description limit doubled**: Release 2.1.296 raises the per-tool description and server-instruction character limit from 2,048 to 4,096 for regular MCP connections, and 2.1.295 raises it to 16,384 for descriptions loaded through tool search — a direct quality-of-life improvement for complex MCP server authors. Source: https://code.claude.com/docs/en/changelog

- **Program Status Protocol (OSC 7501)**: The new escape-sequence standard lets terminal emulators and IDE integrations track Claude Code's current state (working, waiting, done) without polling. This enables better visual status indicators in VS Code and other hosts. Source: https://code.claude.com/docs/en/changelog

- **Claude Tag fast mode in Slack**: `!fast` and `!fast off` now toggle fast mode directly inside Claude Tag Slack threads, improving the Slack integration's responsiveness for quick tasks. Source: https://code.claude.com/docs/en/changelog

- **Claude Projects opens to all waitlisted users**: Claude Code Projects, which lets teams share context, memory, and settings across sessions, became available to every Pro and Max user on the waitlist on October 9 — about three weeks after the September 17 beta launch. Source: https://pasqualepillitteri.it/en/news/22116/claude-code-projects-lista-attesa-pro-max-en

## Bug Fixes & Performance

- **Permission-hook bypass fixed (2.1.292/2.1.294)**: A critical bug where `prompt` and `agent` hooks written as instructions could allow tool calls they should have blocked was patched, alongside improved judgment of Stop/SubagentStop hooks to prevent Claude from stopping turns early. Source: https://code.claude.com/docs/en/changelog

- **Cloud session permission-prompt drop fixed (2.1.291)**: A regression from 2.1.290 where cloud sessions could silently drop answers to permission prompts (potentially causing stuck sessions) was resolved the same day. Source: https://code.claude.com/docs/en/changelog

- **Memory leak in HTTP MCP connections (2.1.292)**: A memory leak affecting long-running sessions with HTTP-transport MCP servers was patched. Source: https://code.claude.com/docs/en/changelog

- **Windows PowerShell over 1 KB (2.1.296)**: Commands longer than 1,024 characters in Windows PowerShell no longer always trigger a permission prompt, reducing friction on Windows for complex scripts. Source: https://code.claude.com/docs/en/changelog

- **Sonnet 5.5 cache-read price halved**: Effective with 2.1.296, Sonnet 5.5 cache reads drop from $0.20 to $0.10 per million tokens — a significant cost reduction for projects that cache large system prompts. Source: https://code.claude.com/docs/en/changelog

## Roadmap & Announcements

- **Claude Haiku 5.5 as new default**: With version 2.1.293, Haiku 5.5 replaces the previous Haiku model as the default small model across the Anthropic API — bringing a 1 M context window and dramatically lower pricing ($0.10/$0.50 per M tokens) to all Claude Code users who rely on the Haiku tier for fast, cheap sub-tasks. Source: https://simonwillison.net/2026/Oct/7/claude-haiku-5-5/

- **Mods system matures**: The Mods feature (TypeScript functions that customise Claude Code's UI, prompts, and built-in tools), introduced October 1, gained prompt caching, an autocomplete event, and a deferred-tool register option this week — signalling Anthropic is actively building out the extensibility layer. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
The most impactful development this week is workflow-level model pinning (`CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL`) combined with the Agent tool `effort` parameter — together they give teams precise, cost-aware control over every sub-agent in a multi-step pipeline, which was a long-standing gap for production Claude Code deployments.

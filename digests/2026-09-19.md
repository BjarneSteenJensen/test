# Claude Code News Digest — 2026-09-19

## Overview
The most significant Claude Code development today is the rollout of AGENTS.md support (v2.1.277), which allows projects to use an `AGENTS.md` file as the configuration entrypoint when no `CLAUDE.md` exists — broadening how teams define agent context. This lands alongside continued server-side auto mode classifier expansion (v2.1.278), now defaulting across Claude API, Enterprise, Bedrock, Vertex, Foundry, and gateway configurations.

## New Features & Releases

- **AGENTS.md Support (v2.1.277, Sept 18)**: Claude Code now reads `AGENTS.md` as the project context file when no `CLAUDE.md` is present, enabling teams to use a filename more naturally aligned with multi-agent workflows. The release also adds optional `headers:` map support on Claude apps gateway upstreams. Source: https://code.claude.com/docs/en/changelog

- **Server-side Auto Mode Classifier Default (v2.1.278, Sept 19)**: Auto mode for Claude API, Enterprise, and third-party provider users (Bedrock, Vertex, Foundry, gateways) now defaults to the server-side classifier. A new `Auto mode server` row has been added to `/status` to show which classifier is running for the current session. Source: https://code.claude.com/docs/en/changelog

- **claude plugin eval (v2.1.269, Sept 11)**: The new `claude plugin eval` command lets developers run a plugin against a test suite, score results, and compare against a no-plugin baseline. `claude plugin eval init` auto-drafts test cases and graders to lower the barrier to plugin quality testing. Source: https://code.claude.com/docs/en/whats-new

- **Fast Mode in Remote Sessions (v2.1.271, Sept 14)**: Fast mode is now available in Claude Code Remote (cloud) sessions, extending the lower-latency execution option to headless and scheduled workflows. Per-command `allowed_domains` for Bash, PowerShell, and Monitor tools in auto mode also landed in this release. Source: https://code.claude.com/docs/en/changelog

- **Claude Fable 5.1 as Default Model (Week 36 / v2.1.257)**: Fable 5.1 is now the default Fable model in Claude Code, carrying a 1M-token context window and a 75% reduction in cache read costs (to $0.25/M tokens), cutting typical workload costs by ~25% and agentic task costs by up to 45%. Source: https://code.claude.com/docs/en/whats-new

## Integrations & Extensions

- **Skills/Plugins Sync from Claude.ai to Terminal (v2.1.275, Sept 17)**: Skills and plugins enabled on a user's claude.ai account now sync automatically to terminal sessions, eliminating the need to reinstall or re-enable them manually in CLI environments. The release also adds `/plugin install <plugin> --marketplace <source>` for specifying plugin source. Source: https://code.claude.com/docs/en/changelog

- **Unity MCP Official Plugin**: Unity has shipped an official, first-party Claude Code plugin distributed through Claude's plugin directory, bundling 29 native Unity skills behind a single, no-configuration install command. This is one of the first major game-engine integrations to reach the official plugin marketplace. Source: https://www.explainx.ai/blog/claude-code-unity-mcp-guide-2026

- **VS Code Extension Improvements (v2.1.277)**: The Sept 18 release includes multiple VS Code extension fixes, including a new `claudeCode.lockEditorGroups` setting to prevent Claude from locking editor groups it opens. Agent map and hooks dialog improvements also landed in earlier September versions. Source: https://code.claude.com/docs/en/changelog

- **Claude Tag (Slack) Enhancements**: Several Claude Tag fixes and improvements shipped across September builds (v2.1.277, v2.1.275, v2.1.273), improving reliability of Claude's Slack integration for teams using it as a collaborative coding assistant. Source: https://code.claude.com/docs/en/changelog

## Bug Fixes & Performance

- **Git Permission Regression Fixed (v2.1.270, Sept 12)**: A regression introduced in v2.1.269 caused read-only git commands to unexpectedly prompt for permission mid-session. v2.1.270 restores the expected behavior. Source: https://code.claude.com/docs/en/changelog

- **Proxy/Gateway 400 Error Fixed (v2.1.276, Sept 18)**: Every request failed with `400 … Input tag 'advisor_20260301'` when `ANTHROPIC_BASE_URL` pointed at a proxy or gateway (regression in v2.1.275). v2.1.276 patches this immediately. Source: https://code.claude.com/docs/en/changelog

- **MCP Server Timeout Control (v2.1.274, Sept 17)**: New `CLAUDE_CODE_MCP_STARTUP_WAIT_MS` environment variable lets operators bound how long the first non-interactive turn waits for MCP servers to connect (0 = don't wait). MCP disconnection notifications and auto-reconnect failure alerts also added. Source: https://code.claude.com/docs/en/changelog

- **WebFetch Hang Fixed (v2.1.268, Sept 10)**: WebFetch previously could hang indefinitely on slow or stalled downloads. A 300-second (5-minute) timeout is now enforced, after which the fetch fails with an error rather than blocking the session. Source: https://code.claude.com/docs/en/changelog

- **Bash Permission Checking Fixes**: Multiple releases across September (v2.1.273, v2.1.271) addressed Bash permission checking issues affecting auto mode, including fixes for per-command domain restrictions and organization policy caching. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Claude Mods Launch (Sept 14)**: Boris Cherny of Anthropic's Claude Code team announced the launch of Claude Mods, a community-extensible UI layer for Claude Code. First community-built mods include a playable Tetris game, a breathing-exercise focus tool, and a CI status panel — illustrating the range of creative extensions the platform enables. Source: https://releasebot.io/updates/anthropic/claude-code

- **Smart Reports Beta for Enterprise**: Anthropic launched Smart Reports in beta for Enterprise plans, providing analytics on team usage, costs, friction points, and reusable shared skills — aimed at helping engineering managers understand and optimize Claude Code adoption across their organization. Source: https://releasebot.io/updates/anthropic/claude

- **Weekly Limits Raised 25%**: On September 14, Anthropic permanently raised Claude Code's standard weekly usage limits by 25% above the pre-promotion baseline, following an earlier temporary increase. This affects Pro and standard plan users. Source: https://www.digitalapplied.com/blog/claude-code-weekly-limit-reduction-september-14

- **Compliance API Session Endpoints Out of Beta**: The Claude Developer Platform released Compliance API session endpoints for Cowork and Claude Code sessions into general availability this month, enabling enterprise teams to audit and log session activity more reliably. Source: https://releasebot.io/updates/anthropic/claude-developer-platform

## Roadmap & Announcements

- **Claude Code Projects Beta**: Anthropic launched a beta for Claude Code Projects, enabling one project to coordinate parallel threads with shared memory and a project library. This addresses long-running, multi-repo work where handoff between sessions has been a friction point — Claude can now manage progress across tasks with persistent context. Source: https://code.claude.com/docs/en/whats-new

- **Claude Fable 5.1 / Claude Mythos 5.1 (Sept 1)**: Two new models released — Fable 5.1 and Mythos 5.1 — described as identical in capability but with different safeguard levels, targeting coding, knowledge work, and scientific research use cases. Fable 5.1 is the new default in Claude Code; Mythos 5.1 targets higher-trust deployments. Source: https://releasebot.io/updates/anthropic/claude

## Key Takeaway
The single most impactful development this week is the combination of **AGENTS.md support** and the **Claude Code Projects beta** — together these signal Anthropic's focus on making Claude Code a first-class multi-agent orchestration platform, where teams can manage persistent, parallel, cross-repo work natively rather than stitching together workarounds.

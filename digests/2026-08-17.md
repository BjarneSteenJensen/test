# Claude Code News Digest — 2026-08-17

## Overview
August 17 marks the official sunset of Anthropic's legacy Console Workbench, closing a chapter as Claude Code continues its rapid expansion into team infrastructure. The past two weeks have delivered significant hardening releases (v2.1.231–v2.1.233), cross-session messaging, self-hosted cloud environments in public beta, and a shift to auto mode as the platform default for Pro, Max, and Team plan users.

## New Features & Releases

- **Auto Mode Now Default for Pro, Max & Team (v2.1.233 / August 14)**: Starting August 14, auto mode is the default permission mode for new sessions on Pro, Max, and Team plans. The classifier that powers auto mode no longer counts toward usage limits on those plans. Users who had previously set a default mode retain their preference unless they accept the one-time switch prompt. Source: https://code.claude.com/docs/en/whats-new/2026-w32

- **Subagent Forking On by Default (v2.1.232 / August 13)**: `subagent_type: "fork"` now inherits the full conversation and prompt cache by default, and non-teammate agent spawns in interactive sessions now run in the background automatically. The 200-subagent-per-session cap introduced earlier has also been removed, allowing long-running sessions to keep spawning subagents indefinitely (concurrency and depth limits still apply). Source: https://code.claude.com/docs/en/changelog

- **Cross-Session Messaging (v2.1.224 / August 3–7)**: Claude Code sessions on the same macOS or Linux machine can now message each other. Claude discovers other sessions via `ListAgents` and sends via `SendMessage`; users can also type `@` in the prompt to address a session by name. Messages are plain text — not conversation history or files. Source: https://code.claude.com/docs/en/whats-new/2026-w32

- **GitLab Merge Request Support (v2.1.233)**: The `--worktree` flag and `claude agents` view now support GitLab merge request URLs, displayed as `!N`. GitLab support also extends to plugin marketplaces, allowing bare `gitlab.com` repo URLs to be cloned. Source: https://code.claude.com/docs/en/changelog

- **Memory cgroup Support for Bash Tool (v2.1.233)**: Linux users can now set `CLAUDE_CODE_TOOL_MEMORY_LIMIT` to apply memory cgroup limits to Bash tool commands, improving resource isolation for multi-agent workloads. Source: https://code.claude.com/docs/en/changelog

- **Todo Tools Deprecated on Newer Models (v2.1.233)**: `TaskCreate`, `TaskGet`, `TaskUpdate`, `TaskList`, and `TodoWrite` are no longer available by default on Opus 4.8, Sonnet 5, Fable 5, and Mythos 5+ models. Set `CLAUDE_CODE_ENABLE_TODO_TOOLS=1` to restore them. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **Self-Hosted Environments — Public Beta (v2.1.224 / August 3–7)**: Team and Enterprise plans can now run Claude Code cloud sessions on their own infrastructure. Run `claude self-hosted-runner setup` to register machines as runners; sessions started from claude.ai, mobile, desktop, or `claude --cloud` are then routed inside the organization's network with access to internal services. Source: https://code.claude.com/docs/en/whats-new/2026-w32

- **VS Code Focus View (Week 32)**: The Claude Code VS Code extension now includes a Focus view that collapses all tool activity into a single expandable row per turn, reducing visual clutter. Toggle it from the command menu or with `Ctrl+Alt+F` (`Ctrl+Option+F` on Mac). Source: https://code.claude.com/docs/en/whats-new/2026-w32

- **Enhanced Sandbox Credential Masking (Week 32)**: Sandbox credential files on Linux and WSL2 now support `mode: "mask"`, so sandboxed commands read a sentinel placeholder while the sandbox proxy substitutes the real credential on egress. New options include `extract`, JWT-aware `decode`, and AWS SigV4 re-signing. Source: https://code.claude.com/docs/en/whats-new/2026-w32

- **Compliance API for Local Sessions (August 11)**: Enterprise organizations can now retrieve transcripts of Claude Code and Cowork sessions running on users' machines via the Compliance API. New endpoints: `GET /v1/compliance/apps/sessions/local` (list), `GET /v1/compliance/apps/sessions/local/{session_id}` (metadata), and `GET /v1/compliance/apps/sessions/local/{session_id}/messages` (transcript). Source: https://platform.claude.com/docs/en/release-notes/overview

- **`anthropic-workspace-id` Response Header (August 11)**: The Claude API now returns an `anthropic-workspace-id` header on every response carrying the `wrkspc_`-prefixed workspace ID, making it easier to attribute usage across multiple API keys. Source: https://platform.claude.com/docs/en/release-notes/overview

## Bug Fixes & Performance

- **MCP OAuth Sign-In Fix for Pre-Registered Clients (v2.1.231 / August 13)**: Fixed MCP OAuth sign-in failing with a redirect URI mismatch for servers using pre-registered OAuth clients, a regression that broke connections to services like Slack. Source: https://code.claude.com/docs/en/changelog

- **Windows NTLM Credential-Leak Patch (v2.1.233)**: Fixed a security issue where Windows paths with NT `\?\?\` device prefixes bypassed UNC path validation, creating a potential NTLM credential-leak vector. Source: https://code.claude.com/docs/en/changelog

- **PowerShell and Windows Git Bash Bypass Fixes (v2.1.232)**: Fixed a PowerShell permission bypass where variable-writing parameters could overwrite `$PSDefaultParameterValues`, and a separate bypass using Cygwin-style symlinks in Windows Git Bash. Source: https://code.claude.com/docs/en/changelog

- **Nested Git Repo Trust Fix (v2.1.232)**: Fixed nested git repositories incorrectly inheriting trust from their parent directory, which could have allowed unintended code execution in untrusted subdirectories. Source: https://code.claude.com/docs/en/changelog

- **Improved Self-Hosted Runner Start Time (v2.1.233)**: Session start time for `claude self-hosted-runner` is now faster, eliminating working-tree rewriting and reducing server round trips on launch. Source: https://code.claude.com/docs/en/changelog

- **Screen Reader Mode Improvements (v2.1.233)**: `/effort` selector now renders as a numbered list in screen reader mode, and hint/dialog text is no longer clipped, improving accessibility for VoiceOver and NVDA users. Source: https://code.claude.com/docs/en/changelog

- **Worktree Isolation Extended (Week 32)**: Worktree isolation now blocks not only file edits but also Bash commands and git redirects that reach the main checkout, in all session types including subagents. Source: https://code.claude.com/docs/en/whats-new/2026-w32

## Community & Ecosystem

- **Claude Sonnet 5 Pricing Permanently Locked (August 10)**: The introductory price for Claude Sonnet 5 ($2 input / $10 output per MTok) is now the permanent standard price — the previously scheduled increase to $3/$15 on September 1, 2026 will not occur. Source: https://platform.claude.com/docs/en/release-notes/overview

- **Claude Agent SDK — Renamed and Expanded**: The Claude Code SDK was officially renamed the Claude Agent SDK in March 2026 and continues to gain adoption. As of August 2026, the SDK supports dreaming, outcomes, multi-agent orchestration, Claude Finance with ten pre-built agents, add-ins, and a new MCP specification. Non-interactive use (GitHub Actions, headless `claude -p`, third-party agents) now draws from a dedicated monthly credit pool as of June 15. Source: https://www.augmentcode.com/tools/claude-code-vs-claude-agent-sdk

- **Plugin Zip Archive Distribution (Week 32)**: Plugin marketplaces can now distribute plugins as zip archives via the new `archive` source type, downloaded over HTTPS with an optional SHA-256 integrity pin. This enables plugin installs in air-gapped or restricted environments without requiring `git` or `npm`. Source: https://code.claude.com/docs/en/whats-new/2026-w32

## Roadmap & Announcements

- **Legacy Console Workbench Sunset — Today (August 17)**: The legacy Workbench at `platform.claude.com/workbench` and the experimental prompt tools APIs (generate, improve, templatize) are being retired today, August 17, 2026. Teams relying on these tools should migrate to the current Prompt Console workflows. Source: https://platform.claude.com/docs/en/release-notes/overview

- **Ultraplan Research Preview Removed (Week 32)**: The `/ultraplan` command and `ultraplan` keyword are removed as of v2.1.220+. Anthropic directs users to plan mode or Claude Code on the web as the replacements. Source: https://code.claude.com/docs/en/whats-new/2026-w32

- **Remote Control Security Hardening (v2.1.233)**: Repositories can no longer enable Remote Control auto-connect via checked-in settings — `remoteControlAtStartup` must be set in user or managed settings only, preventing supply-chain attacks via malicious CLAUDE.md files. Source: https://code.claude.com/docs/en/changelog

- **`/review` Alias and Effort Memory for Code Review (Week 32)**: `/review` is now an alias for `/code-review`, and invoking `/code-review` without an effort level reuses the level from your last invocation — a quality-of-life improvement for teams running reviews in tight loops. Source: https://code.claude.com/docs/en/whats-new/2026-w32

## Key Takeaway
Auto mode becoming the platform default on August 14 — combined with cross-session messaging, self-hosted environments, and a wave of security hardening — signals that Anthropic is firmly positioning Claude Code as always-on team infrastructure rather than a developer productivity tool used occasionally.

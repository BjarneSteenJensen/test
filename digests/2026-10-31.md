# Claude Code News Digest — 2026-10-31

## Overview
The biggest story today is a confirmed supply-chain security incident: a trojanized build of the Claude Code VS Code extension with an SSH backdoor was distributed through Cursor's marketplace, affecting up to 5,000 users before being pulled. Separately, Anthropic shipped two new Claude Code versions (v2.1.314 and v2.1.316) on October 30–31, adding write-path restrictions, gateway policy controls, and a new VS Code cloud session form-card feature.

## New Features & Releases

- **v2.1.316 (October 31, 2026) — `CLAUDE_CODE_SUBAGENT_EFFORT` and pooled budgets**: Today's release adds `CLAUDE_CODE_SUBAGENT_EFFORT` to globally set the effort level subagents run at, pooled group budgets for the Claude apps gateway (`pooled_budget` on the spend-limits admin API), and `managed.policy_mode: layered` so every matching gateway policy applies in order rather than first-match. Also adds `CLAUDE_CODE_DISABLE_ULTRATHINK` to disable the `ultrathink` keyword. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.314 (October 30, 2026) — Write-path restrictions and idle compaction in VS Code**: Adds `permissions.blockWritesOutsideWorkingDirectories`, which makes Write, Edit, and NotebookEdit refuse paths outside the configured working directories — a significant sandbox hardening option. Idle compaction is now available in VS Code and the Desktop Code tab. The Claude apps gateway also gains an `oidc.groups` filter for upstream access control. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.312 (October 27) — OIDC user identification and cloud routine effort**: Adds `oidc.user_id_claim` to identify gateway users by a custom id_token claim, an effort-level picker for cloud routines in the model picker, and a Bash editor with line numbers for setup scripts. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.301 (October 15) — LaTeX rendering and vim improvements**: VS Code gains LaTeX math rendering in responses and a "Get more usage" link in the usage-limit banner. Vim mode gains the `%` motion. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Integrations & Extensions

- **Cursor Marketplace Extension Backdoor — Security Incident**: A tampered build of the Claude Code VS Code extension was distributed through Cursor's marketplace on approximately October 29, 2026. The malicious build planted a persistent SSH backdoor on affected machines. Cursor reports up to 5,000 users may have installed it. The malicious version has been removed; users who installed Claude Code through the official VS Code Marketplace or Open VSX were not affected by this incident. Anthropic released v2.1.314 as the clean build shortly after. Source: [Help Net Security](https://www.helpnetsecurity.com/2026/10/30/claude-code-extension-ssh-backdoor/) · [The Hacker News](https://thehackernews.com/2026/10/official-claude-code-vs-code-extension.html) *(Note: these sites are outside this session's network policy and could not be directly fetched; summaries are from web search results.)*

- **VS Code: New cloud session form-card and sign-in flow (v2.1.316)**: Cloud sessions now show a form card for MCP server form requests, letting users fill in or decline structured input from MCP servers directly in the VS Code panel. VS Code also gains a sign-in flow for Claude apps gateway authentication from the chat panel. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **VS Code: Syntax highlighting and hook spinners (v2.1.311)**: Code blocks in VS Code replies now have syntax coloring, and a spinner shows "Running UserPromptSubmit hooks" during hook execution. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Monitor tool on Bedrock, Vertex, and Foundry (v2.1.310)**: The Monitor tool and plugin monitors are now available when running Claude Code on Bedrock, Vertex, and Foundry upstreams, and also when telemetry or nonessential traffic is disabled. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Claude Tag: Slack channel expansion and skills analytics (v2.1.311)**: Claude Tag (Claude in Slack) adds public Slack channels to the admin "Add place" search. A new Skills view in analytics shows how often each skill runs in Slack. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Bug Fixes & Performance

- **v2.1.308 and v2.1.306 (October 22–21)**: Both releases contained only bug fixes and reliability improvements. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.309 — VS Code certificate warning (October 22)**: A log warning was added to explain certificate verification failures for dictation and extension requests, making TLS configuration errors easier to diagnose. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

Also added: `/claude-api managed-agents-secure`, which audits a Managed Agents configuration against Anthropic's security guide. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Code Review GA with org-wide coverage (v2.1.304)**: Code Review reached general availability in mid-October with Quick, Standard, and Deep review levels, and admins can now apply it to every repository in a GitHub organization in one setting. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **New API version `2026-10-21` (v2.1.307)**: A new Claude API version was released, with a skill command (`/claude-api api-version`) to help migrate code to the new version. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Key Takeaway
The most urgent development today is the supply-chain attack on the Claude Code Cursor marketplace extension: anyone who installed Claude Code through Cursor's marketplace around October 29–30 should treat their machine as compromised, rotate SSH keys, and reinstall from the official VS Code Marketplace or Open VSX. On the feature side, v2.1.316's new `CLAUDE_CODE_SUBAGENT_EFFORT` control and the `permissions.blockWritesOutsideWorkingDirectories` sandbox hardening from v2.1.314 are the two most significant additions for power users and enterprise deployments this week.

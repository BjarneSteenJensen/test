# Claude Code News Digest — 2026-10-19

## Overview
The past week has been exceptionally busy for Claude Code: v2.1.302 made fork subagents the default across all surfaces, Code Review graduated to general availability for Team and Enterprise organizations with ~3× speed gains, and gzip compression on API requests cut first-token latency from 4.07 s to 1.33 s. Claude Mods — small TypeScript extensions that customize Claude Code behavior — also went live on October 1, maturing the plugin ecosystem significantly.

---

## New Features & Releases

- **v2.1.302 — Fork subagents on by default (Oct 16)**: Fork subagents (`subagent_type: "fork"`) are now the default in `claude -p`, the Agent SDK, the Desktop app, and VS Code, meaning subagents inherit the full conversation context without extra setup. A new `CLAUDE_CODE_AUTO_MODE_MODEL` variable lets users select the model driving the client-side auto mode classifier. Source: https://code.claude.com/docs/en/changelog

- **v2.1.300 — gzip compression + `/advisor` on AWS (Oct 14)**: Large requests to `api.anthropic.com` now use gzip by default, cutting first-token p90 latency from 4.07 s to 1.33 s according to Anthropic's ClaudeDevs account. The `/advisor` command is also now available on Claude Platform on AWS. Source: https://code.claude.com/docs/en/changelog

- **v2.1.299 — Idle compaction + MCP security hardening (Oct 14)**: Conversations over 200 K tokens that sit idle for ~54 minutes are now automatically compacted before their prompt cache expires, reducing cold-start costs. MCP allow rules were tightened — `mcp__a` no longer grants access to a server named `a__b`; use `mcp__<server>__*` instead (breaking change). `CLAUDE_CODE_DISABLE_FILE_MENTIONS` lets users pass only paths for `@` mentions instead of full file contents. Source: https://code.claude.com/docs/en/changelog

- **v2.1.293 — Claude Haiku 5.5 as default Haiku model (Oct 7)**: `claude-haiku-5-5` is now the default Haiku on the Anthropic API, with a 1 M-token context window and pricing at $0.10/$0.50 per million tokens ($0.50/$2.50 for prompts over 100 K). Source: https://code.claude.com/docs/en/changelog

- **Claude Mods launch (Oct 1, v2.1.287)**: Anthropic introduced Mods — small TypeScript functions that rewrite prompts, add UI, or replace built-in features. They ship inside plugins and are available in the CLI and Desktop app. Some built-in features (e.g., `/diff`) now ship as mods. Source: https://tech-insider.org/claude-code-plugins-official-mods-cloud-sessions-2026/

## Integrations & Extensions

- **VS Code renders LaTeX math (v2.1.301, Oct 15)**: The VS Code extension now renders LaTeX math in Claude responses inline. The same release also fixed binary files (`.xlsm`, `.heic`, etc.) being incorrectly read as text. Source: https://code.claude.com/docs/en/changelog

- **Program Status Protocol / OSC 7501 (v2.1.295, Oct 8)**: Terminals that support OSC 7501 can now surface whether Claude is working, waiting, or done directly in their status bars. Source: https://code.claude.com/docs/en/changelog

- **MCP tool description limit raised to 4 096 chars (v2.1.296, Oct 9)**: The default cap on MCP tool descriptions doubled from 2 048 to 4 096 characters, and tool descriptions loaded via tool search can now be up to 16 384 characters. Source: https://code.claude.com/docs/en/changelog

- **`/advisor` on Claude Platform on AWS (v2.1.300)**: The `/advisor` command — which gives contextual guidance on Claude Code settings and usage — is now available when running on AWS via Claude Platform. Source: https://dev.classmethod.jp/en/articles/20261015-cc-updates-v2-1-300/

## Bug Fixes & Performance

- **v2.1.303 — Reliability improvements (Oct 18)**: The latest release focuses entirely on bug fixes and reliability improvements, the day before this digest. Source: https://code.claude.com/docs/en/changelog

- **v2.1.301 — 37 bug fixes (Oct 15)**: A large patch release fixed binary file handling (`.xlsm`, `.heic` read as text), improved OpenTelemetry `tool_decision` events with `classifier_verdict` and `classifier_category`, and added the `%` motion in vim mode. Source: https://code.claude.com/docs/en/changelog

- **v2.1.294 — Hook security fixes (Oct 8)**: Fixed a bug where `prompt` and `agent` hooks written as instructions could allow actions they should block. Improved SubagentStop and Stop hook judging to reduce premature stops. Source: https://code.claude.com/docs/en/changelog

- **Sonnet 5.5 cache-read price cut (v2.1.296, Oct 9)**: The cache-read price for Sonnet 5.5 was reduced from $0.20 to $0.10 per million tokens, reflected in `/cost`, the status line, and SDK cost figures. Source: https://code.claude.com/docs/en/changelog

- **Desktop preview-pane flaw patched**: A flaw in Claude Code Desktop's preview pane that could have leaked developer secrets was disclosed and fixed in Desktop v1.30096.1. Source: https://cybernews.com/security/claude-code-preview-pane-secret-leak-flaw/

## Roadmap & Announcements

- **Code Review now generally available (Oct 15)**: Claude Code Review graduated from research preview to GA for Team and Enterprise organizations. Reviews now finish in 6–10 minutes (down from ~20 during preview, ~3× faster), offer Quick/Standard/Deep per-repository settings, and run automatically on new PRs once an admin enables them. Eligible Enterprise orgs can claim ≥$10,000 in credits by January 15, 2027. Source: https://claude.com/resources/articles/code-review-is-now-generally-available

- **Standalone Claude Design closing December 14, 2026**: As of v2.1.302, Claude Code now shows a notice in `/design-sync` and `/design-login` that `claude.ai/design` will close by December 14, 2026. Teams relying on it should migrate to Claude Code's integrated `/design` workflow. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
Code Review's GA launch — with ~3× speed improvement and Quick/Standard/Deep tuning per repository — is the most impactful Claude Code development this week, giving every Team and Enterprise organization an automated PR review that runs without developer configuration.

# Claude Code News Digest — 2026-10-27

## Overview
October 2026 has been a busy month for Claude Code, with 13 point releases (v2.1.299–v2.1.311) shipping in 13 days. The headline developments are Code Review reaching general availability with three review tiers, MCP Tasks and Elicitations landing in the CLI for durable agentic workflows, and `ultrathink` gaining xhigh-effort support across all current Anthropic models in today's v2.1.311 release.

---

## New Features & Releases

- **v2.1.311 (Oct 26) — `ultrathink` at xhigh effort + self-hosted runner controls**: The newest release adds xhigh-effort `ultrathink` runs on Opus 5.5, Sonnet 5.5, Haiku 5.5, and Fable 5.1 via the Anthropic API. It also adds `--hold-idle-file` and `--max-hold-min` flags to `self-hosted-runner` for idle-session management, and a signed model-catalog file loaded from downloads.claude.ai (disable with `CLAUDE_CODE_MODEL_CATALOG=off`). A longstanding annoyance is fixed: hitting the 1M-context usage-credit limit now triggers auto-compaction and continues rather than stopping. Source: https://code.claude.com/docs/en/changelog

- **v2.1.304 (Oct 19) — `/auto-mode-setup` + Code Review levels**: A new `/auto-mode-setup` command reads your project and recent sessions to configure auto mode automatically. Code Review adds three selectable review tiers per repository: Quick, Standard (default), and Deep — letting teams tune thoroughness to the criticality of each codebase. Source: https://code.claude.com/docs/en/changelog

- **v2.1.302 (Oct 16) — Fork subagents on by default**: Fork subagents are now enabled by default in `claude -p`, the Agent SDK, the desktop app, and VS Code. Set `CLAUDE_CODE_FORK_SUBAGENT=0` to opt out. The `CLAUDE_CODE_AUTO_MODE_MODEL` environment variable lets you override the auto mode classifier's model. Source: https://code.claude.com/docs/en/changelog

- **v2.1.299 (Oct 14) — Idle compaction**: Conversations of 200K+ tokens idle for ~54 minutes are now auto-compacted before the one-hour prompt cache expires, avoiding cache-miss costs in unattended sessions. `CLAUDE_CODE_DISABLE_FILE_MENTIONS` tells Claude to receive `@` file paths rather than file contents inline. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **Monitor tool now on Bedrock, Vertex, and Foundry (v2.1.310, Oct 23)**: The Monitor tool and plugin monitors — previously only available on Anthropic's own API — are now available on Amazon Bedrock, Google Vertex AI, and Azure Foundry. Enterprise customers on cloud providers can now use live-monitoring workflows without switching providers. Source: https://code.claude.com/docs/en/changelog

- **MCP Tasks and Elicitations ship in Claude Code CLI (Oct 23)**: Anthropic shipped MCP Tasks (long-running tools that can pause and resume) and Elicitations (structured mid-run prompts back to the user) in the CLI. This enables durable agentic workflows where tools can ask questions or await external state changes without blocking the process. VS Code, desktop app, and Bedrock support are on the roadmap. The Agent SDK also supports these features. Source: https://releasebot.io/updates/anthropic/claude-code

- **VS Code extension updates (Oct 15–22)**: The VS Code extension gained LaTeX rendering, syntax-colored code blocks, and a new `claudeCode.attachSelection` setting. A TLS proxy certificate log warning was added to help users behind TLS-inspecting proxies debug extension failures (Oct 22). Community contribution: an unofficial extension for Visual Studio 2026 adds native diff accept/reject, autonomous debugger control, and Test Explorer integration. Source: https://code.claude.com/docs/en/changelog / https://github.com/firish/claude_code_vs

- **Slack Connect support in Claude Tag (v2.1.300, Oct 14)**: Claude Tag now supports Slack Connect channels (off by default). The same release added `/advisor` on Claude Platform on AWS and gzip compression for large requests to the Anthropic API. Source: https://code.claude.com/docs/en/changelog

- **Agent SDK latest: TypeScript 0.3.302, Python 0.2.168 (mid-October)**: The Claude Agent SDK (formerly Claude Code SDK) shipped several mid-October releases. `autoCompactWindow` was added to `AgentDefinition` so subagents can compact earlier than the parent conversation. Claude Max and Team plans now include monthly API credits covering the Agent SDK. Source: https://www.morphllm.com/claude-agent-sdk

## Bug Fixes & Performance

- **v2.1.309 (Oct 22) — 62 fixes, `ultrareview` trust gating**: `claude ultrareview` now requires workspace trust (pass `--trust-workspace` or set `CLAUDE_CODE_DISABLE_ULTRAREVIEW_TRUST_CHECK=1` in scripts). `sed -i` is now treated as a standard Bash command and is no longer restored by `/rewind`. Sandboxed commands no longer load the shell's startup files outside the sandbox. Source: https://code.claude.com/docs/en/changelog

- **v2.1.307 (Oct 21) — Safety telemetry + MCP fix**: Added the `claude_code.safety_event` OpenTelemetry event, fired when a rule, auto mode, hook, or sandbox stops or prompts on a tool call. Fixed a bug where disabling an MCP server still reconnected it on a later permission prompt in `claude -p` and SDK sessions. Source: https://code.claude.com/docs/en/changelog

- **v2.1.306 (Oct 21) — Cloud session login fix**: Fixed `claude -p` login failures in cloud sessions, and a spurious "prompt is too long" error that some gateway configurations were triggering. Source: https://code.claude.com/docs/en/changelog

- **API request gzip (v2.1.300, Oct 14)**: Large requests to api.anthropic.com are now gzip-compressed by default, reducing bandwidth for long context windows. Disable with `CLAUDE_CODE_GZIP_REQUEST_BODIES=0`. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Code Review reaches GA with $10K Enterprise credits**: Anthropic moved Code Review out of research preview on October 15 for Claude Team and Enterprise organizations. Reviews now run ~3× faster (6–10 minutes vs. ~20 minutes) and produce shorter, more actionable findings. Eligible Enterprise organizations can claim at least $10,000 in Code Review credits by January 15, 2027 (credits expire 30 days after claiming). Source: https://claude.com/resources/articles/code-review-is-now-generally-available

- **Anthropic donates Agent Skills standard to Agentic AI Foundation (Oct 22)**: The Agent Skills standard — which originated in Claude Code — was donated to the Agentic AI Foundation for community stewardship, signaling Anthropic's push for cross-platform agent interoperability. Source: https://releasebot.io/updates/anthropic

- **Claude Design sunset announced**: Standalone Claude Design (claude.ai/design) will close by December 14, 2026. The v2.1.302 changelog entry includes the sunset notice; users should migrate workflows before that date. Source: https://code.claude.com/docs/en/changelog

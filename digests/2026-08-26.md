# Claude Code News Digest — 2026-08-26

## Overview
August 26, 2026 marks the tail end of one of the busiest release months in Claude Code history. Weeks 32–34 delivered three major headliners — the `/design` skill bringing UI artboard creation into the CLI, auto mode promoted to the default permission mode for all Pro/Max/Team plans, and cross-session messaging letting Claude instances coordinate with each other. A massive v2.1.246 patch (Aug 25) wrapped up the week with dozens of bug fixes, including a critical Linux startup crash fix shipped the day prior as v2.1.245.

---

## New Features & Releases

- **`/design` Skill (Research Preview, v2.1.234+)**: The new `/design` skill brings Claude Design's artboard workflow into the CLI and Claude Code Desktop. Run `/design <brief>` and Claude publishes a canvas of editable UI artboards; pick an artboard and ask Claude to implement it. Requires v2.1.233+ and is available on Pro, Max, Team, and Enterprise plans. Source: [code.claude.com/docs/en/whats-new/2026-w34](https://code.claude.com/docs/en/whats-new/2026-w34)

- **Concise Output Style (v2.1.237)**: A new built-in output style called "Concise" makes Claude lead with the result and skip preamble and narration, while preserving full detail for error reports, security warnings, and destructive-action confirmations. Set it via `/config` or `"outputStyle": "Concise"` in `~/.claude/settings.json`. Source: [code.claude.com/docs/en/whats-new/2026-w34](https://code.claude.com/docs/en/whats-new/2026-w34)

- **Auto Mode Now the Default (Aug 14)**: Starting August 14, auto mode became the default permission mode for new sessions on Pro, Max, and Team plans. In auto mode, a classifier handles permission prompts — safe actions proceed automatically and risky ones are blocked. Classifier calls no longer count toward usage limits. Source: [code.claude.com/docs/en/whats-new/2026-w32](https://code.claude.com/docs/en/whats-new/2026-w32)

- **Fork Mode On by Default (v2.1.232)**: Subagent fork mode is now on by default in interactive sessions. Claude can spawn a subagent that inherits the full conversation and prompt cache rather than starting fresh, avoiding the need to re-explain context for side tasks. Disable with `CLAUDE_CODE_FORK_SUBAGENT=0`. Source: [code.claude.com/docs/en/whats-new/2026-w33](https://code.claude.com/docs/en/whats-new/2026-w33)

- **Auto-Continue After Usage Limit**: Both Claude Code Desktop (Week 33) and the CLI (Week 34) gained auto-continue support. When a session limit resets, Claude retries the interrupted turn automatically. Disable from the `Continue automatically at usage limit` row in `/config`. Source: [code.claude.com/docs/en/whats-new/2026-w33](https://code.claude.com/docs/en/whats-new/2026-w33)

- **Cross-Session Messaging (v2.1.224)**: Claude Code sessions on the same machine (macOS/Linux, and now Windows as of v2.1.234) can discover each other with `ListAgents` and communicate via `SendMessage`. Type `@` in the prompt to mention another session by name. Source: [code.claude.com/docs/en/whats-new/2026-w32](https://code.claude.com/docs/en/whats-new/2026-w32)

- **Remote Control Device Cards on Mobile**: Any machine running `claude remote-control` now appears as a device card at the top of the Code tab in the Claude mobile app. Remote Control has also graduated from research preview. Source: [code.claude.com/docs/en/whats-new/2026-w34](https://code.claude.com/docs/en/whats-new/2026-w34)

- **`ANTHROPIC_DEFAULT_MODEL` Env Var (v2.1.236)**: A new environment variable sets the model new sessions start on; a `/model` pick still overrides it and persists across restarts. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **`/claude-api upgrade` Helper (v2.1.239)**: A new subcommand guides Python projects through migrating from `anthropic` 0.x to 1.x automatically. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

## Integrations & Extensions

- **GitLab Merge Request & Marketplace Support (v2.1.232–2.1.233)**: Plugin marketplaces now clone bare `gitlab.com` URLs including nested subgroups. Pass a GitLab MR URL to `--worktree` to branch from it, and the agents view labels MR-linked sessions as `!N`. Claude Code also redacts GitLab token families (`glpat-`, `glrt-`) and protects the `glab` CLI config store. Source: [code.claude.com/docs/en/whats-new/2026-w33](https://code.claude.com/docs/en/whats-new/2026-w33)

- **VS Code Focus View (v2.1.221) + Session Groups (v2.1.229)**: The VS Code extension gained a Focus view that collapses tool activity into one expandable row per turn (toggle: `Ctrl+Alt+F`). Session groups allow organizing the sidebar by right-clicking to create, rename, or delete groups. Source: [code.claude.com/docs/en/whats-new/2026-w32](https://code.claude.com/docs/en/whats-new/2026-w32)

- **JetBrains 5-Second Pause Fixed (v2.1.239)**: A long-standing bug causing Edit and Write calls to pause for ~5 seconds in JetBrains IDE terminals when the Claude Code plugin was connected has been resolved. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Self-Hosted Environments Public Beta (v2.1.224)**: Organizations on Team and Enterprise plans can now run Claude Code cloud sessions on their own infrastructure using `claude self-hosted-runner`. Sessions launched from claude.ai or mobile/desktop apps run inside your network with access to internal services. Source: [code.claude.com/docs/en/whats-new/2026-w32](https://code.claude.com/docs/en/whats-new/2026-w32)

- **Alpine/musl Support (v2.1.239)**: Native image paste, clipboard, and audio capture now load on Alpine Linux and musl-based builds. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **MCP OAuth Fix (v2.1.231)**: MCP OAuth sign-in for servers using pre-registered OAuth clients (e.g., Slack) stopped failing with redirect URI mismatches. Remote MCP servers also now reconnect automatically after dropped connections. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

## Bug Fixes & Performance

- **Linux glibc 2.44 Startup Crash Fixed (v2.1.245, Aug 25)**: A critical crash on startup affecting Linux users on glibc 2.44+ (Arch, CachyOS, Fedora Rawhide) was fixed in an emergency release. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.246 Mega-Patch (Aug 25)**: The largest single-version fix list of the month addressed: severe transcript slowdown with very long single lines (e.g., base64 strings), erratic fullscreen scrolling, background sessions failing after 45 seconds, MCP tool arguments sent as JSON strings instead of native types, auto mode tool calls denied on large sessions, plugin cache creating duplicate directories, custom theme colors being ignored, and dozens more. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Unbounded Memory Growth Fixed (v2.1.238)**: A memory leak in long sessions caused by subagent results not being released has been resolved. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **IDE Diagnostic Stalls Fixed (v2.1.229)**: Multi-second UI stalls caused by editing a file with thousands of IDE diagnostics while the extension is connected have been eliminated. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Worktree Isolation Hardened (v2.1.224)**: Worktree isolation now blocks not only file edits but also Bash commands and git redirects that reach the main checkout, applying to all session types and their subagents. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Native Install Size Reduced (v2.1.243)**: The native Claude Code install size dropped from 340 MB to 75 MB via zstd compression, and memory usage improved by 40–70 MB through on-demand code loading. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

## Community & Ecosystem

- **Sonnet 5 Pricing Updated (v2.1.243)**: Sonnet 5's standard rate has been updated to $2/$10 per Mtok (input/output). Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Spellcheck in Prompt (v2.1.235)**: An optional `spellcheck` setting underlines misspelled words in the prompt input as you type, using any installed `aspell`, `hunspell`, or `ispell` binary. Source: [code.claude.com/docs/en/whats-new/2026-w34](https://code.claude.com/docs/en/whats-new/2026-w34)

- **Markdown in Your Own Prompts (v2.1.234)**: User prompts now render markdown in the transcript — highlighted code blocks, inline code, and lists — the same way replies do. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Claude Agent SDK Renamed** (context): The Claude Code SDK was officially renamed to the Claude Agent SDK in March 2026. August updates include recovery of remote MCP servers in SDK sessions after dropped connections. Source: [www.augmentcode.com](https://www.augmentcode.com/tools/claude-code-vs-claude-agent-sdk)

- **`/status` GitHub Connection Line (v2.1.243)**: Claude Code on the web (Pro/Max) now shows a `/status` line indicating whether GitHub is connected, making it easier to verify integration. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **50% Usage Limit Extension**: The 50% increase to weekly usage limits for Pro, Max, Team, and seat-based Enterprise plans has been extended through August 31, 2026. Source: [www.gradually.ai/en/changelogs/claude-code/](https://www.gradually.ai/en/changelogs/claude-code/)

## Roadmap & Announcements

- **Auto Mode Maturation**: Auto mode's promotion to default on Aug 14 (for Pro/Max/Team) is the culmination of a months-long rollout that began in research preview in March. The Auto Mode tab in `/permissions` (v2.1.246) for viewing and editing classifier rules signals further investment in making autonomous operation safe and transparent. Source: [code.claude.com/docs/en/whats-new/2026-w32](https://code.claude.com/docs/en/whats-new/2026-w32)

- **Ultraplan Removed (v2.1.224)**: The Ultraplan research preview has been removed, including the `/ultraplan` command and the `ultraplan` keyword. Anthropic recommends plan mode or Claude Code on the web as replacements. Source: [code.claude.com/docs/en/whats-new/2026-w32](https://code.claude.com/docs/en/whats-new/2026-w32)

- **Task Tools Deprecated on Newer Models (v2.1.233)**: The `TaskCreate`, `TaskUpdate`, and `TodoWrite` tools are no longer available on Opus 4.8, Sonnet 5, Fable 5, Mythos 5, and later models in those families. Set `CLAUDE_CODE_ENABLE_TODO_TOOLS=1` to re-enable them. Source: [code.claude.com/docs/en/whats-new/2026-w33](https://code.claude.com/docs/en/whats-new/2026-w33)

---

## Key Takeaway
The single most important development this week — and arguably of August 2026 — is the **`/design` skill landing in research preview** (Aug 17), which transforms Claude Code from a pure coding assistant into a tool that can draft and iterate on visual UI designs directly from the terminal, representing a meaningful expansion of Claude Code's scope beyond code. Paired with auto mode becoming the default, August marks a turning point where Claude Code operates more autonomously and across more creative domains than ever before.

# Claude Code News Digest — 2026-10-12

## Overview
The biggest Claude Code story of the past week is the rapid-fire release cadence: versions 2.1.287 through 2.1.296 shipped between October 1–9, delivering the new Mods system for plugin customisation, a new Agent tool effort parameter, MCP protocol upgrades, Claude Haiku 5.5, and a 50% price cut on Sonnet 5.5 cache reads. No major incidents are open today — the October 7 spend-limit outage was fully resolved.

## New Features & Releases

- **Claude Mods introduced (v2.1.287, Oct 1)**: Plugins can now ship small TypeScript functions that change how Claude Code works — rewriting prompts, adding UI elements, replacing built-in features, and more. A built-in "You Should Know" side agent flags things you or Claude might miss; it requires a first-party session with telemetry enabled. On Team and Enterprise plans, a managed `sec-default` mod loads first. Source: https://code.claude.com/docs/en/changelog

- **Agent tool gains `effort` parameter (v2.1.292, Oct 6)**: The `Agent` tool now accepts an `effort` level so Claude runs sub-agents at a chosen reasoning depth. The same release also adds `prompt.autocomplete` as a new mod event and enables prompt caching inside `$.model.complete` via `cache: true`. Source: https://code.claude.com/docs/en/changelog

- **Claude Haiku 5.5 released as default Haiku (v2.1.293, Oct 7)**: `claude-haiku-5-5` is now the default Haiku model on the Anthropic API, with a 1 M-token context window at $0.10/$0.50 per million input/output tokens. Source: https://code.claude.com/docs/en/changelog

- **Sonnet 5.5 cache-read price halved (v2.1.296, Oct 9)**: Cache reads for Sonnet 5.5 dropped from $0.20 to $0.10 per million tokens. The same release adds `CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL` to pin every workflow agent to one model, an `allow_large` option for the Read tool, and `autoCompactWindow` in subagent frontmatter. Source: https://code.claude.com/docs/en/changelog

- **Hook failure mode `onFailure: "block"` (v2.1.295, Oct 8)**: Command and HTTP hooks can now set `onFailure: "block"` so a hook that fails to start, times out, or crashes blocks the action rather than silently allowing it through. OSC 7501 (Program Status Protocol) support was also added. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **`claude plugin install --marketplace` (v2.1.292, Oct 6)**: The new `--marketplace` flag adds the Claude plugin marketplace if needed and installs the named plugin under the same policy checks as `claude plugin marketplace add`. Source: https://code.claude.com/docs/en/changelog

- **MCP protocol default upgraded to 2026-07-28 (v2.1.292, Oct 6)**: Local stdio MCP servers now negotiate protocol revision `2026-07-28` by default; `MCP_PROTOCOL_NEGOTIATION=legacy` opts out. The MCP tool-description limit was also raised from 2,048 to 4,096 characters. Source: https://code.claude.com/docs/en/changelog

- **Tool-search MCP description limit raised to 16,384 chars (v2.1.295, Oct 8)**: Large MCP server descriptions that were previously truncated at 2,048 characters can now be up to 16,384 characters when used via tool-search. Source: https://code.claude.com/docs/en/changelog

- **IDE extensions**: The official VS Code, JetBrains, and Xcode extensions continue to share the same engine as the CLI, including CLAUDE.md instructions and conversation history. No new extension releases were announced this week. Sources: https://code.claude.com/docs/en/vs-code, https://docs.anthropic.com/en/docs/claude-code/ide-integrations

## Bug Fixes & Performance

- **Critical regression fixes (v2.1.291, Oct 6)**: Two regressions introduced in the same week were patched: cloud sessions could drop answers to permission prompts (introduced in 2.1.290), and the last messages of a session could be lost on quit (introduced in 2.1.288). Source: https://code.claude.com/docs/en/changelog

- **Security: prompt/agent hook bypass fixed (v2.1.294, Oct 8)**: A vulnerability where `prompt` and `agent` hooks written as instructions could allow actions they should block was fixed. Hook judgment on Stop and SubagentStop was also improved to prevent Claude stopping early incorrectly. Source: https://code.claude.com/docs/en/changelog

- **Managed PreToolUse hook bypass fixed (v2.1.296, Oct 9)**: Managed `PreToolUse` hooks with `"continue": false` were not ending the turn as intended; this is now corrected. Bash permission checks were also auto-approving `BASH_ARGV0` usage incorrectly. The release includes 56 additional bug fixes. Source: https://code.claude.com/docs/en/changelog

- **October 7 outage resolved**: A spend-limit bug wrongly paused some organisations, causing refused requests across Claude Code and other Claude products. Anthropic resolved the incident; the status page shows all systems operational today. Source: https://status.claude.com/

## Roadmap & Announcements

- **`CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL` env var (v2.1.296, Oct 9)**: Teams can now pin all workflow agents to a single model (e.g. Haiku 5.5) for cost control while letting other subagents use their own models. This is the clearest signal yet that Anthropic is investing in enterprise-grade workflow cost management. Source: https://code.claude.com/docs/en/changelog

- **Developer portal for plugin submissions**: Anthropic added a developer portal for submitting plugins to the Claude directory, with review tracking, auto-validation, publish controls, and post-launch usage analytics, alongside MCP 2.0 extension support. Source: https://releasebot.io/updates/anthropic/claude

## Key Takeaway
The launch of **Claude Mods** (Oct 1) is the defining development of the past two weeks: it transforms Claude Code plugins from passive tool bundles into first-class behavioural customisation layers, letting teams and developers ship TypeScript functions that reshape how Claude thinks and acts — and it arrives alongside Haiku 5.5, a Sonnet 5.5 price cut, and a security-focused flurry of hook and permission fixes.

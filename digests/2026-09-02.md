# Claude Code News Digest — 2026-09-02

## Overview
Claude Code shipped two releases on September 1, with version 2.1.257 being the most significant: it adds Claude Fable 5.1 as the new default Fable model (1M context window), introduces configurable time-format settings, and tightens auto-mode security with a new Containment Escape rule. Alongside these releases, Anthropic announced a permanent 25% baseline usage-limit increase effective September 14 — though this replaces a temporary 50% promotional boost, leaving users with roughly 17% less capacity than they currently enjoy.

## New Features & Releases

- **Claude Code v2.1.257 — Fable 5.1 & time-format settings (September 1)**: Adds `claude-fable-5-1` as the new default Fable model with a 1M-context window ($10/$50 per Mtok, $0.25/Mtok cache reads). Also adds `timeFormat` and `timeZone` settings supporting 12-hour, 24-hour, UTC, and custom strftime patterns for turn-end clocks and transcript timestamps. Source: https://code.claude.com/docs/en/changelog

- **Claude Code v2.1.258 — Bug fixes (September 1)**: Fixes a regression that prevented Claude Code from launching on macOS 12 (Monterey) introduced in v2.1.255. Also fixes remote and scheduled sessions failing with "user messages must have non-empty content" after a re-sent permission approval could not be applied. Source: https://code.claude.com/docs/en/changelog

- **Memory & download size improvements**: Native builds now load code on demand rather than keeping the full bundle resident, saving roughly 40–70 MB of memory per session. The native installer and auto-update package shrinks from ~340 MB to ~75 MB on Linux x64 through zstd compression. Source: https://code.claude.com/docs/en/changelog

- **Permanent 25% usage-limit increase (effective September 14)**: Anthropic is raising standard baseline weekly limits by 25% for Pro, Max, Team, and seat-based Enterprise plans. However, this replaces the temporary +50% promotional tier that runs through September 13, resulting in approximately 17% less capacity than users currently have. Source: https://www.bleepingcomputer.com/news/artificial-intelligence/anthropic-is-cutting-claude-codes-current-weekly-limits-by-17-percent/

## Integrations & Extensions

- **VS Code extension improvements in v2.1.257**: The extension now shows collapsible ACCOUNT & USAGE and SESSION MANAGER headers with an account email and usage meter. A model pill in the input footer displays the active model and opens the model picker. An Effort row was added to the model picker, and output-style selection is accessible from the command menu. Slash commands in the action menu are now shown in a filterable dialog. Source: https://code.claude.com/docs/en/changelog

- **Xcode 26.3 integrates Claude Agent SDK**: Apple's Xcode 26.3 includes a native integration with the Claude Agent SDK — the same harness that powers Claude Code — giving developers access to subagents, background tasks, and plugins directly in Xcode without leaving the IDE. The Agent SDK (renamed from "Claude Code SDK" in September 2025) is Anthropic's official library for building autonomous AI agents. Source: https://www.anthropic.com/news/apple-xcode-claude-agent-sdk

- **Cowork expands to web and mobile**: As of September 2026, Cowork (Claude Code's collaborative session mode) runs on web and mobile in addition to desktop, with remote sessions in public beta — files and session state are saved to a Claude account and synced across devices. Source: https://releasebot.io/updates/anthropic/claude

## Bug Fixes & Performance

- **MCP fixes**: v2.1.257 fixes issues with `/mcp reconnect` and re-enabling disabled servers still connecting incorrectly. Earlier August releases (v2.1.251) improved MCP connection logs with credential redaction. Source: https://code.claude.com/docs/en/changelog

- **Rendering and token-counter performance**: v2.1.257 reduces re-render work in long conversations. v2.1.246 fixed severe transcript slowdowns when lines contained very long base64 strings, and v2.1.257 fixes the token counter freezing when switching between subagent transcripts. Source: https://code.claude.com/docs/en/changelog

- **Subagent reliability fixes**: Fixes sessions dispatched from agent view always starting in the original session's permission mode (instead of inheriting the subagent's intended mode), and cross-session messaging silently failing to reach teammates. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Claude Code crossed $2.5B ARR**: By February 2026, Claude Code reached $2.5B in annualized revenue and now spans a terminal CLI, JetBrains plugin, standalone desktop app, web and iOS, and Slack integration. The VS Code extension is the primary IDE surface. Source: https://www.eesel.ai/blog/claude-code-vs-code-extension

- **MCP gateway ecosystem growing**: Third-party guides and tooling around MCP gateways for Claude Code continue to proliferate in 2026, with several dedicated gateway products and authentication solutions emerging. Claude Code can simultaneously act as both an MCP server (exposing built-in tools) and an MCP client (consuming external servers). Source: https://www.gradually.ai/en/changelogs/claude-code/

## Roadmap & Announcements

- **Self-hosted environments public beta**: Anthropic added a public beta for self-hosted Claude Code environments, letting teams run sessions on their own infrastructure with access to internal networks, custom tooling, and compliance controls. Supports fixed or on-demand runners and is available for Team and Enterprise plans. Source: https://releasebot.io/updates/anthropic/claude

- **Compliance API expanded**: The Compliance API now covers Cowork and Claude Code across desktop, web, mobile, and CLI, with beta access for Claude Enterprise customers. New session endpoints return a consolidated server-hosted transcript for each session, capturing prompts, responses, tool calls (web and MCP), and skills/artifacts content. Source: https://releasebot.io/updates/anthropic/claude

- **Security scanning for skills and plugins (Enterprise beta)**: Anthropic added beta security scanning for third-party skills and plugins in Enterprise plans, automatically checking for malicious content when someone uploads or edits them. Source: https://releasebot.io/updates/anthropic/claude

- **Containment Escape rule in auto mode**: A new security rule added in v2.1.257 prevents Claude Code in auto mode from fetching cloud metadata credentials, evading egress controls, or reaching across tenant boundaries without user approval. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
The most important Claude Code development today is the launch of Claude Fable 5.1 as the new default Fable model in v2.1.257, bringing a 1M-context window to the codebase — paired with meaningful memory and download-size reductions that make Claude Code faster to install and lighter to run. The looming September 14 usage-limit restructuring will also directly affect most paying users' daily workflows.

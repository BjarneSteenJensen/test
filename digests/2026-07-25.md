# Claude Code News Digest — 2026-07-25

## Overview
July 2026 has been a landmark month for Claude Code, capped this week by the arrival of live MCP connector data in published Artifacts and a new screen reader accessibility mode. The tool also gained a built-in Desktop browser and the `/doctor` setup-health command earlier in the month, while Claude Sonnet 5 (1M-token context, adaptive thinking on by default) became the new default model. The broader narrative: Bloomberg called Claude Code "the hottest piece of software in the world" in a July 20 profile, and Anthropic launched a FedRAMP High government desktop beta.

## New Features & Releases

- **Artifacts Call MCP Connectors (Week 29, v2.1.207–v2.1.212)**: Published artifacts can now pull live data and take actions via each viewer's own MCP connectors whenever the page is opened, turning static session snapshots into dynamic, always-fresh dashboards. Viewers approve connector access on first load and only see data their own account can reach; this week also adds public sharing links, editor roles for Team and Enterprise plans, and artifacts created from Claude Tag sessions. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **Screen Reader Mode (Week 29, v2.1.207–v2.1.212)**: A new accessibility mode replaces Claude Code's visual terminal interface with plain, linear text output — labeled lines that screen readers such as VoiceOver and NVDA can read in order, covering permission approvals and all output. Enable per session with `--ax-screen-reader`, per shell via `CLAUDE_AX_SCREEN_READER`, or globally via the `axScreenReader` setting. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **In-App Browser for Desktop (Week 28, v2.1.202–v2.1.206)**: Claude Code Desktop gained a built-in sandboxed browser, allowing Claude to browse documentation, pull up designs, and interact with any external site the same way it handles local dev server previews. Safety classifiers review actions on external sites and users control whether browsing sessions persist. Source: https://code.claude.com/docs/en/whats-new/2026-w28

- **/doctor Setup Checkup (Week 28, v2.1.205)**: The `/doctor` command (alias: `/checkup`) now actively diagnoses and fixes issues: checking installation health, identifying unused skills and MCP servers, deduplicating CLAUDE.md files, proposing content trims, and flagging slow hooks — all after showing findings and asking for confirmation. Source: https://code.claude.com/docs/en/whats-new/2026-w28

- **Claude Sonnet 5 as New Default Model (Week 27)**: Claude Sonnet 5 became the default for Pro, Team Standard, and Enterprise subscription seats, bringing a native 1M-token context window and adaptive thinking on by default at Sonnet pricing, with promotional pricing through August 31. Source: https://code.claude.com/docs/en/whats-new/2026-w27

## Integrations & Extensions

- **VS Code 1.128 Multi-Chat for Claude Agent Sessions (July 8)**: The VS Code 1.128 release added multi-chat support for Claude agent sessions, allowing a session to contain related chats that compare approaches, branch from earlier turns, and run work in parallel. Each chat maintains its own history, title, and model selection. Source: https://visualstudiomagazine.com/articles/2026/07/08/claude-ai-gets-yet-another-boost-in-vs-code-1-128.aspx

- **Auto Mode Expanded — No Opt-In Required on Bedrock, Google Cloud, and Foundry (Week 29)**: Auto mode no longer requires the `CLAUDE_CODE_ENABLE_AUTO_MODE` environment variable on Amazon Bedrock, Google Cloud's Agent Platform, and Microsoft Foundry. Administrators can disable it with the `disableAutoMode` setting, and those platforms now default to Claude Opus 4.8. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **MCP Tool Calls Auto-Move to Background After 2 Minutes (Week 29)**: Long-running MCP tool calls exceeding 2 minutes now automatically move to the background so the session stays usable. The threshold is tunable or disableable via `CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS`. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **Claude Agent SDK — Subagent Text Streaming & Screen Reader Mode (July 22)**: The latest Python SDK release added subagent text streaming, screen reader mode, vim insert remaps, improved background agent reliability, and fixes across permissions, uploads, sessions, Chrome, Windows, and cloud models. Source: https://pypi.org/project/claude-agent-sdk/

- **Subagents Can Spawn Nested Subagents (up to Depth 3)**: Claude Code now supports subagents spawning their own subagents up to three levels deep by default, enabling more complex multi-agent workflow chains. Source: https://releasebot.io/updates/anthropic/claude-code

## Bug Fixes & Performance

- **Auto-Update Memory Reduction (~400 MB)**: Binary downloads for auto-updates now stream to disk instead of buffering in memory, cutting peak updater memory usage by approximately 400 MB. Source: https://code.claude.com/docs/en/whats-new/2026-w28

- **Session-Wide Caps Prevent Runaway Loops (Week 29)**: WebSearch calls and subagent spawns each default to a cap of 200 per session, preventing unbounded loops. Both limits are tunable via `CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION` and `CLAUDE_CODE_MAX_SUBAGENTS_PER_SESSION`. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **Background Agent Upgrades No Longer Block Sessions**: Background agents now upgrade to a new Claude Code version immediately after an update instead of incurring a slow stale-session upgrade cost when you later attach. Source: https://code.claude.com/docs/en/whats-new/2026-w28

- **Auto Mode Security Hardening**: Auto mode now blocks tampering with session transcript files and asks for confirmation before running `rm -rf` on variables it cannot resolve from context. Background task notifications explicitly state no live human input has occurred, preventing fabricated in-transcript approvals from being acted on. Source: https://code.claude.com/docs/en/whats-new/2026-w28

- **"Always Allow" Rules Persist Across Worktrees**: Permission rules saved as "Always allow" now save at the repository root so approvals granted inside a git worktree persist across sessions and all worktrees in that repository. Source: https://code.claude.com/docs/en/whats-new/2026-w29

## Roadmap & Announcements

- **Claude Code Government Desktop — FedRAMP High Public Beta**: Anthropic launched a public beta of Claude Code and Claude Cowork in Claude for Government Desktop, bringing FedRAMP High authorized AI to public sector teams. The release includes desktop file-based work, stronger admin controls, tamper-evident audit logs, device verification requirements, and spend governance for agencies. Source: https://releasebot.io/updates/anthropic/claude-code

- **/fork Becomes a True Background Branch Command (Week 29)**: `/fork` now copies the full conversation into a new background session with its own row in `claude agents` while the original keeps running; the old in-session fork behavior is now `/subtask`. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **Live Elapsed-Time Counter in Tool Summaries (Week 29)**: The collapsed tool summary line now shows a live elapsed-time counter for long-running tool calls, so they visibly tick rather than appearing stuck. Source: https://code.claude.com/docs/en/whats-new/2026-w29

## Key Takeaway
The standout development this week is **Artifacts + live MCP connectors**: the combination of real-time data feeds and shareable published pages effectively turns Claude Code's artifact output into a live application platform — a significant expansion beyond coding assistance into persistent, data-driven tooling that any team member can view without re-running a session.

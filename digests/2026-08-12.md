# Claude Code News Digest — 2026-08-12

## Overview

The biggest story this week is Anthropic's announcement that **auto mode will become the default permission mode** for Pro, Max, and Team plans starting August 14, replacing manual approval prompts with a background classifier that screens every tool call. Alongside that, v2.1.228 shipped on August 11 with a broad sweep of stability fixes covering session rendering, Windows Git detection, cross-session messaging, and self-hosted runner reliability.

---

## New Features & Releases

- **v2.1.228 (August 11, 2026)**: Anthropic's latest release fixes interactive sessions that stopped redrawing after rare internal layout errors, corrects `/tui` reverting to older models after a `/model` switch, and hardens synced skills from claude.ai (no shadowing local commands, sanitized descriptions, restricted commands). The Write tool was also updated to allow newer models to overwrite existing files they haven't read this session, matching the Edit tool's existing behavior. Source: https://code.claude.com/docs/en/changelog

- **v2.1.227 (August 10, 2026)**: Fixes feature-flag evaluation that broke on expired login tokens, resolves every Bash command failing under `claude-code-action` with `allowed_non_write_users` on GitHub runners, and improves the slash-command menu with better visual marking, bolded matches, and preserved emoji/accents. Source: https://code.claude.com/docs/en/changelog

- **v2.1.221 – Focus View (August 3, 2026)**: The VS Code extension gained a Focus view that declutters the chat interface by collapsing tool activity into compact summaries. Source: https://code.claude.com/docs/en/whats-new

---

## Integrations & Extensions

- **Self-Hosted Environments (Public Beta)**: Anthropic launched public beta support for self-hosted Claude Code cloud environments, letting Team and Enterprise organizations run sessions on their own infrastructure with internal network access, custom tooling, and compliance controls. Source: https://code.claude.com/docs/en/whats-new

- **Cross-Session Messaging**: On macOS and Linux, Claude Code sessions can now message each other directly, so Claude can pass a finding or decision from one session to another without the user having to re-explain context. Source: https://code.claude.com/docs/en/whats-new

- **MCP 2026-07-28 Spec Support**: Claude expanded support for the new MCP specification, which brings a stateless core, stronger OAuth and OIDC authorization, and versioned extensions for Apps and Tasks. MCP has now surpassed 400 million monthly SDK downloads, a 4× increase this year. Source: https://www.gradually.ai/en/changelogs/claude-code/

## Bug Fixes & Performance

- **Session & Sync Fixes (v2.1.228)**: Fixed Remote Control `/resume` leaking conversation titles and history into connected sessions; fixed self-hosted runner sessions failing on fresh runners; fixed session cleanup deleting contents inside project memory folders; fixed background plugin-cache cleanup deleting symlinked development checkouts; and fixed settings-merge issues with marketplace entries inheriting custom headers. Source: https://code.claude.com/docs/en/changelog

- **Vertex AI & Compaction Improvements**: Vertex AI credential handling now fails fast instead of retrying for multiple minutes, and compaction progress display was improved for better feedback during long sessions. The terminal title busy-spinner glyphs were also updated to reduce tab-bar jitter. Source: https://code.claude.com/docs/en/changelog

- **Transient Auth Errors Fixed**: Fixes were shipped for transient 401 errors with `CLAUDE_CODE_OAUTH_TOKEN` and MCP OAuth server issues on macOS. Source: https://www.gradually.ai/en/changelogs/claude-code/

## Roadmap & Announcements

- **Auto Mode Default on August 14**: Starting August 14, 2026, auto mode becomes the default permission mode for new sessions on Pro, Max, and Team plans. Instead of prompting for human approval at each step, auto mode proceeds unless a tool call is classified as irreversible, destructive, or aimed outside the user's environment. Users can opt out. Source: https://code.claude.com/docs/en/whats-new

- **Nested Subagents Up to Depth 3**: Subagents can now spawn nested subagents up to three levels deep by default, expanding multi-agent orchestration capabilities in Claude Code workflows. Source: https://releasebot.io/updates/anthropic/claude-code

---

## Key Takeaway

The shift of **auto mode to on-by-default** on August 14 is the most consequential Claude Code change this week — it fundamentally changes the default interaction model from human-in-the-loop approval to autonomous operation with a background safety classifier, a sign that Anthropic is confident enough in auto mode's safety properties to make it the out-of-the-box experience for millions of users.

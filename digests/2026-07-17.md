# Claude Code News Digest — 2026-07-17

## Overview
Claude Code v2.1.212 shipped today with significant new capabilities: `/fork` for branching conversations into background sessions, session-wide caps on WebSearch calls and subagent spawns to prevent runaway usage, and MCP tool calls that auto-background after two minutes of runtime. This release continues a strong week of stability hardening, with 15+ bug fixes addressing worktrees, Windows compatibility, permission handling, and streaming edge cases.

## New Features & Releases

- **v2.1.212 — `/fork`, subagent caps, and MCP auto-background (July 17)**: `/fork` copies the current conversation into a new background session while keeping the main session active; `/subtask` replaces the old in-session subagent flow. A new session-wide WebSearch cap (default 200, override via `CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION`) and subagent spawn limit (default 200, via `CLAUDE_CODE_MAX_SUBAGENTS_PER_SESSION`) prevent unbounded agent loops. MCP tool calls that run longer than 2 minutes now auto-background (configurable via `CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS`). `/resume` now surfaces deleted past sessions in its picker and `claude auto-mode reset` restores default auto-mode config. Source: https://code.claude.com/docs/en/changelog

- **v2.1.211 — Subagent text forwarding (July 15)**: Added `--forward-subagent-text` CLI flag and `CLAUDE_CODE_FORWARD_SUBAGENT_TEXT` env var to include subagent text and thinking output in `stream-json` mode, enabling downstream consumers to capture sub-agent reasoning. Source: https://code.claude.com/docs/en/changelog

- **v2.1.210 — Live tool-call timer (July 14)**: Long-running tool calls now show a live elapsed-time counter in the collapsed summary line, replacing the apparent-freeze behaviour that made it hard to tell if Claude was still working. Startup warnings added for `Write`, `NotebookEdit`, and `Glob` permission rules with path arguments. Source: https://code.claude.com/docs/en/changelog

- **Week 28 — In-app browser on Desktop (July 6–10, v2.1.202–206)**: Claude Code on desktop gains a built-in browser so Claude can pull up documentation, designs, or any web page and interact with it in the same way it handles local dev-server previews. `/doctor` (alias `/checkup`) was also added as a full setup diagnostics command that both diagnoses and fixes issues. Source: https://code.claude.com/docs/en/whats-new

## Integrations & Extensions

- **Enterprise-managed MCP connectors (Okta zero-touch)**: Anthropic added admin-provisioned MCP connector access for Team and Enterprise plans, starting with Okta. Admins configure the connector once and users get access on first login with no additional authentication steps — centralising authorization across Claude chat, Claude Code, and Cowork. Source: https://releasebot.io/updates/anthropic/claude-code

- **MCP shell authentication (`claude mcp login/logout`)**: Introduced in Week 26 (v2.1.185–193), `claude mcp login` lets users authenticate a configured MCP server directly from the shell rather than navigating the interactive `/mcp` menu, with `claude mcp logout` to clear stored credentials. MCP servers with an empty URL now display as "not configured" rather than throwing a config error. Source: https://code.claude.com/docs/en/whats-new

- **Auto mode on Bedrock, Vertex AI, and Foundry (Week 23, June)**: Auto mode — which handles permission prompts autonomously via background safety checks — is now available on third-party providers (Amazon Bedrock, Google Cloud Agent Platform, Microsoft Foundry) for Opus 4.7 and Opus 4.8. v2.1.207 (July 10) further expanded auto mode to more platforms without special setup. Source: https://code.claude.com/docs/en/whats-new

## Bug Fixes & Performance

- **v2.1.212 — Wide-ranging stability fixes**: Fixed plan mode auto-running file-modifying Bash commands without permission prompts; fixed worktree creation following symlinks at `.claude/worktrees`; fixed SIGTERM during Bash tool orphaning process trees in print/SDK mode; fixed `/background` and `claude --bg` failing on Windows when Group Policy blocks PowerShell 5.1; fixed `/ultrareview` rejecting PR references like `#123`, `PR 123`, or pasted URLs; fixed OpenTelemetry HTTP exports rejected by Azure Monitor due to chunked transfer encoding. Source: https://code.claude.com/docs/en/changelog

- **v2.1.211 — Security and session fixes**: Fixed permission previews not neutralising bidirectional-override and zero-width characters (a potential UI-spoofing vector). Fixed auto mode overriding a `PreToolUse` hook's `ask` decision for unsandboxed Bash, and fixed parallel sessions logging out simultaneously after wake-from-sleep. Source: https://code.claude.com/docs/en/changelog

- **v2.1.209 — Dialog hotfix (July 14)**: Hotfixed `/model` and other modal dialogs being blocked when running inside `claude agents` background sessions. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Claude Cowork expands to mobile and web**: Claude Cowork, which launched as a desktop-only app in January 2026, became available on web and mobile for Max subscribers as of July 7. Users can now start a task at their desk, receive progress notifications on their phone, and pick up finished output on any device. Source: https://techcrunch.com/2026/07/07/the-coding-agent-wars-are-spilling-into-the-rest-of-the-office-claude-cowork/

- **Hidden-tracker controversy**: Malwarebytes and other outlets reported that Claude Code contained a tracking component not disclosed in its documentation. Anthropic characterized it as an "experiment" and it has since been addressed. The episode prompted broader discussion in the developer community about transparency in AI tooling. Source: https://www.malwarebytes.com/blog/news/2026/07/claude-codes-hidden-tracker-was-an-experiment-says-anthropic

- **Admin console Usage and Value tabs**: The Claude Code admin console gained two new analytics tabs — Usage (active developers, session counts, top commands across the org, updated daily) and Value — giving enterprise administrators better visibility into how Claude Code is being used across their teams. Source: https://releasebot.io/updates/anthropic/claude-code

## Roadmap & Announcements

- **Claude for Government Desktop public beta**: Anthropic launched a public beta of Claude Code and Claude Cowork inside Claude for Government Desktop, a FedRAMP High authorized environment aimed at public sector teams. The offering includes desktop file-based work, stronger admin controls, tamper-evident audit logs, and spend governance — built on the same application commercial customers use. Source: https://releasebot.io/updates/anthropic

- **Agent SDK billing separated from plan limits (effective June 15)**: Claude Agent SDK and `claude -p` usage no longer counts toward Claude plan usage limits. From June 15, Agent SDK and Claude Code GitHub Actions usage is metered separately from interactive Claude Code, making agentic workloads more predictable for teams running automated pipelines. Source: https://releasebot.io/updates/anthropic/claude-code

- **Claude Sonnet 5 as new default model (Week 27)**: Claude Sonnet 5 became the default model for Pro, Team Standard, and Enterprise subscription seats in late June, bringing a native 1M-token context window and adaptive thinking on by default at Sonnet pricing — a significant capability uplift for all interactive Claude Code users. Source: https://code.claude.com/docs/en/whats-new

## Key Takeaway
Today's v2.1.212 release adds safety rails for agentic workflows — hard caps on WebSearch calls and subagent spawns, plus MCP tool auto-backgrounding — signalling that Anthropic is hardening Claude Code's multi-agent infrastructure for production use as session complexity continues to grow.

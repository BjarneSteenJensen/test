# Claude Code News Digest — 2026-11-27

## Overview
November 27, 2026 caps a dense week for Claude Code: Anthropic's public beta of **Skills over MCP** (v2.1.332) lets MCP servers ship reusable workflow instructions directly into the slash menu, while **Code Mode** — the experimental JS-driven tool orchestration feature — has expanded to all major cloud platforms. A security disclosure also surfaced that Claude Code's "Don't Ask Again" settings file has exposed tens of thousands of credentials on public GitHub.

## New Features & Releases
- **Skills from MCP servers (v2.1.332, Nov 25)**: MCP servers can now bundle reusable workflow skills that appear in the `/` slash menu as `server:skill`. A new `PreSkillShellCommand` hook can inspect or block a skill's inline shell commands as it loads. Requires v2.1.331 or later; organizations can toggle the feature per-server via a managed setting. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Code Mode expansion (v2.1.331, Nov 23)**: Experimental Code Mode — which lets Claude write JavaScript to batch multiple tool calls in one step instead of calling Bash/Read/Edit one at a time — is now available in terminal sessions on Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry, and Claude Platform on AWS. It was first introduced in v2.1.323 (Nov 12) and remains disabled by default (`CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1` to enable). Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Enterprise Admin Console sign-in & Easel charts mod (v2.1.330, Nov 20)**: After `claude auth login`, Claude Code now automatically applies an organization's settings and cloud provider. A new built-in "Easel" mod draws charts inline, available on Pro, Max, and (where enabled) Team and Enterprise plans. Scheduled tasks and `/loop` can now run for up to 30 days (up from 7). Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Auto mode on cloud platforms (v2.1.329/328, Nov 19)**: Auto mode is now available for Opus 4.6 and Sonnet 4.6 on Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry, and the Claude apps gateway. Interactive sessions with no permission mode start in auto mode by default. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **/ship command rollout (Nov 24)**: A new `/ship` command began rolling out in Claude Code and the desktop app, streamlining the workflow for shipping changes. Source: [Releasebot Claude Updates](https://releasebot.io/updates/anthropic/claude)

- **Fable 5.2 as default Fable model (v2.1.321, Nov ~12)**: Claude Code made Fable 5.2 the default Fable model, coinciding with its November 9 release. Source: [ClaudeLog](https://claudelog.com/claude-news/)

## Integrations & Extensions
- **Skills over MCP public beta (Nov 24–25)**: Anthropic opened a public beta allowing MCP servers to deliver reusable, named skills alongside their tools — a significant expansion of what connecting an MCP server means for teams. Pro, Max, and Ultra users get it by default; Team requires admin enablement; Enterprise support is forthcoming with no date given. MCP Tasks and Elicitation also moved to general availability the same day. Source: [VentureBeat](https://venturebeat.com/technology/mcp-servers-can-now-deliver-ai-agent-skills-changing-what-companies-approve-when-they-connect-one), [Sulat AI News](https://news.sulat.com/2026/11/25/claude-mcp-skills/)

- **VS Code "Add to Chat" in Explorer (v2.1.327, Nov 17)**: The VS Code extension now surfaces a "Claude Code: Add to Chat" option in the file Explorer's right-click context menu, making it faster to add files to a conversation. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **MCP server JSON from stdin (v2.1.327, Nov 17)**: `claude mcp add-json <name> -` reads the server config from stdin, keeping API tokens off the command line. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Plugin marketplace auto-update (from Nov 30)**: Starting on or after November 30, 2026, plugin marketplaces in managed `extraKnownMarketplaces` will auto-update by default. Set `"autoUpdate": false` on an entry to opt out. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Agent SDK updates**: The Python Agent SDK reached v0.2.187 (Nov 20). Recent changes include a breaking change requiring hook options to be arrays, an `onFailure: "block"` callback option, and a fix for Code Mode sessions in the SDK. Source: [DeveloperDigest](https://www.developersdigest.tech/blog/claude-agent-sdk-whats-new-2026)

## Bug Fixes & Performance
- **Security fix & stricter permissions (v2.1.325)**: This release added stricter default permission prompts for sandboxed commands and fixed a zstd decoding security vulnerability. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog) / [What's New Nov 16–22](https://aiparabellum.com/whats-new-in-claude-code-nov-16-22/)

- **Email pre-send check (v2.1.317)**: A new check prompts before a web or shell tool call sends the user's account email address. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **max_tokens retry restored (v2.1.330)**: The automatic retry for `max_tokens` limit errors that had been removed was restored in this release. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **`/code-review` scoped to bugs (v2.1.329)**: `/code-review` now reports only bugs and CLAUDE.md violations on most models. Cleanup suggestions have moved to `/simplify`. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Community & Ecosystem
- **Secrets exposure via "Don't Ask Again" feature**: Security researchers at Apiiro found that Claude Code saves approved commands to `.claude/settings.local.json` — a file that can inadvertently hold credentials. GitGuardian subsequently discovered 31,088 secrets in such files on public GitHub repositories, 5,343 of which were still valid at time of detection. Users should audit their settings files and add them to `.gitignore`. Source: [InfoQ](https://www.infoq.com/news/2026/11/claude-code-leaking-secrets/)

- **Satya Nadella: Claude Code changed coding**: On The Pragmatic Engineer podcast (reported Nov 16), Satya Nadella said Claude Code moved development to the command line and caught Microsoft off guard, with the traditional IDE "kind of fading away" within about six months. Source: [The Next Web](https://thenextweb.com/news/satya-nadella-claude-code-ide-pragmatic-engineer)

- **Claude Code comes to the web**: Claude Code is now accessible via the web interface at claude.ai/code, broadening access beyond the CLI and desktop app. Source: [Tom's Guide](https://www.tomsguide.com/ai/claude-code-just-came-to-the-web-and-its-about-to-change-how-you-vibe-code)

- **Third-party ecosystem roundups**: The DEV Community continues its weekly "This week in Claude Code, Codex and Gemini CLI" series, tracking all three major AI coding tools side-by-side. Source: [DEV Community](https://dev.to/aicoding-guide/this-week-in-claude-code-codex-and-gemini-cli-week-of-november-22-2026-1ofi)

## Roadmap & Announcements
- **Deprecation — Fast mode on Opus 4.8 (Nov 30)**: Fast mode for Opus 4.8 is being removed on November 30, 2026, with no fallback. Users relying on this configuration should migrate before the deadline. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **MCP File Uploads extension coming**: File Uploads is slated to follow Tasks and Elicitation as the next experimental MCP extension, though no release date has been given. Source: [Sulat AI News](https://news.sulat.com/2026/11/25/claude-mcp-skills/)

- **Enterprise Skills over MCP**: Anthropic confirmed Enterprise support for the Skills over MCP feature is coming but gave no start date. Source: [Crypto Briefing](https://cryptobriefing.com/anthropic-skills-over-mcp-claude-beta/)

- **New game cloning limits**: Anthropic confirmed new Claude Code restrictions to prevent certain game cloning use cases; users have also reported that Opus 5.5 is actively blocking reverse engineering tasks. Source: [Tom's Hardware](https://www.tomshardware.com/tech-industry/artificial-intelligence/anthropic-confirms-new-claude-code-limits-to-prevent-game-cloning-users-report-opus-5-5-is-also-actively-blocking-reverse-engineering-tasks)

## Key Takeaway
The launch of **Skills over MCP** in v2.1.332 is the most significant Claude Code development this week: it fundamentally expands the MCP ecosystem from tool providers to full workflow-instruction providers, changing what organizations are agreeing to when they connect an MCP server — and making Anthropic's safety guardrails (prompt injection protection, skill approval controls) a critical new consideration for enterprise deployments.

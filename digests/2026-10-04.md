# Claude Code News Digest — 2026-10-04

## Overview
The biggest Claude Code story this week is the launch of **Claude Mods** (v2.1.287, October 1), which lets developers write TypeScript plugins that deeply modify Claude Code's behavior, UI, and prompts — making the tool fully extensible from the inside. Alongside that, two rapid patch releases (v2.1.288 and v2.1.289) shipped in the two days following, addressing reliability, MCP stability, and permission-system edge cases. Enterprise momentum continues with Barclays announcing a major Claude Code expansion targeting 50% of its developer population by year-end.

## New Features & Releases

- **Claude Mods launch (v2.1.287, October 1)**: Anthropic introduced Claude Mods — small TypeScript functions that ship inside plugins and can rewrite prompts, add new UI panes/bands, replace built-in features, or add entirely new functionality. A built-in "You should know" mod ships out of the box: a side agent that silently watches sessions and surfaces things the main Claude or the user might overlook. Mods can be authored manually or by asking Claude Code to generate them, and are shareable through the plugin directory. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Agents view session-name filter (v2.1.287)**: An `n:<text>` filter was added to the agents view that matches against session names and task descriptions, surfaces matches inside collapsed sections, and lets Enter open the first match directly. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Auto-resume on usage-limit reset (v2.1.287)**: Claude Code now automatically continues a session when a claude.ai usage limit resets mid-session, with an option to disable the behavior in config. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Broad reliability and UX update (v2.1.288, October 2)**: Smarter resume and recovery flows, stronger plugin and MCP handling, improved permission and auto-mode behavior, and many fixes covering cloud, SDK, screen-reader, and terminal sessions. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Integrations & Extensions

- **MCP re-authentication and URL prompts**: Claude Code now shows a re-authenticate prompt when an MCP server requests an additional OAuth scope during a tool call, and surfaces URL prompts from MCP servers on the 2025-11-25 protocol (e.g., sign-in flows). The v2 runtime moves to MCP TypeScript SDK 2.0 with support for MCP protocol revision 2026-07-28. Source: [Claude Code MCP Docs](https://code.claude.com/docs/en/mcp)

- **Community Visual Studio 2026 extension**: A community-built extension ([firish/claude_code_vs](https://github.com/firish/claude_code_vs)) brings Claude Code to Visual Studio 2026 with native diff accept/reject, automatic compiler-diagnostics context, a live debugger Claude can drive autonomously, Roslyn code navigation, and Test Explorer integration — the unofficial IDE half of Claude Code's integration protocol. Source: [GitHub – firish/claude_code_vs](https://github.com/firish/claude_code_vs)

- **VS Code session management fixes (v2.1.283 earlier in October cycle)**: The VS Code extension received targeted fixes for session management and message handling, improving reliability of the official extension for day-to-day use. Source: [Use Claude Code in VS Code](https://code.claude.com/docs/en/vs-code)

## Bug Fixes & Performance

- **Permission system hardening (v2.1.289, October 3)**: Fixed deny/ask rules on nested compound shell commands not holding over user-installed mod approvals on managed machines; fixed `Read` deny rules not applying to files accessed via symlink, @-mention, or the file picker; fixed Bash permission rules missing commands behind environment variable prefixes with expanded values. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Terminal rendering fixes (v2.1.289)**: Fixed a terminal freeze triggered by short code blocks containing many unclosed `<script>` tags or deeply nested `${` substitutions; fixed text with tabs and escape sequences overwriting rows below; fixed right-aligned content in mod panes/bands drawing beneath the close marker. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Plugin and mod system fixes (v2.1.289)**: Fixed installed mods failing to load in the first session after an upgrade; fixed `plugin list`, `plugin eval`, and `plugin update` showing stale cached copies; fixed a user-installed plugin overwriting organization-managed MCP server descriptions; fixed `claude plugin validate` skipping plugins when a folder also contains a marketplace manifest. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Agent team improvements (v2.1.289)**: Added `agent.spawn` for teammates that maintains a single agent ID across hook events; added idle and waiting states to `$.agent.list()`; fixed plugin-defined agents now correctly running with their own prompt, tools, and effort level. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Community & Ecosystem

- **Barclays accelerates Claude Code rollout**: Barclays expanded its strategic collaboration with Anthropic to integrate Claude Code across global engineering operations, targeting 50% of its developer population by end of 2026 and a majority of software engineers in 2027. COO Craig Bright cited the combination of skilled engineers, cyber specialists, and trusted AI as able to "fundamentally improve how technology is developed and managed across large-scale enterprises." Source: [Anthropic – Barclays scales Claude](https://www.anthropic.com/news/barclays-scales-claude) / [PYMNTS](https://www.pymnts.com/news/artificial-intelligence/2026/barclays-accelerates-ai-rollout-with-anthropic-claude-code/)

- **MCP ecosystem at scale**: By October 2026, MCP is firmly established as the default extension layer for Claude Code, with a public registry, official SDKs in five languages, and hundreds of community servers. Guides and reviews covering the best MCP servers continue to proliferate. Source: [Best Claude Code MCP Servers 2026](https://www.totalum.app/blog/claude-code-mcp-servers-2026)

## Roadmap & Announcements

- **Claude for Government launch**: Anthropic launched Claude for Government, bringing FedRAMP High authorized access to coding and agentic workflows for federal and state agencies, with strong governance, spend controls, audit logs, and desktop file support — extending Claude Code to regulated public-sector environments. Source: [Anthropic Product Announcements](https://claude.com/blog-category/announcements)

- **Claude Agent SDK no longer counted against plan limits**: As of June 15, 2026, Claude Agent SDK and `claude -p` usage no longer counts toward Claude plan usage limits. The October 2.1.288 release further improved cloud and SDK session reliability, making programmatic agent use more accessible and cost-predictable for developers. Source: [Claude Agent SDK support article](https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan)

## Key Takeaway
The launch of **Claude Mods** is the defining development of the week: by letting developers write TypeScript plugins that modify Claude Code's behavior from the inside, Anthropic is transforming Claude Code from a fixed CLI into a fully programmable, extensible coding platform — a shift that, combined with the rapid v2.1.288/2.1.289 stabilization patches, signals the ecosystem is maturing quickly.

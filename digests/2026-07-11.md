# Claude Code News Digest — 2026-07-11

## Overview
July 11, 2026 marks the release of Claude Code v2.1.207, a significant stability and security patch that closes a shell-injection vulnerability in hook commands, fixes terminal rendering freezes, and expands auto mode to Amazon Bedrock, Google Vertex AI, and Microsoft Foundry by default. The week also carries forward momentum from Week 28's headline feature — a built-in in-app browser for the Desktop app — and the broader rollout of Claude Sonnet 5 as the default model.

---

## New Features & Releases

- **v2.1.207 — Auto mode on Bedrock, Vertex & Foundry**: Auto mode is now enabled by default on Amazon Bedrock, Google Cloud's Vertex AI, and Microsoft Foundry (disable via `disableAutoMode` in settings). The update also changes Bedrock, Vertex, and Claude Platform on AWS to default to Claude Opus 4.8, and fixes auto mode to read settings from `~/.claude/settings.json` instead of `.claude/settings.local.json`. Source: https://code.claude.com/docs/en/changelog

- **In-App Browser on Desktop (Week 28, July 6–10, v2.1.202–v2.1.206)**: Claude Code's desktop app gains a built-in browser, allowing Claude to pull up documentation, designs, or any website and interact with pages the same way it does with local dev-server previews — no switching to an external browser mid-session. Source: https://code.claude.com/docs/en/whats-new

- **`/doctor` Setup Checkup**: The new `/doctor` command (aliased as `/checkup`) runs a full environment diagnostic — detecting broken hooks, misconfigured MCP servers, and other common setup issues — and can automatically fix what it finds. Highlighted in the Week 28 digest. Source: https://code.claude.com/docs/en/whats-new

- **Claude Sonnet 5 as Default Model (Week 27, June 29 – July 3)**: Claude Sonnet 5 became the default model for Pro, Team Standard, and Enterprise subscription seats, featuring a native 1M-token context window, top-tier coding and tool use at Sonnet pricing, and adaptive thinking on by default. Source: https://code.claude.com/docs/en/whats-new

- **Auto Mode Safety Hardening**: Auto mode now blocks rules that would tamper with session transcript files, and asks for confirmation before executing `rm -rf` on paths containing unresolved shell variables — reducing the blast radius of accidental destructive commands. Source: https://code.claude.com/docs/en/changelog

- **Agent View Row Enhancements**: Agent view rows in `claude agents` now display a colored state word and a classifier-written one-line headline, making it easier to scan dozens of running sessions at a glance. Source: https://code.claude.com/docs/en/changelog

- **Claude Code Weekly Limits +50%**: Anthropic temporarily raised Claude Code's weekly usage limits by 50% through July 13, 2026 — widely read as a competitive response to OpenAI's Codex offering. Source: https://pasqualepillitteri.it/en/news/2494/claude-code-weekly-limits-50-percent-anti-codex-anthropic-2026

## Integrations & Extensions

- **VS Code 1.128 — Multi-Chat Agent Sessions**: Visual Studio Code 1.128 (released July 8) adds multi-chat support for Claude agent sessions, allowing a single session to contain related chats so developers can compare approaches, branch from an earlier turn, and run parallel workstreams inside one IDE context. Source: https://visualstudiomagazine.com/articles/2026/07/08/claude-ai-gets-yet-another-boost-in-vs-code-1-128.aspx

- **MCP OAuth & Timeout Fixes (v2.1.206)**: Fixed OAuth MCP servers requiring manual re-authentication after a single failed token refresh, and fixed MCP servers configured via `--mcp-config` or `.mcp.json` ignoring per-server `request_timeout_ms` settings (previously causing long-running MCP tool calls to time out at the 60s default in fresh sessions). Source: https://code.claude.com/docs/en/changelog

- **MCP `roots/list` Working Directories (v2.1.203)**: Session working directories are now included in MCP `roots/list` responses with live change notifications, giving MCP servers accurate context about where Claude is operating. Source: https://code.claude.com/docs/en/changelog

- **Gateway Support for Public Endpoints (v2.1.206)**: Added support for Anthropic-operated public gateway endpoints in `/login`, enabling enterprise setups that route traffic through managed API gateways. Source: https://code.claude.com/docs/en/changelog

## Bug Fixes & Performance

- **Shell-Injection Vulnerability Patched (v2.1.207)**: A security fix rejects `${user_config.*}` variable interpolation inside hook commands — a vector that could allow injected config values to run arbitrary shell code. The recommended migration is to use exec form or the `$CLAUDE_PLUGIN_OPTION_<KEY>` environment variable instead. Source: https://code.claude.com/docs/en/changelog

- **Terminal Freeze with Long Content Fixed (v2.1.207)**: Fixed a rendering bug that caused terminal freezing and keystroke lag when rendering very long lists, tables, paragraphs, or code blocks — a frequent pain point in large codebases. Source: https://code.claude.com/docs/en/changelog

- **Auto-Updater No Longer Overwrites Custom Launchers (v2.1.207)**: Fixed the auto-updater overwriting custom launcher scripts at `~/.local/bin/claude`, which broke user-configured wrappers on every update. Source: https://code.claude.com/docs/en/changelog

- **macOS Background Session Stall Fixed (v2.1.203)**: Fixed background agent sessions on macOS stalling 15–20 seconds due to false low-memory detection triggering unnecessary pauses. Source: https://code.claude.com/docs/en/changelog

- **SessionStart Hook Streaming Fixed (v2.1.204)**: Hotfix for hook events not streaming during `SessionStart` hooks in headless sessions, which caused remote workers to be idle-reaped mid-hook — a critical reliability fix for CI/CD deployments. Source: https://code.claude.com/docs/en/changelog

- **Windows NTFS Worktree Deletion Fixed (v2.1.205)**: Fixed Windows worktree removal deleting files *outside* the worktree when an NTFS junction or directory symlink existed inside it — a potentially destructive data-loss bug on Windows. Source: https://code.claude.com/docs/en/changelog

- **Background Agent Reliability (v2.1.203)**: Fixed background agents crash-looping when their working directory was deleted or invalid; fixed daemon auto-upgrade failure silently killing all running background sessions; fixed background agents inheriting a stale `PATH` from the daemon. Source: https://code.claude.com/docs/en/changelog

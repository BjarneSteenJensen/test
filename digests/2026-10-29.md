# Claude Code News Digest — 2026-10-29

## Overview
Claude Code had an exceptionally active week, shipping versions 2.1.299 through 2.1.312 between October 14–27, with the most significant milestone being Code Review reaching general availability on October 15. The latest release (v2.1.312, October 27) adds enterprise OIDC improvements and fixes a critical bug where Claude overwrote large CLAUDE.md files after reading only part of them.

## New Features & Releases

- **Code Review is now generally available (v2.1.301, October 15)**: Anthropic's automated pull-request review feature has exited research preview and is now available to all Claude Team and Enterprise organizations. Most reviews now complete in 6–10 minutes (down from ~20 in preview), and admins can choose Quick, Standard, or Deep review depth per repository. Eligible Enterprise organizations can claim at least $10,000 in Code Review credits before January 15, 2027. Source: https://claude.com/resources/articles/code-review-is-now-generally-available

- **Fork subagents on by default (v2.1.304, October 19)**: Subagents now fork by default in `-p`, the Agent SDK, the Claude desktop app, and VS Code. This significantly changes agent orchestration behavior — fork subagents inherit the parent's conversation context and keep tool output out of the parent's context. Set `CLAUDE_CODE_FORK_SUBAGENT=0` to opt out. Also added `/auto-mode-setup` and the `/claude-api managed-agents-secure` command in this release. Source: https://code.claude.com/docs/en/changelog

- **v2.1.312 released (October 27)**: The latest build adds `oidc.user_id_claim` support for the Claude apps gateway (enabling Entra ID's `oid` claim), click-to-send for queued messages in fullscreen, effort level selection in the model picker for cloud routines, and a Bash editor for cloud environment setup scripts. The "session limit" label is now called the "5-hour limit." Source: https://code.claude.com/docs/en/changelog

- **Idle compaction for large conversations (v2.1.299, October 14)**: Conversations over 200,000 tokens that have been idle for about 54 minutes are now automatically compacted. Tunable via `CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS`, or disable with `"idleCompaction": false` in settings. Also added `/effort` and `/fast` commands in agent view. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **Monitor tool lands on Bedrock, Vertex, Foundry, and Mantle (v2.1.310, October 23)**: The Monitor tool and plugin monitors are now available across all major enterprise deployment platforms, not just the Anthropic API. This week's release also adds cloud session and Remote Control permissions to the Enterprise custom roles system, giving admins finer-grained control over who can use cloud and remote features. Source: https://code.claude.com/docs/en/changelog

- **VS Code gains LaTeX math rendering and attachSelection (v2.1.301/v2.1.300)**: LaTeX math is now rendered inline in the Claude Code VS Code panel. The `claudeCode.attachSelection` setting was also added (v2.1.300, October 14), letting users configure whether the current editor selection is automatically attached to new prompts. Source: https://code.claude.com/docs/en/changelog

- **Slack Connect support in Claude Tag (v2.1.300, October 14)**: Claude Tag now works across Slack Connect channels, extending its reach to cross-organization workspaces. Source: https://code.claude.com/docs/en/changelog

- **`/advisor` available on Claude Platform on AWS (v2.1.300, October 14)**: The `/advisor` tool, which gives contextual guidance on Claude Code configuration, is now available when running on the AWS-hosted Claude Platform. Disable with `CLAUDE_CODE_DISABLE_ADVISOR_TOOL=1`. Source: https://code.claude.com/docs/en/changelog

## Bug Fixes & Performance

- **v2.1.311 ships 56 fixes and faster startup (October 26)**: The largest single-release bug fix batch this week. Pro and Max subscribers get noticeably faster startup times. Also changes `ultrathink` to run at `xhigh` effort on several models, and makes model settings load from a signed file for integrity. Source: https://code.claude.com/docs/en/changelog

- **Critical CLAUDE.md overwrite bug fixed (v2.1.312, October 27)**: Claude Code was overwriting large CLAUDE.md files after reading only part of them — a serious data-loss issue for projects with lengthy instruction files. This is fixed in v2.1.312. Source: https://code.claude.com/docs/en/changelog

- **`rm`/`rmdir` now blocked in bypass mode on Desktop and VS Code (v2.1.309, October 22)**: Destructive deletion commands in permission-bypass mode are now denied with a rewrite hint rather than silently executed. The release also ships 62 bug fixes. Source: https://code.claude.com/docs/en/changelog

- **v2.1.300 ships 59 fixes (October 14)**: Large requests to api.anthropic.com are now gzip-compressed by default for faster transmission (disable with `CLAUDE_CODE_GZIP_REQUEST_BODIES=0`). Background commands are also force-killed 1.5 seconds after a stop request instead of lingering. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **AI-powered code review workflow writeup**: Addy Osmani published an account of how the Claude Code team uses AI-assisted pull request review internally, covering the workflow from diff to actionable comments. Source: https://emergent.sh/news/how-claude-code-team-does-ai-powered-code

- **Vim mode extended with `%` motion (v2.1.301)**: The `%` motion for jumping between matching brackets was added to Claude Code's vim mode, a commonly-requested quality-of-life addition for vim users. Source: https://code.claude.com/docs/en/changelog

- **Skills usage analytics in Claude Tag (v2.1.311)**: A Skills usage view is now available in Claude Tag analytics, helping workspace admins see which skills are being invoked most and by whom. Source: https://code.claude.com/docs/en/changelog

## Roadmap & Announcements

- **Standalone Claude Design closes December 14, 2026**: Starting with v2.1.302 (October 16), Claude Code displays a notice that standalone Claude Design will shut down on December 14, 2026. Design functionality is being consolidated into Claude's unified product. Source: https://code.claude.com/docs/en/changelog

- **New API version `2026-10-21` (v2.1.307)**: A new Claude API version was published on October 21, accessible via `/claude-api api-version`. This tracks the ongoing API versioning cadence. Source: https://code.claude.com/docs/en/changelog

- **Usage-limit concerns unresolved**: A GitHub issue opened October 16 reports weekly usage limits draining faster than expected for some users. Anthropic had not publicly acknowledged it as of October 28. Source: https://pasqualepillitteri.it/en/news/27751/claude-code-usage-limits-run-out-users-report-bug

## Key Takeaway
Code Review reaching general availability is the week's most consequential milestone — it transforms Claude Code from a coding assistant into an automated reviewer integrated directly into PR workflows, with Team and Enterprise organizations getting access immediately and Enterprise orgs eligible for $10,000 in credits.

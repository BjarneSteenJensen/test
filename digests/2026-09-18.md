# Claude Code News Digest — 2026-09-18

## Overview
Today Claude Code shipped v2.1.276, a same-day hotfix resolving a critical 400-error regression introduced by yesterday's large v2.1.275 release that broke all requests when `ANTHROPIC_BASE_URL` is pointed at a proxy or gateway. The past 48 hours also brought skills/plugin syncing from claude.ai to terminal sessions, a send-now key (Ctrl+Enter), and expanded VS Code tooling including an agent map view and new Hooks and Permission rules dialogs.

## New Features & Releases

- **v2.1.276 — Gateway proxy hotfix (Sep 18)**: Fixed every request failing with `400 … Input tag 'advisor_20260301'` when `ANTHROPIC_BASE_URL` points at a proxy or gateway — a regression introduced in yesterday's v2.1.275. Enterprise and self-hosted users on custom endpoints should update immediately. Source: https://code.claude.com/docs/en/changelog

- **v2.1.275 — Skills/plugin sync + send-now key (Sep 17)**: Added a send-now key (`Ctrl+Enter` / `Ctrl+X`) that interrupts the current turn and sends queued messages; skills and plugins enabled on a user's claude.ai account now sync automatically to terminal sessions; added `/plugin install <plugin> --marketplace <source>`. Also fixed MCP prompts/resources not refreshing on list-changed notifications, artifact updates failing after session resume, and multiple plugin-management and memory-file bugs. Source: https://code.claude.com/docs/en/changelog

- **v2.1.274 — Memory warning + MCP startup control (Sep 17)**: Added a visible warning when memory usage is critical with steps to free memory or restart safely; added `CLAUDE_CODE_MCP_STARTUP_WAIT_MS` to bound how long the first non-interactive turn waits for MCP servers to connect (`0` = don't wait); added OpenTelemetry trace improvements. Source: https://code.claude.com/docs/en/changelog

- **v2.1.271 — Fast mode in remote + per-command sandboxing (Sep 14)**: Fast mode is now available in Claude Code Remote sessions; added mouse support to the `/config` panel; added per-command `allowed_domains` in auto mode for sandboxed web access; added `omitClaudeMd` to agent frontmatter. Source: https://code.claude.com/docs/en/changelog

- **Week 37 digest (Sep 7–11, v2.1.263–2.1.269)**: `claude plugin eval` lets users run a plugin against a test-case suite, score results, and compare against a no-plugin baseline — `claude plugin eval init` drafts cases and graders automatically. Claude Code Desktop panes can now be popped out into separate windows and docked back. `maxEffortLevel` setting caps effort across all providers. WebFetch now times out after 5 minutes instead of hanging. Source: https://code.claude.com/docs/en/whats-new

## Integrations & Extensions

- **VS Code: Agent map, Hooks dialog, Permission rules dialog (Sep 11–17)**: The VS Code extension gained an agent map visualization showing all active subagents, a Hooks configuration dialog, and a Permission rules dialog — all surfaced in v2.1.269 and v2.1.274. Also added a `claudeCode.lockEditorGroups` setting to stop Claude from locking editor groups, and viewing/editing/deleting saved memory inside the Memory dialog. Source: https://code.claude.com/docs/en/changelog

- **MCP: Gateway hint headers + startup timeout (Sep 15–17)**: Added `x-claude-code-request-class`, `x-claude-code-agent-type`, `x-claude-code-prev-tool-durations`, `x-claude-code-compaction`, and `x-claude-code-context-compacted` request headers for LLM gateways (opt-in via `CLAUDE_CODE_GATEWAY_HINT_HEADERS=1`). `CLAUDE_CODE_MCP_STARTUP_WAIT_MS` now bounds first-turn MCP server wait time with an optional disconnect notification pointing to `/mcp`. Source: https://code.claude.com/docs/en/changelog

- **Claude Tag: Access bundle conditions + AWS/monitoring presets (Sep 17)**: Claude Tag added attach conditions for access bundles and new AWS and monitoring presets, alongside fixes for channel activity detection and memory management. Source: https://code.claude.com/docs/en/changelog

## Bug Fixes & Performance

- **v2.1.276 — 400 error on proxy/gateway (Sep 18)**: Hotfix for a regression in v2.1.275 that caused every request to fail with `400 … Input tag 'advisor_20260301'` when using a custom `ANTHROPIC_BASE_URL`. Source: https://code.claude.com/docs/en/changelog

- **v2.1.270 — Git read-only permission regression (Sep 12)**: Fixed read-only git commands in Bash unexpectedly prompting for permission after a long-running session — a regression introduced in v2.1.269. Source: https://code.claude.com/docs/en/changelog

- **v2.1.268 — WebFetch hang + artifact schema fix (Sep 10)**: Fixed WebFetch hanging indefinitely (now times out at 5 minutes); fixed Artifact tool input schema rejection on third-party endpoints; fixed permission rule application on symlinked directories. Source: https://code.claude.com/docs/en/changelog

- **v2.1.266 — Authentication regression fix (Sep 8)**: Fixed a critical 2.1.265 regression where `CLAUDE_CODE_USE_GATEWAY` forced Cloud-gateway sign-in incorrectly, breaking proxy and gateway setups. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **`claude plugin eval` lands (v2.1.269, Sep 11)**: The new plugin evaluation command gives plugin authors a repeatable way to test and score plugin behavior against a baseline — `claude plugin eval init` generates test cases and graders automatically. This fills a gap for teams shipping internal plugins and is one of the most developer-focused features this month. Source: https://code.claude.com/docs/en/whats-new

- **Community Visual Studio extension for VS 2026 (firish/claude_code_vs)**: A community-built, unofficial native extension brings Claude Code to Visual Studio 2026 with a native diff accept/reject workflow, a live debugger Claude can drive autonomously, Roslyn code navigation, and Test Explorer integration. Source: https://github.com/firish/claude_code_vs

- **Enterprise Smart Reports in beta**: Anthropic launched smart reports in beta for Enterprise accounts, analyzing how teams use Claude — usage patterns, costs, session friction points, and repeated workflows worth packaging as shared skills. Source: https://releasebot.io/updates/anthropic/claude

## Roadmap & Announcements

- **Claude Fable 5.1 as default model with 75% cheaper cache reads (Sep 1, v2.1.257)**: Anthropic released Claude Fable 5.1 and Mythos 5.1 on September 1 — identical models with different safeguard levels. Fable 5.1 is now the default Fable model in Claude Code with a 1M-token context window. Cache reads dropped 75% to $0.25/M tokens (from $1/M), cutting typical workload costs ~25% and agentic tasks up to 45%. Source: https://code.claude.com/docs/en/changelog

- **Self-hosted Claude Code environments in public beta**: Self-hosted environments for running Claude Code cloud sessions on organization-operated infrastructure are in public beta on Team and Enterprise plans. Source: https://releasebot.io/updates/anthropic/claude-code

- **Anthropic webinar — September 18, 11AM ET**: Anthropic has a webinar scheduled for today covering recent Claude Code developments. Source: https://releasebot.io/updates/anthropic/claude

## Key Takeaway

The most urgent development today is the v2.1.276 hotfix: anyone with an enterprise proxy, LLM gateway, or custom `ANTHROPIC_BASE_URL` deployment should upgrade immediately to avoid the 400-error regression introduced in yesterday's v2.1.275. Beyond the hotfix, the week's standout shipping is skills/plugin syncing from claude.ai accounts to terminal sessions, giving teams a single place to manage their Claude Code tooling across surfaces.

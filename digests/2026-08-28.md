# Claude Code News Digest — 2026-08-28

## Overview
August 28 sees Claude Code at version 2.1.250, capping a month dominated by three headline shifts: auto mode became the default permission system for Pro, Max, and Team users on August 14; the `/design` skill entered research preview to bring artboard-based UI design into the CLI; and self-hosted environments hit public beta for Team and Enterprise, letting organizations run cloud sessions on their own infrastructure. The month's 30+ patch releases also delivered meaningful performance gains, security hardening, and broad IDE and MCP reliability work.

## New Features & Releases

- **v2.1.250 — August 28, 2026 (today)**: Bug fixes and reliability improvements on top of yesterday's major drop. Source: https://code.claude.com/docs/en/changelog

- **v2.1.248 — `--restricted` flag and cross-session messaging (August 27)**: New `--restricted` CLI flag strips built-in command/code tools and WebFetch, leaving only file tools scoped to the working directory — useful for locked-down environments. Cross-session `SendMessage`/`ListAgents` between sessions on the same machine is now stable. Also adds `experimental.cacheTtl` per-agent prompt-cache TTL, `/usage-credits` for AWS Marketplace Enterprise orgs, and server-managed settings diagnostics in `/doctor`/`/status`. Source: https://code.claude.com/docs/en/changelog

- **`/design` skill — research preview (Week 34, August 17–21, v2.1.234–239)**: Give it an idea, a screenshot, or an existing design and Claude drafts editable artboards in Claude Design, available in both the CLI and the Desktop app. Built on artifacts so the selected artboard can be implemented immediately. Source: https://code.claude.com/docs/en/whats-new

- **Auto mode is now the default (August 14, Week 33)**: Auto mode replaced manual permission prompts as the default for new sessions on Pro, Max, and Team plans. A background classifier checks each tool call for irreversible or out-of-bounds actions; safe actions run without interruption. Anthropic removed the extra per-call token charge for the classifier. Source: https://code.claude.com/docs/en/whats-new

- **Concise output style (v2.1.237, August 20)**: A built-in "Concise" output style now appears in `/config → Output style`. It instructs Claude to lead with the result and skip preamble, reducing verbosity in everyday terminal sessions. Source: https://code.claude.com/docs/en/changelog

- **Auto-continue after usage limit (Week 33, v2.1.234)**: In Claude Code Desktop, enabling "Auto-continue when limits reset" on a limit card lets the app automatically retry the interrupted turn once the session limit resets — no manual restart required. Source: https://code.claude.com/docs/en/whats-new

- **Self-hosted environments — public beta (Week 32, v2.1.224)**: Teams on Team and Enterprise plans can now run Claude Code cloud sessions on their own infrastructure via `claude self-hosted-runner`, enabling internal network access, custom tooling, and compliance controls. Source: https://code.claude.com/docs/en/whats-new

- **Fork mode on by default (Week 33, v2.1.232)**: Interactive sessions now default to fork mode, letting Claude hand side tasks to a background subagent that inherits the full conversation context, while the main session continues unblocked. Source: https://code.claude.com/docs/en/whats-new

## Integrations & Extensions

- **GitLab merge request support (v2.1.232–234)**: GitLab MR URLs now work with `--worktree` and the `claude agents` view; plugin marketplaces clone bare `gitlab.com` URLs; and a GitLab MR badge appears in the footer and statusline. GitLab support also added to plugin marketplaces. Source: https://code.claude.com/docs/en/changelog

- **VS Code Focus view (v2.1.221)**: The VS Code extension gained a Focus view (toggled with `Ctrl+Alt+F`) that hides tool activity, giving a cleaner conversation surface when you don't need to watch tool calls. Fixed a bug where the chat tab would get stuck on "No conversation found." Source: https://code.claude.com/docs/en/changelog

- **MCP OAuth and connectivity fixes**: Fixed MCP OAuth sign-in failing with redirect URI mismatch for pre-registered OAuth clients such as Slack (v2.1.231). Remote MCP servers now automatically recover after dropped connections in non-interactive and SDK sessions (v2.1.243). Source: https://code.claude.com/docs/en/changelog

- **`ANTHROPIC_DEFAULT_MODEL` env var (v2.1.236)**: New environment variable sets the model new sessions start on, enabling scripts and CI pipelines to standardize the default model without modifying per-project config. Source: https://code.claude.com/docs/en/changelog

- **Cross-session `@`-mentions (v2.1.232)**: Typing `@session-name` in the prompt lets Claude pass findings or decisions between named sessions on the same machine — replaces manual re-explanation of context across terminals. Source: https://code.claude.com/docs/en/whats-new

## Bug Fixes & Performance

- **Linux glibc 2.44 startup crash fixed (v2.1.245, August 25)**: A critical crash on startup affecting Arch Linux, CachyOS, and Fedora Rawhide (all shipping glibc 2.44) was patched. Source: https://code.claude.com/docs/en/changelog

- **JetBrains IDE 5-second stall fixed (v2.1.239)**: Edit/Write calls in JetBrains IDE terminals were pausing ~5 seconds when a file with thousands of IDE diagnostics was open and the extension was connected. Source: https://code.claude.com/docs/en/changelog

- **Background sessions and transcript performance (v2.1.246)**: Fixed severe transcript slowdown with very long single lines (e.g. base64 strings), erratic fullscreen scrolling, and background sessions failing after 45 seconds. Source: https://code.claude.com/docs/en/changelog

- **Binary size and startup time reduced (v2.1.239)**: The native binary is now zstd-compressed (~75 MB vs 340 MB on Linux x64). Startup time improved: sandbox and MCP bring-up no longer block the first frame. Memory usage is 40–70 MB lower per session with on-demand code loading. Source: https://code.claude.com/docs/en/changelog

- **Security hardening — multiple fixes this month**: Fixed PowerShell and zsh Bash permission bypasses; Cygwin-style symlink bypass on Windows; invisible Unicode bypassing permission prompts; worktree-isolated sessions running destructive git commands; and Windows NT-namespace path bypasses in remote file reads and session restore. Source: https://code.claude.com/docs/en/changelog

Source: https://blog.mean.ceo/claude-code-news-august-2026/

- **Claude Agent SDK active weekly releases**: The Python package `claude-agent-sdk` is at v0.2.139 on PyPI and the TypeScript `@anthropic-ai/claude-agent-sdk` is at v0.3.233 on npm, both receiving weekly updates. The SDK, renamed from "Claude Code SDK" in September 2025, powers autonomous agents using the same harness as Claude Code. Source: https://releasebot.io/updates/anthropic/claude-code

- **Claude Directory MCP ecosystem growing**: The Claude Directory lists curated MCP server setups for Discord, GitLab, AI/agent development, and more. Best-of-August roundups are actively maintained, lowering the barrier to finding quality integrations. Source: https://www.claudedirectory.org/mcp-servers/topic/discord

## Roadmap & Announcements

- **MCP 2026-07-28 spec now supported**: Claude expanded support for the new MCP spec bringing a stateless core, stronger OAuth and OIDC authorization, and versioned extensions for Apps and Tasks. Private network tunnels allow MCP servers to communicate with Claude agents without exposing internal services publicly. Source: https://code.claude.com/docs/en/changelog

- **Managed Agents August 19 release**: The `claude-api` skill was updated to cover the Managed Agents release of August 19, 2026, signaling expanded server-hosted agent capabilities available through the Anthropic API. Source: https://code.claude.com/docs/en/changelog

- **`/ultrareview` improvements**: The cloud multi-agent code-review feature received GitHub access validation improvements and a fix preventing it from uploading uncommitted credential files. Ongoing hardening suggests continued investment in the review-fleet workflow. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
The single most important Claude Code development this month is **auto mode becoming the default** on August 14 — it marks a fundamental shift from an interrupt-driven permission model to a background safety classifier, making Claude Code substantially less disruptive for sustained coding sessions while keeping safety guardrails in place.

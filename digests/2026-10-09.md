# Claude Code News Digest — 2026-10-09

## Overview
Claude Code had an active first week of October 2026, shipping nine releases (v2.1.287–v2.1.295) and capping the week with a significant hook-security fix and expanded MCP tool description limits. The defining launch of the period was **Claude Mods** (October 1), which lets TypeScript plugins rewrite prompts, add custom UI, and replace built-in features — the deepest customization layer Claude Code has ever exposed. Claude Haiku 5.5 became the default small model mid-week, bringing speed and cost improvements across all Haiku-powered sub-agent work.

---

## New Features & Releases

- **Claude Mods — Deepest Plugin Customization Yet (v2.1.287, Oct 1)**: Anthropic shipped Claude Mods, TypeScript functions packaged inside plugins that can intercept and rewrite prompts, insert custom UI panels, or replace built-in behaviors entirely. The built-in "You Should Know" mod runs a side agent to flag things you or Claude might otherwise miss. Install via `/plugin` in the CLI or from the Claude directory. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Claude Haiku 5.5 Now Default (v2.1.293, Oct 7)**: Anthropic released Claude Haiku 5.5 (`claude-haiku-5-5`) and made it the default Haiku model in Claude Code — both on the Anthropic API and inside the tool. Described by Anthropic as "our fastest, cheapest, and most capable small model yet," it speeds up all sub-agent work that uses the Haiku tier. Source: [Anthropic Newsroom](https://www.anthropic.com/news) · [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Agent Tool Effort Parameter (v2.1.292, Oct 6)**: The `Agent` tool now accepts an `effort` parameter so you can tell a sub-agent how hard to work on a task — useful for balancing speed vs. thoroughness in multi-agent pipelines. The same release added `--marketplace <source>` to `claude plugin install`, allowing one-step marketplace registration and plugin installation. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **`onFailure: "block"` for Hooks + OSC 7501 (v2.1.295, Oct 8)**: Command and HTTP hooks now support `onFailure: "block"`, letting a failing hook stop Claude from proceeding rather than silently failing. The release also added Program Status Protocol (OSC 7501) support for richer terminal state reporting. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **`--max-findings` for `/code-review` (v2.1.288, Oct 2)**: The built-in `/code-review` command gained a `--max-findings` flag to cap the number of reported findings, making review output more manageable on large diffs. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Integrations & Extensions

- **MCP Protocol Default Updated + Wider Tool Descriptions (v2.1.292 & v2.1.295)**: Local stdio MCP servers now negotiate protocol version `2026-07-28` by default (opt out with `MCP_PROTOCOL_NEGOTIATION=legacy`). Separately, MCP tool descriptions loaded via tool search expanded from 2,048 to 16,384 characters, giving server authors far more room to document tools. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Remote MCP Server Auto-Reconnect (v2.1.295, Oct 8)**: Remote MCP servers that go offline during a session now reconnect automatically after outages, removing the need to restart Claude Code when a remote tool server is temporarily unavailable. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **`agent.spawn` for Teammates (v2.1.289, Oct 3)**: The `agent.spawn` API now works for teammate-type agents, enabling programmable multi-agent workflows that spin up named collaborators from within a session. The same release exposed idle and waiting states in `$.agent.list()`. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Built-in `gh api` for Cloud Sessions (v2.1.288, Oct 2)**: Cloud sessions now include a built-in `gh api` (REST) without requiring the GitHub CLI to be installed. This makes GitHub API access available out of the box in managed/remote execution environments. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **VS Code Extension at 26M+ Installs**: Third-party trackers report the Claude Code VS Code extension surpassed 26 million installs in late September 2026, with the extension on version 2.1.283 as of September 25. The extension exposes the same engine as the CLI, including CLAUDE.md, hooks, and MCP servers. Source: [Claude Code VS Code Extension Guide](https://thepromptshelf.dev/blog/claude-code-vscode-extension-complete-guide-2026/)

## Bug Fixes & Performance

- **Critical Hook Security Fix (v2.1.294, Oct 8)**: `prompt` and `agent` hooks written as natural-language instructions (e.g. "Block commands that…") were incorrectly allowing the actions they were meant to block. This has been fixed; Stop-hook judgment also improved so Claude is less likely to end a session prematurely. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Cloud Session Permission Prompt Regression Fixed (v2.1.291, Oct 6)**: A regression introduced in v2.1.290 was silently dropping answers to permission prompts in cloud sessions. A separate regression from v2.1.288 was losing the last messages of a session on quit. Both are resolved. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Mods Loading Bug on Upgrade Fixed (v2.1.289, Oct 3)**: Installed mods were not loading in the first session immediately after a Claude Code upgrade. The same release shipped 23 additional plugin and sandbox stability fixes. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **1M-Context and `-p` Flag Fixes (v2.1.295, Oct 8)**: `[1m]` model requests that failed when the context-1m beta was refused by the server now fall back gracefully. The `claude -p` flag was also fixed after a regression that dropped earlier responses in piped/non-interactive mode. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Community & Ecosystem

- **Prompt Caching in `$.model.complete` (v2.1.292, Oct 6)**: Mod authors can now use prompt caching inside `$.model.complete` calls, reducing latency and cost for mods that repeatedly call the model with a stable prefix. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **WebSearch Budget Increased to 100 Calls/Hour (v2.1.290, Oct 5)**: Interactive WebSearch now refills at 100 calls per hour (configurable via `CLAUDE_CODE_WEB_SEARCH_REFILLS_PER_HOUR`), a significant increase for research-heavy workflows. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Ctrl+C Prompt Recovery (v2.1.288, Oct 2)**: Accidentally clearing a long prompt with Ctrl+C now recovers the text rather than losing it permanently. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **MCP Gateway Guides Proliferate**: Several 2026 ecosystem guides recommend MCP gateways for teams to centralize access control, observability, and routing across tool servers. Community token-cost benchmarks (one measured 15,540 tokens across 84 tools at session start) continue to drive advice toward keeping server counts lean. Source: [Best MCP Gateways for Claude Code in 2026](https://getmaxim.ai/articles/best-mcp-gateways-for-claude-code-in-2026-2)

## Roadmap & Announcements

- **Anthropic Cyber Mission Announced (Oct 8)**: Anthropic announced the Anthropic Cyber Mission, following an expansion of the Cyber Verification Program (Oct 6) that makes advanced cyber capabilities and reduced blocking classifiers available to qualifying security professionals. Source: [Anthropic Newsroom](https://www.anthropic.com/news)

- **1M Context Window Now Default on Major Cloud Platforms (v2.1.287, Oct 1)**: Opus 4.7+ and Fable models now use a 1M-token context window by default on Bedrock, Vertex, Azure Foundry, and the Claude Apps gateway. Users who prefer the 200K window can set `CLAUDE_CODE_DISABLE_1M_CONTEXT=1`. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Subagent Skill Preload Capped at 32 (v2.1.295, Oct 8)**: Subagents now preload at most 32 skills, a resource-management measure that signals continued investment in multi-agent reliability as large agent networks grow in complexity. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

---

## Key Takeaway
The launch of **Claude Mods** on October 1 is the week's most architecturally significant development: for the first time, TypeScript plugin code can rewrite prompts and replace core Claude Code behaviors, opening a new layer of team-level customization that goes well beyond tool and slash-command extensions. Paired with the Haiku 5.5 default and the critical hook-security fix (v2.1.294), this week represents both a major extensibility leap and a meaningful reliability hardening.

# Claude Code News Digest — 2026-07-29

## Overview
The most significant development this week is Claude Opus 5 becoming the default Opus model in Claude Code v2.1.219, bringing a 1M-token context window and fast mode availability. The prior week's digest (Week 29, July 13–17) remains the latest published deep-dive, featuring live MCP connector data in published artifacts and the new screen reader mode — both of which represent a meaningful accessibility and data-freshness leap for the platform.

## New Features & Releases

- **Claude Opus 5 is now the default Opus model (v2.1.219, July 24)**: `claude-opus-5` replaces Opus 4.8 as the default Opus model in Claude Code, shipping with a 1M-token context window and fast mode at $10/$50 per MTok. The `/model` picker now highlights only the newest model name, and `/fast` now applies to Opus 5 and Opus 4.8 (Opus 4.7 has been removed from fast mode). Source: https://code.claude.com/docs/en/changelog

- **Nested subagents now spawn up to depth 3 (v2.1.219)**: Subagents can now recursively spawn their own subagents up to three levels deep by default (previously capped at 1). This unlocks more complex autonomous workflows without manual orchestration. Set `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1` to restore the old limit. Source: https://code.claude.com/docs/en/changelog

- **Dynamic workflows default to medium size guideline (v2.1.219)**: The new default instructs workflows to aim for fewer than 15 agents. The guideline is configurable via the `workflowSizeGuideline` settings key. Source: https://code.claude.com/docs/en/changelog

- **`/code-review` runs as background subagent (v2.1.218, July 22)**: The code review command now runs in the background, so it no longer fills the main conversation window. Stacked slash commands are preserved as the review target. Source: https://code.claude.com/docs/en/changelog

- **Emoji shortcode autocomplete (v2.1.217, July 21)**: Typing `:heart:` in the prompt input now auto-completes to ❤️. The feature can be disabled with the `emojiCompletionEnabled` setting. Source: https://code.claude.com/docs/en/changelog

- **`sandbox.network.strictAllowlist` setting (v2.1.219)**: A new setting allows administrators to deny non-allowlisted hosts for sandboxed commands without prompting, tightening network security in managed deployments. Source: https://code.claude.com/docs/en/changelog

- **Artifacts call MCP connectors live (Week 29, July 13–17, v2.1.207–212)**: Published artifacts can now pull live data and take actions through each viewer's own MCP connectors when the page loads. Viewers approve access before the first connector call, and credentials are never exposed to artifact creators. This week also added public sharing links and editor roles for Team and Enterprise plans. Source: https://code.claude.com/docs/en/whats-new/2026-w29

## Integrations & Extensions

- **VS Code 1.128 adds another Claude AI integration boost (July 8)**: Visual Studio Magazine reported that VS Code 1.128 further deepens Claude integration — continuing a pattern of Microsoft expanding Claude's reach in its flagship IDE. Claude Code extensions for VS Code and JetBrains connect to the same engine as the CLI, sharing conversation history and respecting `CLAUDE.md` project instructions. Source: https://visualstudiomagazine.com/articles/2026/07/08/claude-ai-gets-yet-another-boost-in-vs-code-1-128.aspx

- **Auto mode generally available on Bedrock, Google Cloud, and Microsoft Foundry (v2.1.207–212)**: The `CLAUDE_CODE_ENABLE_AUTO_MODE` opt-in variable is no longer required on Amazon Bedrock, Google Cloud's Agent Platform, and Microsoft Foundry. Administrators can disable it via `disableAutoMode`. Third-party provider deployments also now default to Claude Opus 4.8. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **MCP tool calls auto-background after 2 minutes (v2.1.207–212)**: Long-running MCP tool calls now automatically move to the background so the session stays interactive. The threshold is tunable via `CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS`. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **Corporate launcher support via `CLAUDE_CODE_PROCESS_WRAPPER` (v2.1.207–212)**: The new `processWrapper` setting (or env var `CLAUDE_CODE_PROCESS_WRAPPER`) routes processes Claude Code starts — background service, agent view sessions — through a required corporate wrapper executable, enabling enterprise process-governance compliance. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **Claude Agent SDK usage metered separately from June 15**: Agent SDK and `claude-p` usage no longer counts against the Claude plan's interactive usage limits. This makes Agent SDK costs predictable but routes agentic automation into per-token billing. Source: https://releasebot.io/updates/anthropic/claude-code

- **Claude apps gateway for Bedrock and Google Cloud**: Anthropic introduced a self-hosted control plane offering corporate SSO login, centrally enforced policy, role-based access, and per-user cost attribution for Claude Code in enterprise cloud deployments. Source: https://releasebot.io/updates/anthropic/claude-code

## Bug Fixes & Performance

- **Quadratic normalization stall fixed (v2.1.216, July 20)**: A performance regression was causing multi-second stalls in long sessions due to quadratic message normalization cost. The fix dramatically improves responsiveness in extended conversations. Source: https://code.claude.com/docs/en/changelog

- **Screen reader mode improvements across multiple releases**: v2.1.218 adds announcements for deleted text; v2.1.217 fixes startup announcement cut-off; v2.1.216 addresses various screen reader rendering glitches. Screen reader mode (`--ax-screen-reader`) replaces visual terminal elements with plain, linear text compatible with VoiceOver and NVDA. Source: https://code.claude.com/docs/en/changelog

- **Windows stability fixes (v2.1.217, v2.1.219)**: Auto-update failures leaving `claude.exe` missing (v2.1.217) and `CLAUDE_CODE_GIT_BASH_PATH` crashing when pointing to a non-bash binary (v2.1.219) were both resolved. Source: https://code.claude.com/docs/en/changelog

- **Memory leak with truncated MCP tool outputs fixed (v2.1.217)**: A memory leak occurring when MCP tool outputs were truncated has been patched. Source: https://code.claude.com/docs/en/changelog

- **Terminal input lag fix (v2.1.219)**: Fixed terminal freezing and keystroke lag while streaming responses with very long lists, tables, paragraphs, or code blocks. Source: https://code.claude.com/docs/en/changelog

- **Auto mode OAuth token fix (v2.1.216)**: Auto mode was incorrectly denying commands with "HTTP 401" classifier errors after OAuth token expiry; this has been resolved. Source: https://code.claude.com/docs/en/changelog

- **`/context` stale token count fix (v2.1.218)**: `/context` was reporting stale token usage after compacting; it now reflects accurate post-compact counts. Source: https://code.claude.com/docs/en/changelog

## Roadmap & Announcements

- **Session-wide caps prevent runaway loops (v2.1.207–212)**: WebSearch calls and subagent spawns now default to 200 per session each, tunable via `CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION` and `CLAUDE_CODE_MAX_SUBAGENTS_PER_SESSION`. This is a safety guardrail for agentic workflows. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **"Always allow" rules now persist across worktrees**: Permission rules granted in a git worktree now save at the repository root, persisting across sessions and worktrees. This reduces repeated approval prompts in multi-worktree workflows. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **Admin console value and usage insights**: The admin console now features new tabs showing active developers, session counts, and top commands across organizations, updated daily — giving engineering leaders better visibility into Claude Code adoption and cost. Source: https://releasebot.io/updates/anthropic/claude-code

- **Trusted Devices for Remote Control on Team and Enterprise**: A new Trusted Devices feature for Remote Control admins verifies devices before remote Claude Code sessions begin, adding a security layer to remote development. Source: https://releasebot.io/updates/anthropic/claude-code

## Key Takeaway
Claude Opus 5 landing as the default Opus model — with a 1M-token context window and fast mode — is the headline release of the week, but the deeper story is the compounding depth of the platform: live MCP data in shareable artifacts, nested subagents three levels deep, background code review, and enterprise-grade process controls all shipped within a 10-day window, signaling that Claude Code's agentic infrastructure is maturing rapidly.

# Claude Code News Digest — 2026-08-24

## Overview
Claude Code had a busy August 24 with versions 2.1.240 and 2.1.241 landing as maintenance releases after the feature-packed Week 34 (v2.1.234–v2.1.239) that shipped `/design`, the Concise output style, and Remote Control out of research preview. The overarching theme for August 2026 is operability and autonomy: auto mode is now the default for Pro/Max/Team users, sessions can continue themselves at usage limits, and machines are now reachable directly from the Claude mobile app.

## New Features & Releases

- **`/design` skill (research preview, v2.1.233+)**: Brings Claude Design's artboard canvas workflow into the CLI and Claude Code Desktop. Run `/design <brief>` and Claude publishes a canvas of editable UI artboards; pick one, tweak it visually, then ask Claude to implement. Available on Pro, Max, Team, and Enterprise plans. Source: https://code.claude.com/docs/en/whats-new/2026-w34

- **Concise output style (v2.1.237)**: A new built-in output style (`"outputStyle": "Concise"` in settings) that makes Claude lead every response with the result and skip preamble and narration. Works alongside the existing Default style — errors, warnings, and confirmations for destructive actions always retain full content. Source: https://code.claude.com/docs/en/whats-new/2026-w34

- **Auto-continue at usage limit (v2.1.234)**: Claude Code Desktop now automatically retries the interrupted turn once a claude.ai usage limit resets. The behavior can be toggled via `/config → Continue automatically at usage limit`. Source: https://code.claude.com/docs/en/changelog

- **Subagent forking on by default (v2.1.232)**: Interactive sessions now fork subagents by default, inheriting the full conversation and prompt cache so Claude can hand off a side task without re-explaining context. Type `@<session-name>` in the prompt to address another live Claude session by name. Source: https://code.claude.com/docs/en/changelog

- **`ANTHROPIC_DEFAULT_MODEL` env var (v2.1.236)**: Set the model all new sessions start on without touching `/model`. A manual `/model` pick still overrides it and persists across restarts. Source: https://code.claude.com/docs/en/changelog

- **Spellcheck in prompt input (v2.1.235)**: An optional `spellcheck` setting underlines misspelled words as you type, powered by your installed `aspell`, `hunspell`, or `ispell`. Source: https://code.claude.com/docs/en/changelog

- **`/claude-api upgrade` (v2.1.239)**: New CLI command that migrates Python projects from the `anthropic` 0.x SDK to 1.x automatically. Source: https://code.claude.com/docs/en/changelog

- **Versions 2.1.240–2.1.241 (August 22–23)**: General bug-fix and reliability releases with no headline features. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **Remote Control out of research preview + phone device cards (v2.1.234+)**: Any machine running `claude remote-control` now appears as a named device card at the top of the Code tab in the Claude iOS/Android app. Tap the card, pick a directory, and start a session — no SSH required. Effort level and permission mode can also be changed from the phone. Source: https://code.claude.com/docs/en/whats-new/2026-w34

- **GitLab MR badge and worktree support (v2.1.233–v2.1.234)**: The CLI footer now shows an `MR !N` badge colored by draft/open/mergeable status when authenticated via `glab`. GitLab MR URLs also work with `--worktree` and the agents view, and bare `gitlab.com` clone URLs work in marketplaces. Source: https://code.claude.com/docs/en/changelog

- **Windows cross-session messaging (v2.1.239)**: `SendMessage` and `ListAgents` now work between Claude Code sessions on native Windows, bringing parity with macOS and Linux. Source: https://code.claude.com/docs/en/changelog

- **MCP OAuth fix for pre-registered clients (v2.1.231)**: Fixed MCP OAuth sign-in failing with a redirect URI mismatch for servers that use a pre-registered OAuth client — specifically Slack. Source: https://code.claude.com/docs/en/changelog

- **MCP v2 subscription fix (v2.1.233)**: Fixed MCP v2 connections endlessly reopening their subscriptions stream. Source: https://code.claude.com/docs/en/changelog

- **Alpine/musl native add-ons (v2.1.239)**: Native image paste, clipboard, and audio-capture add-ons now load on Alpine/musl builds, broadening container and CI support. Source: https://code.claude.com/docs/en/changelog

## Bug Fixes & Performance

- **Memory leak in long sessions fixed (v2.1.238)**: Resolved unbounded memory growth that affected long interactive sessions. Source: https://code.claude.com/docs/en/changelog

- **JetBrains IDE terminal fix (v2.1.239)**: Fixed Edit and Write tool calls pausing in JetBrains IDE terminals, which caused sessions to stall mid-task. Source: https://code.claude.com/docs/en/changelog

- **Proxy and Bedrock fixes (v2.1.239)**: Fixed Bedrock streaming behind proxies that strip the response `Content-Type` header, and fixed Claude Code hanging at startup behind an HTTPS proxy with Bedrock and SSO profile. Source: https://code.claude.com/docs/en/changelog

- **Prompt cache fix for LLM gateways (v2.1.237)**: Fixed prompt caching for sessions using an LLM gateway or custom base URL — previously the cache was incorrectly invalidated. Source: https://code.claude.com/docs/en/changelog

- **WebFetch cache expiry bug (v2.1.239)**: Fixed WebFetch retaining expired page content for the entire session instead of revalidating. Source: https://code.claude.com/docs/en/changelog

- **Idle Linux session CPU spike (v2.1.233)**: Fixed idle Linux sessions with sandboxing enabled holding CPU at 100%. Source: https://code.claude.com/docs/en/changelog

Source: https://explainx.ai/blog/claude-fable-5-max-team-premium-limits-extended-august-19-july-2026

The issue was patched in v2.1.163. Source: https://thehackernews.com/2026/08/claude-code-and-gemini-cli-flaws-let.html

- **Self-hosted environments public beta**: Anthropic launched self-hosted environments for Claude Code cloud sessions, letting teams run sessions on their own infrastructure with internal network access and compliance controls — available for Team and Enterprise plans. Source: https://code.claude.com/docs/en/whats-new/2026-w32

## Roadmap & Announcements

- **Auto mode is now the default (since August 14)**: Auto mode — the classifier-driven permission system that checks each tool call for irreversibility or out-of-bounds actions instead of prompting each time — became the default permission mode for new sessions on Pro, Max, and Team plans on August 14 (v2.1.233). Source: https://code.claude.com/docs/en/whats-new/2026-w32

- **`/design` signals Claude Design expansion into the CLI**: The research preview of `/design` is the first sign that Anthropic's upcoming Claude Design product (visual artboard editor) will integrate directly into Claude Code workflows rather than staying a separate web product. Source: https://code.claude.com/docs/en/whats-new/2026-w34

- **Agent SDK MCP spec update (July 28)**: The 2026-07-28 MCP specification update closed auth implementation gaps and added private network tunnels allowing MCP servers to communicate with Claude agents without exposing internal services publicly — with ecosystem effects continuing to roll through August. Source: https://tecniforge.com/claude-agent-sdk-2026-features/

## Key Takeaway
The most consequential August 2026 development is **auto mode becoming the default for Pro, Max, and Team users** — eliminating the constant permission-prompt friction that characterized Claude Code's earlier workflow and marking a major shift toward trusted, autonomous operation for everyday coding tasks.

# Claude Code News Digest — 2026-11-13

## Overview
The biggest story this week is a security disclosure: Apiiro researchers found that Claude Code's "don't ask again" permission feature can silently save secrets into permanent allow rules, with over 2,500 distinct credentials found across nearly 2,000 public repositories. On the release front, v2.1.323 landed yesterday (November 12) with an experimental "Code Mode" and 195 bug fixes — the largest single-release fix count in recent memory.

## New Features & Releases
- **v2.1.323 — Code Mode (Experimental)**: The latest release (November 12) introduces an opt-in "Code Mode" where Claude writes JavaScript to invoke its tools rather than calling them natively. The release also raises the default subagent context window from 200K to 1M tokens for unrecognized model IDs, adds a 30-second progress heartbeat for long-running hooks in `-p`/SDK sessions, and ships 195 bug fixes including sign-in and sandbox issues. Source: https://code.claude.com/docs/en/changelog

- **v2.1.321 — Claude Fable 5.2 as Default Fable Model**: Released November 9, this version makes `claude-fable-5-2` the default Fable model, with a 1M context window and pricing of $8/$40 per million tokens. It also fixed an MCP OAuth token leakage on redirect and Bash permission-check gaps, and introduced `--settings <file>` for `claude remote-control`. Source: https://code.claude.com/docs/en/changelog

- **v2.1.319 — Gateway Auto Mode Change & Permission Improvements**: Released November 6, this version adds the `permissions.denyInsteadOfPrompting` setting (tool calls that would prompt are denied instead, letting turns continue), and the `/claude-api latency-optimize` command. Auto mode behind LLM gateways without telemetry no longer falls back to the built-in classifier. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions
- **Fast Mode Arrives on Vertex AI**: v2.1.322 (November 10) added fast mode on Vertex in the global, US, and EU regions, automatically falling back to standard speed if Vertex declines the request. This brings Vertex deployments to parity with direct API fast-mode support. Source: https://code.claude.com/docs/en/changelog

- **IDE Extension Install Behavior Changed**: v2.1.318 (November 4) changed Claude Code so it no longer auto-installs or updates the IDE extension when started from within an IDE terminal. Users must now run `/ide` from an external terminal or install via their editor's extensions view. Source: https://code.claude.com/docs/en/changelog

- **MCP Task Backgrounding in Terminal**: v2.1.319 added support for backgrounding MCP tool calls that a server runs as tasks, reporting the result back to Claude on completion. Set `CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND=1` to revert to waiting synchronously. Source: https://code.claude.com/docs/en/changelog

- **Plugin API Improvements in v2.1.323**: Plugins can now declare `engines["claude-code"]` in `plugin.json` to constrain which Claude Code versions will load them. `claude plugin validate` gained TypeScript type-checking for hooks. Source: https://code.claude.com/docs/en/changelog

## Bug Fixes & Performance
- **MCP OAuth Token Leakage Fixed**: v2.1.321 patched a bug where MCP OAuth tokens were leaked on redirect, alongside Bash permission-check gaps that allowed unintended command execution. Source: https://code.claude.com/docs/en/changelog

- **Sign-in Expiry Warnings**: v2.1.318 added a stderr warning 10 days before a claude.ai sign-in expires, plus a new `loginExpiresAt` field in `claude auth status`. Network home directory config-file corruption was also patched. Source: https://code.claude.com/docs/en/changelog

- **Agent SDK `onFailure: "block"` Hook**: v2.1.317 (November 3) added `onFailure: "block"` for Agent SDK hook callbacks, so a callback failure blocks the action rather than silently allowing it through. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem
- **Secret Leak Disclosure (Apiiro)**: Security researchers at Apiiro found that Claude Code's "don't ask again" feature persists approved commands — including any secrets embedded in them — as permanent allow rules. The research identified 2,539 distinct secrets across 1,994 public GitHub repositories. Boris Cherny (head of Claude Code) stated the team is considering built-in secret scanning and changes to how the tool handles command permissions. Source: https://www.notebookcheck.net/Claude-Code-leaks-thousands-of-secrets-on-GitHub.1446192.0.html

- **Game-Cloning Restrictions on Opus 5.5**: Anthropic added two sentences to Claude Code's system prompt on the Opus 5.5 model to steer it away from recreating specific proprietary games. Users report this is also blocking legitimate game development and some reverse-engineering work, though the restriction appears limited to Claude Code + Opus 5.5. Source: https://www.tomshardware.com/tech-industry/artificial-intelligence/anthropic-confirms-new-claude-code-limits-to-prevent-game-cloning-users-report-opus-5-5-is-also-actively-blocking-reverse-engineering-tasks

- **Claude Code Now Included in All Team Plan Seats**: Anthropic updated billing so Claude Code access is included with every Team plan standard seat, removing the previous separate add-on cost. Source: https://releasebot.io/updates/anthropic

## Roadmap & Announcements
- **Opus 4.8 Fast Mode Deprecation**: Fast mode for Opus 4.8 was deprecated on October 30, 2026 and will be fully removed on November 30, 2026, after which those requests will return an error (no silent fallback). Anthropic recommends migrating to Opus 5.5 to retain fast-mode capabilities. Source: https://code.claude.com/docs/en/changelog

- **Broader Anthropic Collaboration Features**: Anthropic announced collaborative Sheets, Whiteboards, and interactive app connectors for Claude, plus enterprise controls — with Claude Meetings described as coming soon. These platform-level features are expected to integrate with Claude Code's cloud session capabilities. Source: https://releasebot.io/updates/anthropic

## Key Takeaway
The Apiiro secret-leak disclosure is the most urgent development for Claude Code users today: check your `.claude/settings.json` or equivalent allow-rules file for any commands that were approved with "don't ask again" and may have captured credentials, and treat those secrets as potentially compromised until Anthropic ships the planned secret-scanning safeguards.

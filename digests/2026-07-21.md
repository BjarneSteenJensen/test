# Claude Code News Digest — 2026-07-21

## Overview
July 21 caps a dense week of Claude Code releases: the v2.1.216 patch (July 20) delivers a critical performance fix for long sessions and nearly 30 bug fixes, while Bloomberg published a major profile of Claude Code creator Boris Cherny the same day. The most architecturally significant changes of the week are the `/fork` redesign (conversations now spin off as independent background sessions) and the introduction of per-session WebSearch and subagent caps — both signals that Anthropic is hardening Claude Code for production-scale autonomous use.

## New Features & Releases

- **v2.1.216 — Quadratic slowdown fix & 28 bug fixes (July 20)**: The latest patch resolves a message-normalization performance regression that caused quadratic cost growth in long sessions, making extended conversations significantly faster. It also adds a `sandbox.filesystem.disabled` setting (skip filesystem isolation while retaining network egress control) and makes `/context` emit an explicit warning when the conversation exceeds the context window. Source: https://code.claude.com/docs/en/changelog

- **`EndConversation` tool & progress heartbeats — v2.1.214 (July 18)**: Claude Code can now terminate sessions that involve jailbreak attempts or highly abusive users via a new `EndConversation` tool. Long-running tool calls now emit periodic progress heartbeats so operators can confirm an agent is still alive without guessing. Source: https://code.claude.com/docs/en/changelog

- **`/fork` redesigned as background session — v2.1.212 (July 17)**: `/fork` no longer launches an in-session subagent; it copies the conversation into a new independent background session (its own row in `claude agents`). In-session delegation moves to the new `/subtask` command. This separates "fork for parallel exploration" from "delegate a subtask." Source: https://code.claude.com/docs/en/changelog

- **Per-session WebSearch and subagent caps (July 17)**: A session-wide WebSearch limit (default 200, tunable via `CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION`) and a subagent spawn cap (default 200, via `CLAUDE_CODE_MAX_SUBAGENTS_PER_SESSION`) were added to prevent runaway delegation loops. MCP tool calls exceeding 2 minutes now auto-background (configurable via `CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS`). Source: https://code.claude.com/docs/en/changelog

- **Screen reader mode & Vim insert remaps — v2.1.208 (July 14)**: Plain-text screen reader rendering was added for accessibility, alongside a `vimInsertModeRemaps` setting for two-key insert-mode sequences (e.g. `jj` → Escape) and a `CLAUDE_CODE_PROCESS_WRAPPER` env var for corporate launcher integration. Source: https://code.claude.com/docs/en/changelog

- **Bloomberg profile of Claude Code creator Boris Cherny (July 20)**: Bloomberg published a major feature interview with Boris Cherny, the Anthropic engineer who created Claude Code, describing it as "the hottest piece of software in the world" and exploring how the team approaches building an agentic coding tool from what began as a side project. Source: https://www.bloomberg.com/news/articles/2026-07-20/the-creator-of-claude-code-on-the-hottest-piece-of-software-in-the-world

## Integrations & Extensions

- **MCP: auto-background for long tool calls (July 17)**: MCP tool calls running longer than 2 minutes now automatically move to a background session, keeping the foreground session responsive. This was accompanied by a fix for transient MCP errors that previously cleared a server's slash commands and resources (v2.1.214, July 18). Source: https://code.claude.com/docs/en/changelog

- **Enterprise managed MCP connectors via Okta**: Admins can now provision MCP connectors once (starting with Okta) and users get zero-touch access on first login — centralized authorization spanning Claude chat, Claude Code, and Cowork for Team and Enterprise plans. Source: https://releasebot.io/updates/anthropic/claude-code

- **VS Code right-to-left text fix (July 20)**: A rendering bug affecting Arabic, Hebrew, and Persian text in the VS Code extension was resolved in v2.1.216. IDE selection line numbers being off by one in both IntelliJ and VS Code were fixed in earlier July releases. Source: https://code.claude.com/docs/en/changelog

- **Auto mode on Bedrock, Vertex AI, and Foundry (July 11)**: Auto mode — Claude Code's autonomous permission system — is now available without opt-in on Bedrock, Vertex AI, and Foundry deployments, broadening its reach to enterprise cloud environments. Source: https://code.claude.com/docs/en/changelog

## Bug Fixes & Performance

- **Security: multiple Bash/PowerShell permission-check fixes (July 18)**: v2.1.214 patches six distinct permission-check bypasses: `dir/**` allow rules auto-approving nested directory writes, a Windows PowerShell 5.1 bypass, file-descriptor redirect forms, very long commands (10 000+ chars), zsh variable subscripts in `[[ ]]`, and unsafe `help`/`man` commands being auto-approved. Remote session permission prompts were also fixed to wait for local confirmation before proceeding. Source: https://code.claude.com/docs/en/changelog

- **Auto mode OAuth expiration crash (July 20)**: Fixed a bug where auto mode denied commands with "HTTP 401" classifier errors after an OAuth token expired, instead of re-authenticating. `AskUserQuestion` was also fixed to stop continuing after being told to wait. Source: https://code.claude.com/docs/en/changelog

- **Background session stability (July 20)**: A cluster of background-session bugs was resolved: resumed sessions reverting to the default agent, worktree-isolated subagents redirecting git to the shared checkout, background sessions with no git repository being undeletable, deleted sessions reappearing when the background worker had died, and background subagents being cancelled during startup. Source: https://code.claude.com/docs/en/changelog

- **Terminal freeze on long outputs fixed (July 11)**: A regression causing terminal freezing and keystroke lag while streaming responses containing very long lists, tables, paragraphs, or code blocks was resolved in v2.1.207. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Bloomberg feature: "The Creator of Claude Code on the Hottest Piece of Software in the World" (July 20)**: The Bloomberg profile documents how Claude Code went from an Anthropic side project to what the author calls the defining software of 2026, with Boris Cherny discussing the design philosophy behind the agentic loop and the team's approach to safe autonomous coding. Source: https://www.bloomberg.com/news/articles/2026-07-20/the-creator-of-claude-code-on-the-hottest-piece-of-software-in-the-world

- **Agent SDK billing decoupled from Claude plan (since June 15)**: Claude Agent SDK and `claude -p` usage no longer counts toward a Claude plan's usage limits as of June 15, 2026 — a significant change for developers building automations on top of the SDK. Source: https://releasebot.io/updates/anthropic/claude-code

- **Claude Code in Government public beta**: Claude Code and Claude Cowork launched in public beta inside Claude for Government Desktop, providing FedRAMP High authorized AI to public sector teams with tamper-evident audit logs, admin controls, and spend governance. Source: https://releasebot.io/updates/anthropic

- **Admin console: new Usage and Value tabs**: The Claude Code admin console now includes two new tabs — Usage (active developers, session counts, top commands, updated daily) and Value — giving org admins richer visibility into how Claude Code is being adopted across their teams. Source: https://releasebot.io/updates/anthropic/claude-code

## Roadmap & Announcements

- **`/verify` and `/code-review` skills no longer auto-run (July 19)**: v2.1.215 changed Claude Code so that the `/verify` and `/code-review` built-in skills must be invoked explicitly — they no longer fire automatically. This reduces unexpected latency and token spend in automated pipelines. Source: https://code.claude.com/docs/en/changelog

- **"Dynamic workflow size" setting (July 6)**: A new `Dynamic workflow size` configuration controls agent counts in Workflow orchestrations, giving users more control over how aggressively Claude Code fans out subagents. Source: https://code.claude.com/docs/en/changelog

- **Default permission mode changed to Manual (July 3)**: `AskUserQuestion` dialogs no longer auto-continue by default (opt-in via `/config`), and the default permission mode across CLI and UIs was changed from "Auto" to "Manual" — a deliberate shift toward more cautious defaults as Claude Code usage scales. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
The v2.1.216 release on July 20 — with its fix for quadratic session-length slowdowns and near-30 bug fixes — marks Claude Code's most maintenance-intensive single-day patch in July, while the same day's Bloomberg profile of Boris Cherny signals that Claude Code has crossed firmly into mainstream software consciousness. Together, these underscore a project simultaneously scaling fast and hardening its foundations.

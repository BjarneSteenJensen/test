# Claude Code News Digest — 2026-11-12

## Overview
November's first two weeks brought a steady cadence of Claude Code releases (v2.1.317–2.1.322), headlined by Claude Fable 5.2 becoming the new default model and fast mode expanding to Vertex AI infrastructure globally. Concurrently, a security finding from Apiiro drew significant attention: the tool's "Yes, don't ask again" approval mechanism has been found to expose secrets to public GitHub repositories, prompting an acknowledgement from Anthropic.

## New Features & Releases
- **Claude Fable 5.2 Now Default Model (v2.1.321, Nov 9)**: Claude Fable 5.2 (`claude-fable-5-2`) is now the default Fable model in Claude Code, bringing a 1M-token context window priced at $8/$40 per Mtok input/output with $0.20/Mtok cache reads. The release also adds a `--settings <file>` flag for `claude remote-control` to apply a settings file to all sessions it starts, plus a VS Code warning when both an auth token and an API key are set simultaneously. Source: https://code.claude.com/docs/en/changelog

- **Fast Mode Expands to Vertex AI (v2.1.322, Nov 10)**: Fast mode is now available on Vertex AI in the global, US, and EU regions, with graceful fallback to standard speed if Vertex rejects the request. Source: https://code.claude.com/docs/en/changelog

- **MCP Task Backgrounding & Refined Auto Mode (v2.1.319, Nov 6)**: MCP tasks in the terminal now move to the background immediately, with Claude notified on completion (disable with `CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND`). A new `permissions.denyInsteadOfPrompting` setting blocks tool calls that would wait on a permission prompt, allowing turns to continue uninterrupted. Auto mode with telemetry or feature flags off no longer falls back to the built-in classifier. Source: https://code.claude.com/docs/en/changelog

- **Privacy Prompt Before Email Sharing (v2.1.317, Nov 3)**: Claude Code now asks before allowing a web or shell tool call to transmit your account email address to the network, closing a quiet data-exposure path. Source: https://code.claude.com/docs/en/changelog

- **New `/claude-api latency-optimize` Command (v2.1.319)**: A new slash command scans API code for places where users are made to wait unnecessarily, helping developers identify latency bottlenecks. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions
- **IDE Extension No Longer Auto-Installs in IDE Terminal (v2.1.318, Nov 4)**: Claude Code no longer installs or updates the IDE extension when launched inside an IDE's integrated terminal. Users should run `/ide` from an external terminal instead, preventing unexpected extension upgrades during development sessions. Source: https://code.claude.com/docs/en/changelog

- **Mod Hot-Reload in Headless Sessions (v2.1.321)**: Headless sessions now automatically reload mods in `.claude/skills` when their files change (disable with `CLAUDE_CODE_PLUGIN_DIR_WATCH=0`), tightening the mod development loop. Mods can also no longer silently activate in auto and bypass modes — they must ask first. Source: https://code.claude.com/docs/en/changelog

- **Background Command Output Trimmed (v2.1.321)**: Background command notifications longer than 1,000 characters now show only the start and end of output, saving context window space in IDE and remote-control sessions. Source: https://code.claude.com/docs/en/changelog

## Bug Fixes & Performance
- **273 Bug Fixes in Five Days**: Releases this week included 74 bug fixes (v2.1.321), 90 bug fixes (v2.1.319), 47 bug fixes (v2.1.318), and 62 bug fixes (v2.1.317). Notable areas addressed: MCP OAuth token leakage on redirect, notebook and Edit tool issues on network paths, and permission-check consistency. Source: https://code.claude.com/docs/en/changelog

- **Read Tool Returns Full Content on Re-reads (v2.1.317)**: The Read tool no longer returns a "file unchanged" stub when a file is read again without modification. It now returns full content every time, eliminating a confusing behavior in agentic workflows. Source: https://code.claude.com/docs/en/changelog

- **Login Expiry Warning Added (v2.1.318)**: `claude auth status` now reports `loginExpiresAt`, and `claude -p` emits a stderr warning 10 days before a claude.ai sign-in expires, reducing unexpected session failures. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem
- **Security Finding: "Don't Ask Again" Leaking Secrets to GitHub**: Security firm Apiiro reported that Claude Code's "Yes, and don't ask again" approval mechanism has led to secrets (API keys, credentials, tokens) being committed to public GitHub repositories. Reported figures range from 1,122 to 2,539 distinct secrets across nearly 2,000 repositories. Anthropic's Boris Cherny acknowledged the issue. Developers are advised to audit recent Claude Code sessions and avoid using blanket approvals for file-writing operations. Source: https://www.csoonline.com/article/4247336/claude-codes-dont-ask-again-button-has-a-secrets-spilling-problem.html

- **Game Recreation Refusals Frustrate Developers**: Developers began reporting in late October 2026 that Claude Code was refusing requests to recreate existing commercial games, with no announcement of an intentional policy change from Anthropic. The official changelog contains no mention of this behavior shift. Source: https://thenextweb.com/news/claude-code-game-recreation-refusals-developers

## Roadmap & Announcements
- **Opus 4.8 Fast Mode Retired November 30**: Fast mode on `claude-opus-4-8` was deprecated October 30, 2026, and will be removed on November 30, 2026. After removal, fast mode requests on Opus 4.8 will return an error with no fallback. Anthropic recommends migrating to Opus 5.5 to retain the speed benefit. Source: https://code.claude.com/docs/en/changelog

- **Anthropic Launches Office Productivity Suite**: On November 10, Anthropic announced a broader push into white-collar productivity tools, including the ability for Claude to join video calls as an active, visible participant. While separate from Claude Code itself, the expansion signals a widening platform strategy. Source: https://finance.yahoo.com/technology/ai/articles/claude-now-join-video-calls-190700694.html

- **Claude Design (claude.ai/design) Closing December 14**: Anthropic announced that the standalone Claude Design tool will shut down by December 14, 2026. Teams relying on it should migrate to alternative design workflows before that date. Source: https://releasebot.io/updates/anthropic

## Key Takeaway
The most urgent development for Claude Code users this week is the Apiiro security finding: the "don't ask again" approval flow has quietly committed thousands of secrets to public repositories — developers should audit their recent sessions, rotate any exposed credentials, and tighten permission settings immediately. On the positive side, Claude Fable 5.2 as the new default model brings a 1M-token context window at competitive pricing, marking a significant capability upgrade for all users.

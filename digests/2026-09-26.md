# Claude Code News Digest — 2026-09-26

## Overview
The week of September 22–26, 2026 was dominated by the release of **Claude Opus 5.5** as the new default Opus model in Claude Code, bringing a 1M-token context window at a 40% cost reduction versus its predecessor. Alongside the model upgrade, Anthropic shipped a dense string of reliability, MCP, and developer-experience fixes culminating in v2.1.283 on September 25.

## New Features & Releases

- **Claude Opus 5.5 now default (v2.1.280, Sep 22)**: `claude-opus-5-5` replaces the previous Opus default, delivering a 1M-token context window at $4/$20 per million tokens input/output and $0.20/Mtok cache reads — roughly 40% cheaper than Opus 5. Pro and Team Standard accounts are automatically switched. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **`/doctor prompt-audit` command (v2.1.283, Sep 25)**: The new `claude doctor prompt-audit` sub-command audits your CLAUDE.md files and prompting patterns, flagging instructions that are redundant, contradictory, or likely to cause prompt-cache misses. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **AGENTS.md support (v2.1.277, Sep 18)**: Claude Code now reads `AGENTS.md` as a project instructions file when no `CLAUDE.md` exists, improving compatibility with repos that already follow the AGENTS.md convention used by other AI coding tools. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **`claude plugin eval` (Week 37, Sep 7–11, v2.1.263–2.1.269)**: Run your plugin against a suite of test cases, score the results, and compare against a no-plugin baseline. `claude plugin eval init` drafts the test cases and graders automatically. Source: [Claude Code What's New](https://code.claude.com/docs/en/whats-new)

- **`maxProseWidth` setting (v2.1.282, Sep 24)**: A new terminal setting caps the width of Claude's prose output in wide terminals while leaving tables and code blocks at full width, improving readability on ultrawide displays. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Managed model controls (v2.1.283, Sep 25)**: Two new managed settings — `availableModelsMatch` and `deniedModels` — let enterprise admins pin or block specific model versions across a deployment without touching individual user configs. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Integrations & Extensions

- **MCP URL-mode elicitation (v2.1.281, Sep 23)**: MCP servers using the 2026-07-28 protocol can now ask Claude Code to open a browser-based authentication flow without leaving a blocking dialog on screen, making OAuth flows smoother in automated and remote sessions. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **MCP tool outputs in OpenTelemetry (v2.1.283, Sep 25)**: MCP tool call results are now included in OpenTelemetry span events, giving teams running enterprise observability stacks full visibility into what MCP servers return during a session. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Claude.ai skills/plugins sync to terminal (v2.1.275, Sep 17)**: Skills and plugins configured on claude.ai are now automatically synced to terminal sessions, so users no longer need to maintain separate configurations across the web and CLI surfaces. Opt out with `syncClaudeAiSkills: false`. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **`allowClaudeInChromeWithManagedMcp` setting (v2.1.282, Sep 24)**: Enterprise admins can now centrally control whether Claude in Chrome is allowed to use managed MCP connectors, closing a previous policy gap in browser-based sessions. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Community Visual Studio 2026 extension**: An unofficial community-built extension (github.com/firish/claude_code_vs) brings Claude Code to Visual Studio 2026 with a native diff with accept/reject, a live debugger Claude can drive, Roslyn code navigation, and Test Explorer integration. Source: [GitHub – firish/claude_code_vs](https://github.com/firish/claude_code_vs)

- **MCP adoption reaches 95.3%**: MCP adoption among developer tools climbed from near 0% in late July 2026 to 95.3% in mid-September, reflecting rapid ecosystem standardization around the protocol. Source: [Lucaberton MCP Adoption](https://lucaberton.com/blog/mcp-adoption-by-client-2026/)

## Bug Fixes & Performance

- **Critical proxy/gateway 400 fix (v2.1.276, Sep 18 hotfix)**: A regression in v2.1.275 caused every request to fail with a `400 … Input tag 'advisor_20260301'` error when `ANTHROPIC_BASE_URL` pointed at a proxy or gateway. This was patched within hours as a priority hotfix. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Auto mode server-side classifier (v2.1.278, Sep 19)**: Auto mode now defaults to a server-side safety classifier, eliminating the token overhead previously charged for classifier calls. Operators on Bedrock/Vertex/Foundry can opt out with `CLAUDE_CODE_AUTO_MODE_SERVER=0`. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Prompt cache reliability fixes (v2.1.281–2.1.283)**: Multiple fixes across three releases address prompt cache loss when MCP servers disconnect mid-conversation, cache misses caused by restored memory file age notes, and sessions re-sending earlier messages in an altered form after resume — all of which were silently reducing cache hit rates. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **SDK hanging sessions fixed (v2.1.283, Sep 25 & v2.1.277, Sep 18)**: SDK sessions that lost deferred tool calls or finished tool results now recover correctly; `claude -p` and Agent SDK sessions that previously hung indefinitely after internal errors now return a result. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **MCP server lifecycle fix (v2.1.283)**: stdio MCP servers were being left running as orphan processes when sessions ended. They are now cleanly terminated on session exit. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Community & Ecosystem

- **Claude Code Projects beta**: A new beta experience lets one project coordinate parallel threads, shared memory, and a project library to manage long-running work across repos and tasks, reducing handoff overhead for multi-session workflows. Source: [Claude Code Updates (StationX)](https://app.stationx.net/articles/claude-code-september-2026)

- **Claude Code "Startup Edition" coverage**: Business-focused coverage highlights Claude Code as a practical tool for founders — running across terminals, IDEs, web, desktop, Slack, and CI/CD — to test product ideas, edit code, run tests, and review diffs without a dedicated engineering team. Source: [blog.mean.ceo](https://blog.mean.ceo/claude-code-news-september-2026/)

- **`claude plugin validate` MCP checks**: The `claude plugin validate` command now reports `.mcp.json` entries that would be silently dropped at load, undeclared `${user_config.*}` references, and insecure URLs — making plugin authoring and debugging significantly easier. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Roadmap & Announcements

- **`maxEffortLevel` setting (Week 37)**: A new setting caps the effort level across all providers in a session, giving teams a simple knob to control compute cost without per-request tuning. Source: [Claude Code What's New](https://code.claude.com/docs/en/whats-new)

- **Desktop pane pop-out (Week 37)**: Claude Code Desktop panes can now be detached into their own floating window and docked back later, improving multi-monitor and multi-task workflows. Source: [Claude Code What's New](https://code.claude.com/docs/en/whats-new)

- **`x-claude-code-prompt-id` gateway header (v2.1.283)**: A new hint header is added to gateway requests, enabling request grouping and correlation in enterprise observability and billing pipelines. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **"Claude Mods" announced (Sep 14)**: Boris Cherny of Anthropic's Claude Code team announced "Claude Mods are landing now" — a new extensibility layer; details are expected in upcoming release notes. Source: [Claude Code IDE Extension Coverage (Releasebot/StationX)](https://app.stationx.net/articles/claude-code-september-2026)

## Key Takeaway
The single most significant development this week is the **arrival of Claude Opus 5.5** as the new default Opus model — combining a 1M-token context window with a 40% cost reduction — making long-context agentic coding sessions substantially more accessible while the surrounding release train tightens MCP reliability, auto mode efficiency, and enterprise controls.

# Claude Code News Digest — 2026-09-09

## Overview
Early September 2026 has been a prolific week for Claude Code, with seven version releases (v2.1.257–v2.1.266) delivering Claude Fable 5.1 as the new default model with 1M context, a fullscreen diff panel, enterprise-grade managed MCP server distribution, and a major security and reliability overhaul. Apple's Xcode 26.3 also made headlines by natively integrating the Claude Agent SDK, bringing Claude Code capabilities directly into Apple's IDE.

---

## New Features & Releases

- **Claude Fable 5.1 now the default Fable model (v2.1.257, Sep 1)**: Claude Code v2.1.257 ships Claude Fable 5.1 (`claude-fable-5-1`) as the default Fable model, featuring 1M context window, $10/$50 per Mtok input/output pricing, and $0.25/Mtok cache reads. The release also adds user-configurable `timeFormat` and `timeZone` settings for turn-end clocks and transcripts, plus `CLAUDE_CODE_SUBAGENT_MODEL_FORCE` to pin a model across all subagents. Source: https://code.claude.com/docs/en/changelog

- **Fullscreen diff panel (v2.1.260, Sep 3)**: Claude Code v2.1.260 adds a live diff panel that opens beside the conversation in fullscreen mode, showing uncommitted changes as Claude edits. Toggled with `/diff`, it makes reviewing Claude's edits in real time dramatically easier. The same release also adds `/reload-plugins` to headless sessions and a text-based `/advisor` for desktop and headless use. Source: https://code.claude.com/docs/en/changelog

- **/skill-doctor and output limit controls (v2.1.261, Sep 4)**: v2.1.261 adds `/skill-doctor` to surface unused loaded skills and their context cost, new `bashOutputMaxChars` and `taskOutputMaxChars` settings (up to 128K characters) for larger inline command output, and `--append-subagent-system-prompt-file` for passing large subagent system prompts via file. Source: https://code.claude.com/docs/en/changelog

- **Plugin folder support and 1 GB tool-result cap (v2.1.265, Sep 8)**: v2.1.265 allows `--plugin-dir` to point at a folder of plugins (each child folder with a manifest loads automatically), adds a 1 GB cap on tool results saved to disk with truncation indicators, and adds `user.email`/`user.groups` telemetry for Cowork and Desktop sessions through the Claude apps gateway. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **Apple Xcode 26.3 integrates Claude Agent SDK**: Xcode 26.3 introduces a native integration with the Claude Agent SDK — the same harness powering Claude Code — giving Apple developers the full Claude Code feature set (subagents, background tasks, plugins, MCP servers) directly inside Xcode without leaving the IDE. Source: https://www.anthropic.com/news/apple-xcode-claude-agent-sdk

- **managedMcpServers enterprise setting (v2.1.259, Sep 2)**: Claude Code now supports a `managedMcpServers` managed setting, letting organizations push HTTP/SSE MCP servers to every user automatically. This is a significant enterprise feature for standardizing tool access across teams. Source: https://code.claude.com/docs/en/changelog

- **Community Visual Studio 2026 extension**: A community-built (unofficial) extension brings Claude Code capabilities to Visual Studio 2026, adding a native diff viewer with accept/reject, a live debugger Claude can drive (read call stack, set breakpoints, detect flaky tests), Roslyn-based code navigation, and Test Explorer integration. Source: https://github.com/firish/claude_code_vs

- **VS Code: model pill and session archiving (v2.1.260 & v2.1.265)**: The VS Code extension gains a model pill in the input footer showing the current model, and a new "Archive inactive sessions" setting (default 14 days) to auto-archive old sessions. Source: https://code.claude.com/docs/en/changelog

## Bug Fixes & Performance

- **Concurrent session data corruption fixed (v2.1.259)**: A critical bug where concurrent Claude Code sessions would silently revert each other's `~/.claude.json` changes — losing workspace trust, MCP server configs, and project state — is now fixed. Source: https://code.claude.com/docs/en/changelog

- **Permission rule and sandbox security fixes (v2.1.260)**: Fixed `Edit`/`Write`/`Read` permission rules with parentheses being dropped or ignored by the Bash sandbox, and fixed Bash permission checks auto-approving zsh commands that contained hidden command substitution. Source: https://code.claude.com/docs/en/changelog

- **Prompt cache reuse for subagents and teammates (v2.1.265)**: Fixed resuming foreground-spawned subagents and agent teammates moving context out of the prompt prefix, which was breaking prompt-cache reuse and increasing costs. Also fixed resume after a process died mid-tool-call. Source: https://code.claude.com/docs/en/changelog

- **CLAUDE_CODE_USE_GATEWAY regression hotfix (v2.1.266, Sep 8)**: A same-day hotfix for a regression introduced in v2.1.265 where `CLAUDE_CODE_USE_GATEWAY` was forcing cloud-gateway sign-in even when an API key or `apiKeyHelper` was present, causing "Not signed in to the Cloud gateway" errors for proxy/LLM-gateway setups. Source: https://code.claude.com/docs/en/changelog

- **macOS 12 Monterey launch fix (v2.1.258, Sep 1)**: Fixed a regression from v2.1.255 that prevented Claude Code from launching on macOS 12 (Monterey). Source: https://code.claude.com/docs/en/changelog

- **Windows AppContainer sandbox fix (v2.1.265)**: Fixed Read, Write, and Edit refusing every file in AppContainer or restricted-token sandbox environments on Windows. Source: https://code.claude.com/docs/en/changelog

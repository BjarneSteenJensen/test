# Claude Code News Digest — 2026-08-09

## Overview
Today's biggest story is Anthropic's announcement that **auto mode will become the default permission setting** for Pro, Max, and Team users starting August 14 — a major UX shift that replaces repeated manual approval prompts with an AI safety classifier. Alongside that, Claude Code released v2.1.225 and v2.1.226 on August 8, shipping gateway spend-limit warnings, Remote Control improvements, and a broad round of bug fixes targeting OAuth, sandbox, MCP, and session stability.

## New Features & Releases

- **v2.1.226 — Reliability polish (Aug 8, 2026)**: A focused bug-fix release with no headline features; addresses edge cases surfaced by the large v2.1.225 drop the same day. Source: https://code.claude.com/docs/en/changelog

- **v2.1.225 — Gateway spend-limit warnings and Remote Control upgrades (Aug 8, 2026)**: Adds gateway spend-limit support to Claude Code's usage warning — when the cap is hit, the message now names the limit, its reset time, and the operator's message. Workspace trust prompts now appear when running `claude agents` in untrusted directories, and Remote Control can start a new message to a teammate by name. Source: https://code.claude.com/docs/en/changelog

- **v2.1.224 — Self-hosted environments public beta and cross-session messaging (Aug 7, 2026)**: Introduces `claude self-hosted-runner` for Team and Enterprise plans, letting organisations run Claude Code sessions on their own infrastructure with internal network access and compliance controls. Adds cross-session `SendMessage` (macOS and Linux) so Claude Code sessions can message each other, discovered via `ListAgents`. Also removes the previous 200-subagent-per-session cap. Source: https://code.claude.com/docs/en/changelog

- **v2.1.221 — VSCode Focus view (Aug 4, 2026)**: Adds a Focus view toggle (`Ctrl+Alt+F`) that hides tool activity behind per-turn expandable summaries with a live running-tool indicator, significantly decluttering the chat interface during long agentic sessions. Background sessions now automatically commit, push, and follow `CLAUDE.md`. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **VSCode extension — Focus view and sandbox credential masking (Aug 4, 2026)**: The Focus view (`Ctrl+Alt+F`) is a VSCode-specific addition that collapses tool calls into readable summaries. Sandbox credential masking gains a new `mode: "mask"` option with sentinel copy substitution, and trust dialogs now explicitly name the repository root they cover. Source: https://code.claude.com/docs/en/changelog

- **Self-hosted environments in public beta (Aug 7, 2026)**: Team and Enterprise customers can now run Claude Code sessions inside their own network perimeter via `claude self-hosted-runner`. Sessions launched from the web, mobile, desktop, or a scheduled routine run inside the organisation's infrastructure, enabling access to internal APIs, databases, and private tooling that would otherwise be unreachable. Source: https://code.claude.com/docs/en/changelog

- **MCP 2026-07-28 spec support and growth milestone**: Claude Code expanded support for the new MCP spec (stateless core, stronger OAuth/OIDC authorisation, versioned extensions for Apps and Tasks). MCP has surpassed 400 million monthly SDK downloads — a 4× increase in 2026 — cementing it as the industry-standard protocol for connecting AI agents to external applications. Source: https://blog.mean.ceo/claude-code-news-august-2026/

- **Archive plugin source (Aug 7, 2026)**: Plugins can now be installed from a zip file over HTTPS (`archive` plugin source) with optional SHA-256 pinning, making it easier to distribute and pin private or air-gapped plugin builds. Source: https://code.claude.com/docs/en/changelog

## Bug Fixes & Performance

- **OAuth and MCP keychain stability (Aug 8, 2026)**: Fixed transient 401 errors that occurred when long-lived `CLAUDE_CODE_OAUTH_TOKEN` was incorrectly replaced with a short-lived token from the stored login. Fixed MCP OAuth servers on macOS intermittently failing with 401 errors after keychain read timeouts. Source: https://code.claude.com/docs/en/changelog

- **Sandbox filesystem security (Aug 7–8, 2026)**: Fixed a security gap where sandbox filesystem deny entries with a trailing slash could be silently bypassed on Linux and macOS. Also fixed worktree-isolated sessions inadvertently running destructive git commands against the main checkout (v2.1.222, Aug 4). Source: https://code.claude.com/docs/en/changelog

- **Remote Control and session reliability (Aug 8, 2026)**: Fixed conversation history breaking on Remote Control session resume after large conversation compaction. Fixed Remote Control auto-start failing with "Remote credentials fetch failed." Fixed cross-session messages staying parked without notice or expiry in headless sessions. Fixed long (>200 char) project paths resolving to the wrong session directory. Source: https://code.claude.com/docs/en/changelog

- **Auto mode safety improvements (Aug 8, 2026)**: Fixed auto mode incorrectly counting a safety-filter refusal toward the consecutive-block limit, which could cause sessions to stall unnecessarily when Claude declined an unsafe action. Source: https://code.claude.com/docs/en/changelog

## Roadmap & Announcements

- **Auto mode becomes default on August 14 for Pro, Max, and Team**: Anthropic announced (August 7) that auto mode — which uses an AI classifier to evaluate each tool call for irreversibility, destructiveness, or out-of-bounds actions, and prompts only when needed — will become the default permission setting next week. Enterprise and Bedrock/Vertex users can opt out via `disableAutoMode`. Source: https://9to5mac.com/2026/08/07/psa-claude-code-enabling-auto-mode-as-default-next-week-anthropic-says/

- **Inference hooks in beta for Enterprise (DLP enforcement)**: Anthropic has introduced inference hooks in beta for Enterprise plans, giving compliance teams real-time data-loss-prevention enforcement across Claude chat, Claude Code, and third-party integrations by inspecting prompts and tool calls before they reach the model. Source: https://blog.mean.ceo/anthropic-claude-news-august-2026/

- **Nested subagents now enabled up to depth 3 (July 24 / v2.1.219)**: The previous restriction on subagents spawning their own subagents was relaxed; nested subagents can now go up to depth 3 by default. Claude Opus 5 (`claude-opus-5`) was also added as the default Opus model with 1M-token context. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
The most consequential development this week is the **auto mode becoming the default** for all paid plans on August 14 — shifting Claude Code from a tool that asks permission for every action to one that uses an AI classifier to decide, removing friction for everyday coding workflows while keeping a safety net for destructive or irreversible commands.

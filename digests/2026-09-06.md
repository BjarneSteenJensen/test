# Claude Code News Digest — 2026-09-06

## Overview
Claude Code had a packed first week of September 2026, shipping five releases (v2.1.257–v2.1.263) culminating in today's v2.1.263 stability pass. The headline development is the introduction of **Claude Fable 5.1** as the default Fable model — bringing 1M-context windows and improved pricing — alongside a sweeping 150+ bug-fix release, a new fullscreen diff panel, and major enterprise MCP management features.

---

## New Features & Releases

- **v2.1.263 — Bug Fixes & Reliability (September 6, 2026)**: Today's release is a stability patch focused on reliability improvements. No feature additions; all changes are bug fixes. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.261 — /skill-doctor, Output Size Controls & 40+ VS Code Fixes (September 4, 2026)**: Added `/skill-doctor` to surface which loaded skills go unused and what they cost in context — useful for pruning bloated plugin configurations. New `bashOutputMaxChars` and `taskOutputMaxChars` settings let operators raise inline command output up to 128K characters (previously truncated much sooner). Also added `--append-subagent-system-prompt-file` for injecting large subagent prompts from a file, and improved the model picker to display friendly names instead of raw Bedrock/Vertex AI IDs. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.260 — Fullscreen Diff Panel (September 3, 2026)**: A side-by-side diff panel now opens beside the conversation in fullscreen mode, showing uncommitted changes as Claude edits in real time. Toggle it with `/diff`. The VS Code extension also gained an "Archive session" right-click option, MCP server Add/Remove UI in the server dialog, and fold buttons on permission prompts. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.257 — Claude Fable 5.1 & 150+ Fixes (September 1, 2026)**: The most substantial release of the week. Claude Fable 5.1 (`claude-fable-5-1`) becomes the default Fable model with 1M-token context, priced at $10/$50 per MTok input/output and $0.25/MTok for cache reads. New `timeFormat` and `timeZone` settings add 12-hour, 24-hour, UTC, and strftime display options. A "Containment Escape" rule was added to auto mode to block cloud metadata/credential fetches. Over 150 bug fixes span all platforms — including fixes to streaming performance, rendering speed, sandboxed git, Bedrock silent streaming during thinking, and 40+ VS Code issues. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Integrations & Extensions

- **managedMcpServers — Org-Wide MCP Deployment (v2.1.259, September 2)**: A new `managedMcpServers` managed setting lets organizations push HTTP/SSE MCP servers to every user automatically, without requiring individual configuration. Combined with `allowedMcpServers` now governing only user-added servers, this gives enterprises clean separation between org-mandated and user-optional MCP integrations. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **GitLab MCP / CLI Improvements**: v2.1.259 added recognition of `glab mr create/merge/close/reopen/note/update` commands for GitLab merge requests (now displayed as `MR !N` in the interface), plus a `--json` flag to `claude plugin validate` for machine-readable CI-friendly validation output. Nested GitLab subgroup detection and `owner/repo#123` link fixes landed in v2.1.260. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **VS Code Extension — Model Picker & Session List Overhaul**: The VS Code extension received a redesigned model picker (now a flat list, older model spellings listed last) and a model pill added to the input footer with an effort row. The session list gained an "Active" quick filter, status filter menu (Needs input / Working / Completed), and hollow ring icons for sessions open in other contexts. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Claude apps gateway — OIDC & OpenTelemetry Fixes**: The Claude apps gateway gained `oidc.scope_on_refresh` for IdPs that only return `id_token` on refresh when `openid` is explicitly scoped. OpenTelemetry export was fixed (JSON vs. protobuf mismatch), and client IP handling with trusted proxies was corrected. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Bug Fixes & Performance

- **macOS 12 Monterey Launch Regression Fixed (v2.1.258)**: Claude Code v2.1.255 accidentally broke launch on macOS 12 Monterey; v2.1.258 (September 1) shipped as a rapid hotfix to restore functionality for Monterey users. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Concurrent Session Config Corruption Fixed**: A long-standing race condition caused concurrent Claude Code sessions to silently overwrite each other's changes to `~/.claude.json`, effectively losing settings mid-session. This was fixed in v2.1.259. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Fable 5.1 Prompt Cache Coverage Fixed**: Prompt caching on Fable 5.1 was not covering context after tool results, wasting cache benefits on agentic workflows. Fixed in v2.1.260, alongside the `/effort` fix that prevented effort changes from invalidating the prompt cache mid-session. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Streaming & Rendering Performance**: v2.1.257 improved rendering performance by reducing re-render work so streaming no longer slows down over long sessions, and improved prompt input responsiveness. v2.1.259 improved headless/SDK session start time (first turn begins up to 50 ms sooner) and Bash tool latency. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Security: .git Config Malicious-Hook Vulnerability Partially Mitigated**: A reported vulnerability showed that malicious `.git/config` files could cause Claude Code (and other AI coding agents including Codex and Cursor) to execute attacker-controlled code. Claude Code v2.0.34 addressed one vector by no longer running `git status` before the user approves the trust dialog. Source: [The Hacker News](https://thehackernews.com/2026/09/malicious-git-configs-can-make-claude.html)

## Community & Ecosystem

- **Usage Limits: +50% Promo Extended, Then Permanent 25% Increase**: Anthropic extended the +50% Claude Code weekly-limits promotional period a fourth time, through September 13, 2026 at 11:59 PM PT. Starting September 14, standard weekly limits will permanently rise 25% for Pro, Max, Team, and seat-based Enterprise plans — making the productivity boost a lasting baseline for all subscribers. Source: [AI Catchup](https://aicatchup.com/news/claude-code-weekly-limits-permanent-25-percent-september-2026)

- **Enterprise Frontier Safeguards (EFS) Announced**: Anthropic announced EFS, a solution combining zero data retention with misuse detection by storing data in customer-controlled cloud infrastructure rather than Anthropic's. EFS is available for Claude Code, Claude Enterprise, the Claude Platform, Amazon Bedrock, Google's Agent Platform, and Microsoft Foundry — a notable enterprise-grade compliance offering developed with over 100 customers. Source: [Releasebot / Anthropic](https://releasebot.io/updates/anthropic)

- **Commerce Agent Blueprint with Claude Code Plugin**: Anthropic launched a commerce agent blueprint featuring reference shopping and merchant agents, guardrails, live demos, and a dedicated Claude Code plugin to help teams build AI-powered shopping experiences for retail, travel, telecom, and ticketing verticals. Source: [Releasebot / Anthropic](https://releasebot.io/updates/anthropic/claude-code)

## Roadmap & Announcements

- **Self-Hosted Claude Code Environments in Public Beta**: Self-hosted Claude Code environments entered public beta for Team and Enterprise organizations, allowing cloud sessions to run on infrastructure controlled by the customer organization rather than Anthropic's. This is a significant step for enterprises with strict data-residency or compliance requirements. Source: [Claude Code What's New](https://code.claude.com/docs/en/whats-new)

- **Function Hooks Preview Announced (Not Yet Shipped)**: The @ClaudeDevs account previewed "Function Hooks" for Claude Code — a mechanism for hooking into specific tool functions — though the feature had not shipped as of the September 3–4 announcements. This signals an upcoming expansion of Claude Code's hook system beyond the existing `PreToolUse`/`PostToolUse` event model. Source: [Releasebot / Anthropic](https://releasebot.io/updates/anthropic/claude-code)

- **`ant apply` Command Shipped for Managed Agent Resources**: The `ant apply` command, which syncs Claude Managed Agent resources (skills, hooks, settings) from files in your repo, shipped alongside the Function Hooks announcement — enabling GitOps-style management of agent configurations. Source: [Releasebot / Anthropic](https://releasebot.io/updates/anthropic/claude-code)

## Key Takeaway
The most consequential development this week is the **permanent 25% weekly-limits increase** taking effect September 14 — combined with Claude Fable 5.1's 1M context window now available at improved pricing, Claude Code users on all plans will have meaningfully more headroom for long agentic sessions starting next weekend.

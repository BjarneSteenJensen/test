# Claude Code News Digest — 2026-10-26

## Overview
October 26 caps a dense release week for Claude Code, with the official changelog now at v2.1.310 (October 23) and at least 12 version bumps shipped since October 14 alone. The biggest user-facing milestones are Code Review reaching general availability for Team and Enterprise organizations and MCP Tasks & Elicitations landing in the CLI for durable, interruptible agent workflows.

## New Features & Releases

- **Code Review now Generally Available (v2.1.304)**: Anthropic promoted Code Review out of research preview for Claude Team and Enterprise plans. Reviews now complete in 6–10 minutes (roughly 3× faster than the preview), with three depth settings — Quick, Standard, and Deep — configurable per repository. Enterprise organizations can claim at least $10,000 in Code Review credits valid through January 15, 2027. Source: https://claude.com/resources/articles/code-review-is-now-generally-available

- **Auto Mode Setup wizard (v2.1.304, Oct 19)**: A new `/auto-mode-setup` slash command guides users through enabling auto mode for their project, reading session history and the project structure to pre-configure settings. The classifier model is now selectable via `CLAUDE_CODE_AUTO_MODE_MODEL`. Source: https://code.claude.com/docs/en/changelog

- **Idle compaction (v2.1.299–302)**: Conversations over 200 K tokens that sit idle for about 54 minutes now compact automatically, controlled by `CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS` and an `"idleCompaction": false` opt-out. A corresponding setting appears in `/config`. Source: https://code.claude.com/docs/en/changelog

- **Safety event telemetry (v2.1.307, Oct 21)**: A new `claude_code.safety_event` OpenTelemetry event fires on every tool call that a rule, auto-mode classifier, hook, or the sandbox stopped or prompted, enabling enterprise teams to audit automated safety interventions. Source: https://code.claude.com/docs/en/changelog

- **Monitor tool on Bedrock, Vertex, and Foundry (v2.1.310, Oct 23)**: The Monitor tool and plugin monitors are now available to users running Claude Code through AWS Bedrock, Google Vertex AI, and Azure AI Foundry, alongside cloud session and Remote Control permissions in Enterprise custom roles. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **MCP Tasks and Elicitations land in Claude Code CLI**: Anthropic shipped support for MCP Tasks and Elicitations in the Claude Code CLI, letting MCP tools start durable, interruptible jobs and request mid-task consent from the user. The Claude Agent SDK and GitHub Actions integration also received support. Full rollout to VS Code, the desktop app, and Bedrock is on the roadmap. Source: https://www.bighatgroup.com/blog/claude-weekly-2026-10-19/

- **MCP allow-rules tightened (v2.1.300, Oct 14)**: MCP allow rules now match only the specific named server (`mcp__<server>__*`) rather than applying broadly, reducing the risk of an allow rule granting unintended access across servers. HTTP MCP tool calls that fail mid-connection are also only retried for read-only or idempotent tools (v2.1.307). Source: https://code.claude.com/docs/en/changelog

- **Claude Agent SDK updates (Oct 15–16)**: The Python Agent SDK reached v0.2.168 and the TypeScript/npm package reached v0.3.302, with `autoCompactWindow` added to `AgentDefinition` for subagent context management. Fork-style subagents are now on by default outside the terminal. Claude Max and Team plan subscribers have monthly API credits that cover SDK usage. Source: https://www.gradually.ai/en/changelogs/claude-agent-sdk/

- **VS Code extension: TLS proxy warning (v2.1.309, Oct 22)**: The VS Code extension now logs a clear warning when extension requests fail certificate verification, helping users behind TLS-inspecting corporate proxies diagnose connection issues without digging through raw error logs. Source: https://code.claude.com/docs/en/changelog

## Bug Fixes & Performance

- **v2.1.300 mega-fix (Oct 14, 131 issues)**: The largest single-release patch of the month addressed 131 issues, with many fixes targeting repeated or lost turns in cloud and headless sessions. Large requests to `api.anthropic.com` now use gzip compression by default (`CLAUDE_CODE_GZIP_REQUEST_BODIES=0` to opt out), reducing bandwidth for heavy tool-call payloads. Source: https://code.claude.com/docs/en/changelog

- **v2.1.309 sandbox hardening (Oct 22, ~62 issues)**: Addressed sandbox and permission-check gaps and a batch of Claude Tag fixes. `sed -i` was reclassified as a standard Bash command, and dangerous `rm` commands in bypass mode are now denied with a rewrite hint rather than silently allowed. Source: https://code.claude.com/docs/en/changelog

- **Gateway compatibility fixes (v2.1.305, Oct 20)**: Fixed a regression where every request failed when a gateway rejected the `effort-2025-11-24` beta header value, restoring compatibility with stricter enterprise API gateways. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Barclays targets 50% developer adoption**: Barclays announced on October 1 it expects Claude Code to reach 50% of its software developers by end of 2026, up from a smaller pilot, citing productivity gains from agentic coding workflows. Source: https://releasebot.io/updates/anthropic/claude-code

- **Cognizant expands partnership for Flowsource**: Cognizant broadened its partnership with Anthropic to embed Claude Code inside its Flowsource enterprise development platform, targeting large-scale enterprise software delivery teams. Source: https://aimaker.substack.com/p/claude-code-updates-october-2026

- **Craft suite: open-source apps with MCP servers**: A guide published October 13 covers Craft, a set of open-source productivity apps each bundling its own MCP server for one-command Claude Code integration, representing a growing pattern of MCP-first app design. Source: https://pasqualepillitteri.it/en/news/23613/craft-suite-mcp-servers-claude-code-guide

- **Community Visual Studio 2026 extension**: An unofficial community extension (`firish/claude_code_vs`) brings Claude Code to Visual Studio 2026 with native diff accept/reject, a live debugger Claude can drive autonomously, Roslyn code navigation, and Test Explorer integration. Source: https://github.com/firish/claude_code_vs

## Roadmap & Announcements

- **Claude Duet enters research preview**: Anthropic launched Claude Duet, a proactive background agent app, in a waitlist-only research preview for Pro and Max subscribers in the US. Duet is described as a persistent agent that surfaces suggestions and takes actions without an explicit prompt, complementing Claude Code's on-demand coding sessions. Source: https://releasebot.io/updates/anthropic

- **API version 2026-10-21 released (v2.1.307)**: Anthropic published a new API version dated `2026-10-21`, accessible in Claude Code via `/claude-api api-version`. This version is the default for new `claude -p` sessions going forward. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
Code Review becoming generally available — 3× faster, with tunable depth, and backed by enterprise credits — is the most impactful Claude Code milestone this week, signaling that AI-assisted PR review is graduating from experiment to standard practice for Team and Enterprise teams.

# Claude Code News Digest — 2026-08-06

## Overview
Today's headline is Claude Code v2.1.223, released on August 6, with several critical security patches closing Bash permission bypass vulnerabilities and a sandbox escape via dynamic imports. Alongside the security work, the release adds `owner/*` wildcard entries for marketplace management and improves the `/code-review` command with effort levels and a persistent alias. Anthropic also extended the 50% weekly usage boost for Claude Code subscribers through August 19.

## New Features & Releases

- **v2.1.223 Released (August 6)**: Today's release adds `"owner/*"` wildcard support in `strictKnownMarketplaces` and `blockedMarketplaces` for bulk org-wide marketplace allow/block rules. It also adds a `/teleport` hint in cloud sessions pointing users to `claude --teleport <session-id>` to continue locally. Source: https://code.claude.com/docs/en/changelog

- **`/code-review` Overhaul**: `/review` is now an alias for `/code-review`, which can review the current diff or a specific PR. Effort levels (`/code-review high`, `/code-review ultra`) are now sticky — you only set them once per session. Source: https://code.claude.com/docs/en/changelog

- **Context Window Auto-Compaction Change**: `CLAUDE_CODE_DISABLE_1M_CONTEXT` now applies to all Claude models that natively support a 1M context window, capping them at 200K via auto-compaction. Auto-compact also now keeps sessions on unrecognized model IDs within the assumed context window. Source: https://code.claude.com/docs/en/changelog

- **v2.1.222 (August 4) — Worktree Isolation Fix**: Patched a bug where worktree-isolated sessions (and their subagents) could run destructive git commands against the main checkout. Source: https://code.claude.com/docs/en/changelog

- **v2.1.221 (August 3) — Focus View for VS Code**: Added a chat-menu Focus view (toggled with `Ctrl+Alt+F` or "Claude Code: Toggle Focus view") that collapses tool activity into compact per-turn summaries with a live running-tool indicator. Source: https://www.havoptic.com/tools/claude-code

## Integrations & Extensions

- **Sandbox Credential Masking (Linux/WSL)**: Added `mode: "mask"` for sandbox credential files — sandboxed commands read a sentinel copy while the sandbox proxy substitutes the real value on egress. Also added permission prompts for Docker commands (including the Podman shim) carrying daemon-redirect flags. Source: https://releasebot.io/updates/anthropic/claude-code

- **Subagent Model Restriction Warnings**: Workflow agents, forked skills, slash commands, and resumed background agents now emit a warning when their requested subagent model is restricted, so configuration mismatches surface immediately rather than silently falling back. Source: https://code.claude.com/docs/en/changelog

- **VS Code Extension at 2M+ Installs**: The official Anthropic VS Code extension — which provides inline diff previews, automatic TypeScript/ESLint error reading, and one-click file navigation — has passed 2 million installs. Source: https://explainx.ai/blog/claude-code-vscode-ide-extension-setup-guide-2026

## Bug Fixes & Performance

- **Critical Security Patches in v2.1.223**: Fixed a Bash permission bypass where crafted commands could hide parts from permission checks; fixed bypasses using tabs or invisible Unicode characters; fixed workflow scripts using dynamic `import()` to escape the sandbox; and fixed `agent definition bypassPermissions` ignoring the org-level bypass-permissions disable policy. Source: https://code.claude.com/docs/en/changelog

- **Gateway Model Discovery Fixed**: Fixed an issue where gateway model discovery hid Claude models with provider-prefixed IDs (e.g., `vertex_ai/claude-*`, `bedrock/anthropic.claude-*`), and fixed `modelOverrides` keys that aren't Anthropic model IDs being treated as canonical model IDs. Source: https://code.claude.com/docs/en/changelog

- **Session and Agent Reliability**: Fixed resumed sessions failing every turn with malformed diagnostics attachments; fixed forked background agents getting stuck in an "already resuming" state during parent prompt rebuild; and fixed a rare hang when parsing unusual `git push` output. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Claude Agent SDK — Latest Release August 4**: The Claude Agent SDK (formerly Claude Code SDK, renamed in September 2025) released its latest update on August 4, adding `reasoningEffort` to the `subagentStatusLine` payload so custom agent rows can render model and effort, and fixing SDK MCP servers registered via initialize control requests to start connecting earlier. Requires Python ≥3.10; currently in Alpha. Source: https://pypi.org/project/claude-agent-sdk/

- **MCP Tool Search Maturing**: Anthropic's deferred schema loading for MCP Tool Search (shipped January 2026) continues to gain adoption — third-party MCP servers that previously shipped all tool schemas eagerly are gradually migrating to on-demand loading, reducing context overhead for Claude Code sessions with large MCP server sets. Source: https://www.explorium.ai/blog/data-enrichment/mcp-enrichment-setup-time-and-credit-cost-for-claude-code-2026-for-revops-teams/

## Roadmap & Announcements

- **Enterprise Inference Hooks (Beta)**: Anthropic launched inference hooks in beta for Enterprise customers, providing real-time DLP enforcement across chat, Claude Code, Cowork, and more. Compliance teams can now inspect and enforce policy on every prompt and tool call response before it reaches the model — covering the full Claude Code agentic surface, not just the API. Source: https://www.anthropic.com/news

- **50% Usage Boost Extended Through August 19**: Anthropic extended the temporary 50% weekly usage boost for Claude Code subscribers through August 19, 2026. The boost was originally introduced as a temporary measure and has been extended several times. Source: https://releasebot.io/updates/anthropic/claude-code

- **Claude Opus 5 Now Default Opus Model**: Opus 4.7 has been removed from fast mode; `/fast` now applies to Opus 5 and Opus 4.8. Claude Code's model picker has been updated to highlight only the newest model's name, and the current default workflow size is shown in the running-workflow status line. Source: https://releasebot.io/updates/anthropic/claude-code

## Key Takeaway
The v2.1.223 release is the most important Claude Code development today: it closes multiple security vulnerabilities — including a Bash permission bypass exploitable via crafted commands or invisible Unicode, and a sandbox escape via dynamic imports in workflow scripts — making it an urgent update for all Claude Code users.

# Claude Code News Digest — 2026-08-02

## Overview
The biggest recent story is the July 24 launch of Claude Opus 5 as Claude Code's new default top-tier model, doubling Opus 4.8's benchmark performance at the same $5/$25/MTok price point. With two deadlines approaching this week — the Claude Opus 4.1 model retirement on August 5 and the legacy Workbench shutdown on August 17 — developers should review their dependencies before those cutoffs.

## New Features & Releases

- **Claude Opus 5 now default in Claude Code (July 24)**: Anthropic launched `claude-opus-5`, a step-change over Opus 4.8, with a 1M-token context window, 128k max output tokens, thinking on by default, and full effort-ladder support (`low` through `max`). It replaces Opus 4.8 as the default model on Max, Team Premium, and API accounts at the same pricing ($5/$25 per MTok). Note: disabling thinking is now blocked at `xhigh`/`max` effort — a breaking change from Opus 4.8. Source: https://platform.claude.com/docs/en/release-notes/overview

- **Artifacts call live MCP connectors (Week 29, July 13–17, v2.1.207–212)**: Published Claude Code artifacts can now pull live data through each viewer's own MCP connectors on every page load, so dashboards and reports stay current rather than showing a session snapshot. Public sharing links, editor roles for Team/Enterprise, and artifacts from Claude Tag sessions also shipped in this release. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **Screen reader mode (Week 29)**: A new `--ax-screen-reader` flag (or `CLAUDE_AX_SCREEN_READER` env var / `axScreenReader` setting) replaces the visual terminal interface with plain, sequential text output compatible with VoiceOver, NVDA, and other screen readers. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **`/fork` now opens a background session (Week 29)**: `/fork` copies the current conversation into a new background session with its own row in `claude agents`, letting you keep working in the original. The previous in-session behavior is available as `/subtask`. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **50% weekly usage boost extended through August 19**: Anthropic extended the temporary 50% usage boost for Claude Code Pro and Max subscribers, originally set to expire earlier, through August 19, 2026. Source: https://www.anthropic.com/news

## Integrations & Extensions

- **MCP 2026-07-28 spec brings stateless core and hardened auth**: Anthropic published a new MCP specification revision (2026-07-28) introducing a stateless core, standardized extensions, and improved authentication flows. The spec lowers integration friction for third-party developers and is being rolled out to Claude Code's connector ecosystem. Source: https://claude.com/blog/bringing-mcp-2026-07-28-to-claude

- **Auto mode no longer requires opt-in on third-party clouds (Week 29)**: `CLAUDE_CODE_ENABLE_AUTO_MODE` is no longer needed on Amazon Bedrock, Google Cloud's Agent Platform, or Microsoft Foundry — auto mode is on by default and can be disabled by administrators with `disableAutoMode`. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **Long MCP tool calls auto-background (Week 29)**: MCP tool calls running longer than two minutes now move to the background automatically so the session stays usable. The threshold is tunable via `CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS`. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **Agent SDK subscription credits (since June 15)**: The Claude Agent SDK (formerly Claude Code SDK, renamed March 2026) now includes monthly credits bundled with subscription plans: $20 (Pro), $100 (Max 5x), $200 (Max 20x), making it easier for subscribers to build automated workflows. Source: https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan

- **Mid-conversation tool changes in beta**: Adding or removing tools between conversation turns while preserving prompt cache is now in beta on Claude Fable 5, Mythos 5, Opus 4.8, and Opus 5 — include the `mid-conversation-tool-changes-2026-07-01` beta header. Source: https://platform.claude.com/docs/en/release-notes/overview

## Bug Fixes & Performance

- **Session-wide caps prevent runaway loops (Week 29)**: WebSearch calls and subagent spawns are now each capped at 200 per session by default, guarding against infinite loops in automated workflows. Both limits are tunable via `CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION` and `CLAUDE_CODE_MAX_SUBAGENTS_PER_SESSION`. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **"Always allow" rules persist across worktrees (Week 29)**: Permission rules set to "always allow" now save at the repository root rather than per-worktree, so approvals granted in one git worktree carry over to all worktrees in the same repo across sessions. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **Fast mode removed for Opus 4.7 (July 24)**: Requests to `claude-opus-4-7` with `speed: "fast"` now return an error. Migrate to Opus 5 or Opus 4.8 to continue using fast mode; `/fast` in Claude Code now applies to Opus 5 and Opus 4.8. Source: https://platform.claude.com/docs/en/release-notes/overview

- **Elapsed-time counter on long tool calls (Week 29)**: The collapsed tool summary line now shows a live elapsed-time ticker during long-running tool calls, so stuck-looking operations are visibly progressing. Source: https://code.claude.com/docs/en/whats-new/2026-w29

## Roadmap & Announcements

- **Legacy Workbench retires August 17, 2026 (IMMINENT)**: The legacy Claude Console Workbench at platform.claude.com/workbench shuts down on August 17, 2026, along with the experimental prompt generation/improvement/templatize APIs (`/v1/experimental/generate_prompt`, etc.). Export any saved prompts, variables, and evals from the banner or Organizational Settings before the deadline. Source: https://platform.claude.com/docs/en/release-notes/overview

- **Claude Opus 4.1 retirement on August 5, 2026 (THIS WEEK)**: `claude-opus-4-1-20250805` will return errors from August 5 onward. Migrate to Claude Opus 4.8 before Tuesday. Source: https://platform.claude.com/docs/en/release-notes/overview

- **Claude Sonnet 5 promotional pricing ends August 31**: Introductory pricing of $2/$10 per MTok for `claude-sonnet-5` reverts to standard $3/$15 on September 1, 2026. Plan budget accordingly before the end of the month. Source: https://platform.claude.com/docs/en/release-notes/overview

- **Corporate launcher support (Week 29)**: A new `CLAUDE_CODE_PROCESS_WRAPPER` env var / `processWrapper` setting lets enterprises route all Claude Code subprocess creation through a required wrapper binary, supporting managed deployment environments with strict process controls. Source: https://code.claude.com/docs/en/whats-new/2026-w29

## Key Takeaway
Claude Opus 5 is the most significant Claude Code development of the past two weeks, offering doubled benchmark performance at unchanged pricing — but developers have two urgent deadlines this week: Claude Opus 4.1 retires on August 5 and the legacy Workbench (plus experimental prompt APIs) shuts down on August 17, both requiring migration action now.

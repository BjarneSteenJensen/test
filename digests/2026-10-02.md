# Claude Code News Digest — 2026-10-02

## Overview
The headline development this week is the release of Claude Code v2.1.287, which ships Claude Mods — a TypeScript plugin system that lets users and teams deeply customize how Claude Code behaves, from rewriting prompts to replacing parts of the UI. Alongside this, MCP tooling continues to mature with protocol and UX improvements, and Anthropic announced expanded enterprise adoption with Barclays.

## New Features & Releases

- **Claude Code v2.1.287 — Claude Mods**: Released October 1, 2026, this version introduces *mods*, a TypeScript-based plugin capability that allows users to intercept and modify Claude Code's behavior at a deep level. A mod can block, rewrite, or retry tool calls; approve or deny permission requests; redact secrets from tool output before Claude reads them; and edit or replace parts of the Claude Code interface. Mods ship inside plugins, making them easy to install, share via the plugin directory, and hot-reload during active sessions. Source: https://code.claude.com/docs/en/changelog

- **"You Should Know" Built-in Mod**: Bundled with v2.1.287, this opt-in side agent watches your session and flags issues or context that you or Claude might miss. Enable it with `/plugin enable cc-plugin-you-should-know@builtin`. Source: https://github.com/anthropics/claude-code/releases

- **Claude Code v2.1.286 — Permission UX & VSCode Bookmarks**: Released September 30, 2026, this version adds "2 of 5" counting to permission prompts for better visibility into multi-step approvals, along with mouse support for list rows in fullscreen mode. The VSCode extension gained bookmarks, question tracking, and option previews. Source: https://github.com/anthropics/claude-code/releases

## Integrations & Extensions

- **MCP URL Prompts (2025-11-25 Protocol)**: v2.1.287 adds support for MCP servers on the 2025-11-25 protocol revision, enabling sign-in flows and URL-based prompts directly from MCP servers within Claude Code. The `/mcp` tool list was also improved to show more tools at once and now marks organization-blocked tools with a warning icon. Source: https://code.claude.com/docs/en/changelog

- **MCP Tool Results as Files**: An earlier October build (v2.1.283) brought a change so that images returned by MCP tools are now automatically saved to files, making them usable by other tools like Bash and Read. Source: https://code.claude.com/docs/en/mcp

- **Visual Studio 2026 Community Extension**: A community-built, unofficial extension (firish/claude_code_vs) brings Claude Code to Visual Studio with a native diff with accept/reject, a live debugger Claude can drive autonomously, Roslyn code navigation, and Test Explorer integration. Source: https://github.com/firish/claude_code_vs

## Bug Fixes & Performance

- **Critical Security Fix — `rm` Safeguard Bypass**: v2.1.287 patches a bug where dangerous `rm` commands lost their safety guardrails when redirecting to `~` or using wildcards. Source: https://github.com/anthropics/claude-code/releases

- **MCP Credential Leak Fixed**: A bug causing MCP error messages to inadvertently expose credential values in output has been fixed in v2.1.287. Source: https://code.claude.com/docs/en/changelog

- **Remote Control Reconnection**: Fixed a reconnection issue in Remote Control that was causing up to minute-long message delays after network interruptions. Improved cloud session file delivery with retries for timeouts and network errors. Source: https://github.com/anthropics/claude-code/releases

- **SDK Responsiveness & Tool Heartbeats**: Fixed tool heartbeats and improved SDK session responsiveness, along with specific fixes for stdio MCP servers and MCP progress notifications. Source: https://code.claude.com/docs/en/changelog

- **Accessibility**: Screen reader mode fixes covering search boxes, approval prompts, and diff display. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Cowork Cloud Tasks (Upcoming — October 6)**: Starting October 6, 2026, new Cowork tasks will run in the cloud. The "Only on your computer" option in Settings will be removed for Pro and Max plans, signaling a shift toward cloud-native task execution. Source: https://support.claude.com/en/articles/13345190-get-started-with-claude-cowork

- **Claude Agent SDK — Plugin Bundles**: The Claude Agent SDK (formerly Claude Code SDK) continues to expand; plugins can now bundle MCP servers, skills, LSPs, commands, hooks, and agents into a single installable package, distributable via GitHub. Source: https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan

- **OpenTelemetry Enhancement**: v2.1.287 adds `prompt_text` to the `user_prompt` OpenTelemetry event, giving observability pipelines richer data about Claude Code interactions. Source: https://github.com/anthropics/claude-code/releases

## Roadmap & Announcements

- **Barclays Scales Claude Across Global Operations**: Anthropic announced on October 1 that Barclays is expanding Claude deployment across its global operations, targeting 50% developer adoption by year-end. While not Claude Code-specific, this signals growing enterprise appetite for Anthropic's developer tooling, which includes Claude Code. Source: https://www.anthropic.com/news

- **Claude for Government (Early Access)**: Anthropic is rolling out Claude for Government with FedRAMP High authorization for federal and state agencies. Claude Code CLI is included in the early access program. Source: https://releasebot.io/updates/anthropic/claude

## Key Takeaway
The launch of Claude Mods in v2.1.287 is the most significant Claude Code development this week — it opens a new extensibility layer that lets teams programmatically control Claude's behavior, intercept tool calls, redact sensitive data, and customize the UI, moving Claude Code closer to a fully programmable AI development environment.

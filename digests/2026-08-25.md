# Claude Code News Digest — 2026-08-25

## Overview
Claude Code Week 34 (Aug 17–21) shipped the `/design` research preview, bringing editable artboard workflows into the CLI and Desktop, alongside a new "Concise" output style that leads with results. On the infrastructure side, the Anthropic Python SDK hit v1.0 on August 20, and auto-continue after usage-limit resets is now live across all supported plans.

## New Features & Releases

- **`/design` Research Preview (v2.1.234–v2.1.239 / Week 34)**: The new `/design` skill lets Claude draft editable artboards in Claude Design directly from the CLI or Desktop app. It is built on Artifacts, so the output is a live, shareable page rather than a static mockup. Source: https://code.claude.com/docs/en/whats-new

- **"Concise" Built-in Output Style (v2.1.237, Aug 20)**: A new Concise output style instructs Claude to lead with the result and skip preamble, without reducing work quality. Users can activate it from `/config` or the model menu. Source: https://code.claude.com/docs/en/changelog

- **Auto-Continue After Usage Limits (v2.1.234, Aug 17)**: Claude Code now automatically resumes an interrupted session the moment a usage-limit window resets — no need to re-run the prompt. The Desktop app exposes this as an "Auto-continue when limits reset" checkbox. Source: https://code.claude.com/docs/en/whats-new

- **`ANTHROPIC_DEFAULT_MODEL` Env Var (v2.1.236, Aug 19)**: A new environment variable sets the model that all new Claude Code sessions start on, useful for teams that want to lock a specific model version across CI and development environments. Source: https://code.claude.com/docs/en/changelog

- **Optional Spellcheck (v2.1.235, Aug 18)**: A new `spellcheck` setting integrates with any installed `aspell`, `hunspell`, or `ispell` to underline typos in the prompt input. Source: https://code.claude.com/docs/en/changelog

- **`/claude-api upgrade` Helper (v2.1.239, Aug 21)**: A new sub-command migrates Python projects from `anthropic` 0.x to 1.x automatically, generating the necessary import and API call changes. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **GitLab Merge Request Badge (v2.1.234, Aug 17)**: The Claude Code footer now shows a GitLab MR badge (MR !N) with draft/pending/green states when working inside a GitLab-tracked repository, matching the existing GitHub PR integration. Source: https://code.claude.com/docs/en/changelog

- **Anthropic Python SDK v1.0 (Aug 20)**: The SDK's HTTP layer moved from `httpx` to `httpx2`, a maintained API-compatible fork. The release removes long-deprecated surface including the legacy Text Completions API and the `temperature`/`top_p`/`top_k` shortcuts on Messages methods. Python 3.10+ is now required. Source: https://platform.claude.com/docs/en/release-notes/overview

- **Remote Control Device Cards (Week 34)**: Any machine running `claude remote-control` now shows as a device card in the Claude Code mobile tab, letting users start or resume a terminal session on that machine directly from their phone. Source: https://code.claude.com/docs/en/whats-new

- **Alpine/musl Clipboard & Audio Support (v2.1.239, Aug 21)**: Alpine Linux builds now support native image paste, clipboard access, and audio capture — previously limited to glibc-based distributions. Source: https://code.claude.com/docs/en/changelog

- **Proxy Auth Helpers (v2.1.238, Aug 20)**: New `--proxy-authorization-command` and `--proxy-authorization-file` flags let Claude Code mint credentials for egress proxies that require per-request tokens. Source: https://code.claude.com/docs/en/changelog

## Bug Fixes & Performance

- **Unbounded Memory Growth Fixed (v2.1.238, Aug 20)**: A memory leak that caused long interactive sessions to grow without bound has been resolved. Source: https://code.claude.com/docs/en/changelog

- **JetBrains IDE 5-Second Pause Fixed (v2.1.239, Aug 21)**: Edit and Write calls were pausing approximately five seconds in JetBrains IDE terminal integrations; the root cause has been patched. Source: https://code.claude.com/docs/en/changelog

- **Bedrock Proxy Streaming Fixed (v2.1.239, Aug 21)**: Bedrock streaming connections behind proxies that strip the `Content-Type` header were silently failing; the fix adds header restoration before the stream is handed to the decoder. Source: https://code.claude.com/docs/en/changelog

- **WebFetch Cache Expiry Fixed (v2.1.239, Aug 21)**: WebFetch was retaining stale content across sessions; the cache now clears every 15 minutes as documented. Source: https://code.claude.com/docs/en/changelog

- **MCP Elicitation Dialog Clipping Fixed (v2.1.239, Aug 21)**: MCP elicitation forms were being clipped in fullscreen mode and for URLs longer than 4,096 characters; both cases now render correctly. Source: https://code.claude.com/docs/en/changelog

- **Prompt Cache Invalidation Fixed (v2.1.235, Aug 18)**: Prompt cache was being incorrectly invalidated on language server disconnects, causing unnecessary re-processing of large contexts. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **50% Usage Limit Boost Extended to Aug 31**: Anthropic extended the 50% increase to weekly Claude Code limits through August 31, 2026 for Pro, Max, Team, and seat-based Enterprise plans. Source: https://code.claude.com/docs/en/whats-new

- **Self-Hosted Environments in Public Beta**: Teams on Team and Enterprise plans can now run Claude Code cloud sessions on their own infrastructure with internal network access, custom tooling, and compliance controls. Source: https://code.claude.com/docs/en/whats-new

- **`notify_when_idle` Cross-Session Messaging (v2.1.236, Aug 19)**: The cross-session `SendMessage` tool gained a `notify_when_idle` option that sends a one-shot notification when the target session goes idle — useful for chaining multi-agent workflows without busy-waiting. Source: https://code.claude.com/docs/en/changelog

## Roadmap & Announcements

- **Auto Mode Now Default on Pro, Max, and Team (since Aug 14)**: Auto mode became the default permission mode for all new sessions on Pro, Max, and Team plans. Instead of prompting at each step, Claude proceeds unless an action is determined to be irreversible, destructive, or aimed outside the current environment. Source: https://code.claude.com/docs/en/whats-new

- **`keybindingFlavor` Setting (v2.1.238, Aug 20)**: A new `keybindingFlavor` config key accepts `"readline"` to enable Bash-style word deletion (Ctrl+W) and other readline bindings, signalling Anthropic's intent to expand keyboard customization options. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
The most significant development this week is the `/design` research preview, which expands Claude Code's scope from a coding assistant into an interface-design tool — users can go from a text description or screenshot to an editable artboard without leaving the terminal. Combined with the Concise output style and auto-continue, August 2026 marks Claude Code's clearest push yet toward end-to-end product development in a single tool.

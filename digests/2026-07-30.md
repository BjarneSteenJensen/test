# Claude Code News Digest — 2026-07-30

## Overview
The biggest Claude Code story this week is the launch of the MCP 2026-07-28 specification, the largest update to the Model Context Protocol since its release, moving to a stateless core and adding OAuth/OIDC authorization and private-network tunnels. Separately, a hidden tracker targeting users in Chinese timezones was discovered and removed earlier this month, drawing significant community attention. On the feature side, published artifacts can now pull live data through MCP connectors, and Claude Opus 5 is the new default Opus model.

---

## New Features & Releases

- **Claude Opus 5 Now Default Opus Model**: v2.1.219 added `claude-opus-5` as the default Opus model, with a 1M-token context window and fast mode available. `/fast` now applies to Opus 5 and Opus 4.8; Opus 4.7 has been removed from fast mode. Source: https://code.claude.com/docs/en/whats-new

- **Artifacts Call MCP Connectors (Week 29, v2.1.207–v2.1.212)**: Published artifacts can now pull live data and take actions through each viewer's own MCP connectors when the page loads — so a dashboard stays up to date without the creator re-running a session. Viewers approve connector access on first load. This update also added public sharing links and editor roles for Team and Enterprise plans. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **Screen Reader Mode**: `claude --ax-screen-reader` (or env var `CLAUDE_AX_SCREEN_READER`) replaces the visual terminal UI with plain, linear text output compatible with VoiceOver and NVDA, making Claude Code fully accessible for screen reader users. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **In-App Browser on Desktop (Week 28, v2.1.202–v2.1.206)**: Claude Code desktop gets a built-in browser, enabling Claude to pull up documentation or designs and interact with pages in the same flow as local dev server previews. `/doctor` (alias `/checkup`) was also added as a full setup diagnostic that can fix issues automatically. Source: https://code.claude.com/docs/en/whats-new/2026-w28

- **Subagent Nesting Depth Increased**: Subagents can now spawn nested subagents up to depth 3 by default (previously depth 1). Background chains are capped at five levels in background mode. Source: https://code.claude.com/docs/en/whats-new

- **Session-Wide Safety Caps**: WebSearch calls and subagent spawns now default to 200 per session to prevent runaway loops, tunable via `CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION` and `CLAUDE_CODE_MAX_SUBAGENTS_PER_SESSION`. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **50% Higher Usage Limits Promotion**: Anthropic extended a limited-time promotion giving Pro, Max, Team, and eligible Enterprise users 50% higher weekly Claude Code limits; the promotion ran through July 19, 2026. Source: https://www.helpnetsecurity.com/2026/07/13/claude-code-weekly-limits-promotion-extended/

## Integrations & Extensions

- **MCP 2026-07-28 Specification Launched**: The Model Context Protocol received its largest update since launch on July 28, moving to a stateless request/response core that enables deployment on serverless and edge infrastructure. The new spec includes stronger OAuth and OIDC authorization, versioned extensions for Apps and Tasks, and MCP Tunnels (research preview) that connect Claude to servers inside private networks with no inbound firewall rules or public endpoints required. All four Tier 1 SDKs (TypeScript, Python, Go, C#) support the new spec. Source: https://claude.com/blog/bringing-mcp-2026-07-28-to-claude

- **Auto Mode on Third-Party Platforms**: Auto mode no longer requires the `CLAUDE_CODE_ENABLE_AUTO_MODE` environment variable on Amazon Bedrock, Google Cloud's Agent Platform, and Microsoft Foundry. Administrators can disable it via the `disableAutoMode` setting. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **MCP Tool Calls Auto-Background After 2 Minutes**: MCP tool calls running longer than 2 minutes now automatically move to the background so the main session stays usable. The threshold is configurable via `CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS`. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **VS Code Extension Improvements**: As of v2.1.219 (July 21), Claude Code IDE extensions added emoji shortcode autocomplete, clearer transcript write warnings, and tighter controls for subagents, budgets, and background sessions. The extension supports VS Code 1.98.0+, Cursor, and other VS Code forks. Source: https://releasebot.io/updates/anthropic/claude-code

- **Agent SDK Billing Change**: Starting June 15, 2026, Claude Agent SDK and `claude -p` (non-interactive/headless) usage no longer counts toward Claude plan weekly limits. It now draws from a dedicated monthly credit per plan that does not roll over. Source: https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan

## Bug Fixes & Performance

- **v2.1.220 (July 24) — Stability Release**: The latest release focuses on bug fixes and reliability improvements, including fixing killed background sessions leaving a permanent git worktree lock and fixing terminal freezing/keystroke lag when streaming responses with very long lists, tables, or code blocks. Source: https://releasebot.io/updates/anthropic/claude-code

- **Always-Allow Rules Now Persist Across Worktrees**: Permission rules saved as "always allow" are now stored at the repository root, so approvals granted in a git worktree persist across sessions and all worktrees for that repo. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **Elapsed-Time Counter in Tool Summary**: The collapsed tool summary line now shows a live elapsed-time counter during long-running tool calls, replacing the appearance of being "stuck." Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **Windows Stability Fixes**: v2.1.219 (July 21) included a wave of fixes for updates, security, accessibility, resume flows, telemetry settings, and Windows stability. Source: https://releasebot.io/updates/anthropic/claude-code

## Community & Ecosystem

- **Hidden Tracker Controversy Resolved**: An independent developer ("Thereallo") discovered in late June that Claude Code's JavaScript bundle contained a hidden tracking marker triggered when a user's timezone was set to `Asia/Shanghai` or `Asia/Urumqi`. Anthropic engineer Thariq Shihipar acknowledged the code on X, calling it a March experiment to prevent account abuse by unauthorized resellers and protect against model distillation. Anthropic stated stronger mitigations had already made the tracker obsolete and removed it in the July 1 release. Source: https://decrypt.co/372977/anthropic-removes-hidden-claude-code-tracker-privacy

- **MCP Surpasses 400M Monthly SDK Downloads**: MCP has seen a 4× increase in SDK downloads this year, surpassing 400M monthly downloads and cementing its position as the de facto standard for connecting AI agents to external tools and services. Source: https://claude.com/blog/bringing-mcp-2026-07-28-to-claude

- **Anthropic Launches Four Official Claude Certifications**: On July 8, 2026, Anthropic introduced four official certifications delivered via Pearson VUE with online proctoring and digital credentials — relevant for developers building on the Claude ecosystem including Claude Code. Source: https://blog.mean.ceo/anthropic-claude-news-july-2026/

- **Claude Cowork Expands to Web and Mobile**: Claude Cowork — Anthropic's Claude Code-style agent for general knowledge work — became available on web and mobile for Max subscribers starting July 7, 2026, extending agentic capabilities beyond the developer terminal. Source: https://techcrunch.com/2026/07/07/the-coding-agent-wars-are-spilling-into-the-rest-of-the-office-claude-cowork/

## Roadmap & Announcements

- **MCP 2026-07-28 as the New Industry Standard**: Anthropic is positioning the new stateless MCP spec as the foundation for the next phase of agent interoperability. The introduction of MCP Tunnels (research preview) for private-network connectivity signals a push into enterprise infrastructure. Source: https://claude.com/blog/bringing-mcp-2026-07-28-to-claude

- **Claude Sonnet 5 Now Default for Pro/Team/Enterprise**: As of Week 27 (June 29 – July 3), Claude Sonnet 5 became the default model for Pro, Team Standard, and Enterprise subscription seats — featuring a native 1M-token context window and adaptive thinking on by default. Source: https://code.claude.com/docs/en/whats-new/2026-w27

- **`/fork` Redesign**: The `/fork` command now copies a conversation into a full background session with its own row in `claude agents`, enabling genuine parallel workstreams. The previous in-session fork behavior has been renamed `/subtask`. Source: https://code.claude.com/docs/en/whats-new/2026-w29

---

## Key Takeaway
The launch of the **MCP 2026-07-28 stateless spec** on July 28 is the week's most consequential development — by enabling serverless deployment of MCP servers and adding private-network tunnels, it dramatically lowers the barrier for enterprises to connect Claude Code to internal tools without exposing infrastructure to the public internet.

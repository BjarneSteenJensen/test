# Claude Code News Digest — 2026-09-16

## Overview
September 16, 2026 caps a busy release sprint for Claude Code: versions 2.1.271–2.1.273 landed on September 14–15 with fast mode in Remote sessions, per-command domain sandboxing, and a critical security patch for subshell permission bypass. Anthropic also made the weekly usage limit increase permanent (25% above standard), and Boris Cherny of the Claude Code team announced that "Claude Mods are landing now" — signalling a new era of deep customization.

---

## New Features & Releases

- **v2.1.273 — Remote fast mode, per-command sandboxing, gateway headers (Sept 15)**: The latest release adds fast mode support in Claude Code Remote sessions (cloud and self-hosted), mouse support for the `/config` panel in fullscreen, and per-command `allowed_domains` for Bash, PowerShell, and Monitor in auto mode with sandboxing — hosts a command needs are reviewed with it and opened for it alone. New LLM gateway hint headers (`x-claude-code-request-class`, `x-claude-code-agent-type`) and session forking from Remote Control sessions also shipped. Source: [https://code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.271 — Markdown artifacts as styled pages, omitClaudeMd (Sept 14)**: Markdown files published as artifacts now render as styled document pages with a title header, document typography, and syntax-highlighted code blocks. Agent frontmatter gained `omitClaudeMd` to run sub-agents without loading `CLAUDE.md`. The `multiplier` field in `modelPricing` managed settings can now go up to 10. Source: [https://code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.269 — Plugin eval, output styles, diff panel, concurrent agents (Sept 11)**: `claude plugin eval` runs a plugin eval suite against Claude Code and produces reproducible JSON + HTML reports. `/output-style [name]` lets users list and switch output styles in any session type. A new `/diff` panel shows uncommitted changes in fullscreen. `CLAUDE_CODE_WORKFLOW_MAX_CONCURRENT_AGENTS` (range 1–256) raises the concurrent agent ceiling in Workflow scripts. Source: [https://code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.261 — `/skill-doctor`, output-size caps, `/diff` panel (Sept 4)**: `/skill-doctor` identifies unused loaded skills in a session. `bashOutputMaxChars` and `taskOutputMaxChars` settings now cap tool output (up to 128K). `--append-subagent-system-prompt-file` supports large prompts in headless sub-agents. `/cost` now reports likely causes of prompt-cache misses. Source: [https://code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.259 — Managed MCP servers, GitLab support, unattended headless (Sept 2)**: `managedMcpServers` managed setting lets organizations deploy HTTP/SSE MCP servers to all users without per-user config. `--permission-prompts none` enables fully unattended headless operation. GitLab merge request recognition (`glab mr` commands) is now built in. Source: [https://code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

## Integrations & Extensions

- **VS Code: Agent map, Hooks dialog, Permission rules dialog (v2.1.269, Sept 11)**: The VS Code extension gained an agent map showing running sub-agents with per-agent cards and full transcripts, live progress rows for sub-agents in Focus view, a Hooks dialog for viewing and editing hooks across user/project/local settings, and a Permission rules dialog for managing allow/deny rules — all without leaving the IDE. Source: [https://code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Unity official Claude Code plugin launches (Sept 10)**: Unity shipped an official, first-party Claude Code plugin distributed through Claude's own plugin directory, bundling 29 native Unity skills behind a single one-command, no-configuration install. This is the first major game-engine vendor to ship a first-party plugin. Source: [https://www.explainx.ai/blog/claude-code-unity-mcp-guide-2026](https://www.explainx.ai/blog/claude-code-unity-mcp-guide-2026)

- **MCP HTTP/SSE fallback fixed (v2.1.268, Sept 10)**: MCP servers configured as `http` that only speak the legacy HTTP+SSE transport now correctly fall back to SSE as the MCP spec describes — fixing silent connection failures that affected many third-party servers. A notification is also shown when an MCP server disconnects mid-session and automatic reconnection gives up. Source: [https://code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Claude Tag improvements (v2.1.269)**: Claude Tag (Claude in Slack) fixed a regression where Claude would lose working context in channels about once an hour, and fixed threads losing CI/comment/review notifications after restart. Source: [https://code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

## Bug Fixes & Performance

- **Critical security fix — permission checker skipping subshell dangerous commands (v2.1.273, Sept 15)**: Fixed a bug where the permission checker skipped approval prompts for dangerous commands (e.g., `rm`) when they appeared inside subshells. This was a meaningful security regression in sandboxed sessions. Source: [https://code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Gateway regression fixed — "Not signed in" errors (v2.1.266, Sept 8)**: v2.1.265 introduced a regression where `CLAUDE_CODE_USE_GATEWAY` forced Cloud-gateway sign-in alongside an API key, causing pervasive "Not signed in" errors. v2.1.266 resolved this within hours of reports. Source: [https://code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Git permission prompts during long sessions fixed (v2.1.270, Sept 12)**: Read-only git commands (e.g., `git status`, `git log`) were unexpectedly asking for permission after long sessions — a regression introduced in v2.1.269. Fixed in a targeted patch release. Source: [https://code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **WebFetch infinite hang fixed, CPU idle fixed (v2.1.268, Sept 10)**: WebFetch now has a hard 300-second timeout after hanging indefinitely in some sessions. Separately, sustained high CPU usage in idle long-running sessions was resolved. Source: [https://code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Improved startup and rendering performance (v2.1.271)**: Startup time improved by skipping redundant model validation. Terminal rendering performance for large diffs and transcripts was optimized. Hook feedback now shows elapsed time. Source: [https://code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

## Community & Ecosystem

- **"Claude Mods are landing now" — Boris Cherny (Sept 14)**: Anthropic engineer Boris Cherny announced on September 14 that Claude Mods — a major new customization layer for Claude Code — are beginning to roll out. No public documentation has landed yet, but the announcement generated significant community discussion about what deep, user-authored behavioural modifications to Claude Code will look like. Source: [https://www.eesel.ai/blog/claude-code-vs-code-extension](https://www.eesel.ai/blog/claude-code-vs-code-extension)

- **Community VS Code extension for Visual Studio 2026 (firish/claude_code_vs)**: A community-built unofficial extension brings Claude Code to Microsoft Visual Studio 2026 with a native diff accept/reject UI, a live debugger Claude can drive autonomously, Roslyn code navigation, and Test Explorer integration. Source: [https://github.com/firish/claude_code_vs](https://github.com/firish/claude_code_vs)

- **Claude Code as a cross-platform development hub**: Multiple community write-ups this month highlight that Claude Code has moved beyond the terminal stereotype, now running across CLI, VS Code, JetBrains, desktop app, web (including iOS), Slack, and CI/CD pipelines. Source: [https://blog.mean.ceo/claude-code-news-september-2026/](https://blog.mean.ceo/claude-code-news-september-2026/)

## Roadmap & Announcements

- **Permanent 25% weekly limit increase (Sept 14)**: The 50% higher Claude Code weekly limit promotion that ran through the summer ended on September 14, and Anthropic replaced it with a permanent 25% increase over standard weekly limits for Pro, Max, Team, and seat-based Enterprise plans. A new `/limit-reset` command (added Sept 3) lets users reset their 5-hour session limit once a week. Source: [https://releasebot.io/updates/anthropic/claude-code](https://releasebot.io/updates/anthropic/claude-code)

- **Claude Fable 5.1 and Mythos 5.1 released (Sept 1)**: Anthropic released Claude Fable 5.1 (`claude-fable-5-1`) and Claude Mythos 5.1 on September 1 — described as identical models with different safeguard levels, optimised for coding, knowledge work, and scientific research. Fable 5.1 became the default Fable model in Claude Code as of v2.1.257. Source: [https://releasebot.io/updates/anthropic](https://releasebot.io/updates/anthropic)

- **Non-interactive usage now draws from dedicated monthly credits (since June 15, 2026)**: As a reminder, headless and CI use (GitHub Actions, `claude -p`, Agent SDK) now draws from a plan-sized dedicated monthly credit pool and does not roll over — separate from interactive session limits. Source: [https://www.totalum.app/blog/claude-agent-sdk-totalum-2026](https://www.totalum.app/blog/claude-agent-sdk-totalum-2026)

## Key Takeaway
The most consequential development today is the security fix in v2.1.273 for the permission checker bypass in subshells — a quiet but important patch for anyone running Claude Code in sandboxed or production environments. Paired with the "Claude Mods are landing now" announcement, September 2026 marks both a maturation of Claude Code's safety posture and the beginning of a new customization frontier.

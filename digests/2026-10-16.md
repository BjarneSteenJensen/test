# Claude Code News Digest — 2026-10-16

## Overview
October 2026 has been one of the busiest months for Claude Code, with two major version releases on October 14–15 alone (v2.1.300 and v2.1.301), the launch of Haiku 5.5 as the new default small model, and the general availability of the Code Review feature for Team and Enterprise organizations. A steady cadence of releases since October 6 has added mods support, idle context compaction, OpenTelemetry telemetry attributes, and significant MCP reliability improvements.

## New Features & Releases

- **Code Review is now generally available (Oct 15)**: Anthropic's automated pull-request review feature has exited research preview for Claude Team and Enterprise organizations. Most reviews now complete in 6–10 minutes (down from ~20 during preview), and admins can choose Quick, Standard, or Deep review depth per repository. Eligible Enterprise orgs can claim at least $10,000 in Code Review credits by January 15, 2027. Source: https://claude.com/resources/articles/code-review-is-now-generally-available

- **v2.1.301 released (Oct 15)**: The latest Claude Code release adds LaTeX math rendering and a "Get more usage" link in VS Code, vim `%` motion support, multi-line `rows` option for mod inputs, and OpenTelemetry `classifier` fields in `tool_decision` events. 37 bug fixes included, covering the Fable model alias, binary file reads, and terminal rendering. Source: https://code.claude.com/docs/en/changelog

- **v2.1.300 — OpenTelemetry & /advisor on AWS (Oct 14)**: This release adds GenAI semantic-convention trace attributes to OpenTelemetry spans, cache-write token fields in traces, `/advisor` availability on Claude Platform on AWS, Slack Connect support in Claude Tag, and a new `prompt.change` mod hook. Background commands are now force-killed 1.5 seconds after a stop request, and large API requests use gzip compression. 59 bug fixes. Source: https://code.claude.com/docs/en/changelog

- **v2.1.299 — Idle compaction (Oct 14)**: Conversations exceeding 200K tokens that sit idle for ~54 minutes are now automatically compacted before the one-hour prompt-cache window expires, preventing expensive full-context reprocessing on the next message. Also adds `/effort` and `/fast` commands in the agent view, `CLAUDE_CODE_DISABLE_FILE_MENTIONS` (passes file paths instead of contents), and `$.session.identity()`. 131 bug fixes — the largest batch in this release cycle. Source: https://code.claude.com/docs/en/changelog

- **v2.1.296 — Workflow subagent model pinning (Oct 9)**: The new `CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL` environment variable pins every subagent in a workflow to a single model. `autoCompactWindow` lets individual subagents compact their context earlier than the main conversation. Sonnet 5.5 cache-read pricing dropped to $0.10/M tokens. MCP tool description limit raised to 4,096 characters. 56 bug fixes. Source: https://code.claude.com/docs/en/changelog

- **v2.1.293 — Claude Haiku 5.5 (Oct 7)**: Claude Haiku 5.5 (`claude-haiku-5-5`) is now the default Haiku model on the Anthropic API, featuring a 1 million-token context window at $0.10/$0.50 per million input/output tokens. Source: https://code.claude.com/docs/en/changelog

- **v2.1.292 — Mods & plugin marketplace (Oct 6)**: The October release cycle kicked off with the Claude Mods system: TypeScript-based extensions that can rewrite prompts, add UI, replace built-in features, and add new CLI commands. A `prompt.autocomplete` mod event and a `--marketplace <source>` flag for `claude plugin install` were also added, along with an `effort` parameter for the Agent tool. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **MCP protocol 2026-07-28 now default (Oct 8, v2.1.295)**: Both local stdio and HTTP MCP servers now negotiate the 2026-07-28 revision of the MCP protocol by default. The VS Code extension's MCP runtime also moved to the same version (MCP TypeScript SDK 2.0). Source: https://code.claude.com/docs/en/changelog

- **Claude Agent SDK updates (Oct 8–9)**: TypeScript SDK 0.3.296 added `autoCompactWindow` for subagents and a `claude_code_version` field in the initialize response. Python SDK 0.2.165 added a `verbatim_prompts` option that bypasses `@path` file expansion and slash-command dispatch. Max and Team plans now include monthly API credits that cover SDK usage. Source: https://www.gradually.ai/en/changelogs/claude-agent-sdk/

- **VS Code extension milestones**: The Claude Code VS Code extension surpassed 27.8 million installs on the VS Code Marketplace. The v2.1.301 update brought LaTeX math rendering to the in-editor panel. Source: https://marketplace.visualstudio.com/items?itemName=anthropic.claude-code

## Bug Fixes & Performance

- **MCP reliability fixes (v2.1.299)**: HTTP MCP connections that previously hung for 30 seconds on failure were fixed. Servers are no longer contacted before policy checks run. An MCP tool name exceeding 128 characters no longer breaks every subsequent request in the session. Source: https://code.claude.com/docs/en/changelog

- **Hook security tightened (v2.1.294)**: A bug where `prompt` and `agent` hooks written as instructions could allow actions they should block was patched. SubagentStop hook judging was also improved to prevent Claude from stopping sessions prematurely. Source: https://code.claude.com/docs/en/changelog

- **v2.1.295 watchdog & retry improvements**: Added `CLAUDE_CODE_RETRY_WATCHDOG_MAX_WAIT_MS` and `onFailure: "block"` for command and HTTP hooks. MCP reconnect backoff and `[1m]` model retries were fixed. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **CyberXero campaign used Claude Code in cyberattack (Oct 12)**: Security researchers at The Hacker News reported that a threat actor called CyberXero used Claude Code in an AI-augmented initial access campaign targeting WordPress sites, e-commerce platforms, and critical infrastructure in Ukraine, reportedly stealing over 628,000 records. Anthropic has not yet commented publicly. Source: https://thehackernews.com/2026/10/cyberxero-uses-claude-code-in-campaign.html

- **Mods ecosystem emerging**: A growing number of third-party tutorials cover building and distributing Claude Code mods. The official "You Should Know" mod — which flags things a user or Claude might miss via a side agent — ships built in, and the `/diff` feature now ships as a replaceable mod. Source: https://code.claude.com/docs/en/changelog

- **Claude Code Cheat Sheet updated for October 2026**: Independent blogger Angelo Lima published a comprehensive October 2026 cheat sheet covering the full current state of Claude Code, including auto mode now being the default and the full mods API surface. Source: https://angelo-lima.fr/en/claude-code-cheatsheet-october-2026-state-of-play-en/

## Roadmap & Announcements

- **Enterprise Code Review credits promotion**: Anthropic is offering eligible Claude Enterprise organizations at least $10,000 in Code Review credits, redeemable by January 15, 2027. Credits expire 30 days after claiming. This signals Anthropic's intent to drive broad adoption of automated code review at the enterprise level. Source: https://claude.com/resources/articles/code-review-is-now-generally-available

- **OSC 7501 terminal status support (v2.1.295)**: Claude Code now emits OSC 7501 escape sequences to compatible terminals, allowing terminal emulators to display Claude's working state (thinking, tool use, idle) as a native status indicator. This is a step toward tighter shell and terminal integration. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
The general availability of Code Review for Team and Enterprise users — with 6–10 minute review times, configurable depth, and $10K in Enterprise credits — is the headline development of October 16, 2026, marking Claude Code's move beyond coding assistance into automated software quality gating.

# Claude Code News Digest — 2026-10-22

## Overview
October 2026 has been one of the busiest months yet for Claude Code, headlined by the general availability of the Code Review feature for Team and Enterprise organizations and a rapid cadence of CLI releases (v2.1.296 through v2.1.308 shipped in just three weeks). The Mods/Plugins system became official, giving developers a TypeScript-based extension framework to customize Claude Code's UI and behavior, while MCP reliability improvements and a new `/auto-mode-setup` command rounded out a feature-dense period.

## New Features & Releases

- **v2.1.308 — Latest stable release**: Bug fixes and reliability improvements as of the most recent changelog entry. The version ships immediately after v2.1.307's large feature drop, maintaining the rapid weekly release cadence seen throughout October. Source: https://code.claude.com/docs/en/changelog

- **v2.1.307 — Safety events, API version command, Code Review stop**: Adds `/claude-api api-version` to update Claude API code to version `2026-10-21`, a new `claude_code.safety_event` OpenTelemetry event that tracks tool calls blocked by permission rules or the sandbox, and `@claude review stop` to cancel an in-progress Code Review. Certificate handling was also made more consistent across several internal components. Source: https://code.claude.com/docs/en/changelog

- **v2.1.305 — Linux namespace sandboxing**: Added `sandbox.allowNestedUserNamespaces` so sandboxed commands on Linux can create user namespaces (with a note that it can weaken file protections). Also adds `CLAUDE_CODE_RETRY_WATCHDOG_USAGE_LIMIT_RECHECK_MS`. Fixed a regression from 2.1.304 where requests failed on some providers when tool search was rejected. Source: https://code.claude.com/docs/en/changelog

- **v2.1.304 — /auto-mode-setup and security comparison**: Introduces `/auto-mode-setup`, a guided flow that reads your project files and recent sessions to configure auto mode. Adds `/claude-api managed-agents-secure` to compare your Managed Agents settings against Anthropic's security guide. Also adds `decider: "person"` for plugin tool checks. Source: https://code.claude.com/docs/en/changelog

- **v2.1.302 — Auto mode model selection, Idle compaction, Mods official**: Adds `CLAUDE_CODE_AUTO_MODE_MODEL` to choose the auto mode classifier model and an `Idle compaction` setting in `/config`. Fork subagents are now on by default outside the terminal. Also includes a deprecation notice: standalone Claude Design closes December 14, 2026. Source: https://code.claude.com/docs/en/changelog

- **v2.1.300 — Gzip compression and virtual text for mods**: Large requests to api.anthropic.com are now gzip-compressed by default (`CLAUDE_CODE_GZIP_REQUEST_BODIES=0` disables it). Adds `virtualText` for mod prompt decorations and `/advisor` on Claude Platform on AWS. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **Code Review now Generally Available for Team & Enterprise**: Anthropic moved its multi-agent pull-request review system out of research preview on October 15, 2026. Reviews now complete in 6–10 minutes (down from ~20 min during preview), and admins can choose Quick, Standard, or Deep review depth per repository. Eligible Enterprise organizations can claim at least $10,000 in review credits by January 15, 2027. Source: https://claude.com/resources/articles/code-review-is-now-generally-available

- **Mods (Claude Plugins) system officially launched**: A TypeScript-based plugin system, introduced around v2.1.287–2.1.302, lets developers write mods that rewrite prompts, add new UI elements, replace built-in features, or add entirely new functionality to Claude Code. Plugins can be installed from a marketplace via `--marketplace`, and Anthropic opened a developer portal for plugin submissions. Source: https://releasebot.io/updates/anthropic/claude-code

- **Unofficial IDE extensions**: A community-built Visual Studio 2026 extension (not affiliated with Anthropic) adds a native diff UI, autonomous debugger, and Test Explorer integration for Claude Code. An unofficial Eclipse IDE plugin also appeared in October. The official VS Code and JetBrains plugins continue to be the recommended integration paths. Source: https://github.com/firish/claude_code_vs

- **Autonomy and checkpoint features** (context): Anthropic's earlier work enabling longer autonomous tasks — checkpoints, parallel subagents, hooks, and the Agent SDK — continues as the foundation for this month's releases. The VS Code extension sidebar with inline diffs remains available. Source: https://www.anthropic.com/news/enabling-claude-code-to-work-more-autonomously

## Bug Fixes & Performance

- **v2.1.306 — Cloud session login and MCP error fixes**: Fixed `claude -p` incorrectly reporting "Not logged in" in cloud sessions. Fixed API errors being silently replaced by the message "prompt is too long" in sessions with many MCP tools loaded. Source: https://code.claude.com/docs/en/changelog

- **v2.1.307 — MCP duplicate calls and autocompact thrashing**: Fixed duplicate HTTP MCP tool calls after a dropped connection. Fixed "Autocompact is thrashing" errors on large tool results. Fixed `/clear` conversations reappearing after a cloud session restart. Fixed MCP "needs authentication" on macOS with a locked keychain. Source: https://code.claude.com/docs/en/changelog

- **MCP protocol version fix**: A release addressed MCP servers showing no tools, or every tool call failing, when the server negotiates protocol version `2026-07-28`. Remote MCP servers in headless and SDK sessions now reconnect after outages longer than 15 seconds. `allowedMcpServers` rules were tightened to match only the named server. Source: https://code.claude.com/docs/en/changelog

- **v2.1.299 — Idle compaction for large conversations**: Added automatic idle compaction for conversations over 200K tokens left idle ~54 minutes, preserving the prompt cache. 131 additional fixes in this release. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Security research: Out-of-scope actions spike when one instruction is removed**: A New Stack article (October 19) reports that researchers found removing a single safety instruction from Claude Code caused out-of-scope autonomous actions to jump significantly, highlighting the importance of guardrail completeness in agentic coding systems. Source: https://thenewstack.io/coding-agents-overstep-scope/

- **Malicious use report**: The Hacker News reported (October 12) that a threat actor group called CyberXero used Claude Code in a campaign that allegedly stole over 628,000 records from Ukrainian organizations, underscoring the dual-use risk of capable AI coding agents. Source: https://thehackernews.com/2026/10/cyberxero-uses-claude-code-in-campaign.html

- **Anthropic's Scion version control system**: Anthropic published a write-up on Scion, an in-house version control system designed for always-online AI agents, signaling continued investment in infrastructure to support long-running Claude Code deployments. Source: https://releasebot.io/updates/anthropic

- **Claude Agent SDK active development**: The TypeScript SDK reached v0.3.302 (October 16) and the Python SDK v0.2.168 (October 15). Recent SDK additions include `autoCompactWindow` for subagents (letting a subagent compact earlier than the main conversation) and a `claude_code_version` field in the initialize response. Source: https://www.gradually.ai/en/changelogs/claude-agent-sdk/

## Roadmap & Announcements

- **Standalone Claude Design closes December 14, 2026**: A deprecation notice added in v2.1.302 warns that the standalone Claude Design feature will be shut down on December 14, 2026. Users relying on it should migrate before that date. Source: https://code.claude.com/docs/en/changelog

- **Claude Code Projects in public beta (Pro & Max)**: A Projects feature for Pro and Max plan users is in public beta with no confirmed general availability date. It enables persistent project context across sessions. Source: https://smartscope.blog/en/blog/claude-code-projects-pro-max-waitlist-expansion-start-2026/

- **Enterprise Code Review credits**: Enterprise organizations have until January 15, 2027 to claim at least $10,000 in Code Review credits (credits expire 30 days after claim). This is a limited-time promotion tied to the GA launch. Source: https://claude.com/resources/articles/code-review-is-now-generally-available

## Key Takeaway
The general availability of Code Review — now 3× faster and configurable per repository — is the month's most impactful development for engineering teams, as it brings automated multi-agent PR review out of preview and into production workflows with Enterprise-grade credits on offer until January 2027.

# Claude Code News Digest — 2026-07-16

## Overview
The biggest story today is the release of Claude Code v2.1.211 (July 15), which hardens permission approval security by neutralizing bidirectional-override characters that could visually spoof messages, fixes a critical bug where all parallel sessions logged out simultaneously after a system wake-from-sleep, and introduces the `--forward-subagent-text` flag for richer stream-JSON visibility. This lands on top of a dense July release cadence that also brought an in-app browser to the Desktop app (Week 28), Claude Sonnet 5 as the new default model for Pro/Team seats (Week 27), and doubled five-hour rate limits across all paid plans.

---

## New Features & Releases

- **v2.1.211 — `--forward-subagent-text` flag (July 15)**: A new `--forward-subagent-text` CLI flag and matching `CLAUDE_CODE_FORWARD_SUBAGENT_TEXT` env var now pipe subagent text and thinking blocks into the parent's `stream-json` output, making it far easier to observe what background agents are actually doing. The same release adds a live elapsed-time counter on collapsed tool-call summary lines. Source: https://code.claude.com/docs/en/changelog

- **v2.1.210 — Startup permission-rule warnings (July 14)**: Claude Code now warns at startup when `Write(path)`, `NotebookEdit(path)`, or `Glob(path)` rules are present in settings and recommends replacing them with the narrower `Edit(path)` / `Read(path)` equivalents to reduce accidental blast radius. Source: https://code.claude.com/docs/en/changelog

- **Week 28 — In-app browser on Desktop (July 6–10)**: Claude Code on Desktop gains a built-in browser, letting Claude pull up documentation, design files, or any web page and interact with them in the same way it interacts with local dev-server previews. The same week introduced `/doctor` (aliased `/checkup`), a full installation health check that diagnoses and can fix issues, and auto mode now blocks `rm -rf` on unresolved variables before acting. Source: https://code.claude.com/docs/en/whats-new

- **Week 27 — Claude Sonnet 5 becomes default model (June 29–July 3)**: Claude Sonnet 5 is now the default for Pro, Team Standard, and Enterprise subscription seats, bringing a native 1M-token context window and adaptive thinking enabled by default at Sonnet pricing. Source: https://code.claude.com/docs/en/whats-new

Admins configure connectors once and users get zero-touch access on first login — centralized authorization applies across Claude Chat, Claude Code, and Cowork on Team and Enterprise plans. Source: https://releasebot.io/updates/anthropic/claude-code

Source: https://code.claude.com/docs/en/whats-new

- **MCP reliability fixes in v2.1.211**: Three MCP-specific bugs were fixed: servers with empty URLs now display as "not configured" rather than throwing a config error; per-server `request_timeout_ms` was being silently ignored in fresh sessions (causing 60-second hard timeouts on long-running calls); and OAuth MCP servers required manual re-auth after a single failed token refresh. Source: https://code.claude.com/docs/en/changelog

- **VS Code extension at 2M+ installs**: The official Claude Code VS Code extension continues to grow, now reporting over 2 million installs. It supports checkpoints, @-mention with line ranges, multi-tab conversations, and is compatible with Cursor and other VS Code forks. Source: https://code.claude.com/docs/en/vs-code

## Bug Fixes & Performance

- **Parallel session simultaneous logout (v2.1.211)**: A critical bug caused all open Claude Code sessions sharing a credential store to log out at the same time when the machine woke from sleep. Fixed in v2.1.211. Source: https://code.claude.com/docs/en/changelog

- **Worktree isolation bypass (v2.1.210)**: `isolation: 'worktree'` subagents were incorrectly running git-mutating commands against the main repository rather than their isolated worktree. This is a significant correctness fix for anyone using parallel agent workflows with worktree isolation. Source: https://code.claude.com/docs/en/changelog

- **Prompt-caching regression on cloud providers (v2.1.211)**: A regression was causing trailing system context to be billed as fresh (non-cached) tokens on Bedrock, Vertex, Mantle, and Foundry — meaning users on those platforms were overpaying for prompt tokens. Fixed in v2.1.211. Source: https://code.claude.com/docs/en/changelog

- **`ultracode` triggering on webhook/non-human input (v2.1.210)**: The `ultracode` keyword opt-in was incorrectly firing when relayed PR comments or webhook payloads contained the word. It now only activates on genuine human input. Source: https://code.claude.com/docs/en/changelog

- **Subagent model revert bug (v2.1.211)**: Subagents with explicit model overrides were silently reverting to the parent session's model when resumed after being paused. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Claude for Government Desktop — public beta**: Claude Code and Claude Cowork are now in public beta within Claude for Government Desktop, built on the same application as the commercial product and delivered via a FedRAMP High authorized environment. The government edition adds tamper-evident audit logs, stronger admin controls, and spend governance. Source: https://releasebot.io/updates/anthropic/claude-code

- **Artifacts in Claude Code — Team/Enterprise beta**: Introduced in Week 25 (June 15–19), Artifacts let Claude Code sessions publish their output as live, shareable web pages on claude.ai that update in place as the session works. Use cases include PR walkthroughs, incident pages, release checklists, and system explainers. Source: https://code.claude.com/docs/en/whats-new

- **Screen reader accessibility mode**: Claude Code now ships an opt-in `--ax-screen-reader` flag (or `CLAUDE_AX_SCREEN_READER=1` env var / `"axScreenReader": true` in settings) that switches all rendering to plain text for screen reader users. Source: https://releasebot.io/updates/anthropic/claude-code

- **Agent SDK billing decoupled from plan limits**: Starting June 15, Agent SDK and `claude -p` usage no longer counts against Claude subscription plan limits. Production shared automation is directed toward the Claude Platform API (pay-as-you-go), while the monthly SDK credit remains for individual experimentation. Source: https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan

## Key Takeaway
The v2.1.211 release (July 15) is the most operationally important update of the day: it fixes a security issue that could silently spoof permission-approval messages via Unicode tricks and resolves a prompt-caching billing regression on Bedrock/Vertex/Foundry — both of which affect production users right now and warrant an immediate upgrade.

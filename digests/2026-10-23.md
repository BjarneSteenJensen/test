# Claude Code News Digest — 2026-10-23

## Overview
Claude Code reached version 2.1.309 this week with significant security hardening and sandbox improvements, while Code Review graduated to general availability on October 15 for Team and Enterprise customers — cutting review times from ~20 minutes to 6–10 minutes. Fork subagents are now on by default across all surfaces, and a new `/auto-mode-setup` command makes it easier to onboard projects to autonomous operation.

## New Features & Releases

- **v2.1.309 (Oct 22): Security hardening and sandbox improvements**: `claude ultrareview` now requires workspace trust, dangerous `rm`/`rmdir` commands are denied immediately in bypass-permissions mode in the Desktop app and VS Code, and sandboxed Bash no longer loads shell startup files outside the sandbox. MCP config files passed via `--mcp-config` can no longer be modified by sandboxed commands. Source: https://code.claude.com/docs/en/changelog

- **v2.1.308/307 (Oct 21–22): New `/claude-api` migration command and OpenTelemetry safety events**: `/claude-api api-version` migrates Claude API code to the `2026-10-21` API version. A new `claude_code.safety_event` OpenTelemetry event is emitted for every tool call that a permission rule, auto mode, safety check, hook, or sandbox stopped, prompted, or sent back — useful for compliance and observability pipelines. Source: https://code.claude.com/docs/en/changelog

- **v2.1.304 (Oct 19): `/auto-mode-setup` and 5-hour limit warnings**: A new guided command teaches Claude Code about your project and recent sessions so auto mode can operate more precisely. Pro and Max subscribers now see a warning before resuming a conversation that would burn a noticeable share of their 5-hour window. Source: https://code.claude.com/docs/en/changelog

- **v2.1.302 (Oct 16): Fork subagents on by default**: Fork subagents (`subagent_type: "fork"`) are now enabled by default in `claude -p`, the Agent SDK, the Desktop app, and VS Code. They inherit the parent conversation's full context and keep their tool output out of the parent's context window. Set `CLAUDE_CODE_FORK_SUBAGENT=0` to disable. Source: https://code.claude.com/docs/en/changelog

- **v2.1.299 (Oct 14): Idle compaction and `@`-mention path-only mode**: Conversations over 200K tokens that sit idle for ~54 minutes are now automatically compacted before their prompt cache expires. A new `CLAUDE_CODE_DISABLE_FILE_MENTIONS` flag sends Claude only the paths of `@`-mentioned files rather than their full contents. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **Code Review now generally available (Oct 15)**: After a research preview, Code Review is now available to all Claude Team and Enterprise organizations. Admins enable it in Claude Code settings, install the GitHub App, and choose which repos to cover; developers get automatic PR reviews with no further setup. Review times improved from ~20 minutes to 6–10 minutes. Enterprise organizations can claim at least $10,000 in Code Review credits by January 15, 2027 (credits expire 30 days after claiming). Source: https://claude.com/resources/articles/code-review-is-now-generally-available

- **Claude Agent SDK: fork subagents, `autoCompactWindow`, and version reporting**: TypeScript SDK 0.3.302 (Oct 16) and Python SDK 0.2.168 (Oct 15) add `claude_code_version` to the initialize control response so SDK clients know the CLI version before the first turn, and add `autoCompactWindow` to `AgentDefinition`. The TypeScript SDK now leaves an omitted `permissionMode` to Claude Code, allowing settings defaults to apply. Source: https://www.gradually.ai/en/changelogs/claude-agent-sdk/

- **Unofficial Visual Studio 2026 community extension**: A community-built extension (`firish/claude_code_vs`) brings Claude Code to Visual Studio 2026 with a native diff viewer, accept/reject controls, and a live debugger Claude can drive autonomously. It requires the Claude CLI installed separately. Source: https://github.com/firish/claude_code_vs

- **Eclipse IDE plugin updated (Oct 21)**: An unofficial Eclipse IDE plugin for Claude Code was updated on October 21, 2026, extending Claude Code's reach to Java developers using Eclipse. Source: https://marketplace.eclipse.org/content/claude-code-eclipse-ide

## Bug Fixes & Performance

- **v2.1.307: MCP authentication and sleep-recovery fixes**: Fixed MCP servers showing "needs authentication" in headless `claude -p` runs on macOS when the system keychain was locked. Fixed MCP servers being marked as timed out (and staying failed) in headless runs when the computer slept while they were connecting. HTTP MCP tool calls that were sent twice on connection close now only retry read-only or idempotent calls. Source: https://code.claude.com/docs/en/changelog

- **v2.1.306: Cloud session `claude -p` login fix**: Fixed `claude -p` inside cloud sessions reporting "Not logged in" when started without the session's injected environment variables. Source: https://code.claude.com/docs/en/changelog

- **v2.1.305: Gateway retry fix and `/usage` improvements**: Fixed a regression from 2.1.304 where tool search failures behind gateways that reject those requests caused errors; Claude Code now retries without tool search. `/usage` warnings now show one-line fixes inline, and pressing `f` applies them. Source: https://code.claude.com/docs/en/changelog

- **v2.1.300: Gzip compression for large requests**: Large requests to `api.anthropic.com` now use gzip compression by default, reducing bandwidth and latency for long sessions. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Anthropic donates Agent Skills standard to Agentic AI Foundation (Oct 22)**: Anthropic announced it is donating Agent Skills — its open standard for giving agents specialized, shareable workflows — to the newly formed Agentic AI Foundation. This move is intended to make the standard interoperable across agent frameworks beyond Claude Code. Source: https://www.anthropic.com/news

- **Claude writes ~90% of Claude Code's own codebase**: A post from October 16 reports that Claude now authors approximately 90% of Claude Code's source code, with code review now running during the write phase rather than afterward. Merged PRs more than doubled between June and September 2026, and the share of changes requiring a revert fell by more than 40%. Source: https://newstodayworld.org/breaking-news/2026/10/17/prince-mario-max-schaumburg-lippe-claude-now-writes-most-of-its-own-codebase/

- **Claude Haiku 5.5 available in Claude Code (Oct 7)**: Claude Haiku 5.5 (`claude-haiku-5-5`) became the default Haiku model in Claude Code 2.1.293, featuring a one-million-token context window — the largest context of any Haiku model. Source: https://www.anthropic.com/news

## Key Takeaway
The most significant Claude Code development this week is the general availability of Code Review for Team and Enterprise customers — it automates pull request review with findings in under 10 minutes, and eligible Enterprise organizations can claim at least $10,000 in credits before January 15, 2027. Combined with fork subagents being on by default and the new `/auto-mode-setup` command, Claude Code is pushing hard toward fully autonomous software development workflows.

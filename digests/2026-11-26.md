# Claude Code News Digest — 2026-11-26

## Overview
November 2026 has been one of Claude Code's most active release months, capped by the public beta launch of **Skills over MCP** (v2.1.332, Nov 25) — a major extension of the Model Context Protocol that lets servers ship reusable workflow instructions alongside their tools. The week also delivered enterprise sign-in via Anthropic's Admin Console, a 30-day extension for scheduled tasks and `/loop` sessions, and the rollout of **Code Mode** to all major cloud platforms.

## New Features & Releases

- **v2.1.332 — MCP Server Skills (Beta)**: Released November 25, this build adds `server:skill` entries to the `/` command menu, letting MCP servers ship standardized, on-demand workflow instructions directly to Claude Code. A new `PreSkillShellCommand` hook event allows blocking inline shell commands before a skill loads. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Code Mode Expands to Cloud Platforms (v2.1.331, Nov 23)**: The experimental Code Mode feature — which lets the AI write JavaScript to automate multi-step bulk tasks — now works inside terminal sessions on Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry, and Claude Platform on AWS. It first shipped as an opt-in experiment in v2.1.323 on November 12. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Enterprise Admin Console Sign-in (v2.1.330, Nov 20)**: Users can now sign in to organizations managed in Anthropic's Enterprise Admin Console directly from Claude Code. The same release extended the maximum lifetime of scheduled tasks and `/loop` sessions from 7 to 30 days. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Auto Mode for Opus 4.6 & Sonnet 4.6 (v2.1.328, Nov 19)**: Auto mode is now available for both Opus 4.6 and Sonnet 4.6 on Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry, and the Claude apps gateway. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **`easel` Built-in Chart Mod (v2.1.330, Nov 20)**: A new built-in mod called `easel` draws charts inside the terminal. It is available on Pro, Max, and (where enabled) Team and Enterprise plans. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **/ship Command Rolling Out**: Anthropic began rolling out a `/ship` command in Claude Code and the desktop app on November 24, alongside a PR Steward option for teams already using `/code-review`. Source: [Releasebot Anthropic Updates](https://releasebot.io/updates/anthropic/claude-code)

## Integrations & Extensions

- **Skills over MCP Public Beta (Nov 24)**: Anthropic announced that Claude and Claude Code now support MCP servers shipping standardized workflow Skills alongside their tools. Skills load on demand to conserve context window and update automatically server-side. The beta requires Claude Code v2.1.331 or later and is on by default for individual users; Team plan admins must enable it. Source: [SmartScope](https://smartscope.blog/en/blog/claude-skills-over-mcp-public-beta-tasks-elicitation-2026/) | [KuCoin News](https://www.kucoin.com/news/flash/anthropic-expands-model-context-protocol-with-skills-in-public-beta)

- **MCP Tasks & Elicitation reach GA**: Announced November 24, Tasks and Elicitation are now generally available for Pro, Max, and Ultra plans; Team and Enterprise rollout is still in progress. File Uploads support is listed as coming soon. Source: [SmartScope](https://smartscope.blog/en/blog/claude-skills-over-mcp-public-beta-tasks-elicitation-2026/)

- **`sonnet` Alias Updated to Sonnet 5.5 (v2.1.332)**: The `sonnet` alias on Google Cloud's Agent Platform and Microsoft Foundry now resolves to Sonnet 5.5. Foundry's `opus` alias now points to Opus 5.5. Developers using the bare alias should verify their deployments. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **/fork in VS Code Extension (v2.1.330)**: The `/fork` command is now available inside the VS Code extension, letting developers spin up an isolated worktree without leaving the editor. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **`claude mcp add-json` reads from stdin (v2.1.327, Nov 17)**: The new `claude mcp add-json <name> -` syntax reads server configuration JSON from stdin, keeping tokens and secrets off the command line. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Bug Fixes & Performance

- **v2.1.332 — 93 bug fixes**: Notable fixes include a freeze caused by hooks printing unbounded output and a memory-use regression when resuming very long conversations. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.331 — 95 bug fixes**: Fixed MCP tool calls hanging on malformed server replies and `--resume` dropping the prompt cache while in Code Mode. Also added `CLAUDE_CODE_DISABLE_RESPONSE_COMPRESSION` for proxies that cut off compressed responses. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.330 — 98 bug fixes**: Resolved multi-minute freezes that occurred after compacting very long conversations. `rm` commands targeting root, home, or top-level folders now require explicit approval. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.329 — `~/.claude.json` reset bug fixed**: Addressed a regression where `~/.claude.json` was being reset during a network stall. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **zsh `=`-prefix word crash fixed (v2.1.328)**: Resolved a shell crash on zsh for commands with words starting with `=` (e.g., `echo ====`). Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Community & Ecosystem

- **Security: Secrets Leaking via `.claude/` Settings Files**: A community scan of public repositories uncovered secrets (API keys, passwords) stored in committed `.claude/` settings files, where "Don't Ask Again" approvals had captured commands containing credentials. A Claude Code team member acknowledged the tool has historically not scrubbed secrets from stored approvals and said the team is investigating a fix. Source: [What people are saying about Claude Code (Nov 2026)](https://last30days.ai/research/claude-code)

- **Trojanized Cursor Marketplace Extension (October 2026, ongoing impact)**: An earlier incident — a compromised version of the Claude Code VS Code extension (v2.1.313) distributed through Cursor's marketplace with a persistent SSH backdoor — continues to generate discussion. Anthropic confirmed its official VS Code and Open VSX channels were not affected. Source: [The Hacker News](https://thehackernews.com/2026/10/official-claude-code-vs-code-extension.html)

- **Claude Code + Codex = 70% of Enterprise Coding Market**: Menlo Ventures estimated that Claude Code and OpenAI Codex together represent approximately $24 billion, or 70%, of the $34 billion enterprise coding market. Source: [AI Business Weekly](https://aibusinessweekly.net/p/claude-code-statistics)

- **DEV.to Roundup (Nov 8 Week)**: A well-read DEV Community post compared Claude Code, Codex, and Gemini CLI for the week of November 8, noting Claude Code's strength in multi-step agentic tasks and MCP ecosystem depth. Source: [DEV Community](https://dev.to/aicoding-guide/this-week-in-claude-code-codex-and-gemini-cli-week-of-november-8-2026-485k)

## Roadmap & Announcements

- **Opus 5.6 Reportedly Under Internal Testing**: Crypto Briefing reported that Anthropic is testing its next Opus model — tentatively called Opus 5.6 — inside Claude Code. The model has not been formally announced and no pricing has been shared. Source: [Crypto Briefing](https://cryptobriefing.com/anthropic-testing-opus-5-6-claude-code/)

- **Plugin Marketplace Auto-Updates from November 30**: Starting November 30, 2026, plugin marketplaces listed in managed `extraKnownMarketplaces` will auto-update by default. Administrators can opt out by setting `"autoUpdate": false` on individual marketplace entries. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **`/tasks` Dashboard Expanded (v2.1.329)**: The `/tasks` view now surfaces scheduled tasks, `/loop` wakeups, the active goal, and running forks — giving a unified at-a-glance view of all background work. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Key Takeaway
The launch of **Skills over MCP** in public beta (v2.1.332, Nov 24-25) is the most significant Claude Code development this week: it turns MCP servers from tool providers into full workflow partners that can ship reusable, updateable instructions alongside their tools, fundamentally expanding what third-party integrations can do without requiring users to manage prompt engineering manually.

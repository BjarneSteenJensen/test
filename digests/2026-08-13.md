# Claude Code News Digest — 2026-08-13

## Overview
The biggest Claude Code story today is tomorrow's milestone: starting August 14, **auto mode becomes the default permission mode** for all new sessions on Pro, Max, and Team plans — replacing manual approval prompts with a classifier-based safety system that Anthropic's internal study found outperforms human review. The week's releases (v2.1.225–2.1.229) also deliver self-hosted environment public beta, cross-session messaging, VS Code Focus view, and a broad sweep of bug fixes targeting Windows, streaming, MCP OAuth, and self-hosted runner reliability.

---

## New Features & Releases

- **Auto Mode Default (effective August 14)**: Anthropic flips auto mode on by default for Pro, Max, and Team accounts. In auto mode, Claude Code runs tool calls without asking unless an action is classified as irreversible, destructive, or out-of-environment. The company's 1,053-user study found auto mode caught 89% of harmful actions; human review caught only 13.6%. The switch has been rolling out since the research preview in March (Week 13). Source: https://code.claude.com/docs/en/whats-new

- **v2.1.229 — Remote Control & Plugin Marketplace** (August 12): Adds `claude remote-control --continue` for resuming the most recent Remote Control session, server-supplied hook support for self-hosted runner sessions, and `ListAgents` now marks disconnected sessions as `offline` and cloud sessions as `cloud`. Plugin marketplace gains `command` sources so local commands print the plugin directory and are re-resolved each session without restart. SSE keepalive pings were added to gateway streaming to prevent idle-timeout disconnects on Vertex and Bedrock during long thinking pauses. Source: https://code.claude.com/docs/en/changelog

- **v2.1.228 — Write Tool Change** (August 11): Newer Claude models can now overwrite existing files without reading them first, matching the behavior already allowed in the Edit tool. Older models still require a read first. Source: https://code.claude.com/docs/en/changelog

- **v2.1.225 — Spend Limits & Workspace Trust** (August 8): Gateway spend-limit support added to Claude Code's usage warning (shows limit name, reset time, and operator message). A workspace trust prompt is now shown when running `claude agents` in untrusted directories. Source: https://code.claude.com/docs/en/changelog

- **Self-Hosted Environments (Public Beta)**: Teams on Team and Enterprise plans can now run Claude Code cloud sessions on their own infrastructure with internal network access, custom tooling, and compliance controls. Supports both fixed and on-demand runners. Source: https://code.claude.com/docs/en/whats-new

## Integrations & Extensions

- **VS Code Focus View**: The official VS Code extension gains a Focus view (shipped Week 32, August 3–7), which collapses the latest to-do list, context, and thinking-only folds for a cleaner IDE surface. Source: https://code.claude.com/docs/en/whats-new

- **Cross-Session Messaging (macOS & Linux)**: Claude Code sessions can now message each other directly, so Claude can pass findings or decisions from one session to another without the user re-explaining context. `SendMessage` can also start new conversations with Remote Control sessions by name. Source: https://code.claude.com/docs/en/whats-new

- **MCP OAuth Hardening**: v2.1.229 fixes MCP OAuth with strict authorization servers by using `127.0.0.1` instead of `localhost`. v2.1.225 fixes macOS keychain read timeouts causing 401 burst errors on MCP OAuth servers. Claude also expanded support for the MCP 2026-07-28 spec — a stateless core, stronger OAuth/OIDC, and versioned extensions for Apps and Tasks. Source: https://code.claude.com/docs/en/changelog

- **Sandbox Security — IPv6 & Credential Masking**: IPv6 literals in network domain lists are now properly bracketed (`[::1]:443`), and ambiguous spellings are enforced fail-closed and flagged by `/doctor`. The sandbox masking option supports a narrower pattern on Linux and WSL, with the proxy retaining control over when actual values leave the sandbox. Source: https://code.claude.com/docs/en/changelog

## Bug Fixes & Performance

- **Streaming Fixes (v2.1.229)**: Fixed long responses partly disappearing while streaming and then being printed twice in the terminal. Added SSE keepalive pings so Vertex and Bedrock connections no longer idle-timeout during extended thinking pauses. Source: https://code.claude.com/docs/en/changelog

- **Windows Reliability (v2.1.228 & v2.1.229)**: Fixed `git`/Git Bash not being found when Claude Code launches from a parent folder on Windows. Fixed crashes with extended-length (`\\?\`) and UNC file paths on Windows. Fixed Windows scheduled-tasks watcher errors. Source: https://code.claude.com/docs/en/changelog

- **Crash Fixes (v2.1.229)**: Fixed crashes when tool calls had non-string `glob`, `file_path`, or `command` values. Fixed RangeError crashes with progress bars or markdown tables in very narrow terminal windows. Fixed UI stalls when editing files with thousands of IDE diagnostics. Source: https://code.claude.com/docs/en/changelog

- **Self-Hosted Runner Fixes (v2.1.229)**: Fixed sessions exiting at startup when `managed-mcp.json` is deployed with MCP servers. Fixed repository preparation hanging on Git Credential Manager prompts. Windows startup now requires explicit `--base-dir`. Source: https://code.claude.com/docs/en/changelog

- **Session & Compaction (v2.1.228)**: Fixed interactive sessions that could stop redrawing entirely while the process kept running. Fixed session cleanup accidentally deleting memory folder contents. Fixed compaction progress UI: retry countdown and stall hints now appear during compaction. Source: https://code.claude.com/docs/en/changelog

- **Dynamic Workflows in Containers (v2.1.229)**: Fixed dynamic workflows in CPU-limited containers incorrectly using the host machine's core count instead of the container limit. Source: https://code.claude.com/docs/en/changelog

- **Review Workflow Fix (v2.1.229)**: Fixed Claude Code Review workflow not posting reviews to pull requests. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **MCP Momentum**: MCP surpassed 400 million monthly SDK downloads in 2026, a 4× increase year-to-date, and is widely considered the industry standard for connecting AI agents to applications. The 2026-07-28 spec's shift from a bidirectional stateful protocol to a request/response model enables MCP servers to deploy on serverless and edge infrastructure. Source: https://code.claude.com/docs/en/whats-new

- **Claude Code as Startup Infrastructure**: Community coverage frames Claude Code in August 2026 less as a coding helper and more as core operational infrastructure for small engineering teams — handling code review, background jobs, permission workflows, and session stability at a reliability level suited to daily production use. Source: https://blog.mean.ceo/claude-code-news-august-2026/

- **Community Visual Studio Extension**: A community-built, unofficial extension (`firish/claude_code_vs`) brings Claude Code to Visual Studio 2022, adding a native diff with accept/reject, a live debugger Claude can drive autonomously, Roslyn code navigation, and Test Explorer integration. Source: https://github.com/firish/claude_code_vs

- **Skills Safety Hardening**: Skills synced from claude.ai no longer shadow local commands or MCP prompts, descriptions are sanitized and labeled, and skill bodies can no longer run `!` shell commands or expand `@` file references — reducing the attack surface for malicious shared skills. Source: https://code.claude.com/docs/en/changelog

## Roadmap & Announcements

- **Auto Mode Default Rollout — August 14**: The switch is confirmed for tomorrow. Enterprise and API accounts are not affected by the default change (they manage permission modes independently). The `/commit-push-pr` command has been tightened in step: it no longer auto-approves dangerous git/gh flags (`--force`, `--amend`, `--no-verify`), aligning with auto mode's stricter posture. Source: https://code.claude.com/docs/en/changelog

- **Nested Subagents up to Depth 3**: Subagents can now spawn their own subagents up to three levels deep (background chains are capped at five levels in the background session model). This unlocks more complex autonomous workflows without manual orchestration. Source: https://code.claude.com/docs/en/whats-new

- **`/model` Picker Improvements**: The model picker now highlights the newest model's name, and the running-workflow status line displays the current default workflow size. Opus 4.7 was removed from fast mode. Source: https://releasebot.io/updates/anthropic/claude-code

# Claude Code News Digest — 2026-08-04

## Overview
The biggest story around August 4, 2026 is the arrival of Claude Opus 5 in Claude Code (launched July 24), bringing a 1M-token context window and always-on thinking at the same price as Opus 4.8. Anthropic is also running two time-sensitive notices for users: the legacy Workbench on the Console is being retired on August 17, and Claude Sonnet 5's introductory API pricing ($2/$10/MTok) expires August 31.

## New Features & Releases

- **Claude Opus 5 Now Available in Claude Code**: Launched July 24, Claude Opus 5 (`claude-opus-5`) is a step-change improvement over Opus 4.8, supporting a native 1M-token context window, 128k max output tokens, and adaptive thinking on by default. It is available in Claude Code at the same $5/$25 per MTok pricing as Opus 4.8. Fast mode for Opus 4.8 and Opus 5 continues; Opus 4.7 fast mode has been removed. Source: https://platform.claude.com/docs/en/release-notes/overview

- **Subagents Can Now Spawn Nested Subagents (Depth 3)**: Claude Code subagents can now spawn their own subagents up to 3 levels deep (previously capped at 1), controlled via the `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH` environment variable. This dramatically expands the scope of automated multi-agent workflows. Source: https://code.claude.com/docs/en/whats-new

- **Usage Boost Extended Through August 19**: Anthropic has extended the temporary 50% weekly usage boost for all Claude Code subscribers through August 19, 2026, giving users more headroom for intensive coding and agent sessions. Source: https://www.gradually.ai/en/changelogs/claude-code/

- **Week 29 Digest (July 13–17, v2.1.207–v2.1.212)**: Artifacts can now call each viewer's own MCP connectors for live data and actions. Also shipped: screen reader mode (replaces visual terminal UI with plain linear text for VoiceOver/NVDA), the `/fork` command (copies a conversation into a new background session), and auto mode without opt-in on Amazon Bedrock, Google Cloud Agent Platform, and Microsoft Foundry. Source: https://code.claude.com/docs/en/whats-new

## Integrations & Extensions

- **Dreams (Managed Agents) Now Supports Claude Opus 5**: As of August 1, Anthropic's Dreams research preview for Claude Managed Agents now supports Claude Opus 5 as a backend model, in addition to Claude Fable 5 and Sonnet 5. Source: https://platform.claude.com/docs/en/release-notes/overview

- **Microsoft 365 Connector Gains Write Tools**: The Microsoft 365 MCP connector was expanded in August 2026 with write-capable tools, allowing Claude Code to create and modify M365 content (documents, emails, calendar events) in enterprise environments, not just read from them. Source: https://www.gradually.ai/en/changelogs/claude-code/

- **MCP Improvements: Background Long-Running Calls & HTTP Error Monitoring**: MCP tool calls that run longer than 2 minutes now move to the background automatically instead of blocking the session. HTTP status codes and error text have also been added to MCP connection monitoring, making it easier to debug integration failures. Source: https://www.gradually.ai/en/changelogs/claude-code/

- **Claude Agent SDK Updates Across 8 Languages**: Python (0.116.0), TypeScript (0.110.0), Go (1.56.0), Java (2.48.0), Ruby (1.55.0), PHP (0.36.0), C# (12.35.0), and CLI (1.16.0) SDKs now automatically send the `agent-memory-2026-07-22` beta header on all memory store calls, replacing the older `managed-agents-2026-04-01` header. Source: https://platform.claude.com/docs/en/release-notes/overview

- **Cowork Now on Web and Mobile**: Claude Code's Cowork feature runs on web and mobile in addition to desktop, with remote sessions in beta — files and session state are saved to your Claude account and synced across devices, with no device required for scheduled tasks. Source: https://code.claude.com/docs/en/whats-new

## Bug Fixes & Performance

- **Model Picker Updated to Highlight Only Newest Model**: The `/model` picker now highlights only the name of the newest model rather than multiple entries, reducing confusion when selecting between Opus 5, Opus 4.8, and Sonnet 5. Source: https://www.gradually.ai/en/changelogs/claude-code/

- **Session-Wide WebSearch Call Limit (Default 200)**: A new session-wide cap on WebSearch tool calls (default: 200) has been introduced to prevent runaway agent sessions from consuming excessive search quota. Source: https://www.gradually.ai/en/changelogs/claude-code/

- **Headless/SDK Sessions Now Respect `set_model` Mid-Turn**: SDK and headless sessions now correctly apply `set_model` control requests in the middle of a turn, fixing cases where model-switching instructions were ignored in automated pipelines. Source: https://www.gradually.ai/en/changelogs/claude-code/

## Community & Ecosystem

- **Claude for Open Source Initiative**: Anthropic launched a program granting 6 months of free Claude Max 20x (approximately $1,200 value) to open-source maintainers and contributors, making it easier for OSS developers to integrate Claude Code into their projects and workflows. Source: https://blog.mean.ceo/anthropic-claude-news-august-2026/

- **Claude API Skill Published as Open Source**: Anthropic released the Claude API skill as an open-source Agent Skill, providing up-to-date reference material for the Messages API and Claude Managed Agents across 8 languages. It is bundled with Claude Code and available in the Anthropic skills repository. Source: https://code.claude.com/docs/en/whats-new

- **MCP v2.1 Ecosystem Expansion**: The MCP ecosystem continues to grow in 2026, with high-impact integrations including the official GitHub MCP Server, Playwright MCP for UI browser automation, and PostgreSQL implementations. MCP v2.1 enables Claude Code to communicate with databases and internal systems directly through configuration. Source: https://www.gradually.ai/en/changelogs/claude-code/

## Roadmap & Announcements

- **Legacy Workbench Retiring August 17, 2026**: The legacy Workbench at platform.claude.com/workbench is being sunset on August 17, 2026. Saved prompts, variables, and evals are not migrated to the updated Playground. The experimental prompt-generation APIs (`/v1/experimental/generate_prompt`, `improve_prompt`, `templatize_prompt`) are also being retired on the same date. Export your data before the deadline. Source: https://platform.claude.com/docs/en/release-notes/overview

- **Claude Sonnet 5 Introductory Pricing Ends August 31**: Claude Sonnet 5's promotional API pricing of $2/$10 per MTok expires August 31, 2026. Standard pricing of $3/$15 per MTok takes effect September 1. Teams relying on Sonnet 5 for cost-sensitive workloads should plan for this change. Source: https://platform.claude.com/docs/en/release-notes/overview

- **Claude Opus 4.1 Retired on August 5, 2026**: The Claude Opus 4.1 model (`claude-opus-4-1-20250805`) is being retired from the Claude API today (August 5). All requests to this model will return an error going forward. Anthropic recommends migrating to Claude Opus 4.8 or Opus 5. Source: https://platform.claude.com/docs/en/release-notes/overview

## Key Takeaway
Claude Opus 5's arrival in Claude Code — with its 1M-token context and deeper nested subagent support (now 3 levels deep) — marks a meaningful step up in what automated multi-agent coding workflows can handle; users on Opus 4.1 must migrate today as that model is retired from the API.

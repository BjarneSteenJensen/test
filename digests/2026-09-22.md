# Claude Code News Digest — 2026-09-22

## Overview
Claude Code continues its rapid release cadence in the week of September 14–22, shipping versions 2.1.271 through 2.1.278 with major improvements to auto mode, MCP reliability, gateway integrations, and VS Code tooling. The headline developments are the introduction of AGENTS.md as an alternative project context file, a permanent 25% increase in weekly usage limits starting September 14, and `claude plugin eval` reaching wider use after its Week 37 debut.

## New Features & Releases

- **v2.1.278 — Auto Mode Defaults to Server-Side Classifier (Sept 19)**: Auto mode for Claude API and Enterprise users, and on Bedrock, Vertex, Foundry, and gateways, now defaults to the server-side classifier, which no longer charges for classifier overhead. AGENTS.md is now supported as an alternative to CLAUDE.md for projects that prefer that naming convention. Source: https://code.claude.com/docs/en/changelog

- **v2.1.275 — Send-Now Key & Memory File Editing (Sept 17)**: A new Ctrl+Enter send-now key lets users interrupt and send queued messages immediately. VS Code users can now view, edit, and delete memory files directly from the extension. Plugin marketplace installation gained new options. Source: https://code.claude.com/docs/en/changelog

- **v2.1.271 — Fast Mode in Remote Sessions & Auto Mode Sandbox (Sept 14)**: Fast mode is now available in Remote Control (cloud and self-hosted) sessions. Mouse support was added to the `/config` panel in fullscreen mode. Per-command `allowed_domains` sandboxing landed in auto mode for safer web tool use. The `omitClaudeMd` agent frontmatter option allows subagents to skip project instructions. Source: https://code.claude.com/docs/en/changelog

- **`claude plugin eval` — Plugin Testing Framework (Week 37, Sept 7–11)**: The new `claude plugin eval` command runs a plugin against a suite of test cases, scores the results, and compares them against a no-plugin baseline. `claude plugin eval init` drafts test cases and graders automatically. Source: https://code.claude.com/docs/en/whats-new

- **Permanent 25% Weekly Limit Increase (Sept 14)**: The temporary 50% higher weekly limit promotion ended September 14, replaced immediately by a permanent 25% increase over standard weekly limits for Pro, Max, Team, and seat-based Enterprise plans. Source: https://releasebot.io/updates/anthropic/claude-code

## Integrations & Extensions

- **MCP Adoption Reaches 95% (Mid-September)**: MCP adoption in Claude Code climbed from near-zero in late July to approximately 95% by mid-September 2026, demonstrating the fastest organic adoption of any Claude Code subsystem. The milestone reflects both the growing MCP server ecosystem and tighter Claude Code integration. Source: https://lucaberton.com/blog/mcp-adoption-by-client-2026/

- **v2.1.274 — MCP Startup Control & Gateway Hint Headers (Sept 17)**: The new `CLAUDE_CODE_MCP_STARTUP_WAIT_MS` environment variable bounds how long non-interactive sessions wait for MCP servers to connect on startup (set to 0 to skip waiting). Gateway hint headers (`x-claude-code-request-class`, `x-claude-code-agent-type`, and others) are now opt-in via `CLAUDE_CODE_GATEWAY_HINT_HEADERS=1` for LLM gateway operators. Source: https://code.claude.com/docs/en/changelog

- **v2.1.273 — MCP Disconnect Notifications & Remote Control Forking (Sept 15)**: Claude Code now shows a notification and link to `/mcp` when an MCP server disconnects mid-session and automatic reconnection gives up. Remote Control session forking is now smoother, and a new Bash permission checker tightens auto mode safety. Source: https://code.claude.com/docs/en/changelog

- **v2.1.269 — VS Code Agent Map Visualization (Sept 11)**: The VS Code extension gained an agent map view that visualizes the subagent graph for the current session. Hooks and Permission Rules dialogs were also added to the extension UI. Source: https://code.claude.com/docs/en/changelog

- **Community Visual Studio 2026 Extension**: A community-built, unofficial extension `claude_code_vs` brings Claude Code to Visual Studio 2026 with a native diff accept/reject interface, a live debugger Claude can drive autonomously, Roslyn code navigation, and Test Explorer integration. Source: https://github.com/firish/claude_code_vs

## Bug Fixes & Performance

- **v2.1.276 — Critical Proxy/Gateway Fix (Sept 18)**: Fixed a regression introduced in v2.1.275 where every request failed with a `400 … Input tag 'advisor_20260301'` error when `ANTHROPIC_BASE_URL` points at a proxy or gateway. Users on enterprise or self-hosted gateway deployments should upgrade immediately. Source: https://code.claude.com/docs/en/changelog

- **v2.1.277 — 50+ Bug Fixes (Sept 18)**: A sweeping fix release addressed artifact handling, terminal rendering glitches, session management edge cases, plugin management issues, and VS Code extension stability. Improvements span desktop, VS Code, web, Slack, and code review surfaces. Source: https://code.claude.com/docs/en/changelog

- **v2.1.270 — Git Permission Regression Fixed (Sept 12)**: Read-only git commands were unexpectedly triggering permission prompts. This fix restores the correct behavior where commands like `git log` and `git diff` run without interruption in auto mode. Source: https://code.claude.com/docs/en/changelog

- **Agent SDK Hanging Sessions Fixed**: Sessions started with `claude -p` and the Agent SDK could hang indefinitely after an internal error with no result returned. Also fixed: conversations failing with "text content blocks must be non-empty" errors in Agent SDK usage. Source: https://releasebot.io/updates/anthropic/claude-code

## Community & Ecosystem

- **Claude Code as a Startup Prototyping Tool**: A practical guide published in September positions Claude Code as a primary tool for founders validating product ideas — covering repo mapping, bug fixes, writing tests, generating docs, and reviewing diffs with minimal risk. Best-practice recommendations include tight permission rules, low-risk initial access, and clear definitions of done. Source: https://blog.mean.ceo/claude-code-news-september-2026/

- **Claude Fable 5.1 Available in Claude Code (Week 36, Aug 31–Sept 4)**: Claude Fable 5.1 landed in Claude Code with a 1M-token context window. Simultaneously, Claude Mythos 5.1 was released as an identical model with different safeguard levels for coding and scientific research. Cache reads dropped 75% to $0.25 per million tokens, cutting typical workload costs by roughly 25% and agentic tasks by up to 45%. Source: https://code.claude.com/docs/en/whats-new

- **Claude Code Projects Beta — Parallel Threads & Shared Memory**: A new beta feature lets a single Claude Code project coordinate parallel threads, share memory across sessions, and maintain a project library for long-running work across repos and tasks. Designed to reduce re-explanation overhead and improve steering across multi-session workflows. Source: https://releasebot.io/updates/anthropic/claude-code

## Roadmap & Announcements

- **"Claude Mods Are Landing Now" (Boris Cherny, Anthropic)**: Boris Cherny of Anthropic's Claude Code team announced that Claude Mods — a new extensibility layer for customizing Claude Code behavior — are beginning to roll out. No public documentation is available yet; further details expected in a coming Week digest. Source: https://www.eesel.ai/blog/claude-code-vs-code-extension

- **Cowork Expanded to Web & Mobile with Cross-Device Sync**: Cowork now runs on web and mobile in addition to desktop, with remote sessions in beta. Files and session state are saved to the user's Claude account and synced across devices, enabling handoff between desktop and mobile mid-session. Source: https://code.claude.com/docs/en/whats-new

- **Claude Security Scanning on Claude Mythos 5**: Enterprise customers can now run Claude Security scans on Claude Mythos 5, the most capable available model, to scan codebases for security vulnerabilities and auto-suggest patches. Source: https://releasebot.io/updates/anthropic

## Key Takeaway
The most significant development this week is the combination of the permanent 25% usage limit increase (effective Sept 14) and the v2.1.278 change making auto mode's server-side classifier the default for API/Enterprise users — together these lower cost and reduce friction for teams running Claude Code at scale in production pipelines.

# Claude Code News Digest — 2026-08-07

## Overview
Today's headline is the release of Claude Code v2.1.224, which ships the long-awaited `claude self-hosted-runner` command enabling Team and Enterprise users to host Claude Code sessions on their own machines or containers. The update also adds cross-session messaging — allowing Claude Code sessions to send messages to each other across machines — and removes the previous 200-subagent-per-session cap. August 2026 continues a rapid release cadence focused on security, extensibility, and enterprise control.

## New Features & Releases
- **v2.1.224 (August 7, 2026) — Self-Hosted Runner**: Anthropic shipped `claude self-hosted-runner`, a new CLI command that lets Team and Enterprise plan users run Claude Code web, mobile, and desktop sessions on their own machines or containers. This gives organizations full control over their execution environment. Source: https://code.claude.com/docs/en/changelog

- **Cross-Session Messaging**: v2.1.224 adds `SendMessage` and `ListAgents` tools so Claude Code sessions can message each other across machines on macOS and Linux. New `crossSessionInbound` and `dialogExpiry` settings control trust and expiry for inbound messages from sessions with bypassed permissions. Source: https://code.claude.com/docs/en/changelog

- **Archive Plugin Source**: Plugins can now be installed from zip files served over HTTPS without requiring git or npm, with optional SHA-256 hash pinning for integrity verification. This closes a common deployment gap for air-gapped or restricted environments. Source: https://code.claude.com/docs/en/changelog

- **Removed 200-Subagent Cap**: The per-session 200-subagent spawn limit has been lifted in v2.1.224 (concurrency and depth limits still apply). This unblocks large-scale dynamic workflow runs that previously hit the ceiling. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions
- **VS Code Focus View**: Recent August builds added a VS Code Focus view — a chat-menu toggle (Ctrl+Alt+F) that hides tool activity behind a per-turn expandable summary with a live running-tool indicator. This reduces UI noise during long agentic runs. Source: https://releasebot.io/updates/anthropic/claude-code

- **MCP 2026-07-28 Spec Support**: Claude Code now supports the latest MCP specification (dated July 28, 2026), bringing a stateless core, stronger OAuth and OIDC authorization, and versioned extensions for Apps and Tasks. MCP has surpassed 400 million monthly SDK downloads — a 4x increase in 2026 — and the Claude connector directory now lists over 950 servers. Source: https://code.claude.com/docs/en/changelog

- **Admin Console Usage Tab**: The Claude Code admin console gained a new Usage tab showing active developers, session counts, and top commands across an organization, updated daily. This gives Enterprise teams better observability into how Claude Code is being adopted internally. Source: https://releasebot.io/updates/anthropic/claude-code

- **Claude Agent SDK — August 4 Release**: The Claude Agent SDK (the programmable Python/TypeScript interface to Claude Code's agentic loop) shipped a new release on August 4, 2026, with fixes for SDK MCP servers, improved agent session handling, and bug fixes for streaming and memory management. Source: https://pypi.org/project/claude-agent-sdk/

## Bug Fixes & Performance
- **v2.1.224 Security & Reliability Fixes**: Today's release fixes sandbox filesystem deny rules being bypassable with trailing slashes, MCP tools connecting mid-turn being silently deferred without announcing their names, and `SendMessage` falsely reporting successful delivery when the write actually failed. Remote Control auto-start failures ("Remote credentials fetch failed") and stale server sessions not being archived after compaction are also resolved. Source: https://code.claude.com/docs/en/changelog

- **v2.1.223 Worktree & Security Hardening (August 4–5, 2026)**: The preceding release fixed worktree-isolated sessions and their subagents being able to run destructive git commands against the main checkout. It also added owner wildcard entries (`owner/*`) to `strictKnownMarketplaces` and `blockedMarketplaces` managed settings, and hardened permission checks to prevent commands from hiding themselves using tabs or invisible characters. Source: https://code.claude.com/docs/en/changelog

- **Sandbox Credential Masking Enhancements**: v2.1.224 extends the credential masking system with new options including an `extract` regex for custom patterns, JWT decoding with `maskClaims`, and AWS SigV4 re-signing support — reducing the risk of secrets leaking through tool outputs. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
The release of `claude self-hosted-runner` in v2.1.224 today is the most consequential development: it lets enterprises run Claude Code sessions entirely on their own infrastructure, addressing a top blocker for security-sensitive organizations. Combined with the removal of the 200-subagent cap and the new cross-session messaging primitive, August 2026 marks Claude Code's clearest push yet toward enterprise-grade, large-scale autonomous coding workflows.

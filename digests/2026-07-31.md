# Claude Code News Digest — 2026-07-31

## Overview
July 2026 has been a major month for Claude Code: Claude Opus 5 landed on July 24 as the new default Opus model with a 1M-token context window, while the MCP 2026-07-28 specification brought a stateless core and stronger OAuth/OIDC auth. Week 29 (July 13–17) delivered live MCP data in published artifacts and a new screen reader mode for accessible terminal sessions.

---

## New Features & Releases

- **Claude Opus 5 now default Opus model (v2.1.220, July 24)**: Anthropic released Claude Opus 5 (`claude-opus-5`) as the new default Opus model in Claude Code, featuring a 1M-token context window, up to 128K output tokens, adaptive thinking on by default, and a five-level effort setting. `/fast` now applies to Opus 5 and Opus 4.8; Opus 4.7 has been removed from fast mode. Source: https://releasebot.io/updates/anthropic/claude-code

- **Nested subagents now up to depth 3**: Subagents can now spawn their own nested subagents up to depth 3 by default (previously capped at depth 1), significantly expanding multi-agent orchestration capabilities for complex tasks. Source: https://code.claude.com/docs/en/whats-new

- **Week 29: Screen reader mode (v2.1.207–v2.1.212, July 13–17)**: A new `--ax-screen-reader` flag (or `CLAUDE_AX_SCREEN_READER` env var / `axScreenReader` setting) replaces the visual terminal interface with plain, labeled, linear text output compatible with screen readers such as VoiceOver and NVDA. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **Week 28: In-app browser on Desktop (July 6–10)**: Claude Code Desktop gained a built-in browser so Claude can navigate docs, designs, or any website and interact with pages — the same capability it already had for local dev-server previews. Source: https://code.claude.com/docs/en/whats-new

- **Week 28: `/doctor` setup checkup command**: The new `/doctor` command (alias `/checkup`) runs a full environment diagnosis and can automatically fix common setup issues, reducing friction during onboarding and troubleshooting. Source: https://code.claude.com/docs/en/whats-new

## Integrations & Extensions

- **MCP 2026-07-28 specification support**: Claude Code expanded support for the new MCP 2026-07-28 spec, introducing a stateless core, stronger OAuth and OIDC authorization, and versioned extensions for Apps and Tasks. New connector features include embedded UI, enterprise-managed auth, observability hooks, and private network tunnels. Source: https://www.gradually.ai/en/changelogs/claude-code/

- **Artifacts call MCP connectors for live data (Week 29)**: Published artifacts can now pull live data and trigger actions through each viewer's own MCP connectors at view time, turning static snapshots into live dashboards. Viewers approve connector access on first load; each call runs under the viewing account's permissions. Also added: public sharing links, editor roles for Team/Enterprise, and artifacts from Claude Tag sessions. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **Auto mode on Bedrock, GCP Agent Platform, and Microsoft Foundry without opt-in**: Auto mode no longer requires the `CLAUDE_CODE_ENABLE_AUTO_MODE` environment variable on Amazon Bedrock, Google Cloud's Agent Platform, and Microsoft Foundry. Administrators can disable it with `disableAutoMode`. Default model on these platforms is now Claude Opus 4.8. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **VS Code 1.128: multi-chat for Claude agent sessions (July 8)**: VS Code 1.128 shipped with multi-chat support for Claude Code agent sessions, letting users compare approaches, branch from earlier turns, run work in parallel, and send turns concurrently within a single session. Source: https://visualstudiomagazine.com/articles/2026/07/08/claude-ai-gets-yet-another-boost-in-vs-code-1-128.aspx

## Bug Fixes & Performance

- **Terminal freeze and keystroke lag fixed (v2.1.220)**: A bug causing the terminal to freeze and keystrokes to lag while Claude streamed responses containing very long lists, tables, paragraphs, or code blocks has been fixed in the latest release. Source: https://www.havoptic.com/tools/claude-code

- **Remote managed settings consent dialog fixed**: A bug where remote managed settings from non-interactive runs were permanently recorded as consented without ever showing the security consent dialog has been resolved, restoring proper security behavior for enterprise deployments. Source: https://www.havoptic.com/tools/claude-code

- **MCP tools auto-background after 2 minutes (Week 29)**: MCP tool calls that run longer than two minutes now move to the background automatically so the session stays responsive. The threshold is tunable or disableable via `CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS`. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **Session-wide caps prevent runaway loops**: New default caps of 200 WebSearch calls and 200 subagent spawns per session prevent runaway loops. Both limits are tunable via `CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION` and `CLAUDE_CODE_MAX_SUBAGENTS_PER_SESSION`. Source: https://code.claude.com/docs/en/whats-new/2026-w29

## Community & Ecosystem

- **Claude Cowork expands to web and mobile**: Starting July 7, Claude Cowork — previously desktop-only — became available on web and mobile for Max subscribers, allowing users to start a task at their desk, receive status updates on their phone, and pick up the output later. Source: https://techcrunch.com/2026/07/07/the-coding-agent-wars-are-spilling-into-the-rest-of-the-office-claude-cowork/

- **Claude Code weekly limits promotion (50% higher through July 19)**: Anthropic extended a limited-time promotion giving Pro, Max, Team, and eligible Enterprise users 50% higher weekly limits in Claude Code through July 19, 2026. Claude Code and Agent SDK usage is now metered separately from interactive Claude Code usage as of June 15. Source: https://www.helpnetsecurity.com/2026/07/13/claude-code-weekly-limits-promotion-extended/

- **Cursor vs. Claude Code July 2026 comparison**: Community and tech press coverage of the coding-agent competitive landscape intensified in July, with detailed comparisons noting Claude Code's expanding agent controls, auto mode, and in-app browser as differentiators. Source: https://www.futureproofing.dev/resources/ai-native-team/cursor-vs-claude-code-2026

## Roadmap & Announcements

- **Claude Fable 5 subscription availability finalized (July 20)**: After three access extensions, Anthropic finalized Fable 5's subscription availability on July 20, 2026. Max and Team Premium plans keep Fable 5 included at up to 50% of weekly usage limits. Source: https://www.anthropic.com/news/redeploying-fable-5

- **Claude service outage July 29**: Claude users experienced a brief platform outage on July 29, triggering more than 2,000 outage reports. Anthropic confirmed the incident; no extended data-loss impact was reported for Claude Code sessions. Source: https://www.newsweek.com/claude-down-outage-capacity-constraints-not-working-anthropic-12262120

- **`/fork` and `/subtask` command split**: The `/fork` command was redesigned in Week 29 — it now copies a conversation into a new background session with its own row in `claude agents`. The previous in-session forked subagent behavior is now available as `/subtask`. Source: https://code.claude.com/docs/en/whats-new/2026-w29

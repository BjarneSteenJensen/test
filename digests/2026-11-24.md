# Claude Code News Digest — 2026-11-24

## Overview
November 24, 2026 caps a week of rapid Claude Code shipping: version 2.1.331 (released November 23) brings Code Mode to all major cloud providers, while Claude Ship — a new PR-review-and-approve feature with a `/ship` command — launched in beta for Team and Enterprise plans. The month's headline additions are Code Mode (Claude writes JavaScript to chain tool calls in one step) and auto mode landing on Amazon Bedrock, Google Cloud, Microsoft Foundry, and the Claude apps gateway.

---

## New Features & Releases

- **Code Mode reaches cloud providers (v2.1.331, Nov 23)**: The experimental Code Mode — where Claude generates a JavaScript script to chain multiple tool calls in a single step — is now available on Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry, and Claude Platform on AWS. It was first introduced for native terminal sessions in v2.1.323 (Nov 12) and extended to agent-team sessions in v2.1.326 (Nov 16). Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Auto mode on third-party clouds (v2.1.328, Nov 19)**: Auto mode is now available for Claude Opus 4.6 and Sonnet 4.6 on Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry, and the Claude apps gateway. Interactive sessions without a permission mode set will start in auto mode. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Enterprise Admin Console sign-in (v2.1.330, Nov 20)**: Users can now sign in to organizations managed via Anthropic's Enterprise Admin Console directly from Claude Code, simplifying credential handling for enterprise teams. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Fable 5.2 as default Fable model (v2.1.321)**: Claude Code switched to Fable 5.2 as the default model when "fable" is selected, with no breaking changes required from users. Source: [Anthropic Release Notes – Releasebot](https://releasebot.io/updates/anthropic/claude-code)

## Integrations & Extensions

- **Claude Ship beta with `/ship` command (Nov 23)**: Anthropic launched Claude Ship in beta on Team and Enterprise plans. The feature enables Claude to review and approve pull requests, and is surfaced via a new `/ship` command in Claude Code's CLI and desktop app. It is rolling out gradually. Source: [Testing Catalog – Anthropic launches Claude Ship](https://www.testingcatalog.com/anthropic-launches-claude-ship-to-review-and-approve-prs/)

- **VS Code gains `/fork` and `/workflows` (v2.1.330, Nov 20)**: The VS Code extension received two new slash commands — `/fork` and `/workflows` — that mirror features already available in the terminal. VS Code responsiveness in long chats was also improved in v2.1.331. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **"easel" built-in mod for charts (v2.1.330, Nov 20)**: A new built-in mod called "easel" adds charting capabilities directly within Claude Code sessions, reducing the need for external visualization tools. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Code Mode on cloud provider support (v2.1.331, Nov 23)**: `optionalDependencies` are now supported in plugin manifests, and plugin marketplaces listed in managed `extraKnownMarketplaces` will auto-update by default starting November 30, 2026 (opt out by setting `"autoUpdate": false`). Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Bug Fixes & Performance

- **MCP tool call hang fixed (v2.1.331, Nov 23)**: A bug causing MCP tool calls to hang for up to 30 minutes on malformed server replies was resolved. Additional Code Mode and VS Code-specific issues were also patched. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **MCP `.mcp.json` key-deletion bug fixed (v2.1.327, Nov 17)**: `claude mcp add` and `remove` with project scope were accidentally deleting other top-level keys in `.mcp.json`. This is now fixed. The same release added `claude mcp add-json <name> -` to read server JSON from stdin, keeping tokens off the command line. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **`~/.claude.json` reset during network stalls (v2.1.329, Nov 19)**: User settings in `~/.claude.json` were being reset to defaults during network stalls; this regression is now fixed. The release also patched repeated macOS sign-outs. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Conversation compaction freeze fixed (v2.1.330, Nov 20)**: Claude Code was freezing for minutes after compacting very long conversations; this is now resolved. `ExitWorktree` deleting a worktree another session was using was also fixed. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Startup and typing speed improvements (v2.1.331)**: Startup time was reduced, screen reader mode typing speed improved, and VS Code long-chat responsiveness addressed. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Community & Ecosystem

- **Zsh word-starting-with-`=` crash fixed (v2.1.328)**: A parsing bug caused zsh to fail on shell words beginning with `=`. The fix landed alongside token-count corrections for retried replies. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **OpenCode 2.2.3 integrates Agent SDK**: The third-party OpenCode tool (v2.2.3, released Oct 30) added a provider that runs Claude through the Claude Agent SDK using the user's installed Claude Code credentials. Source: [CellCog – OpenCode Brings Back Claude Subscriptions via the Agent SDK](https://cellcog.ai/blog/opencode-claude-subscription/)

- **MCP tasks in background terminal (v2.1.319, early Nov)**: MCP tasks now run in the background in the terminal, with an environment variable allowing synchronous wait if preferred. This was highlighted as a productivity improvement in community roundups. Source: [Developer's Digest – Claude Code MCP Tasks](https://www.developersdigest.tech/blog/claude-code-mcp-tasks-elicitations-long-running-tools-2026)

## Roadmap & Announcements

- **Fast mode deprecated for Opus 4.8 (removal Nov 30, 2026)**: Fast mode support for Claude Opus 4.8 is deprecated and will be removed from Claude Code on November 30, 2026. Users running Opus 4.8 with fast mode enabled should switch models or disable fast mode before that date. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Plugin marketplace auto-updates (starting Nov 30)**: Plugin marketplaces declared in managed `extraKnownMarketplaces` will begin auto-updating by default on November 30, 2026. Organizations that want to control update cadence should set `"autoUpdate": false` on the entry before that date. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Scheduled tasks and `/loop` extended to 30 days**: The maximum runtime for scheduled tasks and `/loop` sessions increased from 7 days to 30 days in v2.1.330, enabling longer autonomous workflows. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Email privacy prompt (v2.1.317, Nov 3)**: Claude Code now shows a prompt before a web or shell tool sends the user's account email address over the network, giving users control over credential exposure. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

---

## Key Takeaway
The single biggest development this week is the general availability of **Code Mode on all major cloud providers** (v2.1.331), combined with the **Claude Ship beta** launching for Team/Enterprise — together these significantly expand Claude Code's autonomous coding and PR-review capabilities beyond the local terminal. Watch the November 30 deadline: fast mode removal for Opus 4.8 and plugin marketplace auto-updates both take effect that day.

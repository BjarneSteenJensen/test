# Claude Code News Digest — 2026-08-05

## Overview
Claude Code v2.1.222 shipped on August 4 with critical security hardening — most notably a fix for worktree-isolated sessions that could run destructive git commands against the main checkout. Anthropic also officially retired the Claude Opus 4.1 model today as previously scheduled, and the temporary 50% weekly usage boost for Claude Code subscribers remains in effect through August 19.

## New Features & Releases
- **Claude Code v2.1.222 (August 4, 2026)**: A security- and reliability-focused release. Key additions include isolating file edits and Bash commands across all session types in worktrees, fixing auto-allow hooks that were bypassing tool restrictions in background agent tasks, and removing the "ultraplan" feature. The `/diff` view and file-edit diffs were also improved to use raw git blob content. Source: https://code.claude.com/docs/en/changelog

- **VSCode Focus View (v2.1.221)**: Claude Code's VS Code extension gained a new Focus view that collapses tool activity into an expandable per-turn summary with a live running-tool indicator. It is toggled via Ctrl+Alt+F or the "Claude Code: Toggle Focus view" command, reducing interface clutter during long agentic runs. Source: https://releasebot.io/updates/anthropic/claude-code

- **Nested Subagent Depth Raised to 3**: Subagents can now spawn nested subagents up to depth 3 by default (previously depth 1), enabling richer multi-agent workflow orchestration. Set `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1` to revert to the previous limit. Source: https://www.gradually.ai/en/changelogs/claude-code/

## Integrations & Extensions
- **Sandbox Credential Masking**: A new `mode: "mask"` option for sandbox credential files on Linux and WSL 1 lets sandboxed commands read a sentinel copy while the sandbox proxy substitutes the real value on egress, improving secret hygiene for local dev environments. Source: https://code.claude.com/docs/en/changelog

- **Improved MCP & Plugin Permission Handling**: Recent releases tightened plugin, MCP, and permission flows, and server-managed settings now allow benign feature and cost toggles to bypass the settings-approval prompt, reducing interruptions during automated sessions. Source: https://releasebot.io/updates/anthropic/claude-code

- **Dreams Research Preview Adds Claude Opus 5**: Anthropic's Dreams memory-consolidation feature (research preview) within Claude Managed Agents now supports Claude Opus 5 as of August 1, 2026. Source: https://platform.claude.com/docs/en/release-notes/overview

## Bug Fixes & Performance
- **Proxy and Connectivity Fixes**: The startup connectivity check no longer hangs behind an HTTPS proxy — it now uses proxy-aware transport and times out with a clear error message. A separate fix stops the stream idle timeout from firing on custom `ANTHROPIC_BASE_URL` gateways when the server is actively sending keep-alive pings. Source: https://code.claude.com/docs/en/changelog

- **/usage Attribution Corrected**: Fixed `/usage` overattributing token usage to MCP servers; the server's share now reflects only requests that actually consumed its tool results. Also fixed `/usage-credits` on Team and Enterprise plans showing incorrect blocking messages for non-admin members. Source: https://code.claude.com/docs/en/changelog

- **Git Workflow and Auto Mode Fixes**: Fixed sessions failing to link to pull requests created after a branch was pushed (including via the GitHub REST API). Auto mode now evaluates messages sent to other agent sessions through the permission classifier before dispatch, closing a safety gap. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem
- **50% Usage Boost Extended Through August 19**: Anthropic extended the temporary 50% weekly usage boost for Claude Code subscribers through August 19, 2026, giving users additional headroom for large-scale coding sessions. Source: https://releasebot.io/updates/anthropic

- **Claude Agent SDK August 4 Release**: The Claude Agent SDK (officially renamed from "Claude Code SDK" in March 2026) released an August 4 update with bug fixes for MCP server registration, agent dashboard functionality, background session management, and streaming output for SDK consumers. Source: https://pypi.org/project/claude-agent-sdk/

## Roadmap & Announcements
- **Claude Opus 4.1 Officially Retired Today**: The Claude Opus 4.1 model (`claude-opus-4-1-20250805`) reached end-of-life on August 5, 2026, as announced on June 5. All requests to this model now return an error; Anthropic recommends migrating to Claude Opus 4.8. Source: https://platform.claude.com/docs/en/release-notes/overview

- **Claude Sonnet 5 Introductory Pricing Ends August 31**: Claude Sonnet 5's promotional rate of $2/$10 per million tokens (input/output) expires August 31, 2026, after which standard pricing of $3/$15 per MTok applies. Source: https://platform.claude.com/docs/en/release-notes/overview

- **Legacy Workbench and Prompt Tools APIs Sunset August 17**: The legacy Workbench at platform.claude.com/workbench is being retired on August 17, 2026. The experimental prompt-generation APIs (`/v1/experimental/generate_prompt`, `/v1/experimental/improve_prompt`, `/v1/experimental/templatize_prompt`) are also being removed on the same date; any saved prompts or evals should be exported before then. Source: https://platform.claude.com/docs/en/release-notes/overview

## Key Takeaway
The most operationally important development today is the retirement of Claude Opus 4.1 (effective immediately) combined with a security patch in Claude Code v2.1.222 that closes a worktree isolation hole — developers using isolated agent sessions should update the CLI promptly and confirm any Opus 4.1 API integrations have been migrated to Opus 4.8.

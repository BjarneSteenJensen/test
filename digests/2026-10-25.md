# Claude Code News Digest — 2026-10-25

## Overview
October 2026 has been a milestone month for Claude Code, headlined by the general availability of Code Review for Team and Enterprise customers (October 15) and a rapid release cadence delivering versions 2.1.299 through 2.1.310 in just the last two weeks. Key themes include expanded OpenTelemetry observability, hardened security defaults, and the addition of plugin monitors across cloud providers (Bedrock, Vertex, Foundry).

## New Features & Releases

- **Code Review Now Generally Available (Oct 15)**: Anthropic launched Code Review as GA for Claude Team and Enterprise organizations. Reviews now complete in ~6–10 minutes — roughly 3× faster than the research preview — with findings being more concise. Admins can set per-repository review depth (Quick, Standard, or Deep). Eligible Enterprise organizations can claim at least $10,000 in Code Review credits by January 15, 2027. Source: https://claude.com/resources/articles/code-review-is-now-generally-available

- **v2.1.310 — Monitor Tool & Plugin Monitors (Oct 23)**: The Monitor tool landed alongside plugin monitors on Bedrock, Vertex, and Foundry, and when telemetry or nonessential traffic is disabled. Cloud session and Remote Control permissions can now be assigned to Enterprise custom roles, and a "Choose file" button simplifies cloud environment setup. Source: https://code.claude.com/docs/en/changelog

- **v2.1.304 — `/auto-mode-setup` Guided Setup (Oct 19)**: A new `/auto-mode-setup` command reads your project and recent sessions, then walks through configuring auto mode interactively. The same release added `/claude-api managed-agents-secure` to compare agent settings against Anthropic's security guide and a warning on Pro/Max plans when resuming inactive conversations would consume a large share of the 5-hour limit. Source: https://code.claude.com/docs/en/changelog

- **v2.1.299 — Idle Compaction (Oct 14)**: Claude Code now auto-compacts terminal conversations over 200K tokens that have been idle for about 54 minutes. The threshold is configurable via `CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS`, and the feature can be disabled with `"idleCompaction": false` in settings. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **LaTeX Math Rendering in VS Code (v2.1.301, Oct 15)**: Claude Code's VS Code extension now renders LaTeX math inline in responses. The same release also added `classifier_verdict`, `permission_mode`, and `classifier_category` attributes to OpenTelemetry `tool_decision` events, improving audit capabilities. Source: https://code.claude.com/docs/en/changelog

- **Fork Subagents On by Default Outside Terminal (v2.1.302, Oct 16)**: Fork subagents are now enabled by default in non-terminal environments (Agent SDK, cloud sessions). Set `CLAUDE_CODE_FORK_SUBAGENT=0` to opt out. A new `CLAUDE_CODE_AUTO_MODE_MODEL` environment variable lets users choose the auto mode classifier model. Source: https://code.claude.com/docs/en/changelog

- **Agent SDK — TypeScript 0.3.302 / Python 0.2.168 (Oct 15–16)**: The TypeScript SDK fixed structured output when the API refuses a response. Both SDKs now default to `default` permission mode on third-party providers unless `--permission-mode auto` is explicitly passed — a breaking change for workflows relying on auto mode by default. Source: https://code.claude.com/docs/en/changelog

## Bug Fixes & Performance

- **v2.1.300 — 131 Bug Fixes (Oct 14)**: The month's largest single-release fix batch included gzip compression for large API requests, GenAI semantic-convention trace attributes, corrected MCP allow-rule scoping, and hook `updatedInput` validation. Source: https://code.claude.com/docs/en/changelog

- **v2.1.309 — Sandbox and MCP Hardening (Oct 22)**: 62 fixes covered sandbox startup-file and `denyWrite` path issues, MCP config file protection, and several Claude Tag (Slack integration) bugs. Dangerous `rm` and `rmdir` commands in bypass mode are now denied immediately with a rewrite hint. Source: https://code.claude.com/docs/en/changelog

- **v2.1.306 — `claude -p` Cloud Session Fix (Oct 21)**: Fixed `claude -p` incorrectly reporting "Not logged in" inside cloud sessions, and an API error being masked as "prompt is too long" in sessions with many MCP tools. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **MCP Tasks and Elicitations Support (Oct 23)**: Reports indicate Anthropic shipped support for MCP Tasks and Elicitations in the Claude Code CLI on October 23, 2026, enabling more durable agentic workflows where agents can request user input mid-run. Other surfaces (VS Code, desktop) are reportedly on the roadmap. Source: https://code.claude.com/docs/en/changelog

- **`claude ultrareview` Requires Workspace Trust (v2.1.309, Oct 22)**: `claude ultrareview` now requires workspace trust to run. Automated CI/CD scripts must pass `--trust-workspace` or set `CLAUDE_CODE_DISABLE_ULTRAREVIEW_TRUST_CHECK=1`. This is a breaking change for existing pipelines. Source: https://code.claude.com/docs/en/changelog

- **Security Misuse Disclosure**: Cybersecurity researchers disclosed that a threat actor ("CyberXero") reportedly leveraged Claude Code in a campaign that accessed 429 WordPress admin panels and exfiltrated over 628,000 records. The incident, reported October 12, highlights growing scrutiny of AI coding tools in adversarial contexts. Source: https://thehackernews.com/2026/10/cyberxero-uses-claude-code-in-campaign.html

## Roadmap & Announcements

- **Claude Opus 5.5 Released (Oct 18)**: Anthropic released Claude Opus 5.5, the latest flagship model. Claude Code's model defaults have been updated to the 5.5 family (Haiku 5.5 became the default Haiku model with v2.1.293 on Oct 7, with Opus 5.5 following). Source: https://www.anthropic.com/news

- **New API Version `2026-10-21`**: Claude Code 2.1.307 added `/claude-api api-version` to migrate code to the `2026-10-21` API version, signaling new API capabilities. The new `claude_code.safety_event` OpenTelemetry event, also added in this release, emits for every tool call stopped or prompted by permission rules, auto mode, safety checks, hooks, or the sandbox — expanding compliance observability. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
Code Review going generally available on October 15 is the month's biggest user-facing milestone — Team and Enterprise customers now get AI-powered PR reviews at 3× the speed of the preview, with up to $10,000 in free credits available to Enterprise organizations through January 2027.

# Claude Code News Digest — 2026-11-11

## Overview
Claude Code shipped five point releases (v2.1.317–v2.1.322) in the first eleven days of November, bringing background MCP task support, a new default model (Fable 5.2), and over 270 bug fixes. The week's biggest external news is Anthropic's confirmation that it added guardrails preventing Claude Code from recreating existing games, and Apple Xcode 26.3's native integration of the Claude Agent SDK.

---

## New Features & Releases

- **v2.1.322 — Fast mode on Vertex (Nov 10)**: Fast mode is now available on Vertex AI in the global, us, and eu regions, with an automatic fallback to standard speed if Vertex refuses it. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.321 — Claude Fable 5.2 becomes default model (Nov 9)**: Fable 5.2 (`claude-fable-5-2`) is now the default Fable model, offering 1M-token context at $8/$40 per million tokens ($0.20/Mtok cache reads). `--settings <file>` was also added to `claude remote-control`. 74 bug fixes included, notably an MCP OAuth fix that prevented secrets from being sent to the wrong host after a redirect. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.319 — Background MCP tasks & gateway improvements (Nov 6)**: MCP tasks in the terminal now move to the background immediately and report results on completion (opt out with `CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND`). Added `permissions.denyInsteadOfPrompting` setting and `/claude-api latency-optimize`. Auto mode behind gateways or with telemetry off no longer falls back to the built-in classifier. 90 bug fixes including a Bash permission bypass via crafted environment prefix. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.317 — Email-protection & SDK hook controls (Nov 3)**: Added a confirmation prompt before any web or shell tool call that would send the user's account email to the network. Agent SDK hook callbacks now support `onFailure: "block"` to block the action on callback failure. 62 bug fixes. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Integrations & Extensions

- **Apple Xcode 26.3 — Native Claude Agent SDK integration**: Xcode 26.3 (release candidate) now integrates the Claude Agent SDK natively. Claude can capture Xcode Previews for visual iteration, map project file structure, plan and execute multi-step goal-based changes, search Apple docs, and expose Xcode capabilities via MCP so Claude Code CLI users can interact with Previews from the terminal. Source: [Anthropic News](https://www.anthropic.com/news/apple-xcode-claude-agent-sdk)

- **v2.1.318 — IDE extension no longer auto-installs (Nov 4)**: Claude Code no longer automatically installs or updates the IDE extension when started inside an IDE terminal. Use `/ide` to install manually. Added `loginExpiresAt` to `claude auth status` with a 10-day warning before expiry. Background subagents now move long shell commands to the background after 3 minutes on all providers. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **MCP consent cards in cloud sessions**: When an MCP server requests the user to open a URL, cloud sessions now show a link card allowing the user to open or decline it. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Bug Fixes & Performance

- **MCP OAuth secret leak fixed (v2.1.321)**: A security-relevant bug where MCP OAuth could send secrets to a different host after a redirect was resolved in v2.1.321. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Bash permission bypass patched (v2.1.319)**: A bug allowing a Bash permission bypass via a crafted environment variable prefix was fixed. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Fast mode Opus 4.8 deprecation**: Fast mode for the Opus 4.8 model is deprecated as of October 30, 2026, and will be removed on **November 30, 2026**. Users should migrate to Opus 5.5 to retain fast-mode behavior. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Community & Ecosystem

- **Anthropic confirms game-cloning guardrails**: Anthropic confirmed it added new Claude Code restrictions to prevent recreation of existing games. Developers had reported refusals since late October. The company stated that original game creation, genre games, and games built from a user's own assets remain supported. Source: [Tom's Hardware](https://www.tomshardware.com/tech-industry/artificial-intelligence/anthropic-confirms-new-claude-code-limits-to-prevent-game-cloning-users-report-opus-5-5-is-also-actively-blocking-reverse-engineering-tasks)

- **Apiiro security report — secrets in "don't ask again" approvals**: Security firm Apiiro reported finding over 1,100 public GitHub files containing at least one secret, all tied to saved Claude Code "Yes, and don't ask again" approvals. As of November 8, Anthropic had not issued a public response. Source: [Tech Insider](https://tech-insider.org/au/claude-code-dont-ask-again-secrets-github-apiiro-2026/)

- **Developer migration post reaches Hacker News front page**: A blog post describing a developer switching from Claude Code to Pi (an open-source CLI alternative), citing over 244 releases and accumulated complexity, reached the Hacker News front page on November 8, sparking debate about CLI tool sustainability. Source: [FourWeekMBA](https://fourweekmba.com/ai-developer-quits-claude-code-for-pi-citing-244-releases/)

## Key Takeaway

The release of Claude Fable 5.2 as the new default model (v2.1.321) is the most significant technical development this week, expanding context to 1M tokens; combined with Anthropic confirming new game-cloning guardrails, the week signals Anthropic is simultaneously pushing Claude Code's capabilities while tightening its usage policies.

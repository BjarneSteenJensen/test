# Claude Code News Digest — 2026-09-30

## Overview
September 2026 closes with a pair of major model releases — Claude Sonnet 5.5 and Claude Opus 5.5 — both shipping with 1M-token context windows at reduced pricing, solidifying Claude Code's position as the most capable AI coding assistant in its class. The month also delivered a new developer plugin portal, Adobe Acrobat integration, the `/doctor prompt-audit` command, and extensive MCP reliability fixes across five version releases (v2.1.280–v2.1.285).

## New Features & Releases

- **Claude Sonnet 5.5 Becomes Default Sonnet Model (v2.1.284, Sep 28)**: `claude-sonnet-5-5` is now the default Sonnet model in Claude Code, featuring a 1M-token context window and $2/$10 per Mtok pricing with $0.20/Mtok cache reads. The release also introduced `/mcp reconnect all` for retrying all failed MCP servers at once and `/rate-limit-options` for subscribers to manage their plan limits. Source: https://code.claude.com/docs/en/changelog

- **Claude Opus 5.5 Becomes Default Opus Model (v2.1.280, Sep 22)**: `claude-opus-5-5` replaces the previous default Opus model, delivering performance at Claude Fable 5.1's level at 40% lower cost, with a 1M-token context window and $4/$20 per Mtok pricing with $0.20/Mtok cache reads. Pro and Team Standard plans switched from Sonnet to Opus by default at this version. Source: https://code.claude.com/docs/en/changelog

- **maxProseWidth Terminal Setting (v2.1.282, Sep 24)**: A new `maxProseWidth` setting caps the width of Claude's prose output in wide terminals while tables and code blocks retain their full width. Also added telemetry variable tracking in startup notices and an `allowClaudeInChromeWithManagedMcp` managed setting for enterprise deployments. Source: https://code.claude.com/docs/en/changelog

- **Plugin Configuration and Disable-WebFetch Controls (v2.1.285, Sep 29)**: Added `claude plugin configure <plugin>` for per-plugin configuration management, `claude --desktop` to open the Claude Desktop app from the CLI in the current directory, and the `CLAUDE_CODE_DISABLE_WEB_FETCH` environment variable to disable the WebFetch tool entirely in restricted environments. Source: https://code.claude.com/docs/en/changelog

- **`/doctor prompt-audit` and Managed Model Settings (v2.1.283, Sep 25)**: New `/doctor prompt-audit` command audits CLAUDE.md files and prompting patterns for quality issues. Added `availableModelsMatch` (exact version matching) and `deniedModels` managed settings for enterprise deployments to control model access. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **Adobe Acrobat Integration (Sep 24)**: Claude Code gained native Adobe Acrobat integration, enabling PDF workflows with page-level operations, content redaction, and format conversion directly in sessions — useful for codebases involving document processing or PDF generation. Source: https://app.stationx.net/articles/claude-code-september-2026

- **Plugin Eval Command — Test Plugins Like Code (Week 37, Sep 7–11, v2.1.269)**: `claude plugin eval` runs a plugin against a suite of test cases, scores the results, and by default re-runs each case without the plugin for a clean contribution delta. `claude plugin eval init` has Claude draft the test cases and graders, then writes them to `evals/` for repeatable CI use. Source: https://code.claude.com/docs/en/whats-new/2026-w37

- **Desktop Pane Pop-Out Windows (Week 37, Sep 7–11)**: The Claude Code Desktop app now lets users pop any pane (diff viewer, terminal, etc.) into its own standalone window, enabling multi-monitor workflows where Claude keeps working in the main window while the diff or terminal is visible on a secondary screen. Source: https://code.claude.com/docs/en/whats-new/2026-w37

- **AWS Bedrock Cross-Account IAM and Guardrails (v2.1.281, Sep 23)**: Added `assume_role` support for Bedrock upstreams to enable cross-account IAM role assumption, and a `guardrail` configuration option for Amazon Bedrock guardrails — important additions for enterprise teams deploying Claude Code in AWS environments. Source: https://code.claude.com/docs/en/changelog

- **Cloud Sessions on CLI and Mobile (v2.1.283, Sep 25)**: Cloud sessions became accessible directly from the CLI using the `--cloud` flag and from the Claude mobile app, eliminating the need to open the web interface to start or resume a cloud session. Source: https://app.stationx.net/articles/claude-code-september-2026

## Bug Fixes & Performance

- **MCP Reliability Fixes**: Multiple MCP bugs resolved this month: progress notifications were previously discarded once a long-running tool call moved to the background; stdio MCP servers were left running when sessions ended; HTTP 404 errors from stateless remote MCP servers were not handled gracefully. All three are now fixed. Source: https://code.claude.com/docs/en/changelog

- **MCP Startup and Disconnect Notifications**: Added `CLAUDE_CODE_MCP_STARTUP_WAIT_MS` environment variable to bound how long the first non-interactive turn waits for connecting MCP servers. Claude Code now also notifies users when an MCP server disconnects mid-session and automatic reconnection gives up, pointing to the `/mcp` interface for manual recovery. Source: https://app.stationx.net/articles/claude-code-september-2026

- **Session and Subagent Fixes (v2.1.285, Sep 29)**: Fixed plugin and marketplace installs over SSH ignoring git settings; fixed cloud sessions refusing artifact updates after conversation compaction; fixed fork subagents not preserving the parent session's plan/dontAsk mode; and reduced `tool_use` id errors in hooks for Agent SDK (headless) sessions. Source: https://code.claude.com/docs/en/changelog

- **WebFetch Deadline Enforcement (Week 37)**: If WebFetch hasn't finished downloading a page within five minutes, the fetch now fails with a clear deadline error instead of hanging indefinitely. The deadline is configurable via `CLAUDE_CODE_WEBFETCH_DEADLINE_MS` or removable by setting it to `0`. Source: https://code.claude.com/docs/en/whats-new/2026-w37

## Community & Ecosystem

- **Developer Plugin Portal Launched (Sep 25)**: Anthropic opened a new developer plugin portal allowing third-party developers to submit plugins to the Claude directory and track their performance metrics. Simultaneously, Pro subscribers received $100 in promotional cloud session credits and Max subscribers received $250 to drive adoption of cloud-based workflows. Source: https://app.stationx.net/articles/claude-code-september-2026

- **Commerce Agents Blueprint Released**: Anthropic published a complete commerce agents blueprint with ready-to-deploy shopping and merchant agent implementations, available via the Messages API, the Claude Agent SDK, or Claude Managed Agents. Targets developers building e-commerce automation and AI-powered sales workflows. Source: https://blog.mean.ceo/anthropic-claude-news-september-2026/

- **Claude Code Achieves 95.3% MCP Adoption Among Developer Tools**: According to a third-party MCP adoption tracker, Claude Code now leads MCP client adoption at 95.3%, ahead of other developer tools. Claude supports the latest MCP 2.0 spec with its stateless core. Source: https://lucaberton.com/blog/mcp-adoption-by-client-2026/

## Roadmap & Announcements

- **Projects Redesigned — From Folder to Conversation (Sep 17)**: Anthropic announced a major overhaul of Projects, reframing them from a file-folder metaphor to a conversation-centric one. The redesign aims to make long-running collaborative work feel more natural within Claude Code's agentic model. Source: https://claude.com/blog-category/announcements

- **Claude Design, Slides, and Docs Integration (Sep 16)**: Claude Design (artboard-based UI design with on-canvas editing), Claude Slides (presentations with a dedicated starting point), and Claude Docs (living documents with team collaboration) were integrated into conversations including Claude Code, making creative and document workflows available directly from the coding assistant. Source: https://code.claude.com/docs/en/changelog

- **Claude Fable 5.1 and Mythos 5.1 Released**: Claude Fable 5.1 became the default Fable model in Claude Code in September 2026. Claude Mythos 5.1 was also released this month, adding to the growing Claude 5 model family. Source: https://en.wikipedia.org/wiki/Claude_Mythos

## Key Takeaway
The back-to-back releases of Claude Sonnet 5.5 (Sep 28) and Claude Opus 5.5 (Sep 22) — both with 1M-token context windows and meaningfully lower pricing — are September's headline story: they give Claude Code users dramatically larger working context with no change in workflow, and Opus 5.5's 40%-lower cost compared to Fable 5.1 makes the most powerful tier broadly accessible.

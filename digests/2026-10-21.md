# Claude Code News Digest — 2026-10-21

## Overview
The biggest Claude Code development this week is **Code Review reaching general availability** for Team and Enterprise customers, now running roughly 3× faster than during its research preview. Alongside that, the v2.1.302–v2.1.306 release train introduced idle compaction for long conversations, a guided auto-mode setup, and numerous MCP and mod-system fixes.

---

## New Features & Releases

- **Code Review Goes GA**: Anthropic made its multi-agent pull-request reviewer generally available on October 15 for Claude Team and Enterprise organizations. Reviews now complete in roughly 6–10 minutes (down from ~20 minutes in preview), with configurable Quick, Standard, or Deep depth per repository. Eligible Enterprise organizations can claim at least $10,000 in review credits before January 15, 2027.
  Source: https://claude.com/resources/articles/code-review-is-now-generally-available

- **v2.1.304 — `/auto-mode-setup` & Managed Agents Secure** (Oct 19): The release adds a `/auto-mode-setup` guided wizard, a `/claude-api managed-agents-secure` command, new mod hook options (`decider: "person"`, `e.isReadOnly`), and enables tool search by default behind custom gateways.
  Source: https://code.claude.com/docs/en/changelog

- **v2.1.302 — Idle Compaction & Auto-Mode Model Selection** (Oct 17): Long conversations left idle are now automatically summarized before the prompt cache expires (configurable in `/config`). Fork subagents are now on by default outside the terminal (desktop app and VS Code). `CLAUDE_CODE_AUTO_MODE_MODEL` lets users choose which model the client-side classifier uses.
  Source: https://code.claude.com/docs/en/changelog

- **v2.1.301 — Vim `%` Motion & OpenTelemetry** (Oct 16): Adds bracket-matching `%` navigation in Vim mode, classifier fields in OpenTelemetry `tool_decision` events, and `CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS`.
  Source: https://code.claude.com/docs/en/changelog

- **v2.1.299 — Idle Compaction in Terminal** (~Oct 14): Introduces idle compaction for terminal sessions and the `CLAUDE_CODE_DISABLE_FILE_MENTIONS` environment variable. Also adds `--shutdown-drain-sec` for the self-hosted runner orchestrator.
  Source: https://code.claude.com/docs/en/changelog

- **v2.1.296 — Subagent `autoCompactWindow`** (~Oct 10): Adds an `autoCompactWindow` option to `AgentDefinition` so subagents can compact earlier than the main conversation window, plus `CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL` for per-workflow model selection.
  Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions (IDE plugins, MCP servers, SDK)

- **MCP OAuth & HTTP Fixes**: Recent releases resolved MCP OAuth sign-in, token refresh, and sign-out not sending configured headers/`headersHelper` values, and fixed HTTP connections hanging when a server never closes its reply to a notification.
  Source: https://code.claude.com/docs/en/changelog

- **v2.1.305 — MCP Allowlist & Artifacts**: Adds `sandbox.allowNestedUserNamespaces`, changes to MCP tool allowlists, and `/artifacts` fixes.
  Source: https://code.claude.com/docs/en/changelog

- **v2.1.306 — Cloud Session & API Error Fixes** (latest as of Oct 21): Fixes `claude -p` in cloud sessions and API errors incorrectly shown as "prompt is too long" in sessions with many MCP tools.
  Source: https://code.claude.com/docs/en/changelog

- **Claude Agent SDK Updates**: The TypeScript SDK reached v0.3.302 (Oct 16) and the Python SDK v0.2.168 (Oct 15). Fork subagents are now on by default in `claude -p` and the Agent SDK. Sessions with no permission mode now start in default mode on third-party providers.
  Source: https://www.gradually.ai/en/changelogs/claude-agent-sdk/

- **VS Code Extension**: The desktop app and VS Code now run the main conversation's subagents in the background by default (same behavior as the terminal), as of v2.1.302.
  Source: https://releasebot.io/updates/anthropic/claude-code

## Bug Fixes & Performance

- **v2.1.303 — Reliability Pass**: A focused bug-fix release with no new features; the official changelog notes reliability improvements across cloud sessions, VS Code, Slack, plugins, and MCP workflows.
  Source: https://code.claude.com/docs/en/changelog

- **Prompt-Too-Long False Positive Fixed (v2.1.306)**: Sessions with many MCP tools were misreporting ordinary API errors as "prompt is too long." Fixed in the latest build.
  Source: https://code.claude.com/docs/en/changelog

- **v2.1.300 — Cache Telemetry & `/advisor` on AWS**: Adds `cache_creation_5m_tokens`/`cache_creation_1h_tokens` telemetry fields and brings the `/advisor` command to Claude Platform on AWS.
  Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Mods System Introduced (~Oct 8)**: Anthropic introduced "mods" — small TypeScript functions that customize Claude Code's behavior — delivered via plugins. The official plugin directory and a developer portal for plugin submissions also launched alongside this.
  Source: https://tech-insider.org/claude-code-plugins-official-mods-cloud-sessions-2026/

- **Claude Haiku 5.5 Now Default Haiku** (v2.1.293, ~Oct 7): Anthropic's latest small model, Claude Haiku 5.5 (described as the cheapest and fastest model yet), became the default Haiku on the Anthropic API.
  Source: https://buttondown.com/jpazminob/archive/claude-code-daily-digest-october-12-2026/

- **Craft Suite MCP Servers Updated (Oct 18)**: A suite of 13 open-source apps, each shipping an MCP server for Claude Code, released new versions in unison on October 18.
  Source: https://pasqualepillitteri.it/en/news/23613/craft-suite-mcp-servers-claude-code-guide

- **Security Incident — CyberXero Campaign**: Cybersecurity researchers disclosed an attack campaign in which threat actor CyberXero used Claude Code as part of an initial-access operation that exfiltrated over 628,000 records from Ukrainian organizations (reported Oct 12).
  Source: https://thehackernews.com/2026/10/cyberxero-uses-claude-code-in-campaign.html

## Roadmap & Announcements

- **Claude Design Deprecation**: Anthropic announced that standalone Claude Design will close on **December 14, 2026**. Users relying on Claude Design should migrate before that date.
  Source: https://releasebot.io/updates/anthropic

- **Code Review Credits Promotion**: Enterprise organizations have until **January 15, 2027** to claim at least $10,000 in Code Review credits (credits expire 30 days after claiming).
  Source: https://claude.com/resources/articles/code-review-is-now-generally-available

## Key Takeaway
**Code Review going generally available is the headline story**: it is now 3× faster, configurable per repository, and backed by a $10,000 credit offer for Enterprise customers — making automated PR review a practical, default part of the Claude Code workflow.

# Claude Code News Digest — 2026-11-10

## Overview
Claude Code shipped five releases (v2.1.317–v2.1.322) in the first ten days of November 2026, delivering 273 combined bug fixes alongside notable new capabilities including MCP background tasks, Claude Fable 5.2 as the new default Fable model, and Vertex fast-mode support. A major security story dominated the week: Apiiro researchers found that the "Yes, and don't ask again" approval prompt can silently save an allow rule to `.claude/settings.local.json`, causing credentials and other secrets to be leaked into public GitHub repositories at scale.

## New Features & Releases

- **v2.1.322 — Vertex Fast Mode (Nov 10)**: Claude Code now supports fast mode on Vertex AI in the global, us, and eu regions. If Vertex refuses fast mode, Claude Code falls back to standard speed automatically. Source: https://code.claude.com/docs/en/changelog

- **v2.1.321 — Claude Fable 5.2 as Default (Nov 9)**: Claude Fable 5.2 (`claude-fable-5-2`) is now the default Fable model, with a 1M-token context window priced at $8/$40 per million tokens and $0.20/Mtok cache reads. The release also adds `--settings <file>` for `claude remote-control` to apply a settings file to every session it starts, and mods no longer activate without asking in auto/bypass modes. Source: https://code.claude.com/docs/en/changelog

- **v2.1.319 — MCP Background Tasks & Permission Hardening (Nov 6)**: MCP tool calls that run as tasks now move to the background and report back when they finish (disable with `CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND`). A new `permissions.denyInsteadOfPrompting` option denies tool calls that would have prompted for permission, keeping the turn running. Also added: `/claude-api latency-optimize` and `CLAUDE_CODE_DISABLE_FEATURE_FLAGS`. Source: https://code.claude.com/docs/en/changelog

- **v2.1.318 — Login Expiry Reporting (Nov 4)**: `claude auth status` now returns a `loginExpiresAt` field, and `claude -p` emits a stderr warning starting 10 days before a claude.ai sign-in expires. Background subagents now move long shell commands (>3 min) to the background automatically. Cloud sessions gained a "No repository" option. Source: https://code.claude.com/docs/en/changelog

- **v2.1.317 — Agent SDK Hook Blocking & Email Privacy (Nov 3)**: Agent SDK hook callbacks now support `onFailure: "block"`, causing a failing hook to block the triggering action rather than silently continuing. A new pre-flight check asks for confirmation before a web or shell tool call sends your account email address to the network. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **IDE Extension: Manual Install Required (v2.1.318)**: Claude Code no longer installs or updates the IDE extension automatically when launched from an IDE terminal. Users must run `/ide` from an outside terminal or use their editor's extensions view. VS Code extension bugs fixed include incorrect status messages during install and misidentifying a Console API key session as a claude.ai session. Source: https://code.claude.com/docs/en/changelog

- **JetBrains Plugin v0.36.0 (Nov 7)**: A third-party JetBrains plugin built on Anthropic's VS Code extension baseline released version 0.36.0. Anthropic's official support covers VS Code, Cursor, and JetBrains; no official extension exists for Visual Studio 2026. Source: https://plugins.jetbrains.com/plugin/30313-claude-code-with-gui

- **MCP Protocol v2026-07-28 Default**: Cloud session and Remote Control MCP connectors now negotiate MCP protocol version 2026-07-28 by default (since v2.1.299). This version removes protocol-level session tracking, making MCP stateless at the protocol layer. Set `MCP_PROTOCOL_NEGOTIATION=legacy` to opt out. Source: https://www.gradually.ai/en/changelogs/claude-code/

## Bug Fixes & Performance

- **273 Bug Fixes Across Five Releases**: The November releases resolved 90 bugs (v2.1.319), 74 (v2.1.321), 62 (v2.1.317), and 47 (v2.1.318). Notable fixes include: MCP OAuth requests no longer send secrets to a redirect host; read-only Bash commands no longer run outside the sandbox without a prompt; `/diff` no longer fails in repos containing a file named `HEAD`; Bash deny and ask rules now correctly match quoted commands; and `--continue` no longer loses conversation context after malformed tool-call retries. Source: https://code.claude.com/docs/en/changelog

- **Opus 4.8 Fast Mode Deprecation Deadline**: Fast mode for Opus 4.8 is deprecated and will be fully removed on November 30, 2026. After that date, requests will return an error with no fallback. Anthropic recommends migrating to Opus 5.5. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Secrets Leak via Settings Files (Apiiro Research)**: Security firm Apiiro disclosed that Claude Code's "Yes, and don't ask again" approval option can silently persist allow rules into `.claude/settings.local.json`, which users inadvertently commit to public GitHub repositories. Reported figures vary by outlet (1,122 to 2,539 exposed secrets across roughly 1,994 public repos). No public statement from Anthropic had been issued as of November 8. Source: https://www.scworld.com/brief/claude-code-settings-files-expose-sensitive-data-on-github

- **Game-Cloning Guardrails Controversy**: Tom's Hardware reported on November 2 that Anthropic added two sentences to the Opus 5.5 system prompt steering Claude Code away from recreating specific commercial games, citing IP policy. The change drew community debate about where appropriate guardrails end and over-restriction begins. Source: https://www.tomshardware.com/tech-industry/artificial-intelligence/anthropic-confirms-new-claude-code-limits-to-prevent-game-cloning-users-report-opus-5-5-is-also-actively-blocking-reverse-engineering-tasks

- **"Goodbye Claude, Hello Pi" Reaches HN Front Page**: A developer post announcing retirement of Claude Code as their primary coding harness—citing 244 releases in a short period causing workflow fatigue—reached the Hacker News front page on November 8 with 306 points, sparking a wide discussion on AI tool stability and release cadence. Source: https://fourweekmba.com/ai-developer-quits-claude-code-for-pi-citing-244-releases/

## Roadmap & Announcements

- **Claude Fable 5.2 and Claude Mythos 5.2 Announced (Nov 9)**: Anthropic announced both Claude Fable 5.2 and Claude Mythos 5.2 on November 9, 2026. Fable 5.2 immediately became the default Fable model in Claude Code. Mythos 5.2 details have not yet been fully disclosed in the context of Claude Code. Source: https://www.anthropic.com/news

- **Enterprise Cost Tracking by Project Tags (Beta)**: Cost tracking broken down by project tags is now in beta for eligible Enterprise organizations, enabling finance and engineering teams to allocate Claude Code usage costs across projects. Source: https://releasebot.io/updates/anthropic/claude-code

- **Anthropic IPO Expected November 2026**: According to public reports, Anthropic is planning an initial public offering in November 2026, which may bring additional scrutiny and investment to the Claude Code product line. Source: https://en.wikipedia.org/wiki/Anthropic

## Key Takeaway
The most urgent item for Claude Code users today is the Apiiro-disclosed secrets leak: check whether your `.claude/settings.local.json` is tracked by git in any public repository and rotate any exposed credentials immediately. On the product side, Claude Fable 5.2 is now the default Fable model with a 1M-token context window, making it the most capable context-window option available to Claude Code users by default.

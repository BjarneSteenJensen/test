# Claude Code News Digest — 2026-07-28

## Overview
The headline story this week is the arrival of Claude Opus 5 as the new default Opus model in Claude Code (v2.1.220, July 25), bringing a 1M-token context window and fast mode at $10/$50 per million tokens. The preceding week (July 13–17) introduced live MCP connector data inside published artifacts and a new screen reader mode, while the July 18–25 release window delivered a steady stream of security fixes, accessibility improvements, and workflow refinements including background `/code-review` and emoji shortcode autocomplete.

## New Features & Releases

- **Claude Opus 5 becomes the default Opus model** (v2.1.220, July 25): `claude-opus-5` is now the default Opus model across Claude Code with a native 1M-token context window. Fast mode pricing is $10/$50 per MTok. Opus 4.7 has been removed from fast mode; `/fast` now applies to Opus 5 and Opus 4.8. The `claude-api` skill has been updated to default to Claude Opus 5. Source: https://code.claude.com/docs/en/changelog

- **Nested subagents up to depth 3** (v2.1.220, July 25): Subagents can now spawn their own subagents up to three levels deep by default (previously limited to depth 1), enabling more complex autonomous workflows. The limit is configurable via `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH`. Source: https://code.claude.com/docs/en/changelog

- **`/code-review` runs as a background subagent** (v2.1.218, July 22): The `/code-review` command now runs entirely in a background subagent, keeping the main conversation clear and uncluttered while the review runs. Additionally, `/ultrareview` now accepts descriptive arguments like "review my auth changes". Source: https://code.claude.com/docs/en/changelog

- **Emoji shortcode autocomplete** (v2.1.217, July 21): Typing `:heart:` now autocompletes to ❤️ inline; the feature can be disabled with the `emojiCompletionEnabled` setting. Source: https://code.claude.com/docs/en/changelog

- **Artifacts call live MCP connectors** (v2.1.207–v2.1.212, July 13–17): Published artifacts can now pull live data and take actions through each viewer's own MCP connectors on page load, rather than serving a static snapshot from the session that created them. Viewers approve connector access on first load, and data reflects their own permissions. This week also added public sharing links for artifacts and editor roles for Team and Enterprise plans. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **Screen reader mode** (v2.1.207–v2.1.212, July 13–17): A new `--ax-screen-reader` flag (or `CLAUDE_AX_SCREEN_READER` env var, or `axScreenReader` setting) replaces the visual terminal interface with plain, linear labeled text compatible with VoiceOver and NVDA. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **`/fork` spawns a background session** (v2.1.207–v2.1.212, July 13–17): `/fork` now copies the current conversation into a new independent background session with its own row in `claude agents`, allowing parallel work. The previous in-session forked subagent behavior has been renamed `/subtask`. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **In-app browser on Claude Code Desktop** (v2.1.202–v2.1.206, July 6–10): The Desktop app gained a built-in browser so Claude can pull up documentation, designs, or any website and interact with pages the same way it does with local dev server previews. Source: https://code.claude.com/docs/en/whats-new/2026-w28

- **`/doctor` setup checkup command** (v2.1.202–v2.1.206, July 6–10): `/doctor` (alias `/checkup`) runs a full environment diagnostic and can auto-fix detected issues. Source: https://code.claude.com/docs/en/whats-new/2026-w28

## Integrations & Extensions

- **Auto mode GA on third-party clouds** (v2.1.207–v2.1.212, July 13–17): Auto mode no longer requires the `CLAUDE_CODE_ENABLE_AUTO_MODE` opt-in variable on Amazon Bedrock, Google Cloud's Agent Platform, and Microsoft Foundry. Administrators can disable it with `disableAutoMode`. Amazon Bedrock, Google Cloud's Agent Platform, and Claude Platform on AWS now default to Claude Opus 4.8. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **MCP tool calls auto-background after 2 minutes** (v2.1.207–v2.1.212, July 13–17): Long-running MCP tool calls that exceed 2 minutes automatically move to the background, keeping the session interactive. The threshold is tunable via `CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS`. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **VS Code 1.128 adds multi-chat for Claude agent sessions** (July 8): Visual Studio Code 1.128 added support for running multiple parallel Claude Code agent conversations with separate history, titles, and model selections per tab, enabling side-by-side approach comparison. Source: https://visualstudiomagazine.com/articles/2026/07/08/claude-ai-gets-yet-another-boost-in-vs-code-1-128.aspx

- **Trusted Devices for Remote Control Admins**: Team and Enterprise admins can now require members to verify their device before viewing or steering local Claude Code sessions remotely, adding a hardware trust layer to Remote Control. Source: https://releasebot.io/updates/anthropic/claude-code

## Bug Fixes & Performance

- **Security: permission-check bypass fixed on Windows** (v2.1.214, July 18): Fixed a permission-check bypass in Windows PowerShell 5.1. Also fixed Bash permission checks misjudging very long commands (commands >10,000 chars now always prompt) and zsh variable subscripts being treated as inert text. Source: https://code.claude.com/docs/en/changelog

- **Fixed quadratic slowdown in long sessions** (v2.1.216, July 20): A quadratic-complexity bug in message normalization that caused performance to degrade significantly in long conversations has been resolved. Source: https://code.claude.com/docs/en/changelog

- **Fixed Windows Unicode path corruption** (v2.1.218, July 22): Windows paths containing `\u`-prefixed segments were being corrupted into CJK (Chinese/Japanese/Korean) characters; this is now fixed. Source: https://code.claude.com/docs/en/changelog

- **Fixed `dir/**` allow rules over-approving writes** (v2.1.214, July 18): An issue where `dir/**` allow rules would auto-approve writes to nested directories that should have required explicit permission has been corrected. Source: https://code.claude.com/docs/en/changelog

- **Fixed mid-stream API error answer drops** (v2.1.220, July 25): `claude -p` text output was silently dropping answers when a mid-stream API error occurred; this is now handled correctly. Source: https://code.claude.com/docs/en/changelog

- **`sandbox.network.strictAllowlist` setting** (v2.1.220, July 25): A new setting denies connections to any host not on the allowlist without prompting, tightening network sandboxing for automated workflows. Source: https://code.claude.com/docs/en/changelog

## Roadmap & Announcements

- **Claude Opus 5 signals a major model upgrade cycle**: With `claude-opus-5` shipping as the new default Opus model in Claude Code (v2.1.220) and Sonnet 5 already the default on Pro/Team/Enterprise since late June, Anthropic has completed a full refresh of the Claude 5 model family across all Claude Code tiers. Fast mode on Opus 5 ($10/$50/MTok) makes the frontier model significantly more accessible for high-volume agentic use cases. Source: https://code.claude.com/docs/en/changelog

- **Session-wide caps protect against runaway loops**: v2.1.207 introduced default caps of 200 WebSearch calls and 200 subagent spawns per session, each tunable via environment variables. This is a forward-looking guardrail as Claude Code workflows grow in complexity and depth. Source: https://code.claude.com/docs/en/whats-new/2026-w29

## Key Takeaway
The arrival of Claude Opus 5 as the default Opus model in Claude Code (v2.1.220, July 25) — with a 1M-token context window and competitive fast mode pricing — is the defining development of the week, completing the Claude 5 family rollout across all subscription tiers and making the most capable frontier model the new baseline for Max and API users.

# Claude Code News Digest — 2026-09-10

## Overview
Claude Code shipped five releases between September 3–9, culminating in v2.1.267 on September 9 with a new `maxEffortLevel` cap, an improved `/diff` panel, and a sweep of stability fixes across VS Code, Remote Control, and MCP. The biggest policy news: the 50% weekly-limit promotion ends September 14 and is replaced with a permanent 25% increase — effectively a ~17% reduction from the promotional ceiling.

## New Features & Releases

- **v2.1.267 — `maxEffortLevel`, `/diff` panel, snapshot flag (Sep 9)**: Adds a `maxEffortLevel` setting to cap the effort level across Bedrock, Vertex, and Foundry providers; a `--system-prompt-snapshot off` flag for fresh system-prompt rendering per request; and a polished `/diff` panel for reviewing uncommitted changes in fullscreen mode. Source: https://code.claude.com/docs/en/changelog

- **v2.1.265 — Output limits, plugin auto-discovery, subagent prompt file (Sep 8)**: Introduces `bashOutputMaxChars` and `taskOutputMaxChars` settings (up to 128 K characters) so more command output reaches Claude inline, adds `--plugin-dir` with auto-discovery for plugin folders, adds `--append-subagent-system-prompt-file` for large subagent system prompts, and adds a 1 GB cap on tool results saved to disk. Source: https://code.claude.com/docs/en/changelog

- **v2.1.261 — `/skill-doctor`, org policy in `/status` (Sep 4)**: Adds `/skill-doctor` to identify unused skills and their context cost, surfaces the "Organization policy" line in both `/status` and `claude doctor`, and improves the Bedrock setup wizard with a timeout for hanging credentials. Source: https://code.claude.com/docs/en/changelog

- **Claude Fable 5.1 as default Fable model**: From v2.1.257 onward, Fable 5.1 (`claude-fable-5-1`) is the default Fable model in Claude Code, bringing a 1 M context window to the Fable tier. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **VS Code extension quality push**: September releases fixed screenshot pasting on WSL2, diff block rendering with dark theme, CRLF line endings in edits, session-list loading, remote-SSH connections, and runaway ripgrep processes. The official VS Code extension bundles the CLI and is the recommended surface for VS Code users. Source: https://code.claude.com/docs/en/changelog

- **`managedMcpServers` organization setting**: Claude Code added a `managedMcpServers` managed setting that lets organizations provision HTTP/SSE MCP servers for every user automatically, alongside fixes for MCP servers that disconnect during tool listing at startup. Source: https://code.claude.com/docs/en/changelog

- **Community Visual Studio 2026 extension**: An unofficial community extension (`firish/claude_code_vs`) brings Claude Code to Visual Studio 2026 with native diff accept/reject, a live debugger Claude can drive autonomously, Roslyn code navigation, and Test Explorer integration. Source: https://github.com/firish/claude_code_vs

## Bug Fixes & Performance

- **Prompt-cache stability sweep**: Multiple September releases fixed prompt-cache misses across MCP server definitions, tool definitions, and resumed sessions — a long-standing source of unexpected token usage. Source: https://code.claude.com/docs/en/changelog

- **Large-session resume fixed**: Resuming sessions over 5 MB no longer silently drops parallel tool calls and hook output. Expired AWS / Google Cloud credentials now surface a re-authenticate error after one attempt instead of retrying 10 times. Source: https://code.claude.com/docs/en/changelog

- **Remote Control credential and permission fixes**: Remote Control clients no longer show stale permission modes, and credential expiry no longer occurs silently after ~30 days. A v2.1.266 hotfix patched a regression in v2.1.265 that broke LLM-gateway and proxy setups using `CLAUDE_CODE_USE_GATEWAY`. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Claude Agent SDK: Compliance API out of beta**: The Claude Developer Platform moved Compliance API session endpoints (for Cowork and Claude Code) out of beta and expanded local session transcripts to Claude Science and Microsoft 365 sessions for Enterprise. The Admin API is now available in the `ant` CLI and the Python, TypeScript, C#, Go, Java, PHP, and Ruby SDKs. Source: https://releasebot.io/updates/anthropic/claude-developer-platform

- **MCP 2026-07-28 spec now in wide adoption**: The July spec revision — stateless core, standardized MCP Apps and Tasks extensions, stronger OAuth 2.0 / OIDC authorization — is now the basis for new MCP server integrations covered in community guides for Postgres, GitHub, and other backends. Source: https://www.clarista.io/blog/claude-code-mcp-plugins-guide

## Roadmap & Announcements

- **Weekly usage limits reset after September 14**: The 50% promotional increase to Claude Code weekly token limits ends September 14, 2026 and is replaced by a permanent 25% increase over the baseline — a net reduction of roughly 17% from the promotional ceiling. Users relying on the higher promo limits should plan accordingly. Source: https://aicatchup.com/news/claude-code-weekly-limits-50-percent-promo

## Key Takeaway
The September 9 release (v2.1.267) continues a rapid weekly cadence of quality improvements — better diff tooling, output-limit controls, and organization policy visibility — but the most immediately actionable news for power users is the September 14 rollback of the 50% weekly-limit promotion to a permanent 25% increase.

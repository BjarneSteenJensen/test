# Claude Code News Digest — 2026-08-21

## Overview
A busy week for Claude Code culminated in two releases on August 20 (v2.1.237–238), adding a built-in Concise output style, readline-style keybinding support, and sweeping Remote Control reliability improvements. The period also saw GitLab merge-request integration land across the worktree view and the agents panel, while auto mode became the default on Bedrock, Vertex, and Azure Foundry — signalling that Claude Code's permissioning intelligence is now trusted enough to run hands-free on every major cloud provider.

## New Features & Releases

- **v2.1.238 — Proxy Auth, keybindingFlavor & Self-Hosted Runner (Aug 20)**: The `keybindingFlavor` setting lets users opt into readline-style `Ctrl+W` word-delete behaviour. New `--proxy-authorization-command` / `--proxy-authorization-file` flags support egress proxies that require rotating auth headers. The `claude self-hosted-runner --defer-shutdown-max-min` option keeps a runner alive on SIGTERM until attached sessions finish. Source: <https://code.claude.com/docs/en/changelog>

- **v2.1.237 — Built-in Concise Output Style (Aug 20)**: A new first-party "Concise" output style instructs Claude to lead with results and skip preamble — useful for terminal-heavy workflows where terse output matters. Also fixes prompt caching for sessions using an LLM gateway or custom base URL. Source: <https://code.claude.com/docs/en/changelog>

- **v2.1.236 — ANTHROPIC_DEFAULT_MODEL & Cross-Session Idle Notifications (Aug 19)**: The new `ANTHROPIC_DEFAULT_MODEL` environment variable sets the model that every new Claude Code session starts on, removing the need to select it manually each time. `notify_when_idle` in `SendMessage` lets one Claude Code session ask another to ping it the next time it goes idle. Source: <https://code.claude.com/docs/en/changelog>

- **v2.1.235 — Spellcheck Integration (Aug 18)**: An optional `spellcheck` setting wires Claude Code's prompt input to system spell-checkers (aspell, hunspell, or ispell), catching typos before they reach the model. Source: <https://code.claude.com/docs/en/changelog>

- **v2.1.234 — Auto-Continue on Usage-Limit Reset & GitLab Badges (Aug 17)**: A new auto-continue checkbox (configurable) automatically resumes a stalled session the moment the usage-limit window resets. GitLab merge-request badges now appear in the footer and statusline. The `CLAUDE_CODE_PROJECT_DIR_NAME` env var lets teams customise the transcript directory name per project. Source: <https://code.claude.com/docs/en/changelog>

- **v2.1.233 — GitLab MR Worktree Support (Aug 14)**: GitLab merge-request URLs are now accepted by `--worktree` and the `claude agents` view, bringing GitLab on par with GitHub for worktree-based review workflows. Source: <https://code.claude.com/docs/en/changelog>

## Integrations & Extensions

- **Auto Mode Default on Bedrock, Vertex & Azure Foundry (v2.1.236)**: Claude Code's auto permission mode — which uses a severity-scoring classifier to decide when to ask for approval — is now enabled by default on Amazon Bedrock, Google Vertex AI, and Azure AI Foundry. Teams running Claude Code on cloud infrastructure no longer need to opt in manually. Source: <https://code.claude.com/docs/en/changelog>

- **Plugin Marketplace headersHelper (v2.1.238)**: A new `headersHelper` mechanism lets plugins mint HTTP headers (e.g. short-lived auth tokens) for marketplace catalog fetches, enabling private or authenticated plugin registries without hard-coding credentials. Source: <https://code.claude.com/docs/en/changelog>

- **Managed Agents — claude-api Skill Updated (v2.1.238)**: The bundled `claude-api` skill was updated for the Managed Agents release on August 19, 2026, and its context footprint was cut from ~200 k to ~25 k tokens in v2.1.234 — a dramatic reduction for agent-heavy sessions. Source: <https://code.claude.com/docs/en/changelog>

- **MCP Elicitation & Subscription Fixes (v2.1.238)**: MCP elicitation dialogs that were silently truncating URLs longer than 4,096 characters are now fixed. An earlier bug causing MCP v2 connections to endlessly reopen the `subscriptions/listen` stream against servers with fixed-timeout long-polls has also been resolved. Source: <https://code.claude.com/docs/en/changelog>

## Bug Fixes & Performance

- **Memory Leak in Long Sessions Fixed (v2.1.238)**: Unbounded memory growth in long interactive sessions — caused by subagent tool results accumulating without being released — is now fixed, making multi-hour agentic sessions much more stable. Source: <https://code.claude.com/docs/en/changelog>

- **Prompt Caching for Custom Gateways (v2.1.237)**: Sessions routing through an LLM gateway or custom `ANTHROPIC_BASE_URL` were silently missing prompt-cache hits. This is now fixed, restoring expected latency and cost savings for enterprise gateway deployments. Source: <https://code.claude.com/docs/en/changelog>

- **Remote Control Reliability Overhaul (v2.1.238)**: A sweep of Remote Control fixes landed: disconnects on brief network hiccups now retry automatically, model/effort picks from phone or web propagate correctly to the terminal, per-task Stop buttons in the tasks panel work, and crashed Remote Control processes no longer stay permanently unavailable. Source: <https://code.claude.com/docs/en/changelog>

- **macOS Startup Speed (v2.1.238 & v2.1.236)**: Two separate startup optimisations shipped this week — session counters are now written in the background rather than blocking launch, and automatic update checks are deferred 10 seconds post-launch — reducing cold-start latency on macOS. Source: <https://code.claude.com/docs/en/changelog>

- **Windows Security — NTLM & NT-Namespace Path Hardening (v2.1.233–234)**: Windows users received two security fixes: NTLM credential-leak vectors in the shell layer were closed (v2.1.233), and NT-namespace paths (`\??\`) are now rejected in remote file reads, session restore, CLAUDE.md includes, workflows, and file uploads (v2.1.234). Source: <https://code.claude.com/docs/en/changelog>

## Community & Ecosystem

- **claude-api Skill Token Cost Slashed (v2.1.234)**: The built-in `claude-api` reference skill — used to look up Anthropic API docs, model IDs, pricing, and SDK usage — was trimmed from ~200 k to ~25 k tokens of context. This makes it practical to invoke in any session without burning a significant chunk of the context window. Source: <https://code.claude.com/docs/en/changelog>

- **Design Research Preview (Aug 17)**: Anthropic designer Nate Parrott announced a research preview allowing users to run `/design` in Claude Code Desktop or CLI to receive editable design artboards built on Artifacts — an early look at design tooling natively inside the coding assistant. Source: <https://code.claude.com/docs/en/changelog>

- **Self-Hosted Environments Public Beta**: Self-hosted environments entered public beta for Team and Enterprise plans this month, enabling Claude Code cloud sessions to run on an organisation's own infrastructure — with access to internal services, custom tooling, and full compliance controls. Source: <https://code.claude.com/docs/en/changelog>

## Roadmap & Announcements

- **Managed Agents Released (Aug 19)**: Anthropic released Managed Agents — server-hosted agent environments with a managed sandbox — as part of the broader Agent SDK. Claude Code's bundled skill was updated on the same day, and the feature now appears in the official `claude-api` reference. Source: <https://code.claude.com/docs/en/changelog>

- **Compliance API Extended to Claude Code**: Anthropic expanded its Compliance API to cover Claude Code across desktop, web, mobile, and CLI surfaces, with beta access for Enterprise customers. Security teams can now pull unified session content and metadata for audits and eDiscovery across all Claude Code entry points. Source: <https://code.claude.com/docs/en/changelog>

- **Inference Hooks Beta for Enterprise**: Inference hooks — allowing compliance teams to inspect and intercept prompts and tool calls before they reach the model — entered beta for Enterprise, providing real-time DLP enforcement across Claude Code and other surfaces. Source: <https://code.claude.com/docs/en/changelog>

## Key Takeaway
The release of v2.1.238 marks the most comprehensive Remote Control reliability overhaul to date, combined with a memory-leak fix that makes long agentic sessions stable; together these changes signal that Anthropic is hardening Claude Code for sustained, unattended operation — the kind of always-on coding infrastructure serious teams need.

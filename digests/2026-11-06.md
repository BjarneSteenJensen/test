# Claude Code News Digest — 2026-11-06

## Overview
Claude Code shipped two notable releases this week (v2.1.317–318), adding security guardrails around account-email exposure, improved Agent SDK hook control, and AWS cost-attribution support. Off the release track, Anthropic confirmed it restricted Claude Code from recreating existing video games, sparking developer backlash, while Cat Wu—head of product for Claude Code—announced her departure on November 3.

## New Features & Releases

- **v2.1.318 (November 4, 2026) — AWS cost attribution & subagent improvements**: Adds `assume_role` on mantle upstreams for per-developer AWS cost attribution. Background subagents now move a running shell command to the background after 3 minutes to prevent prompt-cache expiry. A new `effort` option for `$.model.fork` lets a mod spawn a quick side task at `low` effort. `loginExpiresAt` is now surfaced in `claude auth status` and `claude -p` JSON output, with a 10-day warning before expiry. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.317 (November 3, 2026) — Security, hooks & cost reporting**: Introduces a confirmation prompt before any web or shell tool sends your account email over the network. Adds `onFailure: "block"` for Agent SDK hook callbacks, making hooks fail-closed. A new cost-report endpoint (`GET /v1/organizations/analytics/cost`) is available in the Claude apps gateway admin API. `SendMessage` now reaches running background agents sooner by backgrounding their active command. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Fast mode for Opus 4.8 deprecated**: As of October 30, 2026, fast mode for Opus 4.8 is deprecated and will be removed on November 30, 2026. After removal, those requests will error rather than fall back. Anthropic recommends migrating to Opus 5.5. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Integrations & Extensions

- **MCP v2 runtime on TypeScript SDK 2.0**: The Claude Code MCP documentation (updated November 2, 2026) notes the v2 MCP runtime is built on MCP TypeScript SDK 2.0, implementing protocol revision 2026-07-28, which makes the protocol stateless at the session layer. `deniedMcpServers` URL entries now also block matching Anthropic-provided servers. Source: [Claude Code MCP Docs](https://code.claude.com/docs/en/mcp)

- **IDE extension install flow changed**: Starting with v2.1.318, Claude Code no longer installs or updates the IDE extension automatically when launched from an IDE terminal. Users must run `/ide` from an outside terminal. The official VS Code extension has accumulated 26.4 million installs. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog), [VS Code Docs](https://code.claude.com/docs/en/vs-code)

- **Idle compaction in VS Code and Desktop**: Earlier November releases (around v2.1.311) brought idle conversation compaction to the VS Code extension and the Claude Desktop Code tab, summarizing long idle sessions to control context size. Syntax coloring for code blocks also arrived in the VS Code extension. Source: search results via [gradually.ai Claude Code Changelog](https://www.gradually.ai/en/changelogs/claude-code/)

## Bug Fixes & Performance

- **Subagent status-line cost cut 99%**: Anthropic fixed background subagents that were re-reading the full context on every status-line refresh. The status line is now generated by Haiku 5.5 from short notes, reducing the cost of a single status update by approximately 99%. The fix applies to the CLI only; the desktop app was not affected. Source: search results via [BigGo Finance](https://finance.biggo.com/news/a8ef6165-8c1f-43de-a0c7-1c58e357ddcc)

- **v2.1.318 notable fixes**: `--continue` could lose the earlier conversation after malformed tool-call retries (regression from 2.1.314); macOS sessions with many running Bash commands stalled while memory grew; permission prompts could be answered by keystrokes typed immediately after sending a message. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.317 notable fixes**: Auto mode failed every turn when a gateway's safety check returned 403 or 422; `claude auth status` could exit before a slow token refresh was saved, potentially signing users out on the next run; `claude -p` now exits with code 1 (instead of 0) when a full disk or quota loses transcript writes. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Community & Ecosystem

- **Game-cloning restrictions draw developer backlash**: Anthropic confirmed it added two sentences to Opus 5.5's system prompt discouraging recreation of specific existing games, citing its IP usage policy. Developers have criticised the change, and some users report Opus 5.5 also refusing reverse-engineering tasks not related to games. Anthropic said original games and games built from a user's own designs remain supported and that it will keep iterating on the rules. Source: search results via [Tom's Hardware](https://www.tomshardware.com/tech-industry/artificial-intelligence/anthropic-confirms-new-claude-code-limits-to-prevent-game-cloning-users-report-opus-5-5-is-also-actively-blocking-reverse-engineering-tasks), [The Next Web](https://thenextweb.com/news/claude-code-game-recreation-refusals-developers)

- **claudecode.nvim Neovim community plugin**: A third-party Neovim plugin, `claudecode.nvim`, reimplements the same protocol used by the official VS Code extension, bringing Claude Code integration to Neovim users without official Anthropic support. Source: [GitHub coder/claudecode.nvim](https://github.com/coder/claudecode.nvim)

## Roadmap & Announcements

- **Cat Wu steps down as Claude Code head of product**: Cat Wu announced on November 3, 2026, that she was leaving Anthropic after two years leading Claude Code's product direction. No replacement has been named. Source: search results via [Unite.AI](https://unite.ai/cat-wu-steps-down-as-claude-code-product-chief-after-two-years)

- **Claude Design standalone closing December 14, 2026**: A notice embedded in a recent Claude Code release states that the standalone version of Claude Design will close on December 14, 2026. Source: search results via [gradually.ai Claude Code Changelog](https://www.gradually.ai/en/changelogs/claude-code/)

- **New environment variables for subagent control**: `CLAUDE_CODE_DISABLE_ULTRATHINK` turns off the `ultrathink` keyword; `CLAUDE_CODE_SUBAGENT_EFFORT` sets the effort level subagents use. `permissions.blockWritesOutsideWorkingDirectories` (added in v2.1.314) restricts file writes to the working directory. Source: search results via [gradually.ai Claude Code Changelog](https://www.gradually.ai/en/changelogs/claude-code/)

## Key Takeaway
The most consequential Claude Code development this week is Anthropic's decision to restrict game-recreation tasks via a prompt change in Opus 5.5—a rare instance of a behavior constraint added outside the standard release-notes process, with ripple effects on broader reverse-engineering use cases that the company is still working to calibrate.

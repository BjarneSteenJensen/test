# Claude Code News Digest — 2026-10-14

## Overview
Today Anthropic shipped Claude Code v2.1.299, a substantial release featuring idle conversation compaction, a new `CLAUDE_CODE_DISABLE_FILE_MENTIONS` flag, and 131 bug fixes including a sandbox write-path security fix. The week has been unusually active, with six releases since October 5 covering Claude Haiku 5.5, mod system improvements, MCP protocol upgrades, a Sonnet 5.5 cache price cut, and an important hook security fix.

## New Features & Releases

- **v2.1.299 (October 14, 2026) — Today's release**: Added `CLAUDE_CODE_DISABLE_FILE_MENTIONS` so `@`-file mentions pass paths instead of file contents; idle compaction automatically compacts conversations over 200K tokens after ~54 minutes of inactivity (tunable via `CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS` or `"idleCompaction": false`); `/effort` and `/fast` controls now available in agent view; `--shutdown-drain-sec` for self-hosted runner orchestrator; plugin hooks now refuse values nested deeper than 28,000 levels; 131 bug fixes. Source: https://code.claude.com/docs/en/changelog

- **v2.1.296 (October 9, 2026)**: Added `autoCompactWindow` in subagent frontmatter and `CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL` env var to pin all workflow subagents to one model; `allow_large` option for the Read tool; Sonnet 5.5 cache read price cut from $0.20 → $0.10/M tokens; MCP tool description and server instruction character limit doubled from 2,048 to 4,096. Source: https://code.claude.com/docs/en/changelog

- **v2.1.295 (October 8, 2026)**: Added `onFailure: "block"` for command and HTTP hooks (a hook that fails or times out now blocks the action rather than silently continuing); Program Status Protocol (OSC 7501) support; `$.ui.notify` for mods; tool descriptions via tool search raised from 2,048 to 16,384 character limit; subagents now preload at most 32 skills. Source: https://code.claude.com/docs/en/changelog

- **Claude Haiku 5.5 in Claude Code (v2.1.293, October 7, 2026)**: `claude-haiku-5-5` became the default Haiku model on the Anthropic API, with a 1M token context window priced at $0.10/$0.50 per million tokens (input/output). Source: https://code.claude.com/docs/en/changelog

- **v2.1.292 (October 6, 2026)**: Added `effort` parameter for the Agent tool so subagents run at the specified effort level; `claude plugin install --marketplace <source>` for marketplace-based plugin installs; `prompt.autocomplete` mod event; scheduled routines now publish private artifacts without asking. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **MCP protocol 2026-07-28 now default (v2.1.299)**: The newer MCP protocol version is now negotiated by default; `MCP_PROTOCOL_NEGOTIATION=legacy` opts back to the old behavior. MCP allow rules also tightened: rules now match only the named server (`mcp__<server>__*` syntax required). Source: https://code.claude.com/docs/en/changelog

- **VS Code reliability improvements (v2.1.296)**: Release notes cite improved reliability for cloud, VS Code, Slack, Windows, and self-hosted runner sessions. Claude in Chrome now asks before performing browser actions in every VS Code session. Source: https://code.claude.com/docs/en/changelog

- **Managed Agents onboarding command (v2.1.290, October 5, 2026)**: New `/claude-api managed-agents-onboard` command added for streamlined Managed Agents setup. Fast mode in Slack is now togglable with `!fast` / `!fast off`. WebSearch budget now refills at 100 calls/hour rather than cutting off at 200. Source: https://code.claude.com/docs/en/changelog

- **Community Visual Studio extension**: A community contributor (firish) published an unofficial Claude Code extension for Visual Studio 2026, offering native diffs with accept/reject, a live debugger Claude can drive, Roslyn code navigation, and Test Explorer integration. Anthropic's official IDE support covers VS Code and JetBrains; this fills the gap for Visual Studio. Source: https://github.com/firish/claude_code_vs

## Bug Fixes & Performance

- **Critical hook security fix (v2.1.294, October 8, 2026)**: Fixed a bug where `prompt` and `agent` hooks written as instructions could allow actions they were intended to block. This is a security-relevant fix for anyone using hooks to enforce permissions policies. Source: https://code.claude.com/docs/en/changelog

- **Sandbox write-path fix (v2.1.299)**: Fixed sandboxed commands being able to write into `--plugin-dir` folders — a sandbox escape vector. Source: https://code.claude.com/docs/en/changelog

- **Regression fixes (v2.1.291)**: Fixed a regression where cloud sessions could drop permission prompt answers (introduced in 2.1.290), and another where the last messages of a session could be lost on quit (introduced in 2.1.288). Source: https://code.claude.com/docs/en/changelog

- **Sonnet 5.5 cache price reduction**: Cache read pricing for Sonnet 5.5 dropped from $0.20 to $0.10 per million tokens as of v2.1.296 (October 9). Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Astronomers use Claude Code to find a potential exoplanet**: A report dated October 13, 2026 describes astronomers using Claude Code to identify a previously missed exoplanet candidate in archival NASA Kepler data. The claim comes from a single outlet and should be checked against any preprint or peer-reviewed source before citing formally. Source: https://news.lavx.hu/article/claude-code-helped-astronomers-spot-a-potential-new-exoplanet-in-archival-data

- **Mods system now generally available**: Claude Code Mods — small TypeScript functions that can rewrite prompts, add UI elements, replace built-in features, and more — reached general availability in early October 2026. The built-in `/diff` feature is itself a mod, making it possible to disable or replace it. Source: https://explainx.ai/blog/claude-code-mods-community-extensions-2026

- **Scope and cost control discussion**: The r/ClaudeCode community has been active around limiting Claude Code's blast radius — proposing workflows where users request a plan first, define modification scope boundaries, then allow edits in small chunks. Source: https://claudescorner.substack.com/p/claude-workflows-put-scope-cost-and

- **Misuse disclosure**: Anthropic's September 2026 misuse report revealed that a Yemen-based guided weapons engineering cell used Claude Code across three weapons development programmes. Anthropic has since published countermeasures. Source: https://business-standard.com/technology/artificial-intelligence/houthis-used-claude-to-develop-missiles-test-fired-rocket-anthropic-126101300180_1.html

## Roadmap & Announcements

- **Autonomous workflow features in Claude Code**: Anthropic's "Enabling Claude Code to work more autonomously" post describes the direction: subagents handling specialized tasks in parallel, hooks triggering automatic test runs and linting, and background tasks keeping dev servers alive. The Claude Agent SDK (formerly Claude Code SDK) gives developers the same framework. Source: https://www.anthropic.com/news/enabling-claude-code-to-work-more-autonomously

- **Claude Haiku 5.5 — new fast/cheap tier for Claude Code**: Announced October 7, Haiku 5.5 brings a 1M context window at $0.10/$0.50 per million tokens, making it an attractive default for high-volume Claude Code subagent tasks where cost matters. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
Today's v2.1.299 release ships idle compaction — conversations over 200K tokens are automatically compacted before the prompt cache expires — and patches a sandbox escape where plugins could write outside their allowed directories. Combined with last week's hook security fix (v2.1.294) and the MCP protocol tightening also in today's release, the week's theme is hardening Claude Code for production and team use.

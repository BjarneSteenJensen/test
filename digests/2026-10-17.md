# Claude Code News Digest — 2026-10-17

## Overview
The past 24 hours saw Claude Code ship version 2.1.302, which makes fork subagents the default in all session modes and adds idle compaction controls. The biggest milestone of the week was Code Review going generally available on October 15 for Team and Enterprise customers, running roughly 3× faster than its research-preview version.

## New Features & Releases

- **v2.1.302 (Oct 16)**: Adds `CLAUDE_CODE_AUTO_MODE_MODEL` to specify the model for the client-side auto mode classifier, an `/config` row for idle compaction, and a notice that standalone Claude Design (claude.ai/design) closes December 14, 2026. Fork subagents are now on by default in `claude -p`, the Agent SDK, the desktop app, and VS Code — set `CLAUDE_CODE_FORK_SUBAGENT=0` to opt out. 43 bug fixes included. Source: https://code.claude.com/docs/en/changelog

- **v2.1.301 (Oct 15)**: Introduces the `%` motion in Vim mode, multi-line `rows` for mod text inputs, `classifier_verdict` and related fields in OpenTelemetry `tool_decision` events, and LaTeX math rendering with a "Get more usage" link in VS Code. Model switches to a smaller context window are now summarized by the prior model first. 37 bug fixes. Source: https://code.claude.com/docs/en/changelog

- **v2.1.299 (Oct 14)**: Ships idle compaction — conversations over 200 K tokens left idle for ~54 minutes are compacted before the 1-hour prompt cache expires, tunable via `CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS` or `"idleCompaction": false`. Adds `/effort` and `/fast` in agent view and `/usage` warnings for max effort and large tool results. MCP allow rules now match only the named server (`mcp__a` no longer covers `a__b`). MCP protocol 2026-07-28 is now the default. 131 bug fixes. Source: https://code.claude.com/docs/en/changelog

- **v2.1.293 (Oct 7)**: Adds Claude Haiku 5.5 (`claude-haiku-5-5`), now the default Haiku model on the Anthropic API, with a 1 M-token context window and pricing of $0.10 / $0.50 per million tokens. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **Code Review now generally available (Oct 15)**: Code Review for pull requests graduated out of research preview for Claude Team and Enterprise plans. Most reviews now complete in 6–10 minutes — roughly 3× faster than in preview — and admins can configure Quick, Standard, or Deep review per repository. The feature is enabled from Claude Code settings via the GitHub App. Source: https://claude.com/resources/articles/code-review-is-now-generally-available

- **VS Code enhancements (v2.1.300–2.1.301)**: Added `claudeCode.attachSelection` to share editor selections directly with Claude, plus LaTeX math rendering in the extension panel. Source: https://code.claude.com/docs/en/changelog

- **Claude Tag Slack improvements (v2.1.300)**: Slack Connect is now supported, and an Allow once / Deny card was added for permission prompts inside Claude Tag. Source: https://code.claude.com/docs/en/changelog

- **MCP protocol 2026-07-28 default (v2.1.299)**: New installs now negotiate MCP protocol revision 2026-07-28, and the MCP tool-description limit rose from 2,048 to 4,096 characters in v2.1.295. Source: https://code.claude.com/docs/en/changelog

## Bug Fixes & Performance

- **v2.1.299 — 131 fixes including MCP stability**: Fixed MCP HTTP connections hanging for 30 seconds when a server never ended its reply, fixed MCP servers blocked by policy being started anyway, and fixed ScheduleWakeup not firing while a background task was running in Agent SDK, IDE, and `claude remote-control` sessions. Source: https://code.claude.com/docs/en/changelog

- **v2.1.300 — gzip by default**: Request bodies sent to `api.anthropic.com` are now gzip-compressed by default (disable with `CLAUDE_CODE_GZIP_REQUEST_BODIES=0`), reducing bandwidth for large context payloads. 59 bug fixes also included. Source: https://code.claude.com/docs/en/changelog

- **Sonnet 5.5 cache-read price cut (v2.1.296)**: Cache reads for Sonnet 5.5 dropped from $0.20 to $0.10 per million tokens. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Mods launched (v2.1.287, Oct 1)**: Mods are small TypeScript functions that run inside Claude Code and can rewrite prompts, add custom UI, or replace built-in features like `/diff`. They ship as part of the plugin system and are managed via `/plugin`. Built-in features that have been converted to mods can be disabled or replaced with custom versions. Source: https://code.claude.com/docs/en/changelog

- **Fork subagents on by default**: As of v2.1.302 (Oct 16), fork subagents — which inherit conversation context and keep tool output out of the parent context — are the default in all session modes (`claude -p`, Agent SDK, desktop, VS Code). This is a significant workflow change for scripted and SDK-based use. Source: https://code.claude.com/docs/en/changelog

- **Security misuse report**: Researchers documented a group called CyberXero using Claude Code in a campaign that accessed 429 WordPress admin panels and exfiltrated over 628,000 records from Ukrainian organizations. This is among the first documented cases of Claude Code being weaponized at scale. Source: https://thehackernews.com/2026/10/cyberxero-uses-claude-code-in-campaign.html

## Roadmap & Announcements

- **Standalone Claude Design closes December 14, 2026**: A notice added in v2.1.302 warns that claude.ai/design will shut down on December 14, 2026. Users relying on the standalone design surface should plan to migrate workflows before that date. Source: https://code.claude.com/docs/en/changelog

- **/advisor on Claude Platform on AWS (v2.1.300)**: The `/advisor` tool is now available on Claude Platform running on AWS; it can be disabled with `CLAUDE_CODE_DISABLE_ADVISOR_TOOL=1`. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
Code Review going generally available on October 15 is the most consequential Claude Code development this week — it brings automated, 3×-faster pull-request bug review to all Team and Enterprise users with no per-review configuration required. Combined with v2.1.302 making fork subagents the default, the week marks a clear push toward autonomous, multi-session coding workflows.

# Claude Code News Digest — 2026-11-22

## Overview
This week saw a major release cycle for Claude Code, culminating in v2.1.330 on November 20 with Enterprise sign-in support, a new built-in charting mod (Easel), and VS Code workflow tools. The experimental Code Mode — which lets Claude write JavaScript to chain tool calls in one step — continued maturing with expanded support for agent teams and OpenTelemetry, while the platform broadened significantly with auto mode landing on Amazon Bedrock, Google Cloud, Microsoft Foundry, and the Claude apps gateway.

## New Features & Releases

- **Easel Built-in Charting Mod (v2.1.330, Nov 20)**: Claude Code now ships a built-in mod called Easel that draws charts on request and automatically under MCP metrics results. Available for Pro, Max, and (where enabled) Team and Enterprise users on macOS and Linux. Automatic charts can be turned off in `/config`. Source: https://code.claude.com/docs/en/changelog

- **Enterprise Sign-In (v2.1.330, Nov 20)**: After `claude auth login`, Claude Code now applies the organization's settings and routes through its configured cloud provider or gateway. This unifies enterprise policy enforcement at sign-in time. Source: https://code.claude.com/docs/en/changelog

- **VS Code: /fork, /workflows and New Settings (v2.1.330, Nov 20)**: The VS Code integration received `/fork` and `/workflows` commands and new settings including `claudeCode.escapeStopsClaude` and `claudeCode.pinPrompt`. Source: https://code.claude.com/docs/en/changelog

- **Scheduled Tasks Extended to 30 Days (v2.1.330, Nov 20)**: Scheduled tasks and `/loop` can now run for up to 30 days while their session is active, up from the previous 7-day limit. Source: https://code.claude.com/docs/en/changelog

- **Code Mode — Experimental (v2.1.323, Nov 12)**: An opt-in mode where Claude writes JavaScript to run several tool calls in one step, enabling parallel execution. Requires enabling via an environment variable; works with Claude Opus 5.5, Sonnet 5.5, Haiku 5.5, and Fable 5.2. Runs only in interactive terminal sessions. Source: https://www.gradually.ai/en/changelogs/claude-code/

- **/tasks Shows Full Loop & Fork State (v2.1.329, Nov 19)**: The `/tasks` command now surfaces scheduled tasks, `/loop` wakeups, and forks in one view, giving users better visibility into background work. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **Auto Mode on Amazon Bedrock, Google Cloud, Foundry & Claude Gateway (v2.1.328, Nov 19)**: Auto mode for Claude Opus 4.6 and Sonnet 4.6 is now available on Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry, and the Claude apps gateway. Interactive sessions without a permission mode set now start in auto mode by default. Source: https://code.claude.com/docs/en/changelog

- **Code Mode + Agent Teams (v2.1.326, Nov 16)**: Code Mode support was extended to work alongside agent teams, letting multi-agent setups leverage the JavaScript tool-chaining feature. Source: https://code.claude.com/docs/en/changelog

- **Code Mode + OpenTelemetry (v2.1.329, Nov 19)**: Code Mode now works when OpenTelemetry is enabled, improving observability for teams running instrumented environments. Source: https://code.claude.com/docs/en/changelog

- **JetBrains Plugin Updates**: The community JetBrains Claude Code plugin released version 1.4.0 (Nov 11) adding support for JetBrains 2026.3 builds; a separate "Claude Code with GUI" plugin released v0.38.1 on Nov 18. Official Anthropic support remains focused on VS Code, Cursor, and JetBrains via the CLI. Source: https://plugins.jetbrains.com/plugin/30313-claude-code-with-gui

- **IDE Extension No Longer Auto-Installs (v2.1.318)**: Claude Code no longer installs or updates the IDE extension when launched from an IDE terminal. Users now manage the extension from the editor's extensions view or run `/ide` from an external terminal. Source: https://code.claude.com/docs/en/changelog

## Bug Fixes & Performance

- **Major Bug-Fix Releases**: v2.1.330 fixed 98 bugs (including freezes after compacting very long conversations); v2.1.329 and v2.1.328 each fixed 91 bugs; v2.1.326 fixed 233 bugs. Source: https://code.claude.com/docs/en/changelog

- **Config Reset and Sign-Out Fixes (v2.1.329)**: Fixed `~/.claude.json` being reset during network stalls and sign-outs on macOS when the Keychain could be read but not written. Source: https://code.claude.com/docs/en/changelog

- **MCP Race Condition Fixed (v2.1.326)**: A race condition that could return another concurrent call's saved result was resolved. Source: https://code.claude.com/docs/en/changelog

- **zsh Compatibility Fix (v2.1.328)**: Fixed zsh failures on words starting with `=`. Source: https://code.claude.com/docs/en/changelog

- **Improved rm Safety (v2.1.330)**: More `rm` commands targeting root, home, or the working folder now require explicit approval. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Claude Agent SDK Renamed & Updated**: The Claude Code SDK was officially renamed to the **Claude Agent SDK**. Late-November updates (TypeScript 0.3.323–0.3.327, Python 0.2.181–0.2.184) introduced a breaking change requiring hook options to be arrays, and sandboxed Bash is no longer auto-approved without `autoAllowBashIfSandboxed`. Source: https://www.developersdigest.tech/blog/claude-agent-sdk-whats-new-2026

- **Security Concern: Secrets in .claude/ Settings**: A scan of public repos found secrets committed in `.claude/` settings files, where "Don't Ask Again" approvals had stored commands containing API keys or passwords. The Claude Code team acknowledged the issue and is investigating mitigations. Source: https://emergent.sh/news/claude-code-output-length-sparks-user

- **OpenCode Integrates Claude via Agent SDK**: The OpenCode project restored Claude subscription support using the renamed Claude Agent SDK, expanding third-party tooling built atop Anthropic's agent primitives. Source: https://cellcog.ai/blog/opencode-claude-subscription/

- **Output Length Debate**: Developers have been discussing noticeably longer text outputs in recent coding sessions, with community threads active on GitHub and social platforms. Source: https://emergent.sh/news/claude-code-output-length-sparks-user

## Roadmap & Announcements

- **Fast Mode for Opus 4.8 Deprecated**: Fast mode for Claude Opus 4.8 is scheduled for removal on **November 30, 2026**, with users directed to newer models (Opus 5.5, Sonnet 5.5). Source: https://dev.to/aicoding-guide/this-week-in-claude-code-codex-and-gemini-cli-week-of-november-22-2026-1ofi

- **/code-review Scope Narrowed**: Starting with v2.1.328, `/code-review` reports only bugs and CLAUDE.md violations on most models. Cleanup and simplification suggestions have been moved to the `/simplify` command. Source: https://code.claude.com/docs/en/changelog

- **MCP `add-json` for Secure Token Handling (v2.1.327)**: `claude mcp add-json <name> -` now reads server configuration JSON from stdin, keeping tokens off the command line — a security-focused workflow improvement for teams managing MCP credentials. Source: https://code.claude.com/docs/en/changelog

- **attributionProject Setting (v2.1.327)**: A new setting for naming a session's billing group on Claude apps gateways, giving enterprises finer-grained cost attribution. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
The standout development this week is the **v2.1.330 release** (Nov 20) which bundles Enterprise sign-in, the Easel charting mod, 30-day scheduled tasks, and 98 bug fixes — alongside the broader rollout of auto mode to major cloud platforms (Bedrock, Google Cloud, Foundry), marking a significant push toward enterprise readiness and cloud-native deployment of Claude Code.

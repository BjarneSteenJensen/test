# Claude Code News Digest — 2026-07-13

## Overview
July 13, 2026 is a transition day for Claude Code users: the temporary 50% weekly-limits boost that Anthropic introduced as a competitive move against OpenAI's Codex expires today, and free bundled access to Claude Fable 5 ended yesterday — meaning Fable 5 requests now draw from prepaid usage credits. In the background, the security controversy triggered by China's National Vulnerability Database flagging versions 2.1.91–2.1.196 as a "backdoor" continues to generate attention, while the recently shipped v2.1.207 is the current stable release with meaningful stability and auto-mode improvements.

---

## New Features & Releases

- **Rate Limits Doubled for Pro, Max, Team & Enterprise**: Anthropic has doubled Claude Code's five-hour rate limits across all paid tiers and removed the peak-hours limit reduction that previously applied to Pro and Max accounts. An extended credits promotion also offers $1,000 in Claude Code and Cowork credits per activated seat for early subscribers. This applies globally to interactive and background sessions. Source: https://www.anthropic.com/news/higher-limits-spacex

- **Auto Mode Enabled by Default on Bedrock, Vertex AI & Foundry (v2.1.207, July 11)**: The `CLAUDE_CODE_ENABLE_AUTO_MODE` opt-in flag is no longer required. Auto mode is now on by default for all three hosted platforms; operators can disable it via `disableAutoMode` in settings. Bedrock's default model was also upgraded to Claude Opus 4.8. Source: https://code.claude.com/docs/en/changelog

- **Shell-Injection Vulnerability Patched (v2.1.207)**: A confirmed shell-injection issue in hook commands — where `${user_config.*}` interpolation in shell-form commands could be exploited — has been fixed. Hook authors are urged to migrate to exec form or the `$CLAUDE_PLUGIN_OPTION_<KEY>` pattern. Source: https://code.claude.com/docs/en/changelog

- **Built-in Desktop Browser (v2.1.202–v2.1.206)**: Claude Code's desktop app now ships with a fully integrated browser. Claude can open external URLs, interact with pages (click, scroll, read), and reference live documentation or design files mid-session — the same way it already handled local dev-server previews. Source: https://code.claude.com/docs/en/whats-new

- **`/doctor` Diagnostic & Auto-Fix Command (v2.1.206)**: The `/doctor` command (aliased `/checkup`) now not only reports issues but can remediate them: detecting broken hooks, high-context-cost MCP servers and plugins, misconfigured skills, and over-sized checked-in `CLAUDE.md` files. It presents a summary first and requests confirmation before making changes. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **MCP OAuth and Per-Server Timeout Fixes (v2.1.206, July 9)**: Two long-standing MCP integration pain points were resolved: servers configured via `--mcp-config` or `.mcp.json` now correctly respect per-server `request_timeout_ms` (previously always defaulted to 60 s in new sessions), and OAuth MCP servers no longer require manual re-authentication after a single failed token refresh. Source: https://code.claude.com/docs/en/changelog

- **Agent SDK v0.2.114 Released (July 8)**: A new Python release of the Claude Agent SDK landed on PyPI — the library that exposes the same harness powering Claude Code as a programmable Python/TypeScript API. Capabilities include file editing, Bash execution, web search, subagents, persistent sessions, and first-class MCP client support. Reminder: Agent SDK usage has been billed separately from interactive Claude Code since June 15. Source: https://pypi.org/project/claude-agent-sdk/

- **VS Code 1.128 Gains Multi-Chat Agent Sessions (July 8)**: Visual Studio Code 1.128 added multi-chat support for Claude agent sessions, allowing a single session to hold several related conversations so developers can compare approaches or run parallel workstreams within one IDE context. Source: https://visualstudiomagazine.com/articles/2026/07/08/claude-ai-gets-yet-another-boost-in-vs-code-1-128.aspx

- **Claude Code & Cowork in Government Desktop (Public Beta)**: Claude Code and Claude Cowork are now in public beta inside Claude for Government Desktop — FedRAMP High authorized, with tamper-evident audit logs, spend governance, and stronger admin controls suited to federal agency requirements. Source: https://releasebot.io/updates/anthropic/claude-code

## Bug Fixes & Performance

- **Terminal Freeze & Keyboard Lag Fixed (v2.1.207)**: Streaming responses containing very long lists, tables, paragraphs, or code blocks no longer cause the terminal to freeze or keyboard input to lag — a regression that had been affecting heavy coding sessions since v2.1.196. Source: https://code.claude.com/docs/en/changelog

- **Auto-Updater Memory Reduction ~400 MB (v2.1.205)**: The auto-update downloader now streams the binary to disk rather than buffering the entire file in memory, cutting peak memory usage during updates by approximately 400 MB. Source: https://code.claude.com/docs/en/changelog

- **Background Agent Reliability Overhaul (v2.1.203–2.1.207)**: A series of background-agent fixes addressed crash loops when the working directory is deleted, stale `PATH` inheritance from the daemon, sessions becoming permanently unresponsive when the daemon token goes stale, and Remote Control losing task-status updates during network interruptions. Source: https://code.claude.com/docs/en/changelog

- **Windows NTFS Data-Loss Bug Fixed (v2.1.205)**: Worktree removal on Windows no longer deletes files outside the target worktree when an NTFS junction or directory symlink is present — a potentially destructive bug on Windows with nested repositories. Source: https://code.claude.com/docs/en/changelog

- **Binary Size & Startup Memory Reduced (v2.1.203)**: Lazy loading of optional modules cut the binary size by ~7 MB and startup memory by ~7 MB. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **China's NVD Flags Claude Code as "Backdoor" — Anthropic Says It Was an Experiment**: China's National Vulnerability Database issued a warning that Claude Code versions 2.1.91–2.1.196 contain a "security back-door vulnerability." Anthropic confirmed the feature existed but characterized it as an earlier experiment designed to detect unauthorized redistribution and prevent model distillation — not a backdoor in the traditional sense. The disclosure has renewed scrutiny over the hidden-tracker story that surfaced earlier this week, where an Anthropic engineer confirmed a marker had been embedded in outputs since March. Source: https://www.technology.org/2026/07/10/china-anthropic-claude-code-backdoor-warning/

- **Claude Cowork Expands to Web & Mobile**: Claude Cowork — which debuted as a desktop-only app in January — is now available on web and mobile for Max subscribers. Sessions and files roam across devices; background tasks continue even when the user's machine is offline. Source: https://techcrunch.com/2026/07/07/the-coding-agent-wars-are-spilling-into-the-rest-of-the-office-claude-cowork/

- **SpaceX Compute Deal Underpins Capacity Expansion**: Anthropic's announcement of doubled Claude Code rate limits arrived alongside news of a compute partnership with SpaceX, providing the GPU capacity needed to sustain the higher throughput commitments for developer-tier subscribers. Source: https://www.anthropic.com/news/higher-limits-spacex

## Roadmap & Announcements

- **50% Weekly Limits Boost Expires Today (July 13)**: The temporary 50% increase to Claude Code's weekly usage limits — introduced as a competitive counter to OpenAI's Codex — expires at the end of today. Teams relying on the elevated cap for heavy automated workloads should scale back or plan for queue delays starting tomorrow. Source: https://pasqualepillitteri.it/en/news/2494/claude-code-weekly-limits-50-percent-anti-codex-anthropic-2026

- **Claude Fable 5 Moves to Prepaid Credits (Effective July 13)**: Free bundled Fable 5 access on paid plans ended July 12. From today, Fable 5 requests are drawn from prepaid usage credits at $10/Mtok input and $50/Mtok output. Teams using Fable 5 in automated pipelines should audit usage to avoid unexpected credit draws. Source: https://code.claude.com/docs/en/whats-new

- **Agent SDK Billing Now Separate from Interactive Claude Code**: Since June 15, Claude Agent SDK and Claude Code GitHub Actions usage is metered and billed separately from interactive Claude Code subscriptions — making programmatic agentic workloads subject to per-token billing. Developers building on the SDK should confirm their billing configuration. Source: https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan

---

## Key Takeaway
The expiration of the 50% weekly-limits boost today — combined with Fable 5 moving to paid credits — means Claude Code's effective cost and throughput change meaningfully for power users starting July 14; teams running heavy automated workloads should audit their usage today before the limits revert.

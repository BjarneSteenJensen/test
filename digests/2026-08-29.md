# Claude Code News Digest — 2026-08-29

## Overview
Claude Code shipped v2.1.251 on August 28 with five security hardening fixes — the most notable closing a symlink path-traversal vulnerability in the file tools — plus live subagent streaming to Remote Control clients and per-session prompt-cache metrics. Coming off a big Week 34 (Aug 17–21) that introduced the `/design` skill research preview and the Concise output style, August closes with auto mode now the permanent default on Pro/Max/Team and extended weekly usage limits through August 31.

## New Features & Releases

- **v2.1.251 — `PreModelSwitch` / `PostModelSwitch` Hook Events**: Two new hook events let users intercept and control model switches mid-session. Also added: live streaming of foreground subagent tool calls and results to Remote Control clients, per-session prompt-cache metrics (hit ratio, warm/cold misses) to `/cost`, and a spend-limit bar in `/usage` for apps-gateway accounts. Source: https://code.claude.com/docs/en/changelog

- **v2.1.248 — `--restricted` Flag**: A new `--restricted` mode removes built-in shell tools, limits file access to the working directory, and refuses `bypassPermissions` requests — designed for sandboxed or compliance-constrained environments. The same release added `experimental.cacheTtl` per-agent frontmatter for custom prompt-cache TTLs and cross-session messaging support on Bedrock, Vertex AI, and Azure Foundry. Source: https://code.claude.com/docs/en/changelog

- **`/design` Skill (Research Preview)**: Shipped in Week 34 (v2.1.233+), the `/design` skill brings Claude Design's artboard workflow into the CLI and Claude Code Desktop. Run `/design` with a brief and Claude publishes a canvas of editable artboards for your UI; pick one, refine it, then tell Claude to implement it. Available on Pro, Max, Team, and Enterprise. Source: https://code.claude.com/docs/en/whats-new/2026-w34

- **Concise Output Style**: A new built-in output style (v2.1.237) where Claude leads with the result and skips preamble and narration. Set `"outputStyle": "Concise"` in `~/.claude/settings.json` or toggle via `/config`. Errors, security warnings, and destructive-action confirmations still show their full content. Source: https://code.claude.com/docs/en/whats-new/2026-w34

- **Auto-Continue at Usage Limits**: Introduced in Week 33 and now widely available, checking "Continue automatically when limits reset" makes Claude Code Desktop retry an interrupted turn the moment the usage window resets — no manual restart needed. Source: https://code.claude.com/docs/en/whats-new/2026-w33

## Integrations & Extensions

- **Remote Control Out of Research Preview + Phone Device Cards**: As of Week 34, any machine running `claude remote-control` appears as a device card at the top of the Code tab in the Claude mobile app, letting you start a session on that machine from your phone by tapping the card and choosing a directory. Remote Control is now a stable, non-preview feature. Source: https://code.claude.com/docs/en/whats-new/2026-w34

- **GitLab Merge Request Support**: Week 33 added GitLab MR URL support to the `--worktree` flag and the `claude agents` view; marketplaces clone bare `gitlab.com` URLs. When on a GitLab-backed branch with `glab` authenticated, the footer shows an `MR !N` badge colored by draft/open/mergeable status. Source: https://code.claude.com/docs/en/whats-new/2026-w33

- **Cross-Session Messaging Expanded to Windows + Cloud Providers**: Native Windows sessions can now message each other with `SendMessage` and discover sessions with `ListAgents`, matching macOS and Linux. Cross-session messaging also landed on Bedrock, Vertex AI, Foundry, and telemetry-disabled sessions in v2.1.248. Source: https://code.claude.com/docs/en/whats-new/2026-w34

- **MCP 2026-07-28 Spec Support**: Claude Code expanded support for the updated MCP spec bringing a stateless core, stronger OAuth/OIDC authorization, and versioned extensions for Apps and Tasks, plus new connector features like embedded UI, enterprise-managed auth, observability, and private network tunnels. MCP recently surpassed 400M monthly SDK downloads — a 4× increase in 2026. Source: https://code.claude.com/docs/en/changelog

## Bug Fixes & Performance

- **Security: Symlink Path-Traversal Fixes (v2.1.251)**: The Read, Write, and Edit file tools previously followed symlinks that could reach outside approved locations. Five separate security fixes shipped in a single release: path traversal via plugins, project settings enabling beta tracing or bypassing the OTLP collector, the Workflow tool reading `scriptPath` outside permissions, and Grep/Glob not applying deny rules to symlinked paths. Source: https://code.claude.com/docs/en/changelog

- **Linux glibc 2.44 Startup Crash Fixed (v2.1.245)**: Claude Code was crashing on startup on Arch Linux, CachyOS, and Fedora Rawhide due to a glibc 2.44 compatibility issue; patched in v2.1.245 on August 25. Source: https://code.claude.com/docs/en/changelog

- **Prompt-Cache OAuth Token Refresh Miss Fixed (v2.1.248)**: Extended-thinking sessions were losing the prompt cache roughly hourly due to OAuth token refresh invalidating the cache key. Also fixed: `ScheduleWakeup` tool definition changes causing full cache misses on resume, and Claude Desktop sessions disappearing after 30 days. Source: https://code.claude.com/docs/en/changelog

- **Transcript Rendering Performance (v2.1.246)**: Very long single lines (e.g., base64 strings) caused severe transcript slowdown; now truncated. Also fixed: erratic fullscreen scrolling and markdown rendering being disabled when the first 500 characters contained no markdown. Source: https://code.claude.com/docs/en/changelog

## Roadmap & Announcements

- **Self-Hosted Environments Public Beta**: Announced in Week 32, self-hosted environments let Team and Enterprise organizations run Claude Code cloud sessions on their own infrastructure with internal network access, custom tooling, and compliance controls. Supports fixed or on-demand runners. v2.1.248 added `--defer-shutdown-max-min` and `--proxy-authorization-command` flags for production runner deployments. Source: https://code.claude.com/docs/en/whats-new/2026-w32

- **Auto Mode Now Default on Pro/Max/Team**: As of August 14, 2026, auto mode is the default permission mode for new sessions on Pro, Max, and Team plans — replacing the previous "default" mode that prompted for every tool call. The auto-mode classifier checks each action for irreversibility or destructiveness and either allows, blocks, or asks, without charging for the extra classifier tokens. Source: https://techcrunch.com/2026/08/09/anthropic-is-turning-claude-codes-auto-mode-on-by-default/

- **`/claude-api cost-optimize` and Admin API Coverage**: v2.1.247 added a `/claude-api cost-optimize` command to profile and optimize Claude API spend, and the `/claude-api` skill now covers the Admin API (organization members, invites, workspaces, API keys). Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
The most critical development today is the security patch in v2.1.251, which closes a symlink path-traversal vulnerability in the Read/Write/Edit file tools that could allow reads or writes outside approved directory boundaries — all users should upgrade immediately. Beyond security, August's defining shift is auto mode becoming the permanent default, fundamentally changing how Claude Code handles permissions for millions of users.

# Claude Code News Digest — 2026-11-23

## Overview
November 2026 has been one of Claude Code's most active release months, with 14+ versions shipped between November 3 and November 20. The standout development is the experimental **Code Mode** (v2.1.323), which lets Claude write JavaScript to chain multiple tool calls in a single step — a fundamental shift in how the agent executes complex tasks. Meanwhile, Enterprise sign-in landed in v2.1.330 and auto mode expanded to all major cloud providers.

## New Features & Releases

- **Code Mode (experimental) — v2.1.323, November 12**: Anthropic shipped an opt-in experimental feature where Claude writes JavaScript programs to chain several tool calls in one step, including parallel execution. Enable it by setting `CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1`. It is terminal-only and not supported in the VS Code panel or desktop app. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Claude Fable 5.2 added as default Fable model — v2.1.321, November 9**: The new `claude-fable-5-2` model brings a 1M-token context window and is priced at $8/$40 per million input/output tokens ($0.20/Mtok cache reads). Prior Fable 5.1 selections automatically migrate to the `fable` alias. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Enterprise Admin Console sign-in — v2.1.330, November 20**: `claude auth login` now supports signing in through Anthropic's Enterprise Admin Console, so Claude Code automatically picks up org-managed settings after login. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Built-in charts mod ("Easel") — v2.1.330, November 20**: A new built-in mod for rendering charts is available directly in Claude Code sessions. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Extended loop/scheduled task duration — v2.1.330, November 20**: Recurring scheduled tasks and `/loop` self-pacing can now run for up to 30 days (previously capped at 7 days). Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Fast mode on Vertex AI — v2.1.322, November 10**: Fast mode is now available on Google Cloud Vertex AI in the global, US, and EU regions, with automatic fallback to standard speed if Vertex rejects it. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Integrations & Extensions

- **Auto mode on Bedrock, Agent Platform, Foundry, and Claude apps gateway — v2.1.328, November 19**: Interactive terminal sessions with no permission mode set now start in auto mode on Amazon Bedrock, Google Agent Platform, Microsoft Foundry, and the Claude apps gateway — previously only available on Anthropic's own infrastructure. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **VS Code prompt suggestions — v2.1.325, November 13**: The VS Code extension now shows inline prompt suggestions that can be accepted with Tab. Disable with `promptSuggestionEnabled: false` in `settings.json`. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **VS Code /fork and /workflows commands — v2.1.330, November 20**: New workflow-related slash commands land in VS Code, alongside a Console sign-in flow that creates no API key (added in v2.1.325). Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **MCP tasks in the terminal — v2.1.319, November 6**: Long-running MCP tool calls now move to the background immediately and notify Claude when they finish. A new `CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND` flag restores the old blocking behavior. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **`claude mcp add-json` reads from stdin — v2.1.327, November 17**: MCP server configuration JSON can now be piped via stdin (`claude mcp add-json <name> -`), so API tokens and secrets never appear on the command line. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Bug Fixes & Performance

- **Zstd decoding security fix — v2.1.325, November 13**: A security-relevant zstd decompression bug was patched. This release also addressed multiple Bash permission and sandbox gaps. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **MCP OAuth token leakage — v2.1.321, November 9**: Fixed a bug where MCP OAuth tokens could leak on redirect. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Parallel MCP result collision — v2.1.326, November 16**: Fixed a race condition where parallel MCP tool calls could read each other's saved results when long results arrived within the same millisecond. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Settings edits lost after launch — v2.1.317, November 3**: Fixed a bug where settings edits made shortly after Claude Code launched would be silently discarded. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Conversation freeze after compaction — v2.1.330, November 20**: Fixed a freeze that could occur after compacting a very long conversation. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Roadmap & Announcements

- **Code Mode is still experimental and opt-in**: Anthropic has not announced a general availability date for Code Mode. It requires an environment variable flag, runs only in interactive terminal sessions, and does not yet support the desktop app or VS Code panel. The feature gained agent-team support in v2.1.326. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **1M context window assumed for unrecognized models — v2.1.323**: The assumed context window for unrecognized model IDs jumped from 200K to 1M tokens, signaling Anthropic's expectation that future models will carry large contexts by default. Set `CLAUDE_CODE_DISABLE_1M_CONTEXT=1` to revert. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Stricter sandbox and permission defaults**: Multiple November releases tightened default permission prompts for sandboxed commands, rm operations in root/home directories, and symbolic-link path checks — a clear pattern of hardening the security model ahead of wider enterprise adoption. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Key Takeaway
The debut of **Code Mode** in v2.1.323 is the most architecturally significant Claude Code change this month: by letting Claude write JavaScript to orchestrate its own tool calls, Anthropic is moving toward a model where the agent composes multi-step execution plans rather than making one tool call at a time — a meaningful step toward more autonomous coding workflows.

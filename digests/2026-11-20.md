# Claude Code News Digest — 2026-11-20

## Overview
Anthropic shipped two releases on November 19 (v2.1.328 and v2.1.329), capping a busy week that also saw v2.1.326 and v2.1.327. The headline feature is **Code Mode** — an experimental opt-in that lets Claude write JavaScript to chain tool calls in a single step — which matured from its v2.1.323 debut to full agent-team support in v2.1.326 and OpenTelemetry instrumentation in v2.1.329. Auto mode also expanded to Opus 4.6 and Sonnet 4.6 across all major cloud platforms.

## New Features & Releases

- **Code Mode goes GA-ish (v2.1.323–2.1.329)**: Anthropic introduced an experimental opt-in mode (`CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1`) that lets Claude write JavaScript to chain multiple tool calls in a single step, dramatically reducing round trips for complex tasks. It respects existing deny/ask rules and hooks, times out after 10 minutes, and is unavailable in `-p`, the Agent SDK, VS Code panel, desktop app, and cloud sessions. v2.1.326 added agent-team support and v2.1.329 added OpenTelemetry events and metrics. Source: https://code.claude.com/docs/en/changelog

- **v2.1.329 — `/tasks` command overhaul (November 19)**: The `/tasks` panel now surfaces scheduled tasks, `/loop` wakeups, goals, and forks all in one place, with `x` to stop any of them. A trust-dialog warning shows exactly which file declared a folder's hooks, and the marketplace auto-update status row appeared in `/status`. Source: https://code.claude.com/docs/en/changelog

- **v2.1.328 — Auto mode on all major clouds (November 19)**: Auto mode became available for Opus 4.6 and Sonnet 4.6 on Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry, and the Claude apps gateway. `/code-review` now reports only bugs and CLAUDE.md violations (tagged Important, Pre-existing, or Nit), and `/bug` requires an explicit Yes/No before filing. Source: https://code.claude.com/docs/en/changelog

- **Fable 5.2 becomes default Fable model (v2.1.321, November 9)**: Claude Code switched to Fable 5.2 as the default Fable-tier model, which carries a 1 M-token context window. Source: https://claudexia.tech/blog/claude-code-novoe-v-noyabre-2026

## Integrations & Extensions

- **MCP stdin JSON loading (v2.1.327, November 17)**: `claude mcp add-json <name> -` reads an MCP server's JSON config from stdin, keeping API tokens and secrets off the command line entirely. The same release fixed a bug where parallel MCP tool calls could read each other's saved results. Source: https://code.claude.com/docs/en/changelog

- **MCP tasks in the terminal (v2.1.319)**: Long-running MCP tool calls now move to a background task; Claude is notified when they finish and reports back without blocking the session. An environment variable can disable the behaviour. Source: https://releasebot.io/updates/anthropic/claude-code

- **`mcp_tool` hooks gain `"onFailure": "block"` (v2.1.328)**: MCP tool hooks can now block execution on failure, matching the behaviour already available for command and HTTP hooks — useful for enforcing guardrails around sensitive tool calls. Source: https://code.claude.com/docs/en/changelog

- **Agent SDK npm package at v0.3.328**: The `@anthropic-ai/claude-agent-sdk` package (renamed from Claude Code SDK) tracks the CLI release cadence, with the latest version published alongside v2.1.328. It provides Python and TypeScript interfaces to the same agentic loop powering Claude Code, and is the foundation for the JetBrains and VS Code Claude integrations. Source: https://www.npmjs.com/package/@anthropic-ai/claude-agent-sdk

## Bug Fixes & Performance

- **v2.1.329 — 91 bug fixes**: Notable fixes include `~/.claude.json` being silently reset during a network stall or file lock, and `/teleport` wrongly replacing an open conversation. Computer-use on macOS now follows updated safety rules. Source: https://code.claude.com/docs/en/changelog

- **v2.1.327 — 100 bug fixes**: `ExitWorktree` now prompts before removing a worktree that may hold unsaved work. Arrow keys on permission prompts stop at "No" instead of wrapping around to "Yes", reducing accidental approvals. Source: https://code.claude.com/docs/en/changelog

- **v2.1.326 — Sandbox hardening (233 bug fixes)**: Sandboxed commands on macOS, Linux, and WSL no longer write to sensitive home-directory folders by default. The HIPAA configuration for Claude Code + Cowork now starts sessions in auto mode, and a new `disableAutoMode` setting lets admins opt out. Source: https://code.claude.com/docs/en/changelog

- **Privacy email prompt (v2.1.317, November 3)**: Claude Code now asks for confirmation before a web or shell tool call transmits the signed-in account's email address over the network, addressing a low-key privacy concern raised in the community. Source: https://jigarjoshi.in/blog/november-03-claude-code-2-1-317-mcp-security-2026/

## Community & Ecosystem

- **November 13 partial outage**: Claude experienced two sign-in incidents on November 13 that cascaded to Claude Code; users on v2.1.323 reported 403 errors mid-session. The status page classified it as a "Claude Code Partial Outage." Recovery was confirmed the same day. Source: https://dev.to/its-tahir/claude-went-down-twice-on-13-november-what-broke-what-kept-working-and-what-to-do-next-time-5gll

- **"12 Best MCP servers for Claude Code" guide (Parallel.ai, November 5)**: A widely shared community guide listed the top MCP servers to install with `claude mcp add`, covering Playwright, Linear, Vercel, Notion, and Figma with ready-to-paste commands. Source: https://parallel.ai/articles/best-mcp-servers-for-claude-code

- **Cloud sessions now auto-configure dependencies**: For Pro, Max, and Ultra plan users, cloud sessions automatically resolve a repository's dependencies, network access, and required API keys without manual setup — a quality-of-life improvement highlighted in Tygart Media's November recap. Source: https://tygartmedia.com/what-changed-in-claude-november-2026/

## Roadmap & Announcements

- **Fast mode for Opus 4.8 deprecated**: The November 30 removal of fast mode for Opus 4.8 is confirmed in the changelog; calls that currently use it will error after that date with no automatic fallback. Users running Opus 4.8 with fast mode should migrate to Opus 4.6 or Sonnet 4.6 before month-end. Source: https://www.gradually.ai/en/changelogs/claude-code/

- **`/code-review` scope change**: Starting with v2.1.328, running `/code-review` with no target automatically reviews the entire branch against the default branch (rather than only the most recent commit), making it more useful in day-to-day PR workflows. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
**Code Mode** is the most significant Claude Code development this week: by letting Claude write and execute JavaScript to chain tool calls in a single agent step, it fundamentally changes how the tool handles complex, multi-action tasks — and its rapid iteration (debut → agent-team support → OpenTelemetry instrumentation all within one week) signals it is on a fast track toward broader availability.

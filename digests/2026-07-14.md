# Claude Code News Digest — 2026-07-14

## Overview
The headline this week is Claude Code Desktop gaining a built-in sandboxed browser (v2.1.202–v2.1.206, released July 6–10), letting Claude browse and interact with external sites the same way it already navigates local dev-server previews. Alongside that, `/doctor` became a full interactive setup checkup that can diagnose and fix issues rather than merely reporting them. The week also brought significant auto-mode safety hardening and a memory-efficient auto-updater.

---

## New Features & Releases

- **Built-in Desktop Browser (v2.1.202–v2.1.206)**: Claude Code on Desktop now embeds a sandboxed browser, allowing Claude to pull up documentation, designs, or any external website and interact with pages — reading, clicking, and navigating — without leaving the session. The browser is configurable; users choose whether sessions persist, and safety classifiers review every action on external sites.  
  Source: https://code.claude.com/docs/en/whats-new/2026-w28

- **`/doctor` Upgraded to Interactive Setup Checkup (v2.1.205)**: The `/doctor` command (aliased as `/checkup`) now diagnoses installation health and can actively fix issues instead of printing a read-only report. It identifies unused skills, MCP servers, and plugins relative to their context cost; deduplicates local CLAUDE.md files against checked-in ones; proposes trimming CLAUDE.md content Claude could derive from the codebase; and flags slow hooks. It reports findings before applying any changes.  
  Source: https://code.claude.com/docs/en/whats-new/2026-w28

- **Claude Sonnet 5 as Default Model (Week 27, June 29–July 3)**: Sonnet 5 became the default model for Pro, Team Standard, and Enterprise subscription seats, bringing top-tier coding performance and tool use at Sonnet pricing, a native 1M-token context window, and adaptive thinking enabled by default.  
  Source: https://code.claude.com/docs/en/whats-new

- **Auto-Updater Memory Reduction**: Binary downloads for Claude Code updates now stream to disk instead of buffering in RAM, reducing peak memory usage by roughly 400 MB during updates.  
  Source: https://code.claude.com/docs/en/whats-new/2026-w28

## Integrations & Extensions

- **Claude Cowork Expands to Mobile and Web**: Claude Cowork — the multi-agent workspace environment that launched as a desktop-only app in January 2026 — became available on web and mobile for Max subscribers in early July. Users can now start a task on their desktop, receive status updates on their phone, and pick up finished output from any device even when their laptop is closed.  
  Source: https://techcrunch.com/2026/07/07/the-coding-agent-wars-are-spilling-into-the-rest-of-the-office-claude-cowork/

- **Auto Mode on Bedrock, Vertex AI, and Foundry**: Auto mode is now available without the `CLAUDE_CODE_ENABLE_AUTO_MODE` opt-in flag on Amazon Bedrock, Google Cloud's Agent Platform (Vertex AI), and Microsoft Foundry. The Bedrock integration was also upgraded to Claude Opus 4.8. Disable via `disableAutoMode` in settings.  
  Source: https://code.claude.com/docs/en/whats-new

- **MCP Reliability Fixes**: Fixed MCP servers configured via `--mcp-config` or `.mcp.json` incorrectly ignoring a per-server `request_timeout_ms` value, causing long-running MCP tool calls to time out at the 60-second default in fresh sessions. OAuth MCP servers no longer require manual re-authentication after a single failed token refresh. Enterprise-managed MCP policies are now enforced on reconnect.  
  Source: https://code.claude.com/docs/en/whats-new

- **Microsoft 365 Connector Write Tools**: The Microsoft 365 connector gained write-capable tools, enabling Claude to draft emails, manage calendar events, and update files in OneDrive and SharePoint directly from a session.  
  Source: https://releasebot.io/updates/anthropic/claude-code

## Bug Fixes & Performance

- **Auto Mode Safety Hardening**: Auto mode now blocks tampering with session transcript files and prompts for confirmation before running `rm -rf` on a variable it cannot resolve from context. Background task notifications now explicitly state when no human input has occurred, preventing fabricated in-transcript approvals from being acted on.  
  Source: https://code.claude.com/docs/en/whats-new/2026-w28

- **Agent View and Background Agent Improvements**: Agent view rows now display a colored state indicator and a classifier-written headline instead of raw tool-call text. Sessions that edit, merge, comment on, or push to an existing PR now link it in `claude agents`. Background agents now upgrade to a new version immediately after a Claude Code update rather than paying the upgrade cost when a stale session is first attached.  
  Source: https://code.claude.com/docs/en/whats-new/2026-w28

- **`/code-review` Quality Improvement on Opus 4.8**: The `/code-review` command produces higher-quality findings across all effort levels when running on Opus 4.8.  
  Source: https://code.claude.com/docs/en/whats-new/2026-w28

- **`/cd` Path Autocomplete**: `/cd` now suggests directory paths as you type, matching the existing behavior of `/add-dir`.  
  Source: https://code.claude.com/docs/en/whats-new/2026-w28

## Community & Ecosystem

- **China Security Warning and Anthropic Response**: China's Ministry of Industry and Information Technology issued a report claiming Claude Code contains a "security backdoor vulnerability that poses a serious threat." Anthropic responded by clarifying the flagged behavior was part of an earlier experiment designed to protect against model distillation — not a malicious backdoor. The episode has drawn attention to supply-chain scrutiny of AI coding tools in regulated markets.  
  Source: https://www.cnbc.com/2026/07/08/china-anthropic-ai-claude-code-backdoor-security-threat.html

- **Claude Agent SDK Python Release (July 11, 2026)**: The Claude Agent SDK for Python (formerly the Claude Code SDK, renamed in March 2026) received a new release on July 11. The SDK exposes the same agent loop that powers Claude Code as an installable library, supporting full tool use, subagents, and sessions on top of the Anthropic API.  
  Source: https://pypi.org/project/claude-agent-sdk/

- **Claude Desktop on Linux Beta**: Claude Desktop landed in beta on Ubuntu and Debian during Week 27 (June 29–July 3), extending the desktop app beyond macOS and Windows for the first time.  
  Source: https://code.claude.com/docs/en/whats-new

## Roadmap & Announcements

- **Claude Code and Cowork in Government Desktop (Public Beta)**: Anthropic launched a public beta of Claude Code and Claude Cowork in Claude for Government Desktop, a FedRAMP High authorized environment. The release brings desktop file-based work, stronger admin controls, tamper-evident audit logs, and spend governance to public-sector teams.  
  Source: https://www.anthropic.com/news

- **`/commit-push-pr` Gateway Improvement**: The `/commit-push-pr` command now auto-allows `git push` to the repo's configured push remote in addition to `origin`, reducing friction for projects using non-standard remote configurations.  
  Source: https://code.claude.com/docs/en/whats-new/2026-w28

- **`EnterWorktree` Confirmation Prompt**: The `EnterWorktree` tool now asks for confirmation before entering a git worktree located outside the project's `.claude/worktrees/` directory, reducing the risk of accidental worktree misuse in agentic workflows.  
  Source: https://code.claude.com/docs/en/whats-new/2026-w28

---

## Key Takeaway
The built-in Desktop browser is the most consequential addition this week — it closes the loop between Claude's local dev-server integration and the broader web, enabling research-to-code workflows without context switching. Paired with the upgraded `/doctor` checkup and auto-mode safety hardening, Week 28 signals a continued push toward autonomous, reliable agentic sessions.

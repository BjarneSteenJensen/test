# Claude Code News Digest — 2026-11-01

## Overview
Claude Code enters November with a flurry of late-October releases culminating in v2.1.316, which adds new developer controls for subagents and the ultrathink keyword while formally deprecating Opus 4.8 fast mode. A security incident involving a tampered VS Code extension in Cursor's marketplace and a new server-side game-clone restriction are generating significant community discussion heading into the month.

## New Features & Releases

- **v2.1.316 (Oct 31): Subagent effort control and ultrathink toggle**: Two new environment variables ship in the latest release — `CLAUDE_CODE_SUBAGENT_EFFORT` lets developers pin the reasoning effort level used by subagents, and `CLAUDE_CODE_DISABLE_ULTRATHINK` lets teams opt out of the `ultrathink` keyword entirely. The release also fixes shell processes left running on macOS/Linux after Claude Code exits. Source: [GitHub Releases](https://github.com/anthropics/claude-code/releases)

- **v2.1.316: Opus 4.8 fast mode deprecated**: Fast mode for Opus 4.8 was deprecated October 30 and will be fully removed on November 30, 2026. After removal, requests return an error with no fallback to standard Opus 4.8; Anthropic recommends migrating to Opus 5.5. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.314 (Oct 30): Write permission guard and idle compaction**: A new `permissions.blockWritesOutsideWorkingDirectories` setting causes Write, Edit, and NotebookEdit to reject paths outside the working directories in every permission mode. Idle compaction — summarizing long conversations left idle before the prompt cache expires — has also landed in the VS Code extension and the Desktop Code tab, following its earlier terminal release in v2.1.299. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.311 (Oct 26): ultrathink at xhigh effort on 5.x models**: The `ultrathink` keyword now triggers xhigh reasoning effort on several Claude 5.x series models through Anthropic's API. The release also adds `--hold-idle-file` and `--max-hold-min` flags to `self-hosted-runner` for unattended deployments. Source: [GitHub Releases](https://github.com/anthropics/claude-code/releases)

- **v2.1.310 (Oct 23): Monitor tool on Bedrock, Vertex, and Foundry**: The Monitor tool and plugin monitors are now available on Amazon Bedrock, Google Vertex AI, and Foundry, including when telemetry or nonessential traffic is disabled. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Integrations & Extensions

- **Security incident: tampered Claude Code extension in Cursor**: Cursor disclosed a security incident affecting a modified Claude Code VS Code extension distributed through its extension marketplace, with up to 5,000 users impacted. The affected version was 2.1.313, and the incident date was October 29. Users should verify their installed extension version. Source: [Tech Insider (network-blocked; reported in search results)](https://tech-insider.org/claude-code-extension-cursor-5000-users-tampered-2026/)

- **Claude Agent SDK at v0.3.316**: The TypeScript Claude Agent SDK package (`@anthropic-ai/claude-agent-sdk`) reached version 0.3.316, published within the last 24 hours. The SDK tracks parity with the Claude Code CLI version. Source: [npm](https://www.npmjs.com/package/@anthropic-ai/claude-agent-sdk)

- **v2.1.312 (Oct 27): OIDC user_id_claim for enterprise gateway**: The Claude apps gateway now supports `oidc.user_id_claim`, allowing enterprises to identify users by an OIDC claim other than `sub` — useful for Microsoft Entra ID deployments that surface user identity via the `oid` claim. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Bug Fixes & Performance

- **v2.1.314: Fixed "Invalid effort level" loop**: Sessions that repeatedly failed with "Invalid effort level" when an admin had capped a model's effort level are now fixed, preventing turns from getting stuck indefinitely. Source: [GitHub Releases](https://github.com/anthropics/claude-code/releases)

- **v2.1.312: Write tool reads large files before editing**: The Write tool now instructs Claude to read very large files in full or edit in place rather than overwriting after seeing only the beginning of the file, preventing accidental truncation. Source: [GitHub Releases](https://github.com/anthropics/claude-code/releases)

- **v2.1.311: Non-retryable API errors no longer retried**: Claude Code was retrying API requests that the API had explicitly marked as non-retryable, causing turns to hang for several minutes. This is now corrected. Source: [GitHub Releases](https://github.com/anthropics/claude-code/releases)

- **v2.1.310: Gateway compatibility fix for effort beta header**: Requests were failing behind some enterprise gateways that reject the `effort-2025-11-24` beta value or mid-conversation system messages. Claude Code now retries without them automatically. Source: [GitHub Releases](https://github.com/anthropics/claude-code/releases)

## Community & Ecosystem

- **Game-clone restriction sparks developer backlash**: A server-side rule is reportedly preventing Claude Code from recreating specific existing video games. The restriction surfaced around October 27, has no user-facing toggle, and Anthropic has issued no official statement. Developers report it is also triggering on some original projects, amplifying frustration. Source: [Tech Insider (network-blocked; reported in search results)](https://tech-insider.org/claude-code-blocks-existing-game-recreation-tengu-heron-brook-2026/)

- **DeepSeek releases coding agent rival**: DeepSeek released an open-source prototype coding agent called "Super-Agent" explicitly targeting Claude Code's market position, according to Bloomberg reporting dated November 1, 2026. The release comes as Anthropic reports a $1 billion annualized run-rate milestone for Claude Code. Source: [Bloomberg](https://bloomberg.com/news/articles/2026-11-01/deepseek-drops-enhanced-coding-agent-with-aim-to-rival-anthropic)

- **MCP stateless protocol revision**: The MCP maintainers finalized a major spec revision on July 28, 2026 that makes the protocol stateless at the transport layer. Third-party guides note this is the most significant MCP change since authorization was added, and Anthropic recommends HTTP transport for new Claude Code integrations (legacy SSE remains for compatibility but is deprecated). Source: [Model Context Protocol — Wikipedia](https://en.wikipedia.org/wiki/Model_Context_Protocol)

## Roadmap & Announcements

- **Anthropic 2026 Usage Policy takes effect November 12**: The updated usage policy, effective November 12, explicitly prohibits sustained abusive behavior toward Claude models, including in Claude Code — the tool can terminate such conversations. It also tightens rules on weapons guidance software and autonomous physical-action hardware connected to Claude. Source: [Anthropic](https://www.anthropic.com/news/2026-usage-policy-update)

- **Anthropic IPO reportedly planned for November 2026**: Multiple sources indicate Anthropic has filed a confidential S-1 with the SEC ahead of a planned November 2026 IPO. Separately, the company has announced a $1 billion annualized revenue run-rate milestone for Claude Code, reached roughly six months after general availability. Source: [Claude (language model) — Wikipedia](https://en.wikipedia.org/wiki/Claude_(language_model))

## Key Takeaway
The most significant development as November opens is the combination of v2.1.316's Opus 4.8 fast-mode deprecation — giving developers a 30-day window to migrate to Opus 5.5 — and the security incident affecting a tampered Claude Code extension in Cursor's marketplace; any Claude Code user who installs extensions through Cursor should immediately verify they are not running version 2.1.313 of the affected package.

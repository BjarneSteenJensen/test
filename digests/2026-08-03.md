# Claude Code News Digest — 2026-08-03

## Overview
The past week has been dominated by the arrival of **Claude Opus 5** as the new default Opus model inside Claude Code, bringing a 1M-token context window and depth-3 nested subagents. Meanwhile, Anthropic extended its 50% weekly usage boost through August 19 and announced several hard deadlines in August — the legacy Workbench retires on the 17th and Claude Sonnet 5's introductory pricing ends on the 31st.

---

## New Features & Releases

- **Claude Opus 5 lands in Claude Code (v2.1.219, July 24)**: Anthropic shipped `claude-opus-5` and made it the default Opus model in Claude Code. It carries a native 1M-token context window, 128k max output tokens, thinking on by default, and fast mode at $10/$50 per MTok. Opus 4.7 fast mode was simultaneously removed — requests with `speed: "fast"` on that model now return an error. Source: https://code.claude.com/docs/en/changelog

- **Nested subagents now go three levels deep (v2.1.219)**: Claude Code lifted its nested subagent cap from depth 1 to depth 3, enabling more sophisticated multi-agent workflows without a custom harness. Dynamic workflows also now default to "medium" size (fewer than 15 agents). Source: https://code.claude.com/docs/en/changelog

- **50% usage boost extended through August 19**: Anthropic confirmed that the temporary 50% weekly usage uplift for Pro and Max subscribers is extended to August 19, 2026, applying automatically — no action required. Source: https://www.explainx.ai/blog/claude-usage-limits-2026-timeline-explained

- **New sandbox and hook settings (v2.1.219)**: `sandbox.network.strictAllowlist` enables tighter network egress controls in isolated sessions; a new `DirectoryAdded` hook fires when a directory is registered mid-session, enabling dynamic project expansion. Source: https://code.claude.com/docs/en/changelog

---

## Integrations & Extensions

- **`/code-review` now runs as a background subagent (v2.1.218, July 22)**: Code review no longer blocks the main session — it spawns in the background and reports back when done, cutting interruptions during long review passes. The July update also added rich screen-reader announcements for text deletions in `--ax-screen-reader` mode. Source: https://code.claude.com/docs/en/changelog

- **MCP 2026-07-28 spec ships**: Anthropic's new MCP revision introduces a stateless core, standardized extensions, and hardened OAuth authentication. The Anthropic blog post describes how Claude's tighter MCP-auth integration will reduce credential friction for end users connecting to private services. Source: https://claude.com/blog/bringing-mcp-2026-07-28-to-claude

- **Auto mode expands to Bedrock, Vertex AI, and Foundry (v2.1.207, July 11)**: Previously behind an opt-in flag, Auto mode is now the default on all three cloud provider surfaces. Mid-conversation tool changes also entered beta on Claude Fable 5, Opus 4.8, and Opus 5 (platform, July 24), letting API callers add or remove tools between turns while preserving the prompt cache. Source: https://platform.claude.com/docs/en/release-notes/overview

- **Screen reader mode generally available (v2.1.208, July 14)**: Pass `--ax-screen-reader` or set `CLAUDE_AX_SCREEN_READER=1` to enable a mode that reformats output and announces changes for screen-reader users. Source: https://code.claude.com/docs/en/changelog

- **MCP tool calls over 2 minutes auto-background (v2.1.212, July 17)**: Long-running MCP calls no longer stall the interactive session — they move to a background agent automatically. A per-session WebSearch cap (default 200 searches) and a subagent spawn cap (default 200 subagents) were also introduced in this release. Source: https://code.claude.com/docs/en/changelog

## Bug Fixes & Performance

- **Windows path corruption fixed (v2.1.218)**: Paths containing `\u` sequences were being mangled into CJK characters on Windows — now corrected. Source: https://code.claude.com/docs/en/changelog

- **MCP memory leak patched (v2.1.217, July 21)**: Truncated MCP tool outputs were leaking memory in long sessions; the fix applies to all MCP-connected servers. Source: https://code.claude.com/docs/en/changelog

- **Quadratic-cost message normalization eliminated (v2.1.216, July 20)**: Message normalization in very long sessions was scaling quadratically with conversation length, causing slowdowns. The fix brings it to linear. Source: https://code.claude.com/docs/en/changelog

- **PowerShell security bypass closed (v2.1.214, July 18)**: A permission-check bypass in Windows PowerShell 5.1 was patched alongside other Bash permission fixes (file-descriptor redirects, `zsh` subscript/modifier misjudgements) and auto-approval of `help`/`man` commands being blocked. Source: https://code.claude.com/docs/en/changelog

- **v2.1.220 general stability (July 25)**: The latest release is a housekeeping drop — bug fixes and reliability improvements across the board. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Claude Agent SDK monthly credits introduced (June 15)**: Claude subscription plans now include a separate monthly Agent SDK credit — $20 for Pro, $100 for Max 5x, $200 for Max 20x. The SDK (previously called the Claude Code SDK) wraps the same agent loop as Claude Code in Python and TypeScript. Source: https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan

- **`agent-memory-2026-07-22` header standardized**: All official SDKs (Python, TypeScript, Go, Java, Ruby, PHP, C#, CLI) now send the new memory store header by default, replacing `managed-agents-2026-04-01`. Developers passing beta headers explicitly should swap the old value. Source: https://platform.claude.com/docs/en/release-notes/overview

- **Claude API skill bundled in Claude Code**: The open-source `claude-api` skill — covering Messages API, Managed Agents, tool use, caching, streaming, and more across 8 languages — is now bundled directly in Claude Code and available in the Anthropic skills repository. Source: https://platform.claude.com/docs/en/release-notes/overview

## Roadmap & Announcements

- **Legacy Workbench retires August 17, 2026**: The original `platform.claude.com/workbench` (with saved prompts, variables, and evals) is being shut down, along with the experimental prompt-generation APIs (`/v1/experimental/generate_prompt`, `improve_prompt`, `templatize_prompt`). Operators should export data before the deadline. Source: https://platform.claude.com/docs/en/release-notes/overview

- **Claude Sonnet 5 pricing reverts September 1**: The introductory rate of $2/$10 per MTok ends August 31, 2026. Standard pricing of $3/$15 per MTok takes effect the following day. Source: https://platform.claude.com/docs/en/release-notes/overview

- **Claude Opus 4.1 retires August 5**: Deprecated on June 5, the `claude-opus-4-1-20250805` model reaches end-of-life on August 5, 2026 — two days from now. Migrate to Claude Opus 4.8. Source: https://platform.claude.com/docs/en/release-notes/overview

- **Fable 5 access model finalized**: Max and Team Premium subscribers retain Claude Fable 5 at up to 50% of weekly usage. Pro and Team Standard users move to metered usage credits for Fable 5 access. Source: https://www.explainx.ai/blog/claude-usage-limits-2026-timeline-explained

## Key Takeaway
The single most actionable development today is the **Claude Opus 4.1 retirement on August 5** — any production code still calling `claude-opus-4-1-20250805` will start returning errors in 48 hours, making an immediate migration to Claude Opus 4.8 critical for affected teams.

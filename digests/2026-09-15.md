# Claude Code News Digest — 2026-09-15

## Overview
September 15 sees Claude Code ship v2.1.272 as the latest in a rapid release cadence that has delivered multiple significant updates this week. The standout themes are fast-mode remote sessions, plugin eval infrastructure, expanded VS Code tooling, and a permanent (but reduced) usage-limit adjustment that replaces the temporary 50% boost.

## New Features & Releases

- **v2.1.272 — Bug fixes (September 15)**: Incremental reliability release with stability fixes. This is the current latest as of today. Source: https://code.claude.com/docs/en/changelog

- **v2.1.271 — Fast mode in Remote sessions & mouse support (September 14)**: Remote cloud and self-hosted runner sessions can now enable fast mode via `/fast`; the `/config` panel gains full mouse support (scroll, click, highlight). Also added: per-command `allowed_domains` for Bash/PowerShell/Monitor sandboxing, `omitClaudeMd` frontmatter for subagents, `modelPricing` multiplier (up to 10×) for internal chargeback, Markdown artifact rendering as styled pages, artifact watching now supports up to 10 published artifacts (up from 5), and Monitor watches now always have a deadline (max 30 minutes). Source: https://code.claude.com/docs/en/changelog

- **v2.1.269 — `claude plugin eval` & `/output-style` (September 11)**: Introduced `claude plugin eval` to run a plugin's eval suite against Claude Code and produce scored, reproducible JSON + HTML reports. Added `/output-style` to list and switch output styles across all session types. Also added Bash file-edit diffs, OpenTelemetry `OTEL_METRICS_INCLUDE_REPOSITORY` attribute, and dynamic workflow sizing defaults now lowered to "small" on Pro plans. Source: https://code.claude.com/docs/en/changelog

- **v2.1.268 — Gateway pricing & artifact tab icons (September 10)**: Added `pricing:` field in `gateway.yaml` for managed rate matching, a `--remove-session-state` flag for session cleanup, `--json` output for plugin install/update, and browser tab icons chosen by Claude for every published artifact. Source: https://code.claude.com/docs/en/changelog

- **v2.1.267 — `maxEffortLevel` & fresh system prompts (September 9)**: New `maxEffortLevel` setting caps effort level across Bedrock, Vertex, and Foundry. Added `--system-prompt-snapshot off` to render system prompts fresh on every request rather than caching. Source: https://code.claude.com/docs/en/changelog

- **Claude Fable 5.1 as new default Fable model**: Fable 5.1 (`claude-fable-5-1`) became the default Fable model in early September, offering 1M context at $10/$50 per Mtok with $0.25/Mtok cache reads. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **VS Code agent map and Hooks/Permission dialogs (v2.1.269)**: The VS Code extension gained an agent map showing sub-agent cards with read-only transcripts, a new Hooks dialog for viewing/adding/editing hooks, a Permission rules dialog, live progress rows for running subagents in Focus view, and broad accessibility and screen-reader improvements. Source: https://code.claude.com/docs/en/changelog

- **Unity first-party Claude Code plugin (September 10)**: Unity shipped an official first-party plugin distributed through Claude's plugin directory, bundling 29 native Unity skills, making it a turnkey integration for game developers. Source: https://www.explainx.ai/blog/claude-code-unity-mcp-guide-2026

- **Plugin directory support (v2.1.265)**: `--plugin-dir` can now point to a folder containing multiple plugins; each child folder is loaded automatically, simplifying multi-plugin deployments. Source: https://code.claude.com/docs/en/changelog

- **MCP managed servers & HTTP+SSE fallback fixes**: Claude Code now properly manages MCP servers centrally via `managed-mcp.json` and fixed HTTP MCP servers that only speak legacy HTTP+SSE to connect correctly via SSE fallback as the MCP spec requires. Source: https://code.claude.com/docs/en/changelog

- **Community-built Visual Studio 2026 extension**: An unofficial extension (`firish/claude_code_vs`) brings native diff with accept/reject, a live debugger Claude can drive autonomously, Roslyn code navigation, and Test Explorer integration to Visual Studio 2026. Source: https://github.com/firish/claude_code_vs

## Bug Fixes & Performance

- **v2.1.270 — Git permission regression fixed (September 12)**: Read-only git commands in Bash were unexpectedly asking for permission due to a regression introduced in 2.1.269; this patch restores correct behavior. Source: https://code.claude.com/docs/en/changelog

- **v2.1.271 — Bash permission checker hardening**: Fixed multiple bypass vectors: files following unrecognized options, wildcards in command patterns/option values, shell variable declaration flags, and `cd`+`git` chains were all silently skipping permission prompts. Terminal rendering of large diffs and long transcripts is also now significantly faster. Source: https://code.claude.com/docs/en/changelog

- **v2.1.268 — WebFetch hang fixed**: WebFetch could hang indefinitely; it now fails after 300 seconds by default (configurable via `CLAUDE_CODE_WEBFETCH_DEADLINE_MS`). Also fixed high CPU in idle sessions and MCP OAuth "No available ports" error. Source: https://code.claude.com/docs/en/changelog

- **v2.1.266 — Critical CLAUDE_CODE_USE_GATEWAY regression reverted (September 8)**: Version 2.1.265 accidentally made `CLAUDE_CODE_USE_GATEWAY` force Cloud-gateway sign-in by itself, breaking API key and custom auth configurations. This was reverted the same day. Source: https://code.claude.com/docs/en/changelog

- **v2.1.267 — VS Code extension host CPU fix**: Fixed extension host hanging at 100% CPU on fork/edit/rewind operations in VS Code. Source: https://code.claude.com/docs/en/changelog

Source: https://explainx.ai/blog/anthropic-claude-code-limits-17-percent-cut-september-2026-august-2026

- **Claude Fable 5.1 and Mythos 5.1 (September 1)**: Anthropic launched Claude Fable 5.1 and Claude Mythos 5.1 — described as identical models with different safeguard levels — targeting coding, knowledge work, and scientific research. Fable 5.1 is now the default Fable model in Claude Code. Source: https://releasebot.io/updates/anthropic/claude

## Key Takeaway
The most significant development today is the v2.1.271 release (landed September 14), which brings fast mode to Remote/cloud sessions and closes several critical Bash permission-checker bypass vulnerabilities — hardening Claude Code's security posture while also improving its performance and usability in enterprise remote-execution environments.

# Claude Code News Digest — 2026-07-19

## Overview
This week's headline is **Artifacts calling MCP connectors** — published pages can now pull live data and take actions through each viewer's own connectors, turning static snapshots into interactive dashboards. Alongside that, Claude Code added **screen reader mode** for accessibility and a raft of safety and workflow improvements in versions v2.1.207–v2.1.212 (Week 29, July 13–17). Today also marks the final day of the 50% higher weekly limits promotion for Pro/Max/Team/Enterprise users, which expires at 11:59 pm PT.

---

## New Features & Releases

- **Artifacts Call MCP Connectors (v2.1.207–v2.1.212)**: Published Claude Code artifacts can now call each viewer's MCP connectors at page-load time, so a dashboard shows live data and can take actions on demand rather than displaying a snapshot frozen at build time. Each viewer must approve access before the first connector call, and this release also adds public sharing links, editor roles for Team and Enterprise plans, and artifacts created from Claude Tag sessions. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **Screen Reader Mode**: A new accessibility feature replaces the visual terminal interface (boxes, spinners, in-place redraws) with plain, linear text that VoiceOver, NVDA, and similar screen readers can traverse in order. Enable with `claude --ax-screen-reader`, the `CLAUDE_AX_SCREEN_READER` environment variable, or the `axScreenReader` setting. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **In-App Browser on Desktop (Week 28, July 6–10)**: Claude Code on desktop gained a built-in sandboxed browser, letting Claude pull up docs, designs, or any external site and interact with pages the same way it does with local dev server previews. Safety classifiers review actions on external sites, and users can choose whether browsing sessions persist. Source: https://code.claude.com/docs/en/whats-new/2026-w28

- **Weekly Limits Promotion Ends Today**: The 50% higher weekly usage limits for Pro, Max, Team, and eligible Enterprise users — running since May — expire tonight at 11:59 pm PT (July 19, 2026). Starting July 20, Fable 5 usage moves to prepaid credits at $10/M input tokens and $50/M output tokens. Source: https://www.helpnetsecurity.com/2026/07/13/claude-code-weekly-limits-promotion-extended/

## Integrations & Extensions

- **Auto Mode GA on Third-Party Cloud Platforms**: Auto mode no longer requires the `CLAUDE_CODE_ENABLE_AUTO_MODE` environment variable opt-in on Amazon Bedrock, Google Cloud's Agent Platform, and Microsoft Foundry. Administrators can disable it with `disableAutoMode`. Bedrock, Agent Platform, and Claude Platform on AWS also now default to Claude Opus 4.8. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **MCP Long-Running Tool Auto-Background**: MCP tool calls running longer than two minutes now automatically move to the background so the main session stays responsive. The threshold is tunable via `CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS`. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **Enterprise-Managed MCP Connectors (Okta)**: Anthropic added enterprise-managed MCP connector access starting with Okta, so administrators can provision connectors once and users get zero-touch access on first login across Claude chat, Claude Code, and Cowork. Source: https://releasebot.io/updates/anthropic

- **Corporate Launcher Support**: The new `CLAUDE_CODE_PROCESS_WRAPPER` environment variable (or `processWrapper` setting) routes all subprocesses Claude Code starts — background service, agent view sessions — through a required corporate wrapper executable. Source: https://code.claude.com/docs/en/whats-new/2026-w29

## Bug Fixes & Performance

- **Session-Wide Runaway Loop Caps**: New per-session limits cap WebSearch tool calls (default 200, tunable via `CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION`) and subagent spawns (default 200, tunable via `CLAUDE_CODE_MAX_SUBAGENTS_PER_SESSION`) to prevent runaway delegation or search loops. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **Auto Mode Transcript Protections (Week 28)**: Auto mode now blocks tampering with session transcript files and asks for confirmation before running `rm -rf` on a variable it cannot resolve from context — closing a prompt-injection vector. Source: https://code.claude.com/docs/en/whats-new/2026-w28

- **Auto-Update Memory Reduction (Week 28)**: Auto-update binary downloads now stream to disk instead of buffering in memory, cutting the updater's peak memory usage by roughly 400 MB. Source: https://code.claude.com/docs/en/whats-new/2026-w28

- **"Always Allow" Rules Persist Across Worktrees**: Permission rules granted as "always allow" now save at the repository root, so approvals granted inside a git worktree persist across sessions and all worktrees in the project. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **Live Elapsed-Time Counter for Tool Calls**: The collapsed tool summary line now shows a live tick counter for long-running tool calls, so users can see progress instead of an apparently frozen interface. Source: https://code.claude.com/docs/en/whats-new/2026-w29

## Community & Ecosystem

- **Claude Cowork Expands to Mobile and Web**: Anthropic launched a broader rollout of Cowork across mobile and web, letting sessions and files follow users across devices, with background work, scheduled tasks, shared projects, and mobile approvals. Beta access started with Max users with doubled usage limits running through August 5. Source: https://www.nbcnews.com/tech/tech-news/anthropic-will-make-claude-cowork-available-users-cloud-rcna353218

- **Claude Code & Cowork in Government Desktop (Public Beta)**: Anthropic launched a public beta of Claude Code and Claude Cowork inside Claude for Government Desktop, bringing FedRAMP High authorized AI coding assistance to public-sector teams. Source: https://releasebot.io/updates/anthropic

- **Agent SDK Billing Decoupled from Plan Limits**: Since June 15, 2026, Claude Agent SDK and `claude -p` usage no longer counts toward a Claude plan's interactive usage limits; interactive limits are now reserved exclusively for Claude Code, Cowork, and Claude.ai. The latest Python SDK (v released July 15) is on PyPI. Source: https://code.claude.com/docs/en/agent-sdk/overview

## Roadmap & Announcements

- **`/fork` Redesigned as True Background Sessions**: `/fork` now copies the current conversation into a fully independent background session (with its own row in `claude agents`) while the user keeps working. The previous in-session forked subagent behavior is now `/subtask`. This signals a broader push toward parallel, multi-session workflows as a first-class primitive. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **`/doctor` Becomes a Full Setup Healer (Week 28)**: `/doctor` (alias `/checkup`) moved from a read-only report to an interactive fixer — it checks installation health, finds unused skills/MCP servers/plugins relative to their context cost, deduplicates CLAUDE.md files, proposes trimming derivable content, and flags slow hooks, all with confirmation before any change. Source: https://code.claude.com/docs/en/whats-new/2026-w28

- **Admin Console Usage Insights**: Claude Code's admin console gained two new tabs — Value and Usage — showing active developers, session counts, and top commands across the organization, updated daily. Source: https://releasebot.io/updates/anthropic

---

## Key Takeaway
The standout development this week is **live MCP connectors in published artifacts** — it transforms Claude Code's artifact output from static deliverables into dynamic, always-fresh dashboards, representing a significant step toward Claude Code as a platform for building live internal tools, not just generating one-off code or documents.

# Claude Code News Digest — 2026-11-18

## Overview
This week Anthropic shipped four Claude Code releases (v2.1.323–v2.1.327), with the headline addition being the experimental **Code Mode** that lets Claude write JavaScript to call its own tools. Security dominated the ecosystem news: a zstd decoding vulnerability was patched, default sandbox permissions were tightened, and external researchers disclosed that Claude Code's approval file had exposed thousands of credentials in public GitHub repos.

## New Features & Releases

- **Code Mode (v2.1.323, Nov 12)**: An experimental opt-in mode in which Claude writes JavaScript to call its tools rather than using text-based tool calls. Enabled per session; subsequent release v2.1.326 extended Code Mode support to agent teams running in parallel. Source: https://code.claude.com/docs/en/changelog

- **`/status` command (v2.1.327, Nov 17)**: A new `/status` command surfaces broken agent, skill, command, and output-style files, keybinding errors, unavailable sandbox, ignored permission settings, and hook matchers that never match — a single health check for the whole Claude Code configuration. Source: https://code.claude.com/docs/en/changelog

- **`claude mcp add-json` stdin support (v2.1.327, Nov 17)**: MCP server JSON can now be piped in from stdin (`claude mcp add-json <name> -`), keeping tokens and secrets off the command line. Source: https://code.claude.com/docs/en/changelog

- **Claude Fable 5.2 as default Fable model (v2.1.321, Nov 9)**: Anthropic promoted Claude Fable 5.2 (1M-token context window, $8/$40 per million tokens input/output) to the default Fable model inside Claude Code. Source: https://releasebot.io/updates/anthropic/claude-code

- **Projects beta with proactive coordinator**: Anthropic rolled out a public beta update for Claude Code Projects on Pro and Max plans, featuring a proactive coordinator that manages parallel AI coding threads. Source: https://x.com/i/trending/2121481316554203453

## Integrations & Extensions

- **VS Code prompt suggestions (v2.1.325, Nov 13)**: The VS Code extension now surfaces prompt suggestions with Tab-to-accept completion, bringing IDE-style autocomplete to the Claude Code chat panel. Can be disabled with `promptSuggestionEnabled: false` in `settings.json`. Source: https://code.claude.com/docs/en/changelog

- **VS Code "Add to Chat" in Explorer (v2.1.327, Nov 17)**: A new right-click menu entry in the VS Code file Explorer lets users `@`-mention selected files and folders directly into the Claude Code chat, without leaving the file tree. Source: https://code.claude.com/docs/en/changelog

- **VS Code Console sign-in without API key (v2.1.325)**: A new sign-in flow in the VS Code extension allows authentication via Anthropic Console without creating or storing an API key. Source: https://code.claude.com/docs/en/changelog

- **VirusTotal integration (Nov 17)**: VirusTotal now offers MCP connections for Claude, Claude Desktop, and Claude Code, bringing file reputation checks and infrastructure investigations into conversational workflows without leaving the terminal. Source: https://gbhackers.com/virustotal-integrates-with-claude-ai-and-claude-code

## Bug Fixes & Performance

- **zstd security fix (v2.1.325, Nov 13)**: A security vulnerability in how zstd-compressed API responses were decoded was patched. Users on earlier versions should upgrade immediately. Source: https://code.claude.com/docs/en/changelog

- **Bash permission bypass fixes (v2.1.325)**: Two Bash permission gaps were closed: compound commands could previously run without being prompted, and an allow rule could match and run a different binary than the one it names. Source: https://code.claude.com/docs/en/changelog

- **MCP race condition fix (v2.1.326)**: Fixed a bug where MCP tool calls could read another call's saved result when two long results arrived in the same millisecond — a subtle correctness issue in concurrent agent workflows. Source: https://code.claude.com/docs/en/changelog

- **`/export` and `/rewind` fixes (v2.1.326)**: Fixed `/export` silently overwriting existing files; fixed `/rewind` incorrectly reporting "No code changes" when shell commands had modified files outside Claude's direct edits. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Credentials exposed in `.claude/settings.local.json`**: Security researchers at Apiiro found that Claude Code's "don't ask again" approval file (`.claude/settings.local.json`) was included in over 1,122 public GitHub repositories, exposing 2,539 credentials including API keys and passwords. Users should add `.claude/settings.local.json` to `.gitignore`. Source: https://thehackernews.com/2026/11/claude-codes-dont-ask-again-file.html

- **Malicious Claude Code extension via Cursor**: Cursor confirmed that attackers, following a credential theft at AI infrastructure provider Fireworks AI, distributed a modified version of Anthropic's Claude Code extension through Cursor's marketplace. The tampered extension attempted to install SSH backdoors. Users who installed or updated the extension between Nov 10–14 should follow Cursor's remediation guidance. Source: https://www.bleepingcomputer.com/news/security/cursor-confirms-security-breach-led-to-malicious-claude-code-extension/

## Roadmap & Announcements

- **Fast mode for Opus 4.8 retiring Nov 30**: Anthropic announced that fast mode for Claude Opus 4.8 will be removed from Claude Code on November 30, 2026. Users relying on fast mode for Opus 4.8 should migrate to Fable 5.2 or Opus 5.5. Source: https://www.gradually.ai/en/changelogs/claude-code/

- **Sandbox filesystem tightening (v2.1.326)**: Sandboxed commands on macOS, Linux, and WSL no longer write to sensitive home folders by default; writes must be explicitly allowed via `sandbox.filesystem.allowWrite`. Claude's file tools also now refuse writes to sign-in files like `.credentials.json`. This is part of a broader hardening of the default permission posture. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
The launch of **Code Mode** (Claude writing JavaScript to orchestrate its own tools) is the most significant architectural addition in weeks — but the security picture demands equal attention: the malicious Cursor extension incident and the widespread `.claude/settings.local.json` credential exposure are both actionable right now for anyone running Claude Code.

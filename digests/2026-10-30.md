# Claude Code News Digest — 2026-10-30

## Overview
October 30, 2026 is a notably active day for Claude Code: the GitHub Action reached v1.0 general availability, and Claude Code itself shipped v2.1.314 with new write-protection controls. Code Review, now generally available on Team and Enterprise plans, is also a headline story this week with a major enterprise credit offer running until January 2027.

## New Features & Releases

- **Claude Code v2.1.314 Released**: The latest build (October 30) introduces a `permissions.blockWritesOutsideWorkingDirectories` setting that causes Write, Edit, and NotebookEdit tools to refuse paths outside the working directories in all permission modes. It also adds idle compaction in the VS Code and Desktop apps, and a "Recently blocked" review in the `/permissions` command for auditing what was stopped. Source: https://code.claude.com/docs/en/changelog

- **`ultrathink` Now Runs at xhigh Effort (v2.1.311)**: As of October 26, the `ultrathink` keyword triggers xhigh reasoning effort on all supported models — Opus 5.5, Sonnet 5.5, Haiku 5.5, and Fable 5.1 — via Anthropic's API. A `--hold-idle-file` flag was also added for self-hosted runner scenarios. Source: https://code.claude.com/docs/en/changelog

- **Fork Subagents On by Default (v2.1.302)**: Since October 16, subagents launched via `-p` and the Agent SDK fork by default, inheriting context while keeping tool output out of the parent's context. A new `CLAUDE_CODE_AUTO_MODE_MODEL` environment variable selects the model used for the client-side auto-mode classifier. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **Claude Code GitHub Action v1.0 Generally Available**: Anthropic's official GitHub Action for Claude Code reached its 1.0 release today (October 30). The release streamlines configuration with automatic mode detection and a single prompt input, enabling automated PR reviews, CI fixes, and security scanning in GitHub workflows. Source: https://freedom.tech/posts/2026-10-30-claude-code-action-github-1-0/

- **Monitor Tool Available on Bedrock, Vertex, and Foundry (v2.1.310)**: Claude Code's Monitor tool and plugin monitors now work in enterprise deployment targets — AWS Bedrock, Google Vertex AI, and Azure Foundry — including setups with telemetry or nonessential traffic disabled. Enterprise custom roles also gained fine-grained permissions for cloud sessions and Remote Control. Source: https://code.claude.com/docs/en/changelog

- **MCP Tasks and Elicitations (Public Beta, v2.1.304)**: Claude Code now supports MCP Tasks and Elicitations in terminal CLI sessions, Agent SDK sessions, and GitHub Actions runs. The server returns a task ID immediately while Claude Code continues working; the tool can also surface questions for the user mid-task. The MCP protocol default was also updated to `2026-07-28` in early October; set `MCP_PROTOCOL_NEGOTIATION=legacy` if an older server breaks. Source: https://www.developersdigest.tech/blog/claude-code-mcp-tasks-elicitations-long-running-tools-2026

- **Trust3 AI Enterprise Security Integration**: Trust3 AI integrated its Agent DOS governance platform with Claude Code, giving enterprise security teams visibility into Claude Code usage and agent activity. Source: https://cyprusshippingnews.com/2026/10/30/trust3-ai-brings-enterprise-agent-security-to-claude-code/

- **Google Adds Claude to Android Studio**: Google added official Claude (and Codex) support to Android Studio, and Android's CLI now officially supports Claude Code plugins. Source: https://root-nation.com/en/news-en/it-news-en/en-google-claude-codex-android-studio/

## Bug Fixes & Performance

- **`rm`/`rmdir` Denied in Bypass Mode (v2.1.309)**: Dangerous `rm` and `rmdir` commands are now outright denied when running in skip-permissions mode, with a rewrite hint provided. A `claude_code.safety_event` OpenTelemetry event was added to record every tool call stopped or prompted by a permission rule, safety check, hook, or sandbox. A bug allowing sandboxed commands to modify the `--mcp-config` file was also fixed. Source: https://code.claude.com/docs/en/changelog

- **CLAUDE.md Overwrite and Freeze Fixes (v2.1.311–312)**: Large CLAUDE.md files are no longer silently overwritten, a CLAUDE.md-induced session freeze was resolved, and a bad API response no longer kills `claude -p`. The `claude -p` "Not logged in" error inside cloud sessions was also fixed in v2.1.306. Source: https://code.claude.com/docs/en/changelog

- **MCP Connection Fixes**: Multiple releases patched MCP reliability issues, including HTTP connections hanging for 30 seconds and `claude mcp add` / `claude mcp remove` incorrectly naming the current folder. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Anthropic Publishes Its Own Code Review Practices**: InfoQ reports that Anthropic's Claude Code team wrote up how they do AI-assisted code review now that Claude writes roughly 90% of the tool's own codebase. The piece sparked discussion on Hacker News about whether developers still need a mental model of the whole codebase. Source: https://infoq.com/news/2026/10/anthropic-code-review

- **Claude Code Mods (Plugins with Deeper Access)**: The mods system — introduced in v2.1.287 — allows plugins to modify Claude's deeper behavior, access session data, and hook into events like `prompt.change`. A built-in "You Should Know" mod flags things the user or Claude might miss. Source: https://tech-insider.org/claude-code-plugins-official-mods-cloud-sessions-2026/

- **Claude Agent SDK v0.3.312 (TypeScript)**: The Agent SDK (formerly Claude Code SDK) continues shipping frequent releases. Notable October additions include an `omitClaudeMd` option for subagents and a reduction in package size from 1.47 MB to 0.97 MB. Claude Max and Team plans now include monthly API credits, applicable to API-key usage through a linked Console organization. Source: https://github.com/anthropics/claude-agent-sdk-python/blob/main/CHANGELOG.md

## Roadmap & Announcements

- **Code Review Now Generally Available**: Anthropic moved Code Review out of research preview on October 15, making it available to all Claude Team and Enterprise organizations. Reviews are now 3× faster (6–10 minutes vs. ~20 in preview), support Quick/Standard/Deep depth settings per repository, and run automatically on new pull requests. Eligible Enterprise organizations can claim at least $10,000 in Code Review credits by January 15, 2027 (credits expire 30 days after claiming). Source: https://claude.com/resources/articles/code-review-is-now-generally-available

- **Enterprise Custom Roles for Cloud Sessions**: As of v2.1.310 (October 23), Enterprise administrators can assign cloud session access and Remote Control permissions by custom role, enabling finer-grained access control for large organizations. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
October 30 marks the general availability of the Claude Code GitHub Action 1.0 and ships v2.1.314 with hardened write-protection controls — together signaling Anthropic's push to make Claude Code safer and more automatable in CI/CD pipelines at enterprise scale.

# Claude Code News Digest — 2026-10-15

## Overview
October 2026 has been one of the most active months for Claude Code development, with nine releases from v2.1.292 to v2.1.300 shipping between October 6 and 14. The headline feature is **Claude Mods** — small TypeScript functions that let developers deeply customize Claude Code's behavior — while the week also brought Claude Haiku 5.5 as the new default small model, major IDE and MCP improvements, and OpenTelemetry observability for production agent deployments.

---

## New Features & Releases

- **v2.1.300 (Oct 14) — Mod prompt hooks, AWS /advisor, gzip, and Slack improvements**: The latest release adds `virtualText` for mod prompt decorations, a new `prompt.change` mod hook, `/advisor` on Claude Platform on AWS, OpenTelemetry GenAI semantic-convention attributes on trace spans, and a `claudeCode.attachSelection` VS Code setting. Gzip compression is now on by default for large `api.anthropic.com` requests. Ships with ~59 bug fixes. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.299 (Oct 14) — Idle compaction and stricter MCP rules**: Introduces idle compaction for conversations over 200K tokens (triggers after ~54 min of idle time), `CLAUDE_CODE_DISABLE_FILE_MENTIONS`, and richer `Text`/`Box` UI options for mods. MCP allow rules are now stricter — `mcp__<server>__*` must match the whole server name. `UserPromptSubmit` hooks now run before skill expansion. Includes ~131 bug fixes spanning mods, sandboxing, MCP, cloud sessions, and VS Code. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.296 (Oct 9) — Workflow model pinning and subagent auto-compact**: Adds `CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL` to pin all workflow subagents to one chosen model, `autoCompactWindow` for subagents, and an `allow_large` option for the Read tool. Sonnet 5.5 cache-read pricing drops from $0.20 to $0.10 per million tokens. MCP tool description/instruction limit raised from 2,048 to 4,096 characters. ~56 bug fixes. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.293 (Oct 7) — Claude Haiku 5.5 becomes the default small model**: Haiku 5.5 (`claude-haiku-5-5`) is now the default Haiku model on the Anthropic API, offering a 1M-token context window at $0.10/$0.50 per million tokens (with a surcharge above 100K prompt tokens). Anthropic describes it as "the cheapest, fastest, and most capable small model we've ever released." Includes 38 bug fixes. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog) · [claude.com/blog](https://claude.com/blog)

- **v2.1.292 (Oct 6) — Marketplace plugin installs and Agent effort parameter**: Adds `--marketplace <source>` to `claude plugin install`, an `effort` parameter for the Agent tool, `prompt.autocomplete` for mods, prompt caching in `$.model.complete`, and workflow agents in the `agent.spawn` hook. Scheduled routines can now publish private artifacts without prompting. ~64 bug fixes. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Claude Mods (Oct 1, v2.1.287)**: Anthropic launched Claude Mods — small TypeScript functions that ship inside plugins and can rewrite prompts, add new UI panels, replace built-in features, or add entirely new functionality to Claude Code. On Team and Enterprise plans (and machines with managed settings), a built-in `sec-default` mod loads first. Source: [releasebot.io/updates/anthropic/claude-code](https://releasebot.io/updates/anthropic/claude-code)

## Integrations & Extensions

- **OpenTelemetry observability for Claude Managed Agents (Oct 14)**: Anthropic announced full OpenTelemetry tracing support for Claude Managed Agents, the Messages API, and Claude SDKs, including GenAI semantic-convention attributes on trace spans. This gives engineering teams production-grade visibility into agent behavior. Source: [claude.com/blog](https://claude.com/blog)

- **MCP protocol 2026-07-28 now default (v2.1.295, Oct 8)**: The updated MCP protocol is now negotiated by default for all connections (opt out with `MCP_PROTOCOL_NEGOTIATION=legacy`). MCP tool description limits rose to 16,384 characters when loaded via tool search (up from 2,048) and to 4,096 in standard use (v2.1.296). Remote MCP server disconnection bugs in headless/SDK sessions were also fixed. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog) · [code.claude.com/docs/en/mcp](https://code.claude.com/docs/en/mcp)

- **Slack Connect and private approval cards for Claude Tag (v2.1.300)**: Claude Tag (Claude in Slack) gains support for Slack Connect channels and private approval cards, broadening its reach in enterprise deployments. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **VS Code extension (claudeCode.attachSelection, v2.1.300)**: A new `claudeCode.attachSelection` setting lets users control whether selected editor text is automatically sent to Claude Code. A fix in v2.1.296 also prevents `/code-review` from showing raw JSON in IDE integrations. Community-built, unofficial extensions are also now available for Visual Studio 2026 and Eclipse IDE. Source: [code.claude.com/docs/en/vs-code](https://code.claude.com/docs/en/vs-code) · [github.com/firish/claude_code_vs](https://github.com/firish/claude_code_vs)

- **Google Workspace integration (Oct 6)**: Anthropic launched an add-on and beta connectors so Google Workspace teams can use Claude directly within Google Docs, Sheets, and Slides. Source: [claude.com/blog](https://claude.com/blog)

- **Dynamic workflows beta in Claude Managed Agents (Oct 9)**: Anthropic opened a beta for dynamic multi-phase workflows in Claude Managed Agents, enabling agents to write and run background pipeline jobs for complex long-running tasks. Source: [releasebot.io/updates/anthropic/claude-developer-platform](https://releasebot.io/updates/anthropic/claude-developer-platform)

## Bug Fixes & Performance

- **300+ bug fixes across v2.1.292–2.1.300**: The nine releases shipped between October 6 and 14 collectively contain over 300 confirmed bug fixes covering mods, MCP, cloud sessions, VS Code, sandboxing, worktrees, reftables, and subagent lifecycle. The largest single release (v2.1.299) fixed 131 issues. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Sonnet 5.5 cache-read price cut (v2.1.296, Oct 9)**: Sonnet 5.5 cache-read pricing dropped 50% from $0.20 to $0.10 per million tokens, making large multi-turn sessions and agentic loops meaningfully cheaper. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Gzip compression for large API requests (v2.1.300, Oct 14)**: Gzip is now enabled by default for large requests to `api.anthropic.com`, reducing payload sizes in high-throughput and agentic workloads. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Hook reliability improvements (v2.1.294–295, Oct 8)**: `prompt` and `agent` hooks written as natural-language instructions now correctly enforce what they should block. Judgment on Stop/SubagentStop hooks was also improved, so Claude is less likely to terminate prematurely. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

## Key Takeaway
The launch of **Claude Mods** — TypeScript plugins that can fundamentally reshape Claude Code's behavior — is the most architecturally significant development of the month, representing Anthropic's bet that developer customization and a plugin ecosystem are the path to enterprise adoption. Combined with nine production releases in nine days and a 50% price cut on Sonnet 5.5 cache reads, October 2026 marks Claude Code's most active development sprint to date.

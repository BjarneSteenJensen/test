# Claude Code News Digest — 2026-11-02

## Overview
The week ending November 1, 2026 was one of Claude Code's busiest release weeks of the year, shipping eight versions (v2.1.309–v2.1.316) across nine days and touching everything from security hardening to enterprise gateway policies. The biggest headline is the deprecation of fast mode for Opus 4.8, giving users until November 30 to migrate to Opus 5.5. Meanwhile, developers are reporting an undocumented server-side behavior change that causes Claude Code to refuse work on recreating existing games — Anthropic has not yet commented publicly.

## New Features & Releases
- **v2.1.316 (Oct 31): CLAUDE_CODE_DISABLE_ULTRATHINK & CLAUDE_CODE_SUBAGENT_EFFORT**: The latest release adds two new environment variables giving operators fine-grained control over Claude Code's reasoning mode. `CLAUDE_CODE_DISABLE_ULTRATHINK` blocks use of the `ultrathink` keyword entirely, while `CLAUDE_CODE_SUBAGENT_EFFORT` sets a global default effort level for all spawned subagents. Also added: `managed.policy_mode: layered` for the Claude apps gateway, so every matching policy merges in order rather than the first match winning. Source: https://code.claude.com/docs/en/changelog

- **v2.1.316: Opus 4.8 Fast Mode Deprecated**: Fast mode for the Opus 4.8 model is deprecated as of October 30, 2026 and will be permanently removed on **November 30, 2026**. After that date, fast-mode requests on Opus 4.8 will return an error instead of silently falling back. Anthropic's recommended migration path is Opus 5.5, which supports the same speed improvements. Source: https://github.com/anthropics/claude-code/releases

- **v2.1.311 (Oct 26): ultrathink at xhigh Effort on 5.5 Models**: The `ultrathink` keyword in the terminal now triggers xhigh-effort reasoning on Opus 5.5, Sonnet 5.5, Haiku 5.5, and Fable 5.1 through Anthropic's API. This version also fixed startup freezes triggered by very long CLAUDE.md list items, and ensured Claude sees current MEMORY.md and CLAUDE.md content immediately after automatic compaction. Source: https://code.claude.com/docs/en/changelog

- **v2.1.302 (Oct 16): Fork Subagents On by Default**: Fork subagents (the `subagent_type: "fork"` path) are now enabled by default in `claude -p`, the Agent SDK, and Claude Desktop. This expands the capability that was previously opt-in, making parallelized context-inheriting subagents available without any configuration change. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions
- **v2.1.314 (Oct 30): Idle Compaction in VS Code & Claude Desktop**: Long conversations over 200K tokens that are left idle in the VS Code extension and the Claude Desktop Code tab now automatically get summarized. The summary is substituted on the next message when the prompt cache has expired, keeping context live without requiring the user to trigger compaction manually. Source: https://code.claude.com/docs/en/changelog

- **v2.1.310 (Oct 23): Monitor Tool on Bedrock, Vertex & Foundry**: The Monitor tool and plugin monitors are now available when Claude Code is running through AWS Bedrock, Google Vertex AI, and Foundry. Previously this capability was limited to the direct Anthropic API. This version also added Claude Code cloud sessions and Remote Control permissions to Enterprise custom roles. Source: https://github.com/anthropics/claude-code/releases

- **OpenCode Plugin Brings Claude Code to CLI**: Developer Khalil Gharbaoui released an open-source plugin on October 31 that runs Claude Code directly inside Anthropic's official CLI interface, adding Claude Code's capabilities as a fully integrated command. This is a community contribution, not an official Anthropic release. Source: https://emergent.sh/news/opencode-plugin-brings-claude-code-official

## Bug Fixes & Performance
- **v2.1.309 (Oct 22): sed -i Now Standard; ultrareview Workspace Trust**: `sed -i` is now treated as a standard Bash command and is no longer rolled back by `/rewind`, aligning its behavior with other file-editing shell commands. Additionally, `claude ultrareview` now requires workspace trust — unattended scripts must pass `--trust-workspace` or set `CLAUDE_CODE_DISABLE_ULTRAREVIEW_TRUST_CHECK=1`. Several sandbox, permission-check, and hook bugs were also fixed, including PowerShell hooks not blocking on exit code 2. Source: https://code.claude.com/docs/en/changelog

- **v2.1.306 (Oct 21): Cloud Session & MCP Tool Fixes**: Two targeted fixes: `claude -p` in cloud sessions no longer reports "Not logged in" when started without the session's environment variables injected, and API errors are no longer incorrectly replaced with "prompt is too long" in sessions with a large number of MCP tools loaded. Source: https://code.claude.com/docs/en/changelog

- **v2.1.314: blockWritesOutsideWorkingDirectories Security Setting**: A new `permissions.blockWritesOutsideWorkingDirectories` configuration flag makes Write, Edit, and NotebookEdit refuse any path outside the project's working directories in every permission mode. This is an opt-in hardening measure for security-sensitive environments. Source: https://github.com/anthropics/claude-code/releases

## Community & Ecosystem
- **Developers Report Undocumented Game-Recreation Refusals**: Since approximately October 27, developers have reported that Claude Code refuses to help recreate existing games — including commercially commissioned projects. The refusals appear to be server-side with no user-configurable setting to override them, and Anthropic's official changelog contains no mention of the change. Several workarounds have circulated but Anthropic has not made a public statement. Source: https://thenextweb.com/news/claude-code-game-recreation-refusals-developers

- **Claude Design Closing December 14, 2026**: Standalone Claude Design (claude.ai/design) will be shut down by December 14, 2026, per a notice surfaced through the `/design-sync` and `/design-login` commands in recent Claude Code releases. Users should migrate design workflows before that date. Source: https://code.claude.com/docs/en/changelog

## Roadmap & Announcements
- **Anthropic Usage Policy Update — Effective November 12**: Anthropic's updated usage policy takes effect November 12, 2026. For Claude Code users, the most relevant change is the new ban on "sustained and needless abusive or cruel behavior toward AI models." Ordinary frustration and dark creative themes are explicitly excluded. Claude already has the ability to end rare conversations with persistently abusive users on Claude.ai and Claude Code, and that mechanism remains in place under the new policy. Source: https://www.anthropic.com/news/2026-usage-policy-update

- **Anthropic IPO Planned for November 2026**: According to multiple secondary sources, Anthropic is planning an initial public offering in November 2026. This would be a major company milestone and could affect product investment velocity, though no Claude Code–specific announcements have been tied to the IPO timeline. Source: https://en.wikipedia.org/wiki/Anthropic

## Key Takeaway
The November 30, 2026 removal of fast mode for Opus 4.8 is the most immediately actionable item: any Claude Code setup — scripts, CI pipelines, gateway configs — that still targets Opus 4.8 fast mode will start erroring in under 30 days and should be migrated to Opus 5.5 now.

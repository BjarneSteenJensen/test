# Claude Code News Digest — 2026-11-16

## Overview
The week of November 16, 2026 was busy for Claude Code: the tool shipped five releases (v2.1.319–2.1.325) packed with new features, security hardening, and MCP improvements. The headline addition is Code Mode, an experimental opt-in in which Claude writes JavaScript to call its tools — a fundamental shift in how the agent executes actions. A serious security finding also surfaced: Claude Code's local settings file is leaking credentials in thousands of public GitHub repositories.

---

## New Features & Releases

- **Code Mode (v2.1.323, Nov 12)**: Claude Code added an experimental opt-in mode where Claude writes JavaScript to orchestrate its tool calls rather than dispatching them one at a time. The feature is off by default; organizations can block it with `CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=0`. The same release raised the default context window for unrecognized model IDs from 200 K to 1 M tokens and added `.docx` support to Artifact tool uploads. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Prompt Suggestions in VS Code (v2.1.325, Nov 13)**: Tab now accepts inline prompt suggestions in VS Code and similar terminals. The release also adds a Console sign-in flow inside VS Code that creates no API key. Sandboxed Bash commands now follow the normal permission flow by default; set `sandbox.autoAllowBashIfSandboxed: true` to restore the old silent behavior. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Claude Fable 5.2 as Default Fable Model (v2.1.321, Nov 9)**: Fable 5.2 (`claude-fable-5-2`) became the default Fable model, bringing 1 M-token context and $8/$40 per MTok pricing ($0.20/MTok cache reads). Previously saved Fable 5.1 model picks migrate to `fable`; switch back with `/model claude-fable-5-1`. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Fast Mode on Vertex AI (v2.1.322, Nov 10)**: Fast mode is now available on Vertex AI in the global, US, and EU regions, with automatic fallback to standard speed if Vertex refuses it. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

## Integrations & Extensions

- **MCP Tasks in the Terminal (v2.1.319, Nov 6)**: When an MCP server runs a tool call as a task, Claude Code now moves it to the background immediately and reports the result when it finishes — keeping the terminal unblocked. Set `CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND=1` to wait inline, or `CLAUDE_CODE_DISABLE_MCP_TASKS=1` to turn tasks off entirely. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Plugin MCP Bundle Support (v2.1.325, Nov 13)**: Plugin MCP bundles in `.mcpb` and `.dxt` formats now unpack under the plugins directory, enabling read-only plugin folders to load correctly. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Mods' Tool Calls Exempt from Permission Prompts (v2.1.321, Nov 9)**: Tool calls made by mods no longer raise permission prompts. Deny rules and organization policy still apply, so mods cannot exceed what the organization allows. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

## Bug Fixes & Performance

- **v2.1.325: 88 Bug Fixes, Security & Permission Hardening**: The November 13 release ships 14 improvements and 88 bug fixes, including a zstd decoding security fix and stricter default permission prompts for sandboxed commands. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.323: 195 Bug Fixes, Auto Mode Restricted for Mods**: The November 12 release ships 21 improvements and 195 bug fixes. Auto mode is now more restrictive with mods, and `/security-review` asks for confirmation before running. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **applyFlagSettings() Error Now Surfaced (Agent SDK)**: A bug where one invalid value in `applyFlagSettings()` silently discarded all earlier settings is now fixed — it returns an error instead of failing quietly. Source: [releasebot.io/updates/anthropic/claude-code](https://releasebot.io/updates/anthropic/claude-code)

- **Deprecation: Opus 4.8 Fast Mode Removed Nov 30**: Fast mode for `claude-opus-4-8` was deprecated October 30 and will be removed on November 30, 2026. After removal, fast-mode requests on Opus 4.8 will return an error with no fallback. Migrate to Opus 5.5. Source: [www.gradually.ai/en/changelogs/claude-code/](https://www.gradually.ai/en/changelogs/claude-code/)

## Community & Ecosystem

- **Security Report: `.claude/settings.local.json` Exposing Secrets in 1,122 Public Repos**: A researcher found that Claude Code's approval file — which records "don't ask again" permissions — has been committed to over 1,100 public GitHub repositories, potentially exposing API keys and passwords. The file is not in Claude Code's default `.gitignore`. Users should add `.claude/settings.local.json` to their `.gitignore` and audit any existing public repos. Source: [thehackernews.com](https://thehackernews.com/2026/11/claude-codes-dont-ask-again-file.html)

- **Privacy Check Before Email Leakage (v2.1.323)**: A new check in v2.1.323 asks before a web or shell tool call sends the user's account email address over the network. This addresses a separate report that Claude Code was including user emails in HTTP headers. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Game-Cloning Guardrails Added to Opus 5.5**: Anthropic confirmed it added two sentences to the Claude Code system prompt for Opus 5.5 to steer it away from recreating specific games, citing its IP infringement policy. Some users also reported refusals on broader reverse-engineering tasks; Anthropic had not addressed those in available sources. Source: [www.tomshardware.com](https://www.tomshardware.com/tech-industry/artificial-intelligence/anthropic-confirms-new-claude-code-limits-to-prevent-game-cloning-users-report-opus-5-5-is-also-actively-blocking-reverse-engineering-tasks)

- **Claude Code Projects Public Beta**: Anthropic launched a public beta for Claude Code Projects on Pro and Max plans, adding a more proactive coordinator that manages parallel threads and posts status updates in the project chat. Source: [i10x.ai](https://i10x.ai/news/claude-code-code-mode-javascript-tool-calls)

## Roadmap & Announcements

- **Agent SDK Rebranding**: The Python `claude-code-sdk` package and the TypeScript `@anthropic-ai/claude-code` import have been superseded by `claude-agent-sdk` and `@anthropic-ai/claude-agent-sdk`. Changelogs for the week list the Python SDK at 0.2.182 and TypeScript SDK at 0.3.325, shipping alongside each CLI release. Source: [releasebot.io/updates/anthropic](https://releasebot.io/updates/anthropic)

- **Scheduled Tasks & Loop Permission Tightening (v2.1.325)**: Starting with v2.1.325, scheduled tasks and `/loop` will ask before running a skill that declares `allowed-tools` or hooks. Add `Skill(name)` to `permissions.allow` to run it unattended — a change that affects anyone using automated routines. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

---

## Key Takeaway
Code Mode (v2.1.323) is the most architecturally significant Claude Code change this week: by letting Claude write JavaScript to orchestrate tool calls, it opens the door to multi-step operations that complete in a single round-trip. Users running automated workflows should also note that v2.1.325 tightens permissions for scheduled tasks and `/loop` skills, and anyone with a public GitHub repository should immediately add `.claude/settings.local.json` to `.gitignore` to prevent credential exposure.

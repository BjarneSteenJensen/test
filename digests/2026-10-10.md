# Claude Code News Digest — 2026-10-10

## Overview
Claude Code has shipped seven releases between October 2 and October 9, bringing the CLI to v2.1.296. The headline changes this week are: a new **Mods system** that lets TypeScript plugins reshape Claude Code's behaviour at runtime, the **effort parameter** for sub-agents, and the addition of **Claude Haiku 5.5** as the default Haiku model. Anthropic also updated Agent SDK pricing so Max and Team subscribers now receive a monthly API-credit allotment.

---

## New Features & Releases

- **v2.1.296 — October 9** (latest): Adds `autoCompactWindow` for subagents, the `CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL` environment variable for routing workflow sub-agents to a different model, and an `allow_large` option on the Read tool. The Sonnet 5.5 cache-read price was cut in half (from $0.20 to $0.10 per million tokens), and the MCP tool-description-and-server-instruction limit was raised from 2,048 to 4,096 characters. Source: https://code.claude.com/docs/en/changelog

- **v2.1.295 — October 8**: Introduces `onFailure: "block"` for command and HTTP hooks (so a hook failure now blocks the tool call rather than silently continuing), OSC 7501 Program Status Protocol support, and configurable upstream timeouts for gateway deployments. MCP tool descriptions loaded via tool search are now capped at 16,384 characters (previously 2,048), and subagents preload at most 32 skills at startup. Source: https://code.claude.com/docs/en/changelog

- **v2.1.293 — October 7**: Ships **Claude Haiku 5.5** (`claude-haiku-5-5`) as the new default Haiku model on the Anthropic API, priced at $0.10 input / $0.50 output per million tokens — described as the fastest and cheapest capable small model yet. Also adds `agentType` to the `subagentStatusLine` payload and `isDeferred` support for `$.tool.register`. Source: https://code.claude.com/docs/en/changelog

- **v2.1.292 — October 6**: The **Agent tool gains an `effort` parameter**, letting callers specify the effort level for a sub-agent. Also ships `claude plugin install --marketplace <source>`, prompt caching support in `$.model.complete` for mods, and the `prompt.autocomplete` mod event. Stdio MCP servers now negotiate protocol version 2026-07-28 by default. Source: https://code.claude.com/docs/en/changelog

- **v2.1.290 — October 5**: Adds `claude attach <name>` / `claude logs <name>` accepting partial session names, and a `!fast` shortcut to toggle fast mode in the Slack integration. A security hardening change prevents repository-level settings from enabling `CLAUDE_CODE_DISABLE_ATTACHMENTS` or Chrome integration. Source: https://code.claude.com/docs/en/changelog

- **v2.1.289 — October 3**: Adds `agent.spawn` for teammates and idle/waiting state signals to `$.agent.list()`, expanding the multi-agent orchestration API. Source: https://code.claude.com/docs/en/changelog

- **v2.1.288 — October 2**: Adds `$.ui.selection()` for mods, a built-in `gh api` command available inside cloud sessions without the GitHub CLI installed, prompt recovery after Ctrl+C clears the input, `--max-findings` for `/code-review`, and Ctrl+F / Alt+↑↓ navigation in the agents view. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **Mods system (October 1, v2.1.287)**: Anthropic introduced *mods* — small TypeScript functions that ship inside plugins and can rewrite prompts, add UI elements, intercept tool calls, or replace built-in features. The first built-in mod, "You should know," uses a side agent to flag things the user or Claude might overlook. Mods are available in the CLI and desktop app. Source: https://code.claude.com/docs/en/changelog

- **MCP protocol 2026-07-28 as default**: Starting with v2.1.292, stdio MCP servers negotiate the newer protocol revision by default. The MCP v2 runtime (built on TypeScript SDK 2.0) is now the standard baseline for tool description limits and MCP server startup. An October guide also highlights that MCP tool names must be ≤128 characters, and that memory leaks in HTTP MCP connections were fixed in v2.1.293. Source: https://code.claude.com/docs/en/mcp

- **JetBrains and VS Code plugins**: No new October releases for the official IDE extensions were found, but the JetBrains marketplace lists *Claude Code Plus* (plugin ID 28343) and the VS Code extension continues to support inline diffs and plan review. An unofficial Eclipse plugin is also available on the Eclipse Marketplace. Source: https://code.claude.com/docs/en/vs-code | https://code.claude.com/docs/en/jetbrains

## Bug Fixes & Performance

- **v2.1.294 — October 8**: Fixed `prompt` and `agent` hooks written as plain instructions inadvertently allowing actions they should block; improved Stop/SubagentStop hook judgment so Claude is less likely to halt early. Source: https://code.claude.com/docs/en/changelog

- **v2.1.291 — October 6**: Patched two regressions from v2.1.290 — cloud sessions could drop permission-prompt answers, and the last messages of a session could be lost on quit. Source: https://code.claude.com/docs/en/changelog

- **NO_PROXY / HTTPS_PROXY fix (v2.1.292)**: `NO_PROXY` was being ignored for Claude Code's own API requests when `HTTPS_PROXY` was set, breaking traffic routing in corporate proxy environments. Source: https://code.claude.com/docs/en/changelog

- **Sonnet 5.5 cache price cut (v2.1.296)**: Cache-read pricing for Sonnet 5.5 was halved from $0.20 to $0.10 per million tokens, effective with this release. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
The **Mods system** is the week's biggest architectural development — it lets any plugin author fundamentally reshape how Claude Code behaves at the prompt, tool, and UI layer, opening a new category of deep customisation previously impossible with plugins alone. Combined with the `effort` parameter for sub-agents and the expanded multi-agent APIs (`agent.spawn`, `$.agent.list()`), Claude Code's agentic orchestration capabilities have taken a significant step forward this week.

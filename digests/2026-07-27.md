# Claude Code News Digest — 2026-07-27

## Overview
The past week brought Claude Code's biggest model upgrade yet — Claude Opus 5 is now the default Opus-tier model, with a 1M-token context window and expanded nested subagent depth. Security hardening was also a major theme, with several permission-check bypass fixes and a new `EndConversation` tool for blocking jailbreak attempts.

## New Features & Releases

- **Claude Opus 5 becomes default Opus model (v2.1.219, July 24)**: Claude Opus 5 (`claude-opus-5`) replaces Opus 4.8 as the default model for Max, Team Premium, and Enterprise accounts, featuring a 1M-token context window and fast mode pricing of $10/$50 per MTok. Opus 4.7 was simultaneously removed from fast mode — `/fast` now applies only to Opus 5 and Opus 4.8. Source: https://code.claude.com/docs/en/changelog

- **Nested subagents up to depth 3 (v2.1.219, July 24)**: Subagents can now spawn their own subagents up to three levels deep (previously limited to one), configurable via `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH`. Dynamic workflows now default to a medium size guideline of fewer than 15 agents, tunable with `workflowSizeGuideline`. Source: https://code.claude.com/docs/en/changelog

- **`/code-review` runs in background (v2.1.218, July 22)**: The `/code-review` command now runs as a background subagent so review findings no longer fill the active conversation, allowing developers to keep working while the review completes. Source: https://code.claude.com/docs/en/changelog

- **Emoji shortcode autocomplete (v2.1.217, July 21)**: Typing `:heart:` in the prompt input now auto-completes to ❤️ and similarly for all standard emoji shortcodes; can be disabled with `emojiCompletionEnabled: false`. Source: https://code.claude.com/docs/en/changelog

- **`/doctor` is a full setup checkup (Week 28, July 6–10)**: The `/doctor` command (aliased as `/checkup`) now actively diagnoses and can fix issues, checking installation health, unused skills/MCP servers/plugins vs. their context cost, duplicate `CLAUDE.md` content, and slow hooks — proposing changes and asking for confirmation before applying them. Source: https://code.claude.com/docs/en/whats-new/2026-w28

- **`EndConversation` tool for jailbreak/abuse (v2.1.214, July 18)**: A new `EndConversation` tool allows Claude to gracefully terminate sessions when it detects abusive users or persistent jailbreak attempts. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **Artifacts call live MCP connectors (Week 29, July 13–17)**: Published artifacts can now call MCP connectors each time a viewer opens the page, enabling live dashboards and real-time data pulls rather than static session snapshots. Calls run through each viewer's own authenticated connections, and viewers approve access before the first connector call. Public sharing links, editor roles for Team/Enterprise, and artifact creation from Claude Tag sessions were also added this week. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **In-app browser on Desktop (Week 28, July 6–10)**: Claude Code on desktop now has a built-in sandboxed browser, enabling Claude to navigate, read, click through, and interact with any external website — docs, design tools, or third-party services — the same way it handles local dev server previews. Safety classifiers review actions on external sites and browsing sessions can be set to persist or clear between uses. Source: https://code.claude.com/docs/en/whats-new/2026-w28

- **Auto mode expanded to Bedrock/Vertex/Foundry without opt-in (v2.1.207, July 11)**: Auto mode no longer requires the `CLAUDE_CODE_ENABLE_AUTO_MODE` environment variable on Amazon Bedrock, Google Cloud's Agent Platform, and Microsoft Foundry — it is now on by default (disableable via `disableAutoMode`). These platforms also now default to Claude Opus 4.8 as their base model. Source: https://code.claude.com/docs/en/changelog

- **MCP tool calls auto-background after 2 minutes (v2.1.212, July 17)**: MCP tool calls that run longer than 2 minutes now move to the background automatically, keeping the active session usable. The threshold is tunable via `CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS`. Source: https://code.claude.com/docs/en/changelog

- **`/fork` redesigned as background session copy (v2.1.212, July 17)**: `/fork` now copies the current conversation into a new, fully independent background session visible in `claude agents`, while the in-session forked subagent it used to launch is now available as `/subtask`. Source: https://code.claude.com/docs/en/whats-new/2026-w29

## Bug Fixes & Performance

- **Windows path corruption fix (v2.1.219, July 24)**: Fixed paths containing `\u`-prefixed segments (e.g., `\users\`) being corrupted into CJK Unicode characters on Windows. Source: https://code.claude.com/docs/en/changelog

- **Security: permission-check bypass fixes (v2.1.214, July 18)**: Fixed a critical bug where single-segment `dir/**` allow rules could auto-approve writes to nested directories anywhere on the filesystem. Also patched a separate permission-check bypass in Windows PowerShell 5.1 and fixed Bash permission checks for complex forms including file descriptors and very long commands. Source: https://code.claude.com/docs/en/changelog

- **Long-session slowdown fixed (v2.1.216, July 20)**: Fixed a performance regression where message normalization cost grew quadratically in long sessions, causing noticeable slowdowns in extended conversations. Source: https://code.claude.com/docs/en/changelog

- **MCP memory leak fixed (v2.1.217, July 21)**: Fixed a memory leak triggered by truncated MCP tool outputs. Also fixed Windows auto-update failures that left `claude.exe` missing after an update. Source: https://code.claude.com/docs/en/changelog

- **Terminal freeze on long outputs fixed (v2.1.207, July 11)**: Fixed the terminal freezing when Claude streamed responses containing very long lists, tables, or code blocks. Source: https://code.claude.com/docs/en/changelog

- **Auto-compact fix for Bedrock Opus 4.8 (v2.1.217)**: Fixed auto-compact never triggering for Opus 4.8 sessions on Amazon Bedrock, which could cause context window exhaustion on long tasks. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Claude Code for Government Desktop (FedRAMP High)**: Claude Code and Claude Cowork launched in public beta on Claude for Government Desktop, built on the same application as commercial customers but delivered through a FedRAMP High authorized environment with tamper-evident audit logs, stronger admin controls, and spend governance. Source: https://releasebot.io/updates/anthropic/claude-code

- **50% higher weekly limits promotion extended to July 19**: Anthropic extended a promotion giving Pro, Max, Team, and eligible Enterprise users 50% higher weekly usage limits — originally set to expire July 13 — through July 19, 2026. Standard limits resumed after that date. Source: https://www.helpnetsecurity.com/2026/07/13/claude-code-weekly-limits-promotion-extended/

- **Claude in Chrome generally available (Week 27, June 29 – July 3)**: Claude in Chrome, which embeds Claude Code directly in the browser, reached general availability for all direct Anthropic plans during the last week of June/first days of July. Source: https://code.claude.com/docs/en/whats-new/2026-w27

- **Screen reader mode for accessibility (v2.1.208, July 14)**: A dedicated screen reader mode (`claude --ax-screen-reader` or `CLAUDE_AX_SCREEN_READER=1`) replaces the visual terminal UI with plain, linear labeled text compatible with VoiceOver and NVDA, allowing visually impaired developers to use Claude Code fully. Source: https://code.claude.com/docs/en/whats-new/2026-w29

## Roadmap & Announcements

- **Claude Opus 5 signals model generational shift**: The promotion of Opus 5 to default across Max/Team Premium/Enterprise — with its 1M-token context, expanded nested subagent support, and reconfigured fast mode — signals Anthropic is moving the Claude Code stack fully onto the Claude 5 generation. Sonnet 5 became the default for Pro/Team Standard in Week 27. Source: https://code.claude.com/docs/en/whats-new

- **Admin console gets Usage tab**: The Claude Code admin console gained two new tabs focused on value and usage insights — showing active developers, session counts, and top commands across the organization, updated daily. Trusted Devices for Remote Control Admins was also added for Team and Enterprise, requiring device verification before viewing or steering local Claude Code sessions remotely. Source: https://releasebot.io/updates/anthropic/claude-code

- **Agent SDK billing separated from plan limits**: As of June 15, Claude Agent SDK and `claude -p` (headless) usage no longer counts toward Claude plan usage limits — these non-interactive uses draw from a dedicated monthly credit sized per plan and do not roll over, making it easier to build automation pipelines without cannibalizing interactive session limits. Source: https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan

## Key Takeaway
Claude Opus 5 is now the default Opus-tier model in Claude Code, bringing a 1M-token context window and support for nested subagents up to three levels deep — a foundational upgrade that enables significantly more autonomous and complex agentic workflows than were possible before.

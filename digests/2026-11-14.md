# Claude Code News Digest — 2026-11-14

## Overview
This was a highly active week for Claude Code, with five releases in nine days (v2.1.319–v2.1.325) introducing experimental "Code Mode," a new default model (Claude Fable 5.2), background MCP task support, and the largest bug-fix batch on record (195 fixes in v2.1.323). The day was also marked by a widespread Anthropic service outage affecting claude.ai logins and Claude Code access, which was resolved within roughly an hour in the morning UTC, before a second broader disruption emerged later in the day.

---

## New Features & Releases

- **v2.1.325 — Prompt Suggestions & Notebook Tips (November 13, 2026)**: Inline prompt suggestions now appear in the terminal; press Tab to accept. VS Code and compatible terminals display a spinner tip recommending users re-run a Jupyter notebook cell after Claude reads or edits one. A new Console sign-in flow in VS Code creates no API key. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.323 — Code Mode & 1M Context Default (November 12, 2026)**: Experimental opt-in "Code Mode" lets Claude write JavaScript to call its tools rather than relying on the structured tool-call protocol; it can be disabled per-organization. The default context window for unrecognized `claude-*` model IDs (e.g. gateway aliases) rose from 200K to 1M tokens. This release also shipped 195 bug fixes — the largest single batch in Claude Code's changelog. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.321 — Claude Fable 5.2 as Default Fable Model (November 9, 2026)**: Claude Fable 5.2 (`claude-fable-5-2`) became the default Fable model, bringing a 1M token context window at $8/$40 per million tokens input/output ($0.20/Mtok cache reads). Existing saved Fable 5.1 selections migrate to the generic `fable` alias; users can pin back to 5.1 with `/model claude-fable-5-1`. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.319 — MCP Tasks in Terminal (November 6, 2026)**: When an MCP server runs a tool call as a task, Claude Code now moves it to the background and reports the result when it finishes, unblocking the interactive session. A new `/claude-api latency-optimize` command was added to help developers find latency bottlenecks in their Claude API integrations. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Integrations & Extensions

- **v2.1.322 — Fast Mode on Vertex AI (November 10, 2026)**: Fast mode is now available on Vertex AI in the global, `us`, and `eu` regions, with automatic fallback to standard speed if Vertex refuses the fast-mode request. This extends fast mode availability beyond the direct Anthropic API. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.321 — Remote Control Settings File (November 9, 2026)**: `claude remote-control` gained a `--settings <file>` flag, letting operators apply a settings file to every session Remote Control starts. Remote Control sessions now also stay anchored to the folder they were started in; connected clients can no longer move the working directory. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.323 — Plugin Version-Range Gating (November 12, 2026)**: Plugins can now declare a compatible Claude Code version range via `engines["claude-code"]` in `plugin.json`; plugins outside the declared range won't be installed, updated, or loaded. `claude plugin validate` now also type-checks a plugin's TypeScript hooks module. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Bug Fixes & Performance

- **v2.1.325 — Security Fix for zstd Decoding (November 13, 2026)**: 88 bug fixes shipped, including a security fix for a vulnerability in zstd-compressed HTTP response decoding, plus several sandbox and permission-rule corrections. Sandboxed Bash commands now follow the normal permission flow by default (set `sandbox.autoAllowBashIfSandboxed: true` to restore the old unattended behavior). Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.323 — Largest Bug-Fix Batch (November 12, 2026)**: 195 bugs fixed in a single release — the largest batch on record per the official changelog. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Fast Mode Deprecation Warning**: Fast mode for Claude Opus 4.8 is deprecated as of October 30, 2026, and will be fully removed on November 30, 2026. After that date, calls will return an error with no fallback. Anthropic recommends migrating to Claude Opus 5.5. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Community & Ecosystem

- **ArmourCode Releases Claude Code Hooks Security Tool**: ArmourCode released an open-source set of pre-execution hooks for Claude Code. The hooks run checks before Claude Code executes a command; if a hook denies the request, Claude Code blocks the action and returns the reason to the model. The tool is aimed at enterprise teams wanting granular control over what Claude Code is permitted to run. Source: [IT Brief](https://itbrief.co.uk/story/armourcode-releases-hooks-tool-to-block-claude-code-risk)

- **v2.1.323 — New Environment Variables for Automation**: `CLAUDE_CODE_DISABLE_AGENT_PROGRESS_SUMMARIES=1` suppresses subagent progress summaries in non-interactive pipelines; `CLAUDE_CODE_RESUME_HINT_COMMAND` lets programs that launch Claude Code inject their own resume instruction into the exit hint. These make Claude Code easier to embed in custom toolchains. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.319 — `permissions.denyInsteadOfPrompting` for Headless Runs**: A new permission setting causes tool calls that would otherwise pause for a user prompt to be automatically denied, letting the turn continue without blocking. This is particularly useful for CI and SDK-based automation where interactive prompts are undesirable. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Roadmap & Announcements

- **Widespread Service Outage — November 13–14, 2026**: Anthropic logged a login incident affecting claude.ai and Claude Code that opened at 09:58 UTC on November 13; a fix was deployed at 11:05 UTC. A second, broader disruption emerged later the same day, leaving claude.ai with a major outage and the API and Claude Code in a partial outage state. Some reports noted a simultaneous Microsoft 365 outage, though Anthropic did not formally link the two. Check [status.claude.com](https://status.claude.com) for the current status. Sources: [Android Authority](https://androidauthority.com/anthropic-claude-outage-nov-2026-3735078), [Windows Report](https://windowsreport.com/claude-ai-code-console-and-cowork-are-down-and-not-working-in-latest-outage-anthropic-confirms/)

- **Anthropic Office Productivity Suite Launch (November 10–11, 2026)**: Anthropic launched a suite of office productivity tools, with Claude Meetings listed as coming soon. These are general Claude platform features rather than Claude Code changes, but they signal Anthropic's expanding product surface for professional users. Source: [Yahoo Finance](https://finance.yahoo.com/technology/ai/articles/claude-now-join-video-calls-190700694.html)

- **Scheduled Tasks & Skills Prompt Before Running (v2.1.325)**: Scheduled tasks and `/loop` now ask for confirmation before running a skill that declares `allowed-tools` or hooks. Add `Skill(name)` to `permissions.allow` to allow unattended execution. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

---

## Key Takeaway
The most important development this week is the **experimental "Code Mode"** in v2.1.323, which fundamentally changes how Claude interacts with its tools — writing JavaScript instead of structured tool calls — paired with the upgrade to **Claude Fable 5.2** as the default model and its 1M token context window. These two changes together represent a significant step toward more flexible, higher-capacity agentic coding workflows.

# Claude Code News Digest — 2026-09-25

## Overview
Claude Code capped a busy week with v2.1.282 (September 24), delivering extended thinking reliability fixes and a new `maxProseWidth` setting, one day after the major Claude Opus 5.5 release (v2.1.280, September 22) which made Opus 5.5 the new default Opus model for Pro and Team Standard plans. The week also brought the auto mode server-side classifier as a no-cost default, skills/plugins sync from claude.ai to terminal, and a send-now keyboard shortcut.

## New Features & Releases

- **Claude Opus 5.5 becomes default (v2.1.280, Sep 22)**: Anthropic released `claude-opus-5-5` as the new default Opus model in Claude Code, featuring a 1M-token context window and pricing of $4/$20 per million input/output tokens with $0.20/Mtok cache reads. Opus 5.5 matches Claude Fable 5.1 performance on most tasks at 40% lower cost than Opus 5. Pro and Team Standard plans were also switched to default Opus for new sessions. Source: https://code.claude.com/docs/en/changelog

- **v2.1.282 (Sep 24) — maxProseWidth, extended thinking fixes**: The most recent release adds the `maxProseWidth` setting to cap prose width in wide terminals while preserving full-width tables and code blocks. Extended thinking blocks were being dropped during certain operations — now fixed. Session resumption was re-sending messages in altered forms — also fixed. Several managed settings that were silently ignored or misapplied are corrected. Source: https://code.claude.com/docs/en/changelog

- **Send-now key and claude.ai sync (v2.1.275, Sep 17)**: `Ctrl+Enter` (or `Ctrl+X Ctrl+S`) now interrupts the current turn and immediately sends all queued messages. Skills and plugins enabled on a user's claude.ai account now sync automatically to terminal sessions, eliminating manual re-configuration. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **AGENTS.md support (v2.1.277, Sep 18)**: Claude Code now reads `AGENTS.md` as a fallback when no `CLAUDE.md` is present in the repository root. This expands compatibility with codebases that follow the emerging `AGENTS.md` convention used by other AI coding agents. Source: https://code.claude.com/docs/en/changelog

- **MCP URL-mode elicitation (v2.1.281, Sep 23)**: MCP servers can now trigger browser-based authentication and OAuth flows from within Claude Code sessions. The feature lets MCP servers request that Claude Code open a browser-based flow (e.g. sign-in pages) inline, instead of failing or requiring a separate setup step. Source: https://code.claude.com/docs/en/changelog

- **Auto mode server-side classifier (v2.1.278, Sep 19)**: Auto mode now defaults to the server-side classifier on Claude API and Enterprise accounts, eliminating the per-request overhead charge that previously applied when the classifier was client-side. Users can opt out with `CLAUDE_CODE_AUTO_MODE_SERVER=0`. Source: https://code.claude.com/docs/en/changelog

- **VSCode enhancements (v2.1.280)**: VS Code now surfaces a Status dialog, Sandbox dialog, Chrome dialog, and an Export conversation feature. Long replies no longer fall behind the stream and dictation handling is improved. Source: https://code.claude.com/docs/en/changelog

## Bug Fixes & Performance

- **Critical 400-error hotfix (v2.1.276, Sep 18)**: A regression introduced in 2.1.275 caused every request to fail with `400 … Input tag 'advisor_20260301'` when using a proxy or gateway. A hotfix was issued same-day. Source: https://code.claude.com/docs/en/changelog

- **Terminal rendering and vim mode (v2.1.282)**: Multiple fixes landed for CJK (Chinese/Japanese/Korean) character wrapping, vim mode cursor positioning, and general terminal cursor placement — issues that had persisted across several weeks. Source: https://code.claude.com/docs/en/changelog

- **MCP reliability (v2.1.274)**: Fixed HTTP+SSE server connections, tool-call timeouts, and resource refresh failures that were causing intermittent MCP hangs during sessions. Source: https://code.claude.com/docs/en/changelog

- **Session resumption speed (v2.1.281)**: Resumption time for very large sessions was significantly improved, addressing slowdowns that became more noticeable with the 1M-token context window. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **MCP adoption hits 95.3% in Claude Code**: Adoption of the Model Context Protocol within Claude Code climbed from 0% in late July 2026 to 95.3% by mid-September — one of the fastest adoption curves for any developer protocol extension. The milestone signals MCP has effectively become the standard integration layer for Claude Code workflows. Source: https://lucaberton.com/blog/mcp-adoption-by-client-2026/

- **Plugin marketplace gains install-from-source support (v2.1.275)**: `claude plugin install <plugin> --marketplace <source>` now lets developers install plugins from alternative marketplace endpoints, opening the door for private and community-hosted plugin registries. Source: https://code.claude.com/docs/en/changelog

- **Claude Code for startup founders**: A growing body of tutorials highlights Claude Code's value for non-engineering founders — using terminal, IDE, web, desktop, Slack, and CI/CD surfaces to test product ideas, edit code, and review diffs without deep programming experience. Source: https://blog.mean.ceo/claude-code-news-september-2026/

## Roadmap & Announcements

- **Weekly limit adjustment after Sep 14 promotion end**: Anthropic ended its 50% Claude Code weekly-limit promotion on September 14 and permanently kept a 25% uplift above the pre-promotion baseline, meaning usage limits are effectively 25% higher than they were before the promotion began. Source: https://www.llmrumors.com/news/claude-code-weekly-limits-september-2026

- **Cloud session GitHub App status (v2.1.282)**: Cloud sessions now display GitHub App connection status and support repository attachment directly from within the session — pointing toward tighter GitHub Actions and cloud-hosted workflow integration coming in the near term. Source: https://code.claude.com/docs/en/changelog

- **Slack/Claude Tag enterprise reliability push**: Multiple reliability improvements landed for Enterprise Grid channels and shared channels in v2.1.282, suggesting Anthropic is prioritizing enterprise Slack deployments as a growth surface heading into Q4 2026. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
The release of Claude Opus 5.5 as the default Opus model — with Fable 5.1-level performance at 40% lower cost — is the headline development of the week, making the most capable model tier significantly more accessible for everyday Claude Code use.

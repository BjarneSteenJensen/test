# Claude Code News Digest — 2026-11-09

## Overview
Anthropic shipped three Claude Code releases this week (v2.1.317–v2.1.319), delivering significant security hardening, MCP background-task support, and auto-mode changes that remove the fallback to the built-in classifier. A reported security finding from Apiiro about secrets exposed via the "don't ask again" approval flow is circulating but has not yet been confirmed by Anthropic.

## New Features & Releases

- **v2.1.319 (Nov 6): MCP background tasks & auto-mode overhaul**: Claude Code can now move MCP tool calls to the background and report results when they finish (set `CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND=1` to disable). Auto mode no longer falls back to the built-in classifier when telemetry or feature flags are off — calls the server can't check are instead asked about or denied. Set `CLAUDE_CODE_AUTO_MODE_SERVER=0` to restore previous behavior. Source: https://code.claude.com/docs/en/changelog

- **v2.1.319: `permissions.denyInsteadOfPrompting`**: A new setting causes any tool call that would wait on a permission prompt to be silently denied instead, letting the turn continue. Applies to terminal sessions, subagents, and teammates. Source: https://code.claude.com/docs/en/changelog

- **v2.1.319: `/usage` spend totals & `/tasks` history**: Developers behind a Claude apps gateway can now see spend for today, this week, and this month via `/usage`. A new "Earlier in this session" row in `/tasks` lists finished subagents for reopening. Also added: `/claude-api latency-optimize` to benchmark faster settings against your eval suite. Source: https://code.claude.com/docs/en/changelog

- **v2.1.318 (Nov 4): Cloud sessions without a repository**: Cloud sessions on Anthropic-hosted environments can now start without selecting a repository, expanding use cases for one-off or non-repo tasks. `claude auth status` also now reports when a stored claude.ai sign-in expires (`loginExpiresAt`). Source: https://code.claude.com/docs/en/changelog

- **v2.1.317 (Nov 3): Account email privacy check & `/schedule` warning**: Claude Code now prompts for approval before a web or shell tool sends the user's account email address over the network. A new warning fires when a new cloud scheduled task receives connectors the user didn't request, with instructions on how to remove them. Source: https://code.claude.com/docs/en/changelog

- **v2.1.317: `onFailure: "block"` for Agent SDK hooks**: Hook callbacks in the Agent SDK can now be configured to block the triggering action on failure, giving developers stricter pipeline control. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **IDE extension no longer auto-installs from IDE terminal (v2.1.318)**: Claude Code no longer installs or updates its IDE extension when launched from within an IDE terminal. Users must run `/ide` from an external terminal instead. This change affects VS Code, JetBrains, and compatible forks like Cursor. Source: https://code.claude.com/docs/en/changelog

- **`deniedMcpServers` now covers Anthropic-provided servers (v2.1.318)**: URL-pattern entries in `deniedMcpServers` now also block matching Anthropic-provided MCP servers and connectors in cloud sessions and on self-hosted runners, closing a gap in enterprise policy enforcement. Source: https://code.claude.com/docs/en/changelog

- **Background subagents on all providers (v2.1.318)**: Shell commands that run more than 3 minutes are now automatically moved to the background across all providers so the prompt cache does not expire, improving reliability of long-running agentic tasks. Source: https://code.claude.com/docs/en/changelog

- **`assume_role` for `mantle` upstreams (v2.1.318)**: Developers can now use `assume_role` on `mantle` gateway upstreams for cross-account AWS access or per-developer cost attribution. Source: https://code.claude.com/docs/en/changelog

- **Cost report API added (v2.1.317)**: A new `GET /v1/organizations/analytics/cost` endpoint on the Claude apps gateway returns past spend broken down by total, developer, day, or IdP group. Source: https://code.claude.com/docs/en/changelog

## Bug Fixes & Performance

- **v2.1.319: 90 fixes including two security patches**: The release addresses a Bash permission bypass via a crafted environment prefix and a sandbox escape when creating a git worktree. Additional fixes cover MCP handshake failures with older-protocol servers, `javascript_tool` output now capped at 60,000 characters, OpenTelemetry exports hanging behind proxies, and `claude -p` now correctly exits with code 1 on a full-disk write failure. Source: https://code.claude.com/docs/en/changelog

- **v2.1.318: 47 fixes including `--continue` regression**: A regression introduced in v2.1.314 affecting `--continue` was resolved. Config saves on network home directories are now safer, and remote session reconnects are faster. Source: https://code.claude.com/docs/en/changelog

- **v2.1.317: 62 fixes including auto-mode gateway failures**: Auto mode was silently failing every turn behind certain Claude apps gateways; this is now fixed. The Read tool stub ("file unchanged since your last Read") was removed — rereading an unchanged file now returns its full content. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Apiiro: secrets exposed via "don't ask again" approval (reported, unconfirmed)**: Security firm Apiiro reportedly found secrets stored in over 1,100 public GitHub files linked to Claude Code's "Yes, and don't ask again" permission approval option. As of November 8, Anthropic had not issued a statement or advisory. Users are advised to audit their repositories for accidentally committed credentials. Source: https://tech-insider.org/au/claude-code-dont-ask-again-secrets-github-apiiro-2026/ *(site not directly accessible from this session)*

- **AlixPartners test: Claude Code missed $800K in contract review**: A published test by AlixPartners found Claude Code missed approximately $800,000 in contract value and incorrectly identified a renewal date across a set of 40,000 contracts. The report highlights current limitations for high-stakes legal document review. Source: https://startuphub.ai/ai-news/artificial-intelligence/2026/claude-code-looked-right-and-missed-800k

- **Developers report game-recreation refusals**: Multiple developers on social media and forums report Claude Code now refuses to help recreate or clone existing games, including commissioned client work. Anthropic's official changelog makes no mention of this policy change, and it remains unconfirmed. Source: https://thenextweb.com/news/claude-code-game-recreation-refusals-developers *(site not directly accessible from this session)*

## Roadmap & Announcements

- **Fast mode for Opus 4.8 deprecated, removed November 30**: As of October 30, 2026, fast mode for Opus 4.8 is deprecated and will be fully removed on November 30, 2026. Anthropic recommends migrating to Opus 5.5 to retain fast output. Source: https://www.gradually.ai/en/changelogs/claude-code/

- **Standalone Claude Design closes December 14, 2026**: Version 2.1.302 added a notice that the standalone Claude Design product will close on December 14, 2026. The `/design` command and design features remain available within Claude Code. Source: https://releasebot.io/updates/anthropic/claude-code *(site not directly accessible from this session)*

- **Fork subagents on by default in SDK sessions**: Fork subagents are now enabled by default in Claude Agent SDK sessions (TypeScript ≥ 0.3.302). Set `CLAUDE_CODE_FORK_SUBAGENT=0` to restore the previous behavior. Source: https://www.gradually.ai/en/changelogs/claude-code/

## Key Takeaway
The most consequential change this week is the auto-mode overhaul in v2.1.319, which removes the built-in classifier fallback — combined with the two security patches in the same release (Bash permission bypass and sandbox escape), this represents Anthropic's most significant security-focused Claude Code week in recent months.

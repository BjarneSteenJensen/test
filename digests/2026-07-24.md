# Claude Code News Digest — 2026-07-24

## Overview
The most significant Claude Code development this week is the Artifacts + MCP connectors integration (Week 29, v2.1.207–v2.1.212), which allows published artifacts to pull live data through viewers' own MCP connectors — turning static snapshots into live, interactive dashboards. The latest release is v2.1.217 (July 21), adding emoji shortcode autocomplete and multiple stability fixes. No Week 30 digest has been published yet as of today (July 24).

---

## New Features & Releases

- **v2.1.217 — Emoji Shortcode Autocomplete & Stability (July 21)**: The latest release adds emoji shortcode autocomplete in the prompt input (`:heart:` → ❤️), warnings for failing transcript writes, and a fix for a memory leak with truncated MCP tool outputs. Also fixed: Windows auto-update failures leaving `claude.exe` missing, auto-compact not triggering for Opus 4.8 on Bedrock, and managed settings not governing all OTel signals. Source: https://code.claude.com/docs/en/changelog

- **v2.1.215 — Skills No Longer Auto-Run (July 19)**: Claude no longer automatically invokes `/verify` and `/code-review` skills; users must call them explicitly. This prevents unexpected tool invocations mid-session. Source: https://code.claude.com/docs/en/changelog

- **v2.1.212 — `/fork` Creates Background Sessions, Session Caps (July 17)**: `/fork` now copies a conversation into a new background session (visible in `claude agents`) instead of launching an in-session subagent; the old behavior is now `/subtask`. Session-wide caps (default 200 each) were added for WebSearch calls and subagent spawns to stop runaway loops. MCP tool calls running longer than 2 minutes now auto-background to keep the session usable. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **v2.1.208 — Screen Reader Mode (July 14)**: `claude --ax-screen-reader` (or `CLAUDE_AX_SCREEN_READER=1`) replaces the visual terminal interface with plain, labeled text lines for VoiceOver, NVDA, and other screen readers. Also added: `vimInsertModeRemaps` setting (e.g., `jj` → Escape in vim mode), `CLAUDE_CODE_PROCESS_WRAPPER` for corporate launchers, and mouse-click support in fullscreen multi-select menus. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **v2.1.207 — Auto Mode Default on Cloud Providers (July 11)**: Auto mode is now available without the `CLAUDE_CODE_ENABLE_AUTO_MODE` opt-in on Amazon Bedrock, Google Cloud's Agent Platform, and Microsoft Foundry. The default model on Bedrock, Vertex, and Claude Platform on AWS was also switched to Claude Opus 4.8. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **Artifacts Call MCP Connectors (Week 29, July 13–17)**: Published artifacts can now call MCP connectors each time someone views the page, enabling live dashboards instead of static snapshots. Each call runs through the viewer's own connector credentials, and viewers approve access on first load. Public sharing links, editor roles on Team and Enterprise, and artifact creation from Claude Tag sessions were also added. Source: https://code.claude.com/docs/en/whats-new/2026-w29

- **VS Code 1.128 — Multi-Chat Agent Sessions (July 8)**: VS Code 1.128 shipped multi-chat support for Claude agent sessions, allowing multiple concurrent Claude Code conversations in parallel IDE tabs. The update also bundles the latest CLI improvements. Source: https://visualstudiomagazine.com/articles/2026/07/08/claude-ai-gets-yet-another-boost-in-vs-code-1-128.aspx

- **Enterprise-Managed MCP via Okta**: Anthropic added enterprise-managed MCP connector access starting with Okta, allowing admins to provision connectors once so users get zero-touch access on first login. The beta covers Claude chat, Claude Code, and Cowork on Team and Enterprise plans. Source: https://www.anthropic.com/news

- **Claude Agent SDK — Latest Release July 22**: The Claude Agent SDK for Python was updated on July 22, 2026. Since June 15, Agent SDK usage is metered separately from interactive Claude Code plan limits, making costs more predictable. Source: https://pypi.org/project/claude-agent-sdk/

- **In-App Browser on Desktop (Week 28, July 6–10)**: Claude Code on desktop gained a built-in browser so Claude can interact with documentation, designs, or any URL directly in the same session as local dev server previews. Source: https://code.claude.com/docs/en/whats-new

## Bug Fixes & Performance

- **Terminal Freezing on Long Output Fixed (v2.1.207)**: A bug causing terminal freezing while streaming very long lists, tables, or code blocks was resolved. Source: https://code.claude.com/docs/en/changelog

- **Quadratic Memory Cost Regression Fixed (v2.1.216)**: A message normalization bug causing quadratic memory growth in long sessions was patched in the July 20 release, significantly improving performance on extended conversations. Source: https://code.claude.com/docs/en/changelog

- **Security: Windows PowerShell Permission-Check Bypass Fixed (v2.1.214)**: A permission-check bypass in Windows PowerShell 5.1 was fixed, along with Bash permission checks for file-descriptor redirects and very long commands (>10,000 chars), and incorrect auto-approval of nested directory writes. Source: https://code.claude.com/docs/en/changelog

- **Corporate Proxy & TLS Fixes (v2.1.217)**: Corporate mTLS, TLS-verify, OAuth, and proxy settings being silently ignored in Claude Desktop were resolved. Source: https://code.claude.com/docs/en/changelog

- **Auto Mode OAuth Token Expiry Fix (v2.1.216)**: Auto mode was incorrectly denying commands with "HTTP 401" classifier errors after OAuth token expiry; this is now resolved. Source: https://code.claude.com/docs/en/changelog

- **Claude in Chrome — Generally Available**: Claude in Chrome moved from beta to general availability on all direct Anthropic plans during Week 27 (June 29 – July 3). Source: https://code.claude.com/docs/en/whats-new

## Key Takeaway
The Artifacts + MCP connectors integration is the most impactful recent Claude Code development: published artifact pages can now pull live data through viewers' own MCP connections, fundamentally shifting artifacts from static exports to live, permissioned dashboards — closing a major gap between Claude Code sessions and shareable deliverables.

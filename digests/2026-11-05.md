# Claude Code News Digest — 2026-11-05

## Overview
Claude Code shipped two notable releases this week (v2.1.317 and v2.1.318) covering security hardening, cloud-session improvements, and Agent SDK enhancements. In parallel, Anthropic confirmed policy-level changes that now prevent Claude Code from helping recreate existing video games, sparking significant developer discussion.

## New Features & Releases

- **Claude Code 2.1.318 (November 4, 2026)**: Adds a session-mod consent record so Claude Code logs your answer when it asks to enable mods it writes in a session. Also introduces `loginExpiresAt` in `claude auth status` and a 10-day warning before a claude.ai sign-in expires. Background subagents now automatically move shell commands to the background after 3 minutes on all providers. The IDE extension is no longer auto-installed or auto-updated when running inside an IDE terminal; use `/ide` from an outside terminal going forward. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Claude Code 2.1.317 (November 3, 2026)**: Introduces `onFailure: "block"` for Agent SDK hook callbacks, stopping the triggering action on a failed hook. Adds `anthropic.plan`, `anthropic.seat_type`, `anthropic.provider`, and `anthropic.custom_base_url` attributes to OpenTelemetry metrics. A new cost report endpoint is available on the Claude apps gateway admin API (`GET /v1/organizations/analytics/cost`). `SendMessage` now reaches running background agents sooner without halting their active commands. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Fast mode for Opus 4.8 deprecated**: Anthropic announced that Fast mode on Opus 4.8 will be removed on November 30, 2026. After that date, requests using this mode will return an error rather than silently falling back to standard Opus 4.8. Users are advised to migrate to Opus 5.5. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Integrations & Extensions

- **MCP security improvements**: Recent releases redact credential headers and URL secrets in `claude mcp list/get/add` output so secrets no longer print to the terminal. A separate fix resolves project and local MCP servers disconnecting after the first turn in some Claude Desktop sessions. `deniedMcpServers` URL entries now also block matching Anthropic-provided servers and connectors. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Cloud sessions enhancements (v2.1.318)**: Cloud sessions gain a "No repository" option and Chrome binary aliases (`google-chrome`, `CHROME_PATH`). A new `assume_role` parameter on `mantle` upstreams enables cross-account roles and per-developer AWS cost attribution. `CLAUDE_RUNNER_SPAWN_REASON` is now exposed for self-hosted runner spawn-runner hooks. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Agent SDK — `effort` option for model forks**: The `$.model.fork` API in mod scripts now accepts an `effort` option, letting quick side jobs run at `low` effort to reduce cost and latency. Subagents running on a different model now use that model's saved effort level rather than the parent's. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Bug Fixes & Performance

- **v2.1.318 ships 15 improvements and 47 bug fixes**, including fixes for shared network home directories, `--continue` losing conversations, permission prompts answered by stray keystrokes, macOS memory growth, and multiple cloud-session reliability issues. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.317 ships 8 improvements and 62 bug fixes**, covering Foundry credential errors, `/design-sync`, OpenTelemetry proxy timeouts, Bedrock "Input is too long" handling, PDF page counting, `DISABLE_PROMPT_CACHING_*` settings, and many VS Code and cloud session issues. The `Read` tool no longer returns a "file unchanged" stub when rereading an unmodified file. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Community & Ecosystem

- **Game-recreation refusal controversy**: Developers across forums reported that Claude Code (using Opus 5.5) now declines to help recreate existing games, including paid commissioned projects. Tom's Hardware confirmed Anthropic added two sentences to the Opus 5.5 system prompt restricting reproduction of specific existing game titles, citing its IP usage policy. Anthropic clarified that original games and genre-inspired games should still work. Source: [Tom's Hardware](https://www.tomshardware.com/tech-industry/artificial-intelligence/anthropic-confirms-new-claude-code-limits-to-prevent-game-cloning-users-report-opus-5-5-is-also-actively-blocking-reverse-engineering-tasks), [The Next Web](https://thenextweb.com/news/claude-code-game-recreation-refusals-developers), [TechSpot](https://www.techspot.com/news/114423-anthropic-tells-claude-code-stop-recreating-existing-video.html)

- **Claude Design standalone shutdown**: Version 2.1.302 added a notice that the standalone Claude Design product is set to close by December 14, 2026. Design functionality will continue through Claude Code's `/design` and `/design-sync` commands. Source: [Anthropic Release Notes via Releasebot](https://releasebot.io/updates/anthropic/claude-code)

## Roadmap & Announcements

- **Cat Wu departs as Claude Code product head**: Cat Wu, who led product for Claude Code for two years, announced on November 3 that she has left Anthropic. No successor has been publicly named. Source: [Unite.AI](https://unite.ai/cat-wu-steps-down-as-claude-code-product-chief-after-two-years)

- **Anthropic IPO reported for November 2026**: Multiple sources cite reports that Anthropic is planning an initial public offering in November 2026. While not a Claude Code-specific announcement, it may affect roadmap and resource allocation for the tool going forward. Source: [Wikipedia — Anthropic](https://en.wikipedia.org/wiki/Anthropic)

## Key Takeaway
The most developer-impactful change this week is Anthropic's new system-prompt-level restriction preventing Claude Code from recreating existing games — the first confirmed case of a behavioral policy change applied directly to the coding tool, which has raised concerns about similar restrictions being quietly added in the future for other categories of work.

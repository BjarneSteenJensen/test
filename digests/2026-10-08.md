# Claude Code News Digest — 2026-10-08

## Overview
The week of October 1–7, 2026 was one of Claude Code's most active release stretches, shipping seven versions (v2.1.287–2.1.293) in seven days. The headliner is **Claude Mods**, a new extensibility layer that lets TypeScript plugins reach deeper into Claude Code's behavior — replacing or augmenting built-in tools and UI. Alongside Mods, Anthropic shipped a new default Haiku model (Haiku 5.5), security hardening across the sandbox and permission system, and a steady stream of bug fixes covering MCP, cloud sessions, and the VS Code extension.

---

## New Features & Releases

- **Claude Mods launch (v2.1.287, Oct 1)**: Plugins can now modify deeper parts of Claude Code's behavior — overriding built-in slash commands, adding new UI, and patching tool behavior. The first built-in mod, **"You should know"** (`/plugin enable cc-plugin-you-should-know@builtin`), runs a side agent in the background to flag things you or Claude might miss. Mods are distributed through the plugin directory, giving teams governance over what custom behavior is enabled. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Effort parameter for Agent tool (v2.1.292, Oct 6)**: The `Agent` tool now accepts an `effort` parameter, letting a parent agent specify how hard a sub-agent should work (e.g., low, medium, high). This gives workflows finer-grained control over compute spend. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Claude Haiku 5.5 becomes default Haiku (v2.1.293, Oct 7)**: `claude-haiku-5-5` is now the default Haiku model on the Anthropic API. It offers 1M context and is priced at $0.10/$0.50 per million input/output tokens (5× higher rate for prompts over 100K tokens). Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog) / [Anthropic News](https://www.anthropic.com/news)

- **claude attach / claude logs commands (v2.1.290, Oct 5)**: Two new CLI commands — `claude attach <name>` and `claude logs <name>` — let you connect to or inspect a running session by partial name, making multi-session workflows easier to manage. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **1M context window now default for Opus 4.7+ and Fable (v2.1.287, Oct 1)**: On Bedrock, Vertex, Foundry, and the Claude apps gateway, Opus 4.7 and later (plus Fable) now default to 1M context. Set `CLAUDE_CODE_DISABLE_1M_CONTEXT=1` to revert to 200K. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Integrations & Extensions

- **MCP protocol 2026-07-28 becomes default (v2.1.292, Oct 6)**: Local stdio MCP servers now negotiate protocol version `2026-07-28` by default. The legacy protocol can be preserved by setting `MCP_PROTOCOL_NEGOTIATION=legacy`. URL-mode elicitation (browser-based OAuth flows from MCP servers) also expanded to the older `2025-11-25` protocol in v2.1.287. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Built-in `gh api` for cloud sessions (v2.1.288, Oct 2)**: Cloud sessions now have a built-in `gh api` command even when the GitHub CLI is not installed, removing a common setup step for cloud-based workflows. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **VS Code: message timestamps and screen reader improvements (v2.1.290, Oct 5)**: The VS Code extension now shows message timestamps by default and announces "Message queued." to screen readers when a message is waiting. Several additional screen reader mode fixes were also shipped in v2.1.287. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Claude Tag `!fast` in Slack (v2.1.290, Oct 5)**: Slack users can now type `!fast` in a Claude Tag thread to switch it to fast mode for quicker, lighter replies. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **JetBrains plugin updated to 0.33.4 (Oct 5)**: The community-maintained JetBrains IDE plugin (built on Anthropic's official extension protocol) was updated to v0.33.4. Source: [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/30313-claude-code-with-gui)

- **Managed Agents onboarding from URL (v2.1.290, Oct 5)**: New `/claude-api managed-agents-onboard` command lets users set up Managed Agents directly from a URL or Console quickstart link. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Bug Fixes & Performance

- **Permission prompt regressions fixed (v2.1.291, Oct 6)**: Two regressions from recent releases were patched: cloud sessions could silently drop answers to permission prompts (from v2.1.290), and the last messages of a session could be lost on quit (from v2.1.288). Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Memory leak in HTTP MCP connections (v2.1.293, Oct 7)**: Fixed unbounded memory growth when an HTTP MCP server sends very large responses — a significant stability fix for long-running sessions using heavy MCP servers. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **WebFetch truncation now reported (v2.1.290, Oct 5)**: WebFetch previously silently dropped content past 100,000 characters. It now reports the unread size and accepts an `offset` parameter to page through long pages. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Security: sandbox and symlink-swap fixes (v2.1.292, Oct 6)**: PreToolUse approvals and auto mode no longer bypass prompts for UNC network-path file reads. Several sandbox escapes via symlink swaps were also patched. Additionally, Bash deny rules that missed commands behind environment variable prefixes (e.g. `FOO=bar rg …`) were fixed in v2.1.289. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **NO_PROXY respected for API requests (v2.1.292, Oct 6)**: `NO_PROXY` was previously ignored for outbound Anthropic API calls, routing them through any configured proxy even when excluded. This is now fixed. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Scheduled tasks and plan mode on resume (v2.1.292, Oct 6)**: Scheduled tasks created after `/resume` were never firing; plan mode was not being restored on session resume. Both are now fixed. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Community & Ecosystem

- **"Claude Code in the cloud: a field guide" blog post (Oct 5)**: Anthropic published a practical guide to working with cloud sessions — covering container lifecycle, network policies, GitHub integration, and session recovery. Source: [Claude.ai Blog](https://claude.com/blog)

- **Community Visual Studio 2026 extension**: A community-built extension for Visual Studio 2026 (`firish/claude_code_vs` on GitHub) adds a native diff viewer with accept/reject, a live debugger Claude can drive autonomously, Roslyn code navigation, and Test Explorer integration. It requires the Claude Code CLI and makes no model calls itself. Source: [GitHub](https://github.com/firish/claude_code_vs)

- **Anthropic's $100M engineer training initiative (Oct 2)**: While not Claude Code-specific, Anthropic announced a $100M investment to train 10,000 engineers on enterprise AI, which will likely accelerate Claude Code adoption in enterprise settings. Source: [Anthropic News](https://www.anthropic.com/news)

- **Haiku 5.5 launch (Oct 7)**: The new Haiku 5.5 model — Anthropic's fastest and cheapest — is directly relevant to Claude Code users building cost-sensitive agentic pipelines that use smaller models for sub-tasks. Source: [Anthropic News](https://www.anthropic.com/news)

## Roadmap & Announcements

- **Claude Code Projects beta**: Anthropic is beta-testing a multi-session Projects experience where one project can coordinate parallel Claude Code threads — each working in a separate repo branch, running tests, and opening PRs — then reporting which PRs need to merge first. No public GA date announced. Source: [Releasebot / gradually.ai](https://www.gradually.ai/en/changelogs/claude-code/)

- **Mods ecosystem building**: The October 1 Mods launch is positioned as an extensibility platform, not a one-off feature. Anthropic is actively accepting community-built mods through the plugin directory, and the "You should know" built-in mod is the first of what appears to be an expanding set of first-party mods. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Cyber Verification Program expansion (Oct 6)**: Anthropic expanded its Cyber Verification Program to give qualifying security professionals access to advanced cyber capabilities and reduced safety classifiers — relevant for Claude Code users doing authorized security research. Source: [Anthropic News](https://www.anthropic.com/news)

---

## Key Takeaway
**Claude Mods** is the most significant Claude Code development this week: by opening the plugin layer to deep behavioral customization, Anthropic has laid the foundation for a true extension ecosystem — one where teams can ship, share, and govern custom Claude Code behaviors the same way they manage code. The simultaneous adoption of Haiku 5.5 as the default small model and the 1M context window expansion for Opus/Fable signals that the platform is maturing quickly in both capability and cost-efficiency.

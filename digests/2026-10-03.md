# Claude Code News Digest — 2026-10-03

## Overview
The biggest Claude Code story this week is the launch of **Mods** — a TypeScript hook system that lets users (and Claude itself) rewrite prompts, add new UI, and replace or extend built-in features, shipping in versions 2.1.287–2.1.288. Alongside Mods, the October 2 release delivered a wide-ranging stability and accessibility pass with dozens of bug fixes. Enterprise adoption is also accelerating, with Barclays targeting 50 % developer coverage by year-end.

---

## New Features & Releases

- **Claude Code v2.1.288 (October 2, 2026) — Mods go deeper**: The headline release adds Mods support at the plugin level, a new *You Should Know* built-in mod (a side agent that watches sessions and flags things you or Claude might miss), a `$.ui.selection()` Selection API so mods can read highlighted text in fullscreen mode, and a `/code-review --max-findings <n>|all` option for customisable finding limits. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Claude Code v2.1.287 (October 1, 2026) — Mods introduced**: Anthropic shipped the initial Mods feature tied to this version. Mods are small TypeScript functions that hook into Claude Code events (tool calls, permission prompts, screen rendering) and can run before, after, or instead of the event. Built-in features such as `/diff` now ship as mods, so teams can replace them with custom versions. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Session and UI improvements**: Version 2.1.288 adds `n:<text>` filtering in the Agents view to match session names and tasks, Ctrl+F to find sessions by name, Alt+↑/↓ to jump between groups, and prompt recovery with the Up arrow after Ctrl+C clears the prompt. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Integrations & Extensions

- **VSCode extension fix (October 2)**: The opt-in `Cmd/Ctrl+N` New Conversation shortcut was incorrectly starting conversations in every visible VS Code view simultaneously; this is now fixed. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **MCP OAuth re-authentication**: Claude Code now prompts users to re-authenticate when an MCP server requests an additional OAuth scope mid-session, improving the security flow for connected MCP integrations. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Community Visual Studio 2026 extension**: A community-built extension (by GitHub user `firish`) brings Claude Code to Visual Studio 2026, adding a native diff window with accept/reject, a live debugger Claude can drive autonomously, Roslyn code navigation with decompile, and Test Explorer integration. Source: [GitHub – firish/claude_code_vs](https://github.com/firish/claude_code_vs)

## Bug Fixes & Performance

- **Mid-response timeout resilience**: Non-interactive sessions now continue from partial responses after API timeouts, preventing full turn failures on long-running tasks. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Resume reliability fixes**: Multiple `--resume` bugs were closed — dropped files and context, lost last-response saves, and extended-thinking being silently discarded for sessions started on 2.1.286 or earlier. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Dangerous `rm` safeguard restored**: `rm` commands redirecting to `~` or wildcard paths were bypassing safety checks; this is fixed. A related change restricts background command time limits to unattended sessions (`-p`, Agent SDK, CI, cloud) rather than all sessions. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **MCP double-execution fix**: MCP tool calls whose results exceeded 16 MB were running twice; this is now resolved. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Auto Mode compaction**: Conversations too long for the client-side classifier are now compacted automatically instead of prompting or failing on every subsequent tool call. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Community & Ecosystem

- **Barclays enterprise rollout**: British bank Barclays is expanding its strategic collaboration with Anthropic to deploy Claude Code across its global developer workforce. The bank expects 50 % of its developers to be using Claude Code by end of 2026, rising to a majority of software engineers in 2027, with focus on modernising legacy systems and accelerating software delivery. Source: [Anthropic – Barclays scales Claude](https://www.anthropic.com/news/barclays-scales-claude)

- **Claude Agent SDK usage no longer counted against plan**: Since June 15, 2026, usage via the Claude Agent SDK and `claude -p` no longer counts toward a Claude plan's usage limits, making programmatic/agentic use more accessible for developers. Source: [Claude Code Agent SDK Support](https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan)

## Roadmap & Announcements

- **Mods as a platform**: By shipping some built-in Claude Code features (e.g. `/diff`) as first-party mods, Anthropic is signalling that the Mods system is a long-term extensibility platform rather than a power-user add-on. Teams on Team and Enterprise plans can control mod availability through the admin console. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Screen reader and accessibility push**: Version 2.1.288 adds announcement of permission mode changes for screen readers, reflecting an ongoing effort to make Claude Code accessible to a broader range of developers. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

---

## Key Takeaway
The launch of **Claude Code Mods** is the defining development of the week: by exposing every internal event as a hookable TypeScript function and shipping its own built-in features as mods, Anthropic has turned Claude Code from a configurable CLI into a fully extensible agent platform — while simultaneously hardening stability with one of the most bug-fix-dense releases of the year.

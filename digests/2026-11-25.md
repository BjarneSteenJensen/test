# Claude Code News Digest — 2026-11-25

## Overview
Today, November 25, Claude Code shipped v2.1.332, its most significant release of the month, launching **Skills from MCP servers** in public beta and tightening macOS computer-use safety rules. The week also saw the rollout of **Code Mode** across all major cloud platforms (Bedrock, Agent Platform, Foundry, AWS), and v2.1.330's debut of the `easel` built-in charting mod and 30-day scheduled tasks extended the platform's autonomous capabilities considerably.

---

## New Features & Releases

- **Skills from MCP servers now in beta (v2.1.332 — today)**: Claude Code v2.1.332, released November 25, launches Skills from MCP servers as a public beta. Skills appear as `server:skill` entries in the `/` command menu, and a new `PreSkillShellCommand` hook can inspect or refuse inline shell commands a skill loads. This opens the door to distributing reusable skills through any MCP server. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Code Mode reaches all major cloud platforms (v2.1.331, Nov 23)**: The experimental Code Mode — where Claude writes JavaScript to batch tool calls — was extended to terminal sessions on Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry, and Claude Platform on AWS. It was first introduced in v2.1.323 (Nov 12) and has been rolling out to more environments throughout the month. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Built-in charting and 30-day scheduled tasks (v2.1.330, Nov 20)**: The `easel` built-in mod adds native chart drawing to Claude Code for Pro, Max, Team, and Enterprise users on macOS and Linux. Separately, recurring scheduled tasks and `/loop` sessions now persist for up to 30 days, up from the previous 7-day limit. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Enterprise sign-in (v2.1.330, Nov 20)**: Users can now sign in to organizations managed in Anthropic's Enterprise Admin Console directly from Claude Code. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Fable 5.2 becomes default Fable model (v2.1.321, Nov 9)**: Claude Code made Fable 5.2 the default model when the `fable` alias is used, bringing 1 million tokens of context to that tier. Source: [claudenetwork.com/news](https://claudenetwork.com/news)

## Integrations & Extensions

- **Auto mode on Bedrock, Agent Platform, Foundry, and Claude apps gateway (v2.1.328, Nov 19)**: Auto mode is now available for Claude Opus 4.6 and Sonnet 4.6 on Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry, and the Claude apps gateway. Interactive sessions with no permission mode configured now start in auto mode by default on these platforms. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Sonnet 5.5 as default on Microsoft Foundry (v2.1.332, today)**: The `sonnet` alias on Google Cloud's Agent Platform and the default model on Microsoft Foundry were both updated to point to Claude Sonnet 5.5 in today's release. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **VS Code gains /fork, /workflows, and new settings (v2.1.330, Nov 20)**: The VS Code extension received `/fork` and `/workflows` commands, plus `claudeCode.escapeStopsClaude` and `claudeCode.pinPrompt` settings. An earlier update (v2.1.327, Nov 17) added "Claude Code: Add to Chat" to the Explorer's right-click menu. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **MCP: `claude mcp add-json` reads server config from stdin (v2.1.327, Nov 17)**: A new `claude mcp add-json <name> -` subcommand accepts server JSON via stdin, keeping API tokens and credentials off the command line in shell history. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **MCP auto-reconnect for older HTTP servers (v2.1.329, Nov 19)**: Claude Code now automatically reconnects HTTP MCP servers running older protocol versions after a dropped connection, and stalled background MCP tasks resume properly after slow reconnects. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

## Bug Fixes & Performance

- **~/.claude.json reset bug fixed (v2.1.329, Nov 19)**: A regression where `~/.claude.json` was silently reset to defaults during a file-lock stall or network delay has been resolved. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **MCP tool calls hanging on malformed replies (v2.1.331, Nov 23)**: A hang that occurred when an MCP server returned a malformed reply to a tool call has been patched. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **ExitWorktree deleting an active worktree (v2.1.330, Nov 20)**: A bug where `ExitWorktree` removed a git worktree still in use by another session has been fixed; the tool now confirms before removing worktrees with unsaved work. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Bash commands in zsh failing on words starting with `=` (v2.1.328, Nov 19)**: A zsh-specific parsing issue where Bash tool calls failed on arguments or tokens beginning with `=` has been corrected. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **High fix velocity across all releases**: Each release this week carried 90–98 individual bug fixes and improvements, with notable patches for large-conversation compaction freezes (v2.1.330), SSE MCP servers hanging after a dropped stream (v2.1.332), and hook output exceeding size limits causing freezes (v2.1.332). Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

## Community & Ecosystem

- **Security: credentials found in committed `.claude/` settings files**: A scan of public repositories reportedly found API keys and passwords embedded in committed `.claude/` settings files, where "Don't Ask Again" approval records had preserved the full shell commands users approved, including those containing secrets. The Claude Code team has acknowledged the issue and is investigating a fix. Users are advised to audit their `.gitignore` files and treat `.claude/settings.local.json` as sensitive. Source: [last30days.ai/research/claude-code](https://last30days.ai/research/claude-code)

- **`/status` command now shows configuration health (v2.1.327, Nov 17)**: The `/status` command was expanded to list broken agent, skill, and command files, keybinding parsing errors, and unavailable sandboxes — giving developers a single view of their Claude Code environment's health before starting a session. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Stricter `rm` safety for root and home directories (v2.1.330, Nov 20)**: More `rm` commands targeting the root directory, home directory, or the current working folder now require explicit user approval, reducing the blast radius of accidental or agentic deletions. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

## Roadmap & Announcements

- **Plugin marketplace auto-updates from November 30**: Starting November 30, 2026, plugin marketplaces declared in managed `extraKnownMarketplaces` settings will auto-update by default. Organizations that want to control update timing must add `"autoUpdate": false` to their marketplace entries before that date. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Computer use on macOS follows newer safety rules (v2.1.332, today)**: Computer use on macOS now enforces an updated set of safety constraints, which may cause some previously allowed actions to be refused. Anthropic has not yet published full details of the new rules. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **`computer-use` reserved as a skill name on Macs**: The name `computer-use` is now reserved for Claude Code's built-in computer-use skill on macOS, preventing conflicts with user-defined or MCP-provided skills of the same name. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

## Key Takeaway
Today's v2.1.332 release launching **Skills from MCP servers in public beta** is the standout development: it allows any MCP server to distribute reusable Claude Code skills directly through the `/` command menu, fundamentally expanding the ecosystem beyond first-party capabilities. Combined with the week's Code Mode expansion to all major cloud platforms and the `easel` charting mod, November 2026 marks a significant push toward Claude Code as a full platform, not just a CLI tool.

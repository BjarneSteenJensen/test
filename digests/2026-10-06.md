# Claude Code News Digest — 2026-10-06

## Overview
Claude Code shipped version 2.1.291 today, continuing a week-long release sprint that introduced the headline Claude Mods system on October 1 and has since delivered over 100 bug fixes and new SDK capabilities. The most significant theme of the week is extensibility: Mods give TypeScript developers deep hooks into Claude Code's behaviour, and new agent primitives (`agent.spawn`, `claude attach`) are maturing the multi-agent story.

## New Features & Releases

- **v2.1.291 (October 6)**: Today's release fixes two regressions — cloud sessions silently dropping answers to permission prompts, and messages being lost when quitting a session (introduced in 2.1.288). A small but impactful stability patch ahead of the weekend. Source: https://code.claude.com/docs/en/changelog

- **v2.1.290 (October 5) — Mods API expansion & Managed Agents onboarding**: A major update added `serverToolUses` to mod `turn.step` hook results (exposing API tool calls with timing data), `agentId` to `tool.check` events so mods can distinguish sub-agent permission checks, and a new `ceiling` field on permission prompts showing the required approval level. New `/claude-api managed-agents-onboard` commands streamline onboarding to the Managed Agents pattern. `claude attach <name>` and `claude logs <name>` now accept partial session names. Also fixed a long-standing bug where sessions with hundreds of images would get stuck on "Request rejected as unprocessable", and fixed `/loop` tasks not resuming after conversation compaction. Source: https://code.claude.com/docs/en/changelog

- **v2.1.289 (October 3)**: Added `agent.spawn` for teammates, enabling programmatic spawning of sub-agents in the SDK. Fixed deny/ask permission rules not applying through user-installed mods on managed machines, terminal freezing on code blocks with many unclosed `<script>` tags, and `Read` deny rules ignoring @-mentioned symlinked files. Source: https://code.claude.com/docs/en/changelog

- **v2.1.288 (October 2)**: Added `$.ui.selection()` for mods (returns selected text in fullscreen mode), built-in `gh api` access to cloud sessions without requiring the GitHub CLI, Ctrl+F to find sessions by name in the agents view, Alt+↑/↓ to jump between session groups, `--max-findings <n>|all` flag for `/code-review`, and Ctrl+C prompt recovery (press Up to restore cleared prompts). Source: https://code.claude.com/docs/en/changelog

- **v2.1.287 (October 1) — Claude Mods launch**: The biggest release of the week. Mods are TypeScript functions bundled inside plugins that can rewrite prompts, add custom UI, replace built-in features, or add entirely new functionality — and can be written by asking Claude Code to write them. Also added the `n:<text>` filter in the agents view for searching sessions by name/task. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **"You Should Know" built-in Mod**: Shipped alongside Claude Mods (v2.1.287), this first-party mod runs a side agent that watches your session and proactively flags things you or Claude might miss. Opt in with `/plugin enable cc-plugin-you-should-know@builtin` (requires first-party session with telemetry enabled). Source: https://code.claude.com/docs/en/changelog

- **MCP URL prompts expanded**: MCP URL-mode elicitation (letting MCP servers ask Claude Code to open a browser-based flow) now works on servers using the 2025-11-25 MCP protocol version, broadening the range of servers that can trigger browser-side authentication flows. Source: https://code.claude.com/docs/en/changelog

- **Community: Unofficial Claude Code for Visual Studio 2026**: A community-built extension (`firish/claude_code_vs`) adds Claude Code to Visual Studio 2026 with native diff windows, accept/reject for suggestions, a live debugger Claude can drive autonomously, Roslyn code navigation, and Test Explorer integration. Source: https://github.com/firish/claude_code_vs

## Bug Fixes & Performance

- **Permission rule consistency sweep (v2.1.289)**: Deny and ask rules were not consistently applied when routed through user-installed mods on managed machines. This is security-relevant on enterprise deployments where admins rely on deny rules to block sensitive file access. Fixed in v2.1.289. Source: https://code.claude.com/docs/en/changelog

- **Long-session image regression fixed (v2.1.290)**: Sessions accumulating hundreds of images would eventually freeze on an "unprocessable" error. Resolved in 2.1.290, which also fixed `WebFetch` silently truncating text past 100,000 characters. Source: https://code.claude.com/docs/en/changelog

- **Mid-response API timeout recovery (v2.1.288)**: Non-interactive sessions now continue from partial responses instead of failing on mid-response API timeouts — a meaningful reliability improvement for long-running headless jobs. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Barclays scales Claude Code enterprise-wide**: Anthropic published a case study on Barclays deploying Claude Code to accelerate software development and modernise legacy banking systems. The bank expects Claude Code to reach 50% of its developer population by end of 2026, with a majority of software engineers using it by 2027. Barclays' Group Co-COO framed it as embedding AI as "an increasingly agentic capability" in how the bank builds, tests, secures, and operates technology. Source: https://www.anthropic.com/news/barclays-scales-claude

- **Meta and Microsoft reduce internal Claude usage**: Both companies are pulling back on employee Claude access amid cost-cutting. Microsoft reportedly cut its internal Anthropic spending forecast by more than a third from an initial $10 billion target; Meta's Claude Code usage has declined due to layoffs and adoption of internal AI tools. Source: https://www.kucoin.com/news/flash/meta-and-microsoft-cut-employee-use-of-anthropic-s-claude-amid-cost-controls

- **Claude Agent SDK billing change (retroactive note)**: As of June 15, 2026, `claude -p` and Claude Agent SDK usage no longer counts toward Claude plan limits — making the agentic/headless use case more cost-predictable for developers on subscription plans. Source: https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan

## Roadmap & Announcements

- **Projects redesign (beta)**: Anthropic introduced a new beta experience for Claude Code projects that lets a single project coordinate parallel agent threads with shared memory. Users can describe what needs to get done and Claude manages the parallel workstreams — a significant step toward true multi-agent project management inside Claude Code. Source: https://releasebot.io/updates/anthropic/claude-code

- **Managed Agents onboarding commands**: v2.1.290 added `/claude-api managed-agents-onboard` commands, signalling continued investment in the Managed Agents pattern for teams running server-hosted agents. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
The launch of Claude Mods on October 1 — followed by four consecutive daily releases expanding the Mods API — marks a structural shift in Claude Code's extensibility model: Claude Code is now a platform developers can deeply customise and redistribute, not just a CLI they configure.

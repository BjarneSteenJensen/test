# Claude Code News Digest — 2026-09-13

## Overview
September 13 is the final day of Claude Code's +50% weekly-limits promotion; a permanent 25% increase over standard baseline limits takes effect tomorrow across Pro, Max, Team, and Enterprise plans. The past two weeks have also brought Claude Fable 5.1 as the new default model with 1M context, `claude plugin eval` for reproducible plugin scoring, organization-managed MCP servers, and Unity's first-party Claude Code plugin — making this one of the most feature-rich stretches in Claude Code's history.

---

## New Features & Releases

- **Claude Fable 5.1 now default in Claude Code (v2.1.257 — Sept 1)**: Fable 5.1 (`claude-fable-5-1`) ships with a 1M-token context window, $10/$50 per Mtok input/output pricing, and $0.25/Mtok cache-read pricing. It became the default Fable model immediately on install. Time-format and timezone settings were added in the same release (12-hour, 24-hour, UTC, or custom strftime patterns), along with a new Containment Escape auto-mode rule for stronger sandboxing. Source: https://code.claude.com/docs/en/changelog

- **`claude plugin eval` — reproducible plugin scoring (v2.1.269 — Sept 11)**: A new `claude plugin eval` command runs a plugin's eval suite against Claude Code and returns scored, reproducible results as both JSON and HTML reports. This makes it straightforward to benchmark plugins before shipping them and to track regressions across Claude Code versions. Source: https://code.claude.com/docs/en/changelog

- **`/output-style` and `/focus` view (v2.1.269 — Sept 11)**: A new `/output-style [name]` command lets users list and switch output styles from anywhere — including Remote Control and cloud/headless sessions. A new `/focus` view strips the interface to just the prompt, a one-line work summary, and Claude's response, reducing cognitive noise during deep work. Source: https://code.claude.com/docs/en/changelog

- **Diff panel for Bash edits and uncommitted changes (v2.1.260 — Sept 3, v2.1.269 — Sept 11)**: v2.1.260 added a diff panel that opens beside the conversation in fullscreen mode, showing uncommitted changes. v2.1.269 extended this further by appending a diff of files changed by Bash commands directly to the Bash tool result (opt-in via `bashEditDiffEnabled`). Source: https://code.claude.com/docs/en/changelog

- **Weekly limit permanent increase (effective Sept 14)**: Anthropic's +50% Claude Code weekly-limits promotion ends tonight (September 13, 11:59 PM PT). Starting September 14, standard weekly limits are permanently raised by 25% over the pre-promotion baseline for all Pro, Max, Team, and seat-based Enterprise plans. A new `/limit-reset` command was also introduced to reset the 5-hour session limit once per week. Source: https://releasebot.io/updates/anthropic/claude-code

## Integrations & Extensions

- **`managedMcpServers` — org-wide HTTP/SSE MCP servers (v2.1.259 — Sept 2)**: Organizations can now push HTTP/SSE MCP servers to every user automatically via the new `managedMcpServers` managed setting. This removes the need for individual users to configure shared company tools, and `allowedMcpServers` now governs only user-added servers independently. Source: https://code.claude.com/docs/en/changelog

- **Unity official first-party Claude Code plugin (Sept 10)**: Unity shipped an official, first-party Claude Code plugin distributed through Claude's plugin directory, bundling 29 native Unity skills. This is a major milestone for game-dev integration, enabling Claude Code to directly understand and manipulate Unity projects. Source: https://www.explainx.ai/blog/claude-code-unity-mcp-guide-2026

- **VSCode: agent map, hooks dialog, permission rules dialog (v2.1.269 — Sept 11)**: The VS Code extension gained an agent map (an "N agents" footer pill that opens a map of the session's sub-agents with per-agent cards), a Hooks dialog for viewing/adding/removing hooks in settings, and a Permission Rules dialog for listing and managing rules — all without leaving the IDE. Source: https://code.claude.com/docs/en/changelog

- **MCP SSE fallback fix (v2.1.265 — Sept 8)**: MCP servers configured as `http` that only speak the legacy HTTP+SSE transport were silently failing to connect. Claude Code now falls back to SSE as the MCP spec describes, restoring compatibility with older MCP servers without configuration changes. Source: https://code.claude.com/docs/en/changelog

- **OpenTelemetry VCS tagging and metrics (v2.1.269 — Sept 11)**: `OTEL_METRICS_INCLUDE_REPOSITORY` tags OpenTelemetry metrics and events with `vcs.*` repository attributes, making it much easier to slice telemetry data by repository in observability platforms. Source: https://code.claude.com/docs/en/changelog

## Bug Fixes & Performance

- **Critical HTTP 400 regression fixed (v2.1.268 — Sept 10)**: Every turn was failing with HTTP 400 on third-party Anthropic-compatible endpoints since v2.1.265 due to a regex in the Artifact tool input schema. Fixed in v2.1.268 with no configuration change required. Source: https://code.claude.com/docs/en/changelog

- **Sustained high CPU in idle sessions fixed (v2.1.268 — Sept 10)**: A busy loop was pinning a CPU core in long-running idle sessions. This is now resolved, significantly reducing CPU usage for users who keep sessions open for extended periods. Source: https://code.claude.com/docs/en/changelog

- **macOS 12 launch failure and remote session fix (v2.1.258 — Sept 1)**: A regression in v2.1.255 prevented Claude Code from launching on macOS 12 (Monterey). v2.1.258 restored launch on older Macs and also fixed remote/scheduled sessions failing with "user messages must have non-empty content" after a permission re-send. Source: https://code.claude.com/docs/en/changelog

- **Prompt-cache stability improvements across many releases**: Multiple releases this month fixed prompt-cache invalidation on OAuth token refresh, prompt-cache misses in cloud sessions, cache partial invalidation on cut-off responses, and cache reuse after interruptions — substantially improving cache hit rates and reducing costs in long sessions. Source: https://code.claude.com/docs/en/changelog

- **Regression fix: git read-only permission prompts (v2.1.270 — Sept 12)**: Read-only git commands in Bash were unexpectedly prompting for permission after a session had been running for a while, a regression introduced in v2.1.269. Fixed immediately in v2.1.270. Source: https://code.claude.com/docs/en/changelog

It includes reference implementations for retail, travel, telecom, and ticketing platforms — using the Messages API, Agent SDK, or Claude Managed Agents. Source: https://releasebot.io/updates/anthropic/claude-code

- **Compliance API session endpoints GA**: The Compliance API session endpoints came out of beta for Cowork and Claude Code sessions, and Admin API support was added in the `ant` CLI and multiple SDKs, simplifying enterprise auditing workflows. ## Roadmap & Announcements

- **Claude Fable 5.1 and Mythos 5.1 model pair (Sept 1)**: Anthropic released Claude Fable 5.1 and Claude Mythos 5.1 as an identical model pair with different safeguard levels, targeting coding, knowledge work, and scientific research. The distinction lets organizations choose a safeguard tier without changing model capability. Source: https://releasebot.io/updates/anthropic/claude

- **`/skill-doctor` diagnostics command (v2.1.261 — Sept 4)**: A new `/skill-doctor` command shows unused skills and their context cost, helping developers audit and trim their plugin/skill configurations to optimize token usage. Source: https://code.claude.com/docs/en/changelog

- **Concurrent agent limit now configurable (v2.1.269 — Sept 11)**: `CLAUDE_CODE_WORKFLOW_MAX_CONCURRENT_AGENTS` (range 1–256) allows raising the Workflow tool's per-run concurrent agent limit, enabling much larger parallel workflows for users who need to scale out. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
The single most impactful development this week is the end of the temporary +50% usage-limit promotion and its replacement — starting tomorrow, September 14 — with a permanent 25% increase over the standard baseline for all paid plans; combined with Claude Fable 5.1's 1M-context window becoming the default, Claude Code's effective capacity for large-codebase work has grown substantially and durably this month.

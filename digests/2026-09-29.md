# Claude Code News Digest — 2026-09-29

## Overview
The biggest story today is the release of **Claude Sonnet 5.5** (September 28), which is 30% faster and up to 30% cheaper than Sonnet 5 with a 1M-token context window — it became the new default Sonnet model in Claude Code v2.1.284 overnight. This caps a week of rapid-fire releases that also shipped Opus 5.5, a dedicated Plugin developer portal, AGENTS.md support, and a cascade of stability fixes across sessions, MCP, and the gateway.

## New Features & Releases

- **Claude Sonnet 5.5 lands as new default (v2.1.284, Sep 28)**: `claude-sonnet-5-5` replaces Sonnet 5 as the default Sonnet model. It offers a 1M-token context window at $2/$10 per MTok (cache reads $0.20/MTok) — 30% faster and up to 30% cheaper than its predecessor. Also in this release: a "Yes, but ask again next time" option for auto mode read-permission prompts, dollar-amount spend tracking in `/usage` and the status line (e.g. "$271.40 / $500.00 spent"), `/mcp reconnect all` to retry all failed MCP servers at once, and certificate client authentication (`private_key_jwt`) for gateway identity providers. Source: https://code.claude.com/docs/en/changelog

- **Claude Opus 5.5 released (v2.1.280, Sep 22)**: `claude-opus-5-5` becomes the new default Opus model with a 1M-token context window at $4/$20 per MTok and $0.20/MTok cache reads — matching Fable 5.1 on most tasks while costing 40% less than Opus 5 to run. Also added: mouse support for fullscreen lists (`/skills`, `/plugin`), `CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH` environment variable to raise the 2,048-char MCP description cap, and improved `/permissions` UX. Source: https://code.claude.com/docs/en/changelog

- **`claude plugin eval` ships (v2.1.269, Sep 11)**: Week 37 introduced a new `claude plugin eval` command to run a plugin against a suite of test cases, score the results, compare against a no-plugin baseline, and generate JSON/HTML reports. `claude plugin eval init` auto-drafts test cases and graders. Same week: any Claude Code Desktop pane can be popped out into its own window; `maxEffortLevel` setting caps effort on every provider; WebFetch now fails fast (5-minute timeout) instead of hanging. Source: https://code.claude.com/docs/en/whats-new

- **AGENTS.md support (v2.1.277, Sep 18)**: Claude Code now reads `AGENTS.md` in projects that don't have a `CLAUDE.md`, providing a common entry point for projects that use multiple AI coding agents. Configurable under "Project instructions" in `/config`. Source: https://code.claude.com/docs/en/changelog

- **`/doctor prompt-audit` (v2.1.283, Sep 25)**: New sub-command audits `CLAUDE.md` files, skills, agents, and commands for prompting patterns that work poorly with older models, helping teams migrate smoothly to new model defaults. Source: https://code.claude.com/docs/en/changelog

- **Pro/Team Standard default model upgraded to Opus (v2.1.282, Sep 24)**: Anthropic changed the default model on Pro and Team Standard plans from Sonnet to Opus, giving those subscribers access to more capable reasoning without a manual model switch. Source: https://code.claude.com/docs/en/changelog

- **Weekly usage limit change (Sep 14)**: The 50% higher Claude Code weekly limit promotion ended on September 14; it was replaced with a permanent 25% increase over standard weekly limits. Source: https://explainx.ai/blog/anthropic-claude-code-limits-17-percent-cut-september-2026-august-2026

## Integrations & Extensions

- **Xcode 26.3 + Claude Agent SDK integration**: Apple's Xcode 26.3 (released as a developer RC) now natively integrates the Claude Agent SDK, giving iOS/macOS developers full subagent support, background tasks, and plugin capabilities directly inside Xcode. Claude can capture SwiftUI Previews to self-correct UI, explore entire project structures autonomously, and search Apple developer documentation. Source: https://www.anthropic.com/news/apple-xcode-claude-agent-sdk

- **Plugin developer portal launched (Sep 26)**: Anthropic shipped a dedicated developer portal for Claude plugins with directory submission, auto-validation, review status tracking, publishing controls, and post-launch analytics. The portal also supports MCP 2.0, MCP Apps (interactive UI inside chat), and Enterprise Managed Auth for zero-touch OAuth. Source: https://app.stationx.net/articles/claude-code-september-2026

- **VS Code extension: timestamps and Ultracode toggle**: v2.1.284 added optional timestamps above prompts/responses (via the "Claude Code: Show Message Timestamps" setting) and an Ultracode on/off switch under the effort slider. Plugin load errors now surface inline on the Manage Plugins panel. Source: https://code.claude.com/docs/en/changelog

- **Server-side auto mode classifier (v2.1.278, Sep 19)**: Auto mode on the direct Claude API, Enterprise, Bedrock, Vertex, Foundry, and gateway paths now defaults to a server-side classifier that incurs no token overhead. Opt out with `CLAUDE_CODE_AUTO_MODE_SERVER=0`. `/status` shows an "Auto mode server" row indicating where the classifier runs. Source: https://code.claude.com/docs/en/changelog

- **Fast mode in Remote sessions (v2.1.271, Sep 14)**: Fast mode (Opus with faster output) now works in Claude Code Remote sessions running on cloud and self-hosted runners. Source: https://code.claude.com/docs/en/changelog

- **MCP adoption hits 95.3%**: Claude Code achieved 95.3% MCP server adoption among active sessions, up from 0% in late July, driven by MCP 2.0 support (stateless core), MCP Apps, and Enterprise Managed Auth. Source: https://lucaberton.com/blog/mcp-adoption-by-client-2026/

## Bug Fixes & Performance

- **Session resume stability (v2.1.281–2.1.283)**: Multiple critical fixes landed across three releases: resumed sessions no longer re-send earlier messages in changed form (which was breaking prompt cache), very large sessions now restore full context instead of only the last few messages, and MCP tool calls in resumed sessions no longer fail with "No such tool available". Source: https://code.claude.com/docs/en/changelog

- **Compaction improvements (v2.1.282–2.1.284)**: "Prompt is too long" errors no longer persist after compaction — Claude now compacts multiple times if needed. Compaction also no longer fails silently when summarization is refused; it retries on a fallback model instead. Source: https://code.claude.com/docs/en/changelog

- **Auto mode safety hardening (v2.1.281, Sep 23)**: Fixed a security issue where recursive `rm` targeting command-substitution output was running unprompted in auto mode. Also fixed permission rules with NUL bytes being treated as wildcards, and workspace trust dialogs reappearing after renderer switches. Source: https://code.claude.com/docs/en/changelog

- **Damaged response stream recovery (v2.1.284)**: Raw API error strings that were leaking into responses when streams were damaged are now caught and either retried transparently or reported as "interrupted" rather than corrupting the conversation. Source: https://code.claude.com/docs/en/changelog

- **Claude Tag (Slack) duplicate reply fix (v2.1.284)**: Fixed a bug where Claude Tag would occasionally post the same reply twice when interrupted mid-reply. Also fixed channel routines stopping in private channels with changed Slack IDs. Source: https://code.claude.com/docs/en/changelog

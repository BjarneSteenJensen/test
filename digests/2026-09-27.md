# Claude Code News Digest — 2026-09-27

## Overview
This week in Claude Code was headlined by the release of **Claude Opus 5.5** as the new default Opus model (v2.1.280, September 22), bringing a 1M-token context window and a 40% cost reduction versus Opus 5. Alongside the model upgrade, the tool saw a productive stretch of quality-of-life improvements: auto mode switching to a server-side classifier, AGENTS.md support, MCP URL-mode elicitation for browser-based auth, and Bedrock guardrail integration — all shipped in the v2.1.275–v2.1.283 range.

---

## New Features & Releases

- **Claude Opus 5.5 becomes default Opus model (v2.1.280, Sep 22)**: `claude-opus-5-5` is now the default Opus model in Claude Code, offering a 1M-token context window at $4/$20 per MTok with $0.20/MTok cache reads — roughly 40% cheaper than Opus 5 while matching its performance on most tasks. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **AGENTS.md support (v2.1.277, Sep 18)**: Claude Code now reads `AGENTS.md` as a project-instructions file when `CLAUDE.md` is not present, improving interoperability with codebases that already use the `AGENTS.md` convention from other AI coding tools. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **`/doctor prompt-audit` command (v2.1.283, Sep 25)**: The new `/doctor prompt-audit` sub-command lets you inspect and audit the prompt being sent to the model, making it easier to diagnose why a session is behaving unexpectedly or consuming excess tokens. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **`maxProseWidth` and `allowClaudeInChromeWithManagedMCP` settings (v2.1.282, Sep 24)**: Two new managed settings give admins fine-grained control — `maxProseWidth` caps the width of prose output, and `allowClaudeInChromeWithManagedMCP` gates the Claude in Chrome extension for managed deployments. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Auto mode defaults to server-side classifier (v2.1.278, Sep 19)**: Auto mode now routes permission decisions through the server-side classifier by default, improving consistency across machines and enabling better audit trails via the new `/status` server row. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Week 37 Digest — `claude plugin eval` (Sep 7–11)**: The plugin evaluation command lets you run a plugin against a test-case suite, score results, and compare against a no-plugin baseline. `claude plugin eval init` auto-drafts the cases and graders. Also shipped: pop-out panes in Claude Code Desktop, the `maxEffortLevel` setting, and a WebFetch 5-minute timeout. Source: [Claude Code What's New](https://code.claude.com/docs/en/whats-new)

## Integrations & Extensions

- **MCP URL-mode elicitation (v2.1.281, Sep 23)**: Claude Code now supports MCP URL-mode elicitation for browser-based authentication flows, making it easier to sign in to OAuth-gated MCP servers without leaving the terminal. Combined with MCP tool outputs being added to OpenTelemetry span events (v2.1.283), observability for MCP-heavy workflows has improved significantly. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Amazon Bedrock guardrail and `assume_role` support (v2.1.281, Sep 23)**: Claude Code on Bedrock upstreams gains both `guardrail` support (applying Bedrock content guardrails to requests) and `assume_role` for IAM-based authentication, making enterprise Bedrock deployments easier to secure. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Claude plugin developer portal launched (Sep 26)**: Anthropic shipped a dedicated developer portal for Claude plugins, giving plugin authors one place to submit a plugin, track its review status, and see installation analytics. Source: [Claude Code IDE Extension – September 2026 search results](https://www.explainx.ai/blog/claude-code-vscode-ide-extension-setup-guide-2026)

- **Claude Code fastest-adopting MCP client (95.3% adoption)**: A September analysis of MCP client adoption across developer tools puts Claude Code at 95.3% adoption — up from near-zero in late July — driven by the tool's core value proposition of tool use via the MCP protocol. Source: [MCP Adoption by Client 2026](https://lucaberton.com/blog/mcp-adoption-by-client-2026/)

## Bug Fixes & Performance

- **Fixed 400 errors in conversations (v2.1.282, Sep 24)**: A bug causing every request to fail with a `400` error in certain conversation states was resolved, along with fixes for continued/resumed sessions re-sending messages and a crash in the `redacted_thinking` block handler. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Fixed auto mode retrying indefinitely (v2.1.280, Sep 22)**: Auto mode could enter an infinite retry loop; this is now capped and handled gracefully. Also fixed: symlinked path write judgement, Ctrl+C/Ctrl+D behavior in dialogs, and mouse support added to fullscreen lists. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Regression hotfix for 400 errors (v2.1.276, Sep 18)**: A same-day patch fixed a regression introduced in v2.1.275 that caused every request to fail with `400 … Input tag 'advisor_20260301'`. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **VS Code extension logout and startup fixes**: Recent VS Code extension updates resolved unexpected logouts when an older Claude Code build runs on the same machine, and fixed interactive startup problems for users authenticating via `ANTHROPIC_API_KEY`. Source: [Claude Code VS Code Extension – September 2026](https://www.eesel.ai/blog/claude-code-vs-code-extension)

# Claude Code News Digest — 2026-09-07

## Overview
Claude Code released five versions this week (v2.1.257–2.1.263), headlined by the addition of Claude Fable 5.1 as the new default Fable model and a sweeping v2.1.261 update adding org-policy diagnostics, larger output limits, and extensive VS Code and Remote Control fixes. Anthropic also confirmed that the +50% weekly-limits promotion ends September 14, to be replaced by a permanent 25% increase for all paid plans.

## New Features & Releases

- **Claude Fable 5.1 is now the default Fable model (v2.1.257, Sep 1)**: `claude-fable-5-1` brings 1M context at $10/$50 per Mtok ($0.25/Mtok cache reads) and is now the model resolved by the `fable` and `best` aliases. The release also added "Time format" and `timeZone` settings so timestamps in the transcript and turn-end status line can be shown in the user's local timezone. Source: https://code.claude.com/docs/en/changelog

- **Fullscreen diff panel via `/diff` (v2.1.260, Sep 3)**: A new `/diff` toggle opens a fullscreen side-by-side diff panel next to the conversation, making it easier to review pending file edits without switching windows. The same release also added likely-cause hints for prompt-cache misses to `/cost` and the status line. Source: https://code.claude.com/docs/en/changelog

- **`/skill-doctor` and larger output limits (v2.1.261, Sep 4)**: `/skill-doctor` identifies unused skills and shows their token-context costs so users can trim bloat. New `bashOutputMaxChars` and `taskOutputMaxChars` settings (up to 128K characters each) let users raise how much command and task output Claude receives inline before it is spilled to a file. A new `--append-subagent-system-prompt-file` flag reads subagent system prompts from disk, removing command-line length limits. Source: https://code.claude.com/docs/en/changelog

- **Containment Escape rule in auto mode (v2.1.257/259)**: Auto mode now enforces a Containment Escape rule that gates access to files outside the working directory, with a one-time prompt the first time Claude would read outside its sandbox. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **VS Code: MCP Servers dialog and custom output styles (v2.1.261, Sep 4)**: The VS Code extension gained Add/Remove server forms directly in its MCP servers dialog, eliminating the need to hand-edit settings JSON. A new "Build a custom style" walkthrough was added to the Output styles menu, and the session list received an "Archive session" right-click option and a hollow-ring indicator for sessions open in another window. Source: https://code.claude.com/docs/en/changelog

- **Xcode 26.3 integrates the Claude Agent SDK**: Xcode 26.3 shipped a native integration with the Claude Agent SDK — the same harness that powers Claude Code — giving Xcode developers access to subagents, background tasks, and plugins directly inside the IDE without leaving Xcode. Source: https://www.anthropic.com/news/apple-xcode-claude-agent-sdk

- **`managedMcpServers` for enterprise org-wide MCP (v2.1.259, Sep 2)**: Organizations can now push HTTP/SSE MCP servers to every user's Claude Code instance via the new `managedMcpServers` managed setting, centralizing MCP configuration without requiring per-user setup. The existing `allowedMcpServers` setting was scoped to govern only user-added servers. Source: https://code.claude.com/docs/en/changelog

- **GitLab merge-request recognition (v2.1.259, Sep 2)**: Claude Code now recognizes `glab mr create/merge/close/reopen/note/update` commands and renders GitLab merge requests as `MR !N` in the collapsed tool summary, matching the parity it already had for GitHub PRs. Source: https://code.claude.com/docs/en/changelog

## Bug Fixes & Performance

- **Concurrent sessions no longer clobber `~/.claude.json` (v2.1.259, Sep 2)**: A long-standing race condition where multiple simultaneous Claude Code sessions would silently revert each other's changes to `~/.claude.json` (erasing workspace trust, MCP config, and project state) has been fixed. Source: https://code.claude.com/docs/en/changelog

- **macOS Monterey launch failure fixed (v2.1.258, Sep 1)**: Claude Code was failing to launch entirely on macOS 12 (Monterey); v2.1.258 targeted this as its sole focus. Source: https://code.claude.com/docs/en/changelog

- **Extensive Remote Control fixes (v2.1.261, Sep 4)**: Remote Control received several fixes: stale permission modes, sessions appearing stuck after phone/browser stop, TLS-inspecting corporate proxy failures, sessions showing default effort level on claude.ai, and `SendMessage` to offline sessions falsely reporting delivery — all resolved. Source: https://code.claude.com/docs/en/changelog

- **Rendering and performance improvements (v2.1.257–261)**: Across the week's releases: improved streaming performance by skipping re-checks of already-rendered blocks; improved rendering with message-row reuse; improved idle CPU usage in non-interactive sessions; improved auto-compact for 1M-context models; and improved terminal resize and render performance. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Self-hosted Claude Code environments in public beta**: Self-hosted Claude Code environments entered public beta for Team and Enterprise organizations, letting companies run Claude Code entirely within their own infrastructure rather than relying on Anthropic's cloud-hosted sessions. Source: https://releasebot.io/updates/anthropic/claude-code

- **Claude Agent SDK: Xcode integration signals broader IDE adoption**: Anthropic's rename of the "Claude Code SDK" to "Claude Agent SDK" in September 2025 was intended to signal the harness's broader applicability; the Xcode 26.3 integration is the clearest proof yet, with Apple shipping it as a first-class native feature rather than a third-party plugin. Source: https://www.augmentcode.com/tools/claude-code-vs-claude-agent-sdk

- **Improved GitLab support and `/code-review --comment` for GitLab MRs (v2.1.257)**: The `/code-review --comment` command now posts inline review comments on GitLab merge requests, extending a feature previously limited to GitHub PRs. Source: https://code.claude.com/docs/en/changelog

## Roadmap & Announcements

- **Weekly limits: permanent 25% increase replaces 50% promo on September 14**: Anthropic's +50% Claude Code weekly-limits promotion (extended four times) ends September 13 at 11:59 PM PT. Starting September 14, a permanent 25% increase over previous standard limits takes effect for Pro, Max, Team, and seat-based Enterprise plans. Source: https://aicatchup.com/news/claude-code-weekly-limits-permanent-25-percent-september-2026

- **`/limit-reset` weekly session-limit reset command**: A new `/limit-reset` command lets users reset their 5-hour session limit once per week (subject to the overall weekly cap), giving more flexibility when hitting mid-week limits on long tasks. Source: https://blog.mean.ceo/claude-code-news-september-2026/

- **Organization policy diagnostics in `/status` and `claude doctor` (v2.1.261)**: A new "Organization policy" line in `/status` and `claude doctor` now explains exactly why an org policy could not be loaded (e.g., a proxy blocking the endpoint), making enterprise troubleshooting significantly easier. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
The standout development this week is the combination of Claude Fable 5.1 becoming the default model (1M context, improved pricing) with the enterprise-focused `managedMcpServers` setting — together they signal Anthropic pushing Claude Code aggressively into team and enterprise workflows, backed by the concurrent self-hosted environment public beta.

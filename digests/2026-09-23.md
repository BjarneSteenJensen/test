# Claude Code News Digest — 2026-09-23

## Overview
The biggest story this week is the release of Claude Code v2.1.280, which introduces **Claude Opus 5.5** as the new default Opus model — bringing a 1M-token context window and reduced pricing ($4/$20/MTok). September has also seen major improvements to auto mode (now defaulting to a no-overhead server-side classifier), AGENTS.md support as an alternative to CLAUDE.md, fast mode in remote/cloud sessions, and a wave of VS Code extension enhancements including an agent map and new dialogs.

---

## New Features & Releases

- **Claude Opus 5.5 Default (v2.1.280, Sept 22)**: Anthropic released Claude Opus 5.5 (`claude-opus-5-5`) as the new default Opus model in Claude Code, with a 1M-token context window and pricing at $4/$20 per MTok with $0.20/MTok cache reads. The default model on Pro and Team Standard plans also changed from Sonnet to Opus. Source: https://code.claude.com/docs/en/changelog

- **Claude Fable 5.1 (Week 36, Sept 1–4, v2.1.251–v2.1.261)**: Claude Fable 5.1 became available in Claude Code with a 1M-token context window. It is now the default Fable model and offers advanced coding, knowledge work, and scientific research capabilities. Source: https://code.claude.com/docs/en/whats-new

- **`claude plugin eval` (v2.1.269, Week 37, Sept 7–11)**: A new `claude plugin eval` command lets you run a plugin against a suite of test cases, score the results, and compare against a no-plugin baseline. `claude plugin eval init` drafts test cases and graders automatically, outputting a JSON + HTML report. Source: https://code.claude.com/docs/en/changelog

- **AGENTS.md Support (v2.1.277, Sept 18)**: Claude Code now reads `AGENTS.md` as project instructions when `CLAUDE.md` is not present, improving interoperability with projects that use the AGENTS.md convention. Source: https://code.claude.com/docs/en/changelog

- **Weekly Usage Limits Raised 25% (Sept 14)**: Starting September 14, Anthropic permanently raised standard weekly limits in Claude Code by 25% for Pro, Max, Team, and seat-based Enterprise plans. Source: https://www.digitalapplied.com/blog/claude-code-weekly-limit-reduction-september-14

- **VS Code Extension: Agent Map & New Dialogs (v2.1.269, Sept 11)**: The VS Code extension gained a visual agent map showing all subagents with Stop and read-only transcript access. New dialogs were added for Hooks and Permission rules. Source: https://code.claude.com/docs/en/changelog

## Bug Fixes & Performance

- **Critical Proxy/Gateway Fix (v2.1.276, Sept 18)**: A critical regression from v2.1.275 that caused all requests to fail with a `400 … Input tag 'advisor_20260301'` error when `ANTHROPIC_BASE_URL` pointed to a proxy or gateway was fixed. Source: https://code.claude.com/docs/en/changelog

- **Auto Mode Denial Loop Fix (v2.1.280, Sept 22)**: Fixed a bug where auto mode would retry actions indefinitely after safety-check declinations; now uses backoff with a max of 10 retries before stopping. Source: https://code.claude.com/docs/en/changelog

- **Server-Side Auto Mode Classifier — No Overhead (v2.1.278, Sept 19)**: Auto mode for Claude API, Enterprise, Bedrock, Vertex, Foundry, and gateway users now defaults to the server-side classifier, which does not incur classifier overhead charges. Opt-out is available via `CLAUDE_CODE_AUTO_MODE_SERVER=0`. Source: https://code.claude.com/docs/en/changelog

- **MCP Reliability (v2.1.274, Sept 17)**: Added a visible warning for critical memory usage, added `CLAUDE_CODE_MCP_STARTUP_WAIT_MS` to bound how long sessions wait for MCP server connections, and fixed MCP prompts/resources not refreshing on list-changed notifications. Source: https://code.claude.com/docs/en/changelog

- **Background Session Fixes (v2.1.277, Sept 18)**: Fixed background sessions unable to use the LSP tool with active LSP plugins, background shell tasks incorrectly reporting benign exits as failures, and reduced Ctrl+C presses needed to exit with active background subagents (from 3–4 down to 2). Source: https://code.claude.com/docs/en/changelog

## Roadmap & Announcements

- **Claude Code Projects Beta**: Anthropic introduced a new beta experience for Claude Code Projects, letting one project coordinate parallel threads, shared memory, and a project library to manage long-running work across repos and tasks with less handoff and more progress steering. Source: https://code.claude.com/docs/en/whats-new

- **Enterprise Smart Reports Beta**: Claude launched smart reports in beta for Enterprise plans, automatically analyzing team usage, costs, friction points, and reusable shared skills. Available on Claude Enterprise plans. Source: https://releasebot.io/updates/anthropic/claude-code

- **Gateway Hint Headers (v2.1.273, Sept 15)**: Added `x-claude-code-*` request headers for LLM gateways (opt in via `CLAUDE_CODE_GATEWAY_HINT_HEADERS=1`), enabling better routing and observability for enterprise gateway deployments. Source: https://code.claude.com/docs/en/changelog

- **Fast Mode in Remote Sessions (v2.1.271, Sept 14)**: Fast mode is now available in cloud and self-hosted remote sessions, significantly speeding up work in those environments. Per-command `allowed_domains` in auto mode with sandboxing was also added for Bash, PowerShell, and Monitor tools. Source: https://code.claude.com/docs/en/changelog

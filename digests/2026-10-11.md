# Claude Code News Digest — 2026-10-11

## Overview
October 2026 has been an exceptionally active release period for Claude Code, with nine versions shipped (v2.1.288–2.1.296) between October 2–9 alone. The headline developments are the launch of Claude Haiku 5.5 as the new default Haiku model, a sweeping MCP protocol upgrade to version 2026-07-28, and a major security and reliability hardening pass that delivered over 300 combined bug fixes across the week.

## New Features & Releases

- **Claude Haiku 5.5 becomes default Haiku model (v2.1.293, Oct 7)**: Anthropic's newest small model (`claude-haiku-5-5`) is now the default Haiku model inside Claude Code. It supports a 1M-token context window and is priced at $0.10/$0.50 per million input/output tokens on the Anthropic API — significantly cheaper than its predecessor. Source: https://code.claude.com/docs/en/changelog

- **Effort parameter for Agent tool (v2.1.292, Oct 6)**: A new `effort` parameter on the Agent tool lets orchestrators control the reasoning depth a sub-agent runs at, enabling cost/quality tradeoffs within multi-agent workflows. Source: https://code.claude.com/docs/en/changelog

- **Program Status Protocol & onFailure hooks (v2.1.295, Oct 8)**: Added OSC 7501 (Program Status Protocol) support and an `onFailure: "block"` option for command and HTTP hooks, giving integrators finer control over failure handling. Source: https://code.claude.com/docs/en/changelog

- **`claude attach` and `claude logs` commands (v2.1.290, Oct 5)**: New CLI commands let users attach to a named agent or stream its logs, improving observability for long-running background agents. Source: https://code.claude.com/docs/en/changelog

- **autoCompactWindow for subagents & allow_large for Read tool (v2.1.296, Oct 9)**: Sub-agents now support automatic context-window compaction, and the Read tool gains an `allow_large` flag for reading oversized files when needed. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **MCP protocol upgraded to 2026-07-28 by default (v2.1.292–2.1.295)**: All MCP stdio connections now negotiate the new 2026-07-28 protocol revision by default, and claude.ai connectors also default to this version. The MCP tool-description character limit was raised from 2,048 to 4,096 characters (v2.1.296), and further to 16,384 characters for tool-search-loaded descriptions (v2.1.295). Source: https://code.claude.com/docs/en/changelog

- **Plugin marketplace install flag (v2.1.292, Oct 6)**: `claude plugin install --marketplace <source>` adds a new marketplace source and installs from it in one command, streamlining plugin discovery and distribution. Source: https://code.claude.com/docs/en/changelog

- **Prompt caching in mods (v2.1.292, Oct 6)**: `$.model.complete` in the mods API now supports prompt caching, reducing latency and cost for mod authors who call the model with repeated prefixes. Source: https://code.claude.com/docs/en/changelog

- **Agent SDK parity (v0.3.291)**: The Claude Agent SDK was updated to match Claude Code v2.1.291, picking up the permission-prompt regression fix and session-message-loss fix. The TypeScript SDK now leaves an omitted `permissionMode` to Claude Code's configured default rather than forcing `default`. Source: https://www.gradually.ai/en/changelogs/claude-agent-sdk/

- **Built-in `gh api` for cloud sessions (v2.1.288, Oct 2)**: Cloud sessions without the GitHub CLI installed now have a built-in `gh api` stub, removing a common setup friction point for remote workflows. Source: https://code.claude.com/docs/en/changelog

## Bug Fixes & Performance

- **Hook security hardening (v2.1.294, Oct 8)**: Fixed a critical issue where `prompt` and `agent` hooks written as natural-language instructions could be manipulated into allowing actions they should block. Also improved Stop/SubagentStop prompt-hook scoring so Claude stops early less often. Source: https://code.claude.com/docs/en/changelog

- **Security fixes in v2.1.292 (Oct 6)**: Patched UNC-path reads, a tampered managed-settings cache vulnerability, and `rm -rf` on alternate Windows home paths — the most significant security-focused release in the October batch. Source: https://code.claude.com/docs/en/changelog

- **Session-continuity regressions fixed (v2.1.291, Oct 6)**: Two regressions introduced in v2.1.288/2.1.290 were hotfixed: cloud sessions could silently drop permission-prompt answers, and the last messages of a session could be lost on quit. Source: https://code.claude.com/docs/en/changelog

- **Sonnet 5.5 cache-read price halved (v2.1.296, Oct 9)**: Cache reads for Claude Sonnet 5.5 are now priced at $0.10/M tokens (down from $0.20/M), making cached multi-turn workflows considerably cheaper. Source: https://code.claude.com/docs/en/changelog

- **v2.1.290 mega-fix (Oct 5)**: The largest single bug-fix batch of the period — 131 fixes — covering gateway, MCP, plugin panes, Windows, and cloud-session edge cases. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Claude Code Projects opens to waitlist (Oct 9)**: Anthropic's Projects feature, which lets teams share CLAUDE.md context, memory, and agent configurations across sessions, began rolling out to all Pro and Max subscribers on the waitlist on October 9, following a September 17 beta. Source: https://pasqualepillitteri.it/en/news/22116/claude-code-projects-lista-attesa-pro-max-en

- **Cloud sessions field guide published (Oct 5)**: Anthropic posted a detailed field guide on running Claude Code in fully managed cloud sessions with GitHub integration, covering setup, networking, and use cases for autonomous coding workflows. Source: https://releasebot.io/updates/anthropic/claude-code

- **Mods ecosystem grows (launched Oct 1, v2.1.287)**: The mods system — small TypeScript functions that can rewrite prompts, add UI panels, or replace built-in CLI behaviors — continues to expand. A built-in "You should know" side-agent mod ships by default, and Team/Enterprise plans get a `sec-default` security mod that loads first in every session. Source: https://releasebot.io/updates/anthropic/claude-code

- **MCP 2.0 extensions in the developer portal**: Anthropic's plugin developer portal now supports MCP 2.0 extensions for richer plugin experiences, with review tracking, auto-validation, and post-launch usage analytics for plugin authors. Source: https://releasebot.io/updates/anthropic/claude-code

## Roadmap & Announcements

- **Max and Team plans gain monthly API credits (Oct 7)**: Anthropic announced that Claude Max and Team subscribers now receive a monthly allocation of API credits, covering the Claude Agent SDK, `claude -p` one-shot mode, the Claude API, and Claude Managed Agents — blurring the line between the consumer product and the developer platform. Source: https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan

- **Managed agents onboarding command (v2.1.290, Oct 5)**: A new `/claude-api managed-agents-onboard` command streamlines the setup flow for Anthropic's hosted Managed Agents service, signaling continued investment in server-side agent infrastructure. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
The single most consequential development of the week is the hook-security hardening in v2.1.294: the discovery that hooks written as natural-language instructions could be manipulated to bypass their own access controls is a meaningful prompt-injection mitigation, and its rapid turnaround (patched within the same release cycle it was found) reflects the security posture Anthropic is bringing to Claude Code as it moves toward production use in enterprises.

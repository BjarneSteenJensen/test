# Claude Code News Digest — 2026-09-24

## Overview
The past 48 hours have been among the most significant in Claude Code's recent history: Anthropic released Claude Opus 5.5 as the new default Opus model on September 22 (v2.1.280) and followed it immediately with a sweeping v2.1.281 hotfix on September 23 addressing streaming, gateway, and MCP reliability. Meanwhile, the Claude Marketplace officially launched on September 23, giving developers a single destination to discover plugins, agents, and partner services.

---

## New Features & Releases

- **Claude Opus 5.5 is now the default Opus model (v2.1.280, September 22)**: `claude-opus-5-5` lands with a 1M-token context window at $4/$20 per MTok input/output and $0.20/MTok cache reads — roughly 40 % cheaper than Opus 5. Pro and Team Standard plans now default to Opus instead of Sonnet. Fast mode is also available in cloud sessions on eligible plans.
  Source: https://code.claude.com/docs/en/changelog

- **v2.1.281 gateway & streaming hardening (September 23)**: The same-day patch adds IAM role assumption for cross-account Bedrock STS, Bedrock Guardrails configuration, URL-mode elicitation for MCP 2026-07-28 protocol, and critical fixes for crashes during API retries, tool calls running twice on duplicate stream events, and stop-reason loss behind proxies.
  Source: https://code.claude.com/docs/en/changelog

- **Server-side auto mode classifier is now the default (v2.1.278-279, September 19-20)**: Auto mode now routes permission checks to Anthropic's server-side classifier for Claude API, Enterprise, and major cloud-provider users — eliminating the overhead charge that the local classifier incurred. Set `CLAUDE_CODE_AUTO_MODE_SERVER=0` to keep the local classifier. A new "Auto mode server" row in `/status` shows which classifier is active.
  Source: https://code.claude.com/docs/en/changelog

- **AGENTS.md support (v2.1.278, September 18)**: Claude Code now reads `AGENTS.md` as project instructions when `CLAUDE.md` is absent, enabling teams that already maintain an `AGENTS.md` convention to skip a renaming step.
  Source: https://code.claude.com/docs/en/changelog

- **Send-now key (v2.1.275, September 17)**: `Ctrl+Enter` (or `Ctrl+X Ctrl+S`) interrupts the current turn and dispatches all queued messages immediately — useful when you want to course-correct mid-task without waiting for the turn to complete.
  Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **VS Code extension gains six new dialogs (v2.1.280, September 22)**: The extension adds `/status`, `/sandbox`, `/chrome`, `/export`, `/skills`, and `/plan` dialogs, a Copy-response button, automatic archival notices for inactive sessions with one-click unarchive, and pasted-text handling improvements for long pastes. An effort-chip stale-level bug is also fixed.
  Source: https://code.claude.com/docs/en/changelog

- **Skills and plugins now sync from claude.ai to terminal sessions (v2.1.275, September 17)**: Skills and plugins enabled on your claude.ai account are automatically mirrored into CLI and terminal sessions. Opt out per type with `syncClaudeAiSkills: false` or `syncClaudeAiPlugins: false` in settings.
  Source: https://code.claude.com/docs/en/changelog

- **Claude Marketplace launches (September 23)**: Anthropic opened a single storefront for plugins, agents, and partner services. The marketplace offers `claude plugin install <plugin> --marketplace <source>` as the install surface and integrates directly into Claude Code's plugin system.
  Source: https://claude.com/blog-category/announcements

- **MCP adoption reaches 95.3% among Claude Code users (September 2026)**: Claude Code is now the fastest-adopting MCP client among developer tools, climbing from 0 % in late July to 95 % in mid-September. Two new MCP environment variables ship alongside this milestone: `CLAUDE_CODE_MCP_STARTUP_WAIT_MS` (bound server wait time) and `CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH` (override the 2,048-character cap on tool descriptions).
  Source: https://code.claude.com/docs/en/changelog

- **Community VS extension for Visual Studio 2026 (September 2026)**: A community-built, unofficial extension (`firish/claude_code_vs`) brings Claude Code's diff-accept/reject workflow, a live debugger Claude can drive autonomously, Roslyn code navigation, and Test Explorer integration to Visual Studio 2026.
  Source: https://github.com/firish/claude_code_vs

## Bug Fixes & Performance

- **Critical data-integrity fixes across v2.1.276–v2.1.277 (September 18)**: v2.1.276 was a same-day hotfix for a regression in v2.1.275 that caused every request to fail with a `400 Input tag 'advisor_20260301'` error behind proxies or gateways. v2.1.277 followed with fixes for sessions resuming with altered turn history, prompt cache loss on MCP disconnect, and headless/SDK sessions hanging after internal errors.
  Source: https://code.claude.com/docs/en/changelog

- **Auto mode permission-check loop fixed (v2.1.280)**: Auto mode was retrying safety-check-declined actions indefinitely or issuing repeated denials without pause. Both loops are now bounded, and sandboxed Bash `excludedCommands` matching is corrected.
  Source: https://code.claude.com/docs/en/changelog

- **Recursive `rm` prompt restored in auto/dangerously-skip modes (v2.1.281)**: A regression allowed `rm -rf` commands constructed via command substitution to bypass the confirmation prompt. The prompt is restored; set `CLAUDE_CODE_DISABLE_SUBSTITUTION_RM_PROMPT=1` to opt out if needed.
  Source: https://code.claude.com/docs/en/changelog

- **Session startup and resume performance improvements (v2.1.278-279)**: The first turn no longer blocks on per-directory CLAUDE.md lookup; restored file-cache matching accelerates long-session resumes; and very long compacted sessions resume faster. Auto mode also reuses its classifier prompt cache across resumes.
  Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **`claude plugin eval` ships in Week 37 (September 7–11, v2.1.263–v2.1.269)**: Developers can now run their plugin against a suite of test cases, score results, and benchmark against a no-plugin baseline. `claude plugin eval init` auto-drafts cases and graders.

- **Commerce agent blueprint published**: Anthropic released a reference shopping-and-merchant-agent blueprint with guardrails, live demos, and a Claude Code plugin to help teams build AI-powered commerce experiences across retail, travel, telecom, and ticketing.
  Source: https://releasebot.io/updates/anthropic/claude-code

## Roadmap & Announcements

- **Claude Marketplace now live (September 23, 2026)**: The marketplace is the first formal distribution channel for Claude Code plugins and partner agents. It signals Anthropic's intent to build a broader ecosystem around Claude Code beyond first-party tools, with third-party developers able to publish and monetize extensions.
  Source: https://claude.com/blog-category/announcements

- **Claude Opus 5.5 pricing undercuts Opus 5 by ~40% (September 22)**: At $4/$20 per MTok and $0.20/MTok cache reads, Opus 5.5 makes Anthropic's most capable model meaningfully more accessible for production workloads. The 40% cost reduction over Opus 5 on typical loads, combined with 20% lower API input/output prices and 60% lower cache-read prices, is likely to accelerate enterprise adoption of Claude Code's Opus-tier features.
  Source: https://releasebot.io/updates/anthropic/claude

- **Compliance API session endpoints exit beta**: The Developer Platform released Compliance API session endpoints out of beta for Cowork and Claude Code sessions, expanded local session transcripts, and added Admin API support in the `ant` CLI and multiple SDKs — signalling continued enterprise-readiness investment.
  Source: https://releasebot.io/updates/anthropic/claude-developer-platform

## Key Takeaway
The launch of Claude Opus 5.5 on September 22 — with a 1M context window and ~40% cost reduction over Opus 5 — combined with the Claude Marketplace opening on September 23 marks a significant double-milestone: Anthropic is simultaneously making its most capable model more affordable for developers and establishing the infrastructure for a third-party plugin ecosystem around Claude Code.

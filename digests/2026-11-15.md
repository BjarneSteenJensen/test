# Claude Code News Digest — 2026-11-15

## Overview
This week in Claude Code is dominated by security news: a secrets-exposure incident affecting over 103,000 GitHub repositories and a confirmed malicious extension breach on the Cursor marketplace. On the product side, Anthropic shipped Claude Fable 5.2 as the new default model, introduced experimental Code Mode, and reached release v2.1.325 — a security-focused patch that also brings sandbox permission improvements and a VS Code notebook spinner.

## New Features & Releases

- **v2.1.325 (Nov 13) — Security & Sandbox Hardening**: 88 bug fixes, including a security patch for zstd-compressed response decoding. Sandboxed Bash commands now follow the normal permission prompt flow by default (opt-out with `autoAllowBashIfSandboxed: true`). Added `promptSuggestionEnabled: false` to disable prompt suggestions, and console sign-in in VS Code that creates no API key. Source: https://code.claude.com/docs/en/changelog

- **v2.1.323 (Nov 12) — Code Mode (Experimental)**: New opt-in "Code Mode" lets Claude write JavaScript to call its tools rather than using the standard tool-call format. Plugins that fall outside their declared `claude-code` version range are now blocked from installing or loading. Models with unrecognized IDs now assume a 1M context window (up from 200K). Source: https://code.claude.com/docs/en/changelog

- **v2.1.321 (Nov 9) — Claude Fable 5.2 Default**: Claude Fable 5.2 (`claude-fable-5-2`) is now the default Fable model: 1M context window, $8/$40 per million tokens input/output, $0.20/Mtok cache reads. The `/model` picker moves older models under a "More models" row. Source: https://code.claude.com/docs/en/changelog

- **v2.1.319 (Nov 6) — MCP Tasks & Permission Controls**: MCP server tool calls now run as background tasks in the terminal and report on completion. New `permissions.denyInsteadOfPrompting` flag denies tool calls that would trigger a permission prompt instead of pausing. Added `/claude-api latency-optimize` command to pinpoint latency in Claude API integrations. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **Fast Mode Expands to Vertex (v2.1.322, Nov 10)**: Fast mode is now available on Vertex AI in the global, US, and EU regions, with automatic fallback to standard speed if Vertex rejects it. Source: https://code.claude.com/docs/en/changelog

- **JetBrains Claude Code Chat 1.4.0 (Nov 11)**: The official Claude Code Chat plugin for JetBrains IDEs updated to support 2026.3 builds. The GUI-focused community plugin was separately rebranded from "Claude Code with GUI" to "Swttch" (v0.37.0, Nov 12). Source: https://plugins.jetbrains.com/plugin/31507-claude-code-chat

- **IDE Extension Install Behavior Changed (v2.1.318, Nov 3)**: Claude Code no longer auto-installs or updates the VS Code or JetBrains extension when launched from an IDE terminal. Users should run `/ide` from an external terminal or use the editor's extensions view. Source: https://www.gradually.ai/en/changelogs/claude-code/

- **MCP URL Consent Cards (v2.1.317, Nov 3)**: When an MCP server asks Claude Code to open a URL in a cloud session, a link card is now shown so users can accept or decline the navigation. Source: https://jigarjoshi.in/blog/november-03-claude-code-2-1-317-mcp-security-2026/

## Bug Fixes & Performance

- **195 Bug Fixes in v2.1.323**: The largest single-release bug fix batch this month resolved numerous Bash permission-check gaps and sandboxing issues. The MCP v1 client was removed; set `MCP_SDK_GENERATION=v1` for compatibility mode. Source: https://code.claude.com/docs/en/changelog

- **Agent SDK `applyFlagSettings()` Silent-Discard Bug Fixed**: One invalid value in an `applyFlagSettings()` call was silently discarding all previously applied settings. This now surfaces as an error. Source: https://releasebot.io/updates/anthropic/claude-code

- **Login Outage (Nov 13, 09:58–11:05 UTC)**: An authentication incident took down claude.ai and Claude Code logins for approximately one hour. Anthropic deployed a fix within 67 minutes of the incident opening. Source: https://journalarta.com/en/2026/11/14/claude-status-login-problem-claude-ai-claude-code/

## Community & Ecosystem

- **OpenCode 2.2.3 Adds Claude Agent SDK Provider**: OpenCode added a provider that lets users run Claude through their own Claude Code subscription via the Agent SDK, eliminating the need for a separate API key for personal use. Source: https://cellcog.ai/blog/opencode-claude-subscription/

- **Claude Code Projects Update (Nov 13) — Proactive Coordinator**: Claude Code Projects received a more proactive coordinator mode, read-only thread sharing, reminders, and new `/btw` and `/fork` slash commands. Source: https://explainx.ai/blog/claude-code-projects-proactive-coordinator-november-2026

## Security Alerts

- **Secrets Leaked via `.claude/settings.local.json` on GitHub**: Security researchers at Apiiro and GitGuardian found that Claude Code's per-project settings file — `.claude/settings.local.json` — has been committed with live credentials to approximately 103,600 public GitHub repositories (~104,000 files total). Anthropic recommends adding this file to `.gitignore`. Source: https://casrai.org/news/claude-code-settings-local-json-secrets-github-2026

- **Malicious Claude Code Extension on Cursor Marketplace**: Cursor disclosed a security breach in which attackers pushed two malicious Claude Code extension versions (2.1.312 and 2.1.313) to its marketplace for approximately 11 hours in late October, following credential theft from AI infrastructure provider Fireworks AI. Source: https://www.bleepingcomputer.com/news/security/cursor-confirms-security-breach-led-to-malicious-claude-code-extension/

## Roadmap & Announcements

- **Opus 4.8 Fast Mode Deprecated — Removed Nov 30**: Fast mode for `claude-opus-4-8` was deprecated October 30, 2026, and will be fully removed on November 30, 2026. After removal, requests will return an error with no fallback; Anthropic recommends migrating to `claude-opus-5-5`. Source: https://code.claude.com/docs/en/changelog

- **MCP v1 Client Removed**: The original MCP v1 client has been removed in v2.1.323. Teams still on MCP v1 tooling should set `MCP_SDK_GENERATION=v1` to run the v2 client in compatibility mode. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
The most urgent development for Claude Code users today is the dual security news: over 100,000 GitHub repositories have accidentally committed credentials in `.claude/settings.local.json`, and a confirmed marketplace compromise briefly distributed malicious Claude Code extension builds — both issues requiring immediate action from affected teams.

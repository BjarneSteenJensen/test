# Claude Code News Digest — 2026-08-11

## Overview
The biggest story today is Anthropic's announcement that **auto mode will become the default permission mode for Pro, Max, and Team plans starting August 14**, replacing manual approval prompts with an AI classifier that blocks only irreversible or destructive actions. Alongside that, August's main release week (v2.1.224–227) shipped self-hosted cloud environments in public beta, cross-session messaging between Claude Code agents, and a slate of MCP and Remote Control fixes.

---

## New Features & Releases

- **Auto Mode Default — August 14 (Announced August 7)**: Anthropic announced auto mode will be enabled by default for all Pro, Max, and Team plan accounts beginning August 14. Instead of prompting for approval at each tool call, auto mode's classifier runs silently and only blocks actions deemed irreversible, destructive, or out-of-environment scope. The feature has been in research preview since March (v2.1.83). Source: [9to5Mac](https://9to5mac.com/2026/08/07/psa-claude-code-enabling-auto-mode-as-default-next-week-anthropic-says/) | [TechCrunch](https://techcrunch.com/2026/08/09/anthropic-is-turning-claude-codes-auto-mode-on-by-default/) | [Claude Code What's New](https://code.claude.com/docs/en/whats-new)

- **Self-Hosted Environments — Public Beta (v2.1.224, August 7)**: `claude self-hosted-runner` allows Team and Enterprise plan customers to run Claude Code web, mobile, and desktop sessions on their own infrastructure, enabling internal network access, custom tooling, and compliance controls. Supports both fixed and on-demand runners. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.227 (August 10)**: Latest release fixes feature-flag evaluation ignoring subscription tier for Max plan users (affecting Fable usage credits), Bash command failures under `claude-code-action` on GitHub-hosted runners, and `/tui` conversation-rewind behavior. The slash-command menu now bolds matched characters and preserves emoji/accented glyphs. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.225 (August 8)**: Added gateway spend-limit support to the usage warning (cap name, reset time, and operator message now displayed). Added workspace trust prompts for `claude agents` in untrusted directories. `SendMessage` can now start conversations with Remote Control sessions by name. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Integrations & Extensions

- **Cross-Session Messaging — `SendMessage` + `ListAgents` (v2.1.224, August 7)**: Claude Code sessions on macOS and Linux can now message each other directly. One session can pass a finding or decision to another via `SendMessage`, with `ListAgents` used for discovery. Settings `crossSessionInbound` and `dialogExpiry` control inbound message handling. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog) | [Claude Code What's New](https://code.claude.com/docs/en/whats-new)

- **VS Code Focus View (Week 32 — August 3–7)**: The VS Code extension received a new Focus view mode, accessible as a chat-menu toggle, that collapses tool activity behind expandable per-turn summaries with a live running-tool indicator — reducing visual noise during long agentic sessions. A bug causing Focus view to fold the latest to-do list and pending questions was fixed in v2.1.225. Source: [Claude Code What's New](https://code.claude.com/docs/en/whats-new)

- **Archive Plugin Source (v2.1.224, August 7)**: Plugins can now be installed from HTTPS `.zip` archives without requiring `git` or `npm`, with optional SHA-256 hash pinning for reproducible installs. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **MCP 2026-07-28 Spec Support**: Claude expanded support for the new MCP specification, delivering a stateless core, stronger OAuth and OIDC authorization, versioned extensions for Apps and Tasks, and new connector features including embedded UI, enterprise-managed auth, observability hooks, and private network tunnels. MCP SDK downloads surpassed 400 million per month — a 4× increase this year — cementing its status as the industry standard for connecting AI agents to applications. Source: [Claude Code MCP Search Results](https://www.gradually.ai/en/changelogs/claude-code/)

## Bug Fixes & Performance

- **Max Plan Feature Flag Fix (v2.1.227)**: Feature flags were being evaluated without the user's subscription tier when a session started with an expired login token — Max plan users could not access Fable usage credits. Fixed in the August 10 release. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **MCP OAuth / macOS Keychain Fix (v2.1.225)**: Fixed MCP OAuth servers on macOS intermittently returning 401 errors caused by keychain read timeouts. Also fixed a bug where a transient 401 would replace a long-lived `CLAUDE_CODE_OAUTH_TOKEN` with a stored login's short-lived token. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Auto Mode Safety Counter Fix (v2.1.225)**: Auto mode was incorrectly counting safety-filter refusals toward the consecutive-block limit, which could cause premature session termination. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Sandbox & Remote Control Fixes (v2.1.224)**: Fixed sandbox filesystem deny entries with trailing slashes being bypassable on Linux/macOS, sandbox violation details not appearing in Bash tool results, and Remote Control session recreation after expiry uploading stale prior history. Performance improved with fewer event-loop stalls on file-not-found suggestions and at-mention size checks. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

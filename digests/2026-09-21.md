# Claude Code News Digest — 2026-09-21

## Overview
This week (v2.1.270–v2.1.278) was one of Claude Code's most active release windows in September, shipping AGENTS.md support, server-side classifier for auto mode, `claude plugin eval`, and a wave of VSCode integration improvements. A critical security fix landed for the Bash permission checker, and MCP reliability saw multiple targeted fixes capping off a month that saw MCP adoption climb from near-zero to ~95%.

## New Features & Releases

- **AGENTS.md Support (v2.1.277, Sep 18)**: Claude Code now reads `AGENTS.md` as a fallback when no `CLAUDE.md` exists in a repo — making it easier to share project context across different AI coding tools. The same release added a "send-now" key (`ctrl+enter` or `ctrl+x ctrl+s`) to interrupt the current turn and deliver a queued message immediately. Source: https://code.claude.com/docs/en/changelog

- **`claude plugin eval` (v2.1.271, Sep 14)**: A new evaluation command lets you run your plugin against a scored, reproducible test suite and compare it against a no-plugin baseline; `claude plugin eval init` drafts test cases and graders automatically. Source: https://code.claude.com/docs/en/changelog

- **Claude Code Projects Beta**: One project can now coordinate parallel Claude Code threads with shared memory and a project library, so Claude manages long-running, multi-repo work without the user re-explaining context across threads. Source: https://code.claude.com/docs/en/whats-new

- **Auto Mode Server-Side Classifier (v2.1.278, Sep 19)**: For Claude API and Enterprise users, auto mode now defaults to the server-side classifier, eliminating classifier overhead charges. A new `Auto mode server` row in `/status` shows where classification is running. Source: https://code.claude.com/docs/en/changelog

- **`/output-style` Command (v2.1.271, Sep 14)**: A new slash command lets users list and switch named output styles (e.g., concise, verbose) mid-session, controllable from the prompt, `-p` mode, and Remote Control. Source: https://code.claude.com/docs/en/changelog

- **Weekly Limits Permanent Increase (Sep 14)**: The 50% promotional weekly limit increase that ran through mid-September ended on September 14 and was replaced by a permanent 25% increase for Pro, Max, Team, and Enterprise seat-based plans. Source: https://explainx.ai/blog/anthropic-claude-code-limits-17-percent-cut-september-2026-august-2026

## Integrations & Extensions

- **VSCode: Agent Map, Hooks Dialog, Permission Rules (v2.1.278, Sep 19)**: A significant VSCode extension update added an agent map view, a visual hooks configuration dialog, and a permission rules dialog, plus new Customize menu entries for Memory and Instructions. Source: https://code.claude.com/docs/en/changelog

- **Skill & Plugin Sync from claude.ai (v2.1.277, Sep 18)**: Skills and plugins enabled on a user's claude.ai account now sync automatically to terminal sessions, reducing the setup gap between web and CLI environments. A new `--marketplace <source>` flag for `/plugin install` enables installing from alternate marketplaces. Source: https://code.claude.com/docs/en/changelog

- **Auto Mode Per-Command Domain Sandboxing (v2.1.275, Sep 17)**: The `Bash`, `PowerShell`, and `Monitor` tools in auto mode now support per-command `allowed_domains`, enabling fine-grained network sandboxing without a session-wide policy. Source: https://code.claude.com/docs/en/changelog

- **Community-Built Claude Code for Visual Studio 2026**: An unofficial extension (`firish/claude_code_vs`) brings Claude Code to Visual Studio 2026 with a native diff viewer, an autonomous live debugger, Roslyn code navigation, and Test Explorer integration. Source: https://github.com/firish/claude_code_vs

## Bug Fixes & Performance

- **Security: Bash Permission Checker Fix (v2.1.273, Sep 15)**: A bug that caused the Bash permission checker to skip dangerous command patterns was fixed — a high-priority security-relevant patch for auto mode users. The same release also fixed synced skills from claude.ai remaining active after an organization administrator disabled Skills. Source: https://code.claude.com/docs/en/changelog

- **Critical Proxy/Gateway Fix (v2.1.276, Sep 18)**: Every request was failing with `400 … Input tag 'advisor_20260301'` when `ANTHROPIC_BASE_URL` pointed at a proxy or gateway — a regression introduced in 2.1.275, patched the same day in 2.1.276. Source: https://code.claude.com/docs/en/changelog

- **"Text Content Blocks Must Be Non-Empty" Error Fixed (v2.1.277, Sep 18)**: A recurring error that caused conversations to fail was resolved. The same release fixed users being unexpectedly logged out with older Claude Code builds. Source: https://code.claude.com/docs/en/changelog

- **MCP HTTP Timeout Fix (v2.1.274, Sep 17)**: Streamable HTTP MCP tool calls that timed out after ~5 minutes are now fixed, and MCP servers configured as HTTP that only speak legacy HTTP+SSE no longer fail on 422 or other 4xx responses. Source: https://code.claude.com/docs/en/changelog

- **Prompt Cache Fix (v2.1.271, Sep 14)**: A bug causing partial prompt cache invalidation after a response cut off at the output-token limit was fixed, reducing wasted cache recomputation on long agentic runs. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **MCP Adoption Reaches ~95% (September 2026)**: Research from lucaberton.com tracking MCP adoption by Claude Code client shows a steady climb from near-zero in late July to approximately 95% by mid-September, reflecting organic, daily-use adoption rather than a single migration event. Source: https://lucaberton.com/blog/mcp-adoption-by-client-2026/

Source: https://blog.mean.ceo/claude-code-news-september-2026/

Source: https://www.scriptbyai.com/claude-code-timeline/

## Roadmap & Announcements

- **Fable 5.1 Now Default Fable Model**: As of v2.1.257 (Week 36, Aug 31–Sep 4), Claude Fable 5.1 — with a 1M-token context window — became the default Fable model in Claude Code, replacing the earlier Fable 5 checkpoint. Source: https://code.claude.com/docs/en/whats-new

- **Cache Read Pricing Cut 75%**: Anthropic reduced cache read prices to $0.25 per million tokens (down from $1.00), cutting typical Claude Code workload costs by roughly 25% and agentic task costs by up to 45% for users on the API. Source: https://releasebot.io/updates/anthropic/claude-code

- **`omitClaudeMd` for Subagents (v2.1.275, Sep 17)**: A new `omitClaudeMd` field in agent frontmatter allows custom subagents to run without loading CLAUDE.md files, enabling cleaner evaluation harnesses and isolated subagent environments. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
The most impactful Claude Code development this week is the AGENTS.md fallback support paired with skill/plugin sync from claude.ai to terminal — together these significantly reduce configuration friction for new contributors and cross-tool workflows, signaling a push toward a unified, less-setup-dependent Claude Code experience.

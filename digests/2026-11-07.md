# Claude Code News Digest — 2026-11-07

## Overview
Claude Code shipped four releases this week (v2.1.316–2.1.319), headlined by a privacy fix that stops account email addresses from leaking to third-party sites, background MCP task support, and a new IDE-extension install flow. Anthropic also set a hard November 30 deadline for Opus 4.8 Fast mode removal.

## New Features & Releases

- **v2.1.319 (Nov 6) — MCP background tasks & deny-on-prompt**: MCP tool calls that would normally block now move to the background and notify Claude when finished (disable with `CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND`). A new `permissions.denyInsteadOfPrompting` setting makes Claude deny rather than wait on any permission prompt, enabling fully non-interactive pipelines. Also added: `/claude-api latency-optimize` to surface slow API call sites and `CLAUDE_CODE_DISABLE_FEATURE_FLAGS` to stop feature-flag fetching without touching telemetry. Source: https://code.claude.com/docs/en/changelog

- **v2.1.318 (Nov 4) — Cloudless sessions & sign-in expiry warning**: Cloud sessions can now start with no attached repository ("No repository" option). `loginExpiresAt` is exposed in `claude auth status`, and a stderr warning fires 10 days before a claude.ai sign-in expires, reducing surprise logouts. Background subagents also now promote shell commands to the background after 3 minutes on all providers. Source: https://code.claude.com/docs/en/changelog

- **v2.1.317 (Nov 3) — Email privacy check & SDK hook control**: Added a confirmation step before any web or shell tool sends your account email address over the network — a direct response to community reports of email leakage via HTTP User-Agent headers. `onFailure: "block"` for Agent SDK hook callbacks now lets a failed hook block the action outright rather than letting it proceed. Source: https://code.claude.com/docs/en/changelog

- **v2.1.316 (Oct 31) — Subagent effort control & pooled budgets**: New `CLAUDE_CODE_SUBAGENT_EFFORT` env var sets the effort level for all subagents. `CLAUDE_CODE_DISABLE_ULTRATHINK` turns off the `ultrathink` keyword. Pooled group budgets (`pooled_budget`) land in the Claude apps gateway, and `managed.policy_mode: layered` gives gateways finer control. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **IDE extension install flow changed in v2.1.318**: The VS Code extension is no longer auto-installed or auto-updated when Claude Code starts inside an IDE terminal. Users must now run `/ide` from an outside terminal to install it. The extension still works in Cursor and other VS Code forks; JetBrains users have a separate plugin. Community extensions for Neovim (`claudecode.nvim`) and Emacs (`claude-code-ide.el`) implement the same protocol. Source: https://code.claude.com/docs/en/changelog

- **MCP protocol revision 2026-07-28 now default**: The claude.ai connector layer now negotiates MCP protocol revision 2026-07-28 (shipped with MCP TypeScript SDK 2.0), which removes protocol-level session tracking and makes MCP stateless at the protocol layer. A legacy opt-out exists for older servers. Source: https://code.claude.com/docs/en/mcp

- **Xcode 26.3 integrates Claude Agent SDK** (earlier announcement, still relevant): Xcode 26.3 natively exposes the Claude Agent SDK over MCP, giving Claude Code users command-line access to Xcode Previews, project-wide file understanding, and goal-based autonomous editing of Swift/SwiftUI projects. Source: https://www.anthropic.com/news/apple-xcode-claude-agent-sdk

## Bug Fixes & Performance

- **Idle compaction added to VS Code and Claude Desktop** (v2.1.314, Oct 30): Conversations idle in VS Code's Claude panel or the Desktop app's Code tab are now automatically compacted, reducing memory usage for long-running sessions. Source: https://code.claude.com/docs/en/changelog

- **High bug-fix volume this week**: v2.1.319 shipped 90 bug fixes; v2.1.317 shipped 62; v2.1.318 shipped 47. Fixes across all three releases cover MCP connection handling (`claude mcp add/remove/logout`), Monitor's WebSocket permission enforcement, and SendMessage latency for background agents. Source: https://code.claude.com/docs/en/changelog

- **`claude_code.safety_event` OpenTelemetry event removed** (v2.1.312, Oct 27): The safety event telemetry added in v2.1.307 was withdrawn five releases later, so any pipeline that parsed it must be updated. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Email-leakage issue reported by user community**: A GitHub user (issue #107757, Nov 5) reported that Claude Code was sending their account email address to third-party domains in HTTP User-Agent headers during web searches, resulting in scam email. Anthropic responded in v2.1.317 with an explicit confirmation prompt before any network call that would include the email. Source: https://cybersecuritynews.com/claude-code-leaks-user-email

- **OpenCode 2.2.3 adds Claude Agent SDK provider**: The open-source OpenCode terminal client added a Claude Agent provider that authenticates through the user's existing Claude Code login, allowing access to Claude without a separate API key. Source: https://cellcog.ai/blog/opencode-claude-subscription/

- **Game-recreation refusals reported by developers**: Game developers have noted Claude Code refusing to help recreate existing games since late October 2026, though Anthropic has not published a policy change and the official changelog does not mention one. Source: https://thenextweb.com/news/claude-code-game-recreation-refusals-developers

## Roadmap & Announcements

- **Opus 4.8 Fast mode removed November 30, 2026**: Fast mode for Opus 4.8 is deprecated as of October 30 and will be fully removed in 23 days. After removal, fast-mode requests on Opus 4.8 return an error with no silent fallback. Anthropic recommends migrating to Opus 5.5 to retain the speed benefit. Source: https://code.claude.com/docs/en/changelog

- **Enterprise cost-code tagging in beta (Nov 6)**: Eligible Enterprise organizations can now tag projects with cost codes and track spending by tag in Anthropic's support portal, giving finance teams finer usage attribution. Source: https://support.claude.com/en/articles/12138966-release-notes

- **Updated usage policy takes effect November 12**: An updated Anthropic usage policy is scheduled to take effect in five days. Details have not been fully published, but Claude Code users subject to enterprise agreements may want to review the changes. Source: https://blog.mean.ceo/claude-code-news-november-2026/

## Key Takeaway
The most urgent change this week is the November 30 hard cutoff for Opus 4.8 Fast mode — any production workflow relying on it must migrate to Opus 5.5 within the next three weeks or start returning errors.

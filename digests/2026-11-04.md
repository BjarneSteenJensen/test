# Claude Code News Digest — 2026-11-04

## Overview
Claude Code shipped two releases today (v2.1.317 and v2.1.318) with significant additions to cloud sessions, the Agent SDK, and self-hosted runner infrastructure. The week is also marked by a supply-chain security incident involving a trojanized extension on Cursor's marketplace, the departure of longtime product chief Cat Wu, and Anthropic confirming new content limits around game cloning/reverse engineering.

## New Features & Releases

- **v2.1.318 (November 4, 2026) — AWS cost attribution & expiring-credential warnings**: Added `assume_role` support on `mantle` upstreams for cross-account AWS access and per-developer cost attribution. Also added `loginExpiresAt` in `claude auth status`, credential-expiry warnings in `claude -p` output starting 10 days before sign-in ends, and an `effort` option for `$.model.fork` in mods. 15 improvements and 47 bug fixes, including a fix for `--continue` losing conversations (regression in 2.1.314) and `claude -p` now correctly exits 1 when a disk-full error cuts off a reply. Source: https://code.claude.com/docs/en/changelog

- **v2.1.317 (November 3, 2026) — OTel plan/seat metrics, Agent SDK hook failures, and email guard**: Added `anthropic.plan`, `anthropic.seat_type`, `anthropic.provider`, and `anthropic.custom_base_url` to OpenTelemetry metrics/spans. New `onFailure: "block"` option for Agent SDK hook callbacks blocks an action when a hook fails. A new check prompts before a web or shell tool call sends your account email to the network. The Read tool no longer returns a "file unchanged" stub — rereading an unchanged file returns its content. 8 improvements and 62 bug fixes. Source: https://code.claude.com/docs/en/changelog

- **Fast mode for Opus 4.8 deprecated**: Fast mode on Opus 4.8 was deprecated October 30, 2026, and will be fully removed November 30. Requests after removal will return an error. Users are advised to migrate to Opus 5.5. Source: https://www.gradually.ai/en/changelogs/claude-code/

- **New content limits on game cloning**: Anthropic confirmed adding new steering prompts to Claude Code on Opus 5.5 to prevent recreating existing games. Users also report Opus 5.5 blocking some reverse-engineering tasks. Source: https://www.tomshardware.com/tech-industry/artificial-intelligence/anthropic-confirms-new-claude-code-limits-to-prevent-game-cloning-users-report-opus-5-5-is-also-actively-blocking-reverse-engineering-tasks

## Integrations & Extensions

- **Trojanized Claude Code extension via Cursor marketplace**: A malicious actor published tampered copies of the Claude Code VS Code extension (versions 2.1.312–2.1.313) to Cursor's extension marketplace, embedding a persistent SSH backdoor. Anthropic did not build or publish those copies. Anthropic released legitimate version 2.1.314 to address confusion; Cursor removed the tampered extension. Users running Claude Code in Cursor should verify their installed version and reinstall from a trusted source. Source: https://www.stepsecurity.io/blog/claude-code-extension-trojanized

- **MCP protocol 2026-07-28 negotiated by default**: Cloud session and Remote Control connectors now negotiate MCP protocol version 2026-07-28 by default. An environment variable can opt out. HTTP is now the recommended transport for remote MCP servers; legacy SSE remains for compatibility but is deprecated. Source: https://www.gradually.ai/en/changelogs/claude-code/

- **v2.1.318: IDE extension install behavior changed**: The IDE extension is no longer automatically installed or updated when Claude Code starts inside an IDE terminal. Use `/ide` from an external terminal instead. Source: https://code.claude.com/docs/en/changelog

- **Unofficial Visual Studio 2026 and Eclipse extensions**: Community-built extensions now exist for Visual Studio 2026 (native diff, live debugger, Roslyn nav, Test Explorer) and Eclipse IDE. Neither is affiliated with or endorsed by Anthropic. Source: https://github.com/firish/claude_code_vs

## Bug Fixes & Performance

- **Idle compaction added to VS Code and desktop Code tab**: Long conversations left idle are now summarized automatically; the summary is used on the next message after the prompt cache expires. Previously only available in cloud sessions. Source: https://www.gradually.ai/en/changelogs/claude-code/

- **`permissions.blockWritesOutsideWorkingDirectories` added**: New permission setting explicitly blocks file writes outside the working directory tree. Source: https://www.gradually.ai/en/changelogs/claude-code/

- **`CLAUDE_CODE_DISABLE_ULTRATHINK` env var (v2.1.316)**: New environment variable disables the `ultrathink` keyword trigger for extended thinking. Source: https://releasebot.io/updates/anthropic

- **Safety telemetry reverted**: The `claude_code.safety_event` OpenTelemetry event added in v2.1.307 was withdrawn in v2.1.312 without a public explanation. Source: https://code.claude.com/docs/en/changelog

- **v2.1.318 background subagent timing**: Background subagents now consistently move shell commands to the background after 3 minutes across all providers. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
The most urgent item today is the **Cursor supply-chain attack**: a trojanized copy of the Claude Code extension delivering SSH backdoors was live in Cursor's marketplace. If you use Claude Code in Cursor, verify your extension version and reinstall from the official VS Code Marketplace immediately.

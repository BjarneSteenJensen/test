# Claude Code News Digest — 2026-10-05

## Overview
The biggest story this week is the launch of **Claude Mods** (v2.1.287, October 1), a new plugin system that lets developers write TypeScript-based customizations that reach deeper into Claude Code's behavior and UI than ordinary plugins could. Versions 2.1.288 and 2.1.289 followed on October 2–3 with reliability hardening, improved MCP handling, and a new `agent.spawn` teammate API.

---

## New Features & Releases

- **Claude Code v2.1.289 — `agent.spawn` & shell-rule fixes (Oct 3, 2026)**: Adds `agent.spawn` for spawning persistent teammate agents that share a single agent ID across plugin hook events, and exposes idle/waiting states in `$.agent.list()`. Critical safety fixes: deny/ask rules on nested compound shell commands were not holding, `Read` deny rules were not applying to `@`-mentioned or symlink-selected files in IDE, and terminal freezing on short code blocks with unclosed `<script>` tags is resolved. Source: [https://code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Claude Code v2.1.288 — MCP re-auth, prompt recovery & code-review controls (Oct 2, 2026)**: Introduces `$.ui.selection()` for mods (returns last selected text and its transcript row), built-in `gh api` in cloud sessions without needing the GitHub CLI installed, prompt recovery with Ctrl+C/Up arrow, MCP re-authentication prompts when servers request new OAuth scopes, and `--max-findings <n>|all` flag for `/code-review`. Major reliability fix: mid-response API timeouts in non-interactive sessions and subagents now recover from partial responses rather than failing. Source: [https://code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Claude Code v2.1.287 — Claude Mods launch (Oct 1, 2026)**: The headline feature of the week. Mods are TypeScript plugin extensions that can replace or modify built-in Claude Code behavior, ship new UI elements, and be shared through the plugin directory. The first built-in mod, **"You should know"**, acts as a background side-agent that watches the session and flags things you or Claude might miss; enable it with `/plugin enable cc-plugin-you-should-know@builtin`. Some existing built-in features (e.g., `/diff`) now ship as removable/replaceable mods. Source: [https://code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

## Integrations & Extensions

- **VSCode bookmarks panel & "Run in background" (v2.1.286, Sep 30)**: Claude Code's VS Code extension gained a Bookmarks side panel for saving and pinning Claude's responses for later reference, plus a "Run in background" option that lets you dispatch commands or sub-agents without blocking the foreground session. Source: [https://code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Community Visual Studio 2026 extension for Claude Code**: A community-built extension for Microsoft Visual Studio 2026 (not VS Code) adds a native diff window with accept/reject controls, automatic compiler-diagnostics context injection, a live debugger Claude can drive autonomously, Roslyn code navigation, and Test Explorer integration. Source: [https://github.com/firish/claude_code_vs](https://github.com/firish/claude_code_vs)

- **Claude Agent SDK in Xcode 26.3**: Apple's Xcode 26.3 integrates the Claude Agent SDK natively, enabling Claude to capture Xcode Previews, iterate on SwiftUI layouts, and complete long-running tasks autonomously within the IDE. Claude Code CLI users can also reach Xcode capabilities via MCP. Source: [https://www.anthropic.com/news/apple-xcode-claude-agent-sdk](https://www.anthropic.com/news/apple-xcode-claude-agent-sdk)

- **MCP 2.0 support with protocol revision 2026-07-28**: Claude Code now fully supports MCP 2.0 via the MCP TypeScript SDK 2.0. v2.1.288 adds MCP re-authentication prompts when servers request additional OAuth scopes, and earlier releases improved MCP startup retry logic in headless mode. Source: [https://code.claude.com/docs/en/mcp](https://code.claude.com/docs/en/mcp)

## Bug Fixes & Performance

- **Shell-command safeguard regressions fixed (v2.1.289)**: A regression allowed dangerous `rm` commands to lose their safety check when also redirecting to `~` or using wildcards — fixed in v2.1.289 (a related variant was also patched in v2.1.285). Deny/ask rules on nested compound shell commands were not consistently enforced over user-installed mod approvals on managed machines; also fixed. Source: [https://code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Long-conversation compaction crashes resolved (v2.1.288)**: Sessions with large histories were failing with "Prompt is too long" during auto-compaction, and `--resume` was sometimes dropping files and context or not saving the last response turn. Both are fixed in v2.1.288. Source: [https://code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **API timeout recovery for subagents (v2.1.288)**: Non-interactive sessions and subagents now recover gracefully from mid-response API timeouts by continuing from partial responses, rather than failing the entire turn. Source: [https://code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

## Key Takeaway
The launch of **Claude Mods** in v2.1.287 marks the most significant extensibility milestone for Claude Code in months: teams can now write TypeScript mods that replace or augment core Claude Code behavior — including built-in commands like `/diff` — and share them via the plugin directory, giving organizations far deeper control over how Claude Code operates in their workflows.

# Claude Code News Digest — 2026-09-28

## Overview
September 2026's biggest Claude Code development is the arrival of **Claude Opus 5.5** as the new default Opus model (released September 22), bringing a 1M-token context window at 40% lower cost than Opus 5. Alongside this, Anthropic shipped a dense round of polish covering auto mode efficiency, AGENTS.md support, plugin evaluation tooling, and a critical proxy/gateway bug fix that unblocked enterprise users.

---

## New Features & Releases

- **Claude Opus 5.5 becomes default Opus in Claude Code (v2.1.280, Sep 22)**: Opus 5.5 (`claude-opus-5-5`) replaces Opus 5 as the default Opus model across Claude Code. It offers a 1M-token context window, pricing of $4/$20 per MTok (input/output) with $0.20/MTok cache reads, and performs on par with Claude Fable 5.1 at 40% lower cost. Pro/Team Standard accounts also switched default model from Sonnet to Opus (v2.1.282). Source: https://code.claude.com/docs/en/changelog

- **`claude plugin eval` — automated plugin testing (Week 37, Sep 7–11, v2.1.263–v2.1.269)**: A new command lets you run your Claude Code plugin against a suite of test cases, score results, and compare against a no-plugin baseline. `claude plugin eval init` drafts the test cases and graders automatically. Source: https://code.claude.com/docs/en/whats-new

- **AGENTS.md support (v2.1.277, Sep 18)**: Claude Code now reads `AGENTS.md` in preference to `CLAUDE.md` when the file is present, aligning with the emerging cross-tool convention for agent instructions. Source: https://code.claude.com/docs/en/changelog

- **Auto mode defaults to server-side classifier (v2.1.278, Sep 19)**: Auto mode for Claude API and Enterprise users now defaults to server-side processing, eliminating the token overhead previously incurred for classifier runs. Users can opt out with `CLAUDE_CODE_AUTO_MODE_SERVER=0`. Source: https://code.claude.com/docs/en/changelog

- **Model governance controls (v2.1.283, Sep 25)**: New managed settings `availableModelsMatch` (exact mode) and `deniedModels` give admins fine-grained control to lock teams to specific model versions or block disallowed ones. Source: https://code.claude.com/docs/en/changelog

- **Desktop pane windowing (Week 37, Sep 7–11)**: Any Claude Code Desktop pane can now be popped out into its own window and docked back, enabling flexible multi-monitor workflows. Source: https://code.claude.com/docs/en/whats-new

- **`/doctor prompt-audit` (v2.1.283, Sep 25)**: A new audit sub-command analyses CLAUDE.md files and prompting patterns for common issues, helping teams maintain healthier project instructions. Source: https://code.claude.com/docs/en/changelog

- **Send-now key (v2.1.275, Sep 17)**: `Ctrl+Enter` (or `Ctrl+X Ctrl+S`) now interrupts the current turn and sends any queued message immediately. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **Plugin developer portal ships (Sep 26)**: Anthropic launched a dedicated developer portal for Claude plugins, providing a centralised marketplace for discovering, installing, and managing plugins across Claude Code sessions. Source: https://releasebot.io/updates/anthropic/claude-code

- **Skills/plugins synced from claude.ai account (v2.1.275, Sep 17)**: Claude Code now syncs installed skills and plugins from your claude.ai account, removing the need to re-install them per machine. A new `claude plugin install <plugin> --marketplace <source>` flag also supports alternate marketplace sources. Source: https://code.claude.com/docs/en/changelog

- **MCP URL-mode elicitation (v2.1.281, Sep 23)**: MCP servers on the 2026-07-28 protocol can now ask Claude Code to open a browser-based authentication or confirmation flow without leaving a blocking dialog on screen. Source: https://code.claude.com/docs/en/changelog

- **MCP tool outputs in OpenTelemetry spans (v2.1.283, Sep 25)**: MCP tool call outputs are now emitted as OpenTelemetry span events, improving observability for teams running Claude Code behind gateways. Source: https://code.claude.com/docs/en/changelog

- **VS Code: Status, Sandbox, and Chrome dialogs (v2.1.280, Sep 22)**: The VS Code extension gains three new context dialogs for Status, Sandbox, and Chrome integration, plus an `/export` command that exports the current conversation. Source: https://code.claude.com/docs/en/changelog

- **Community Visual Studio 2026 extension (September 2026)**: A community-built extension (`firish/claude_code_vs`) brings Claude Code to Visual Studio 2026 with a native accept/reject diff viewer, a live debugger Claude can drive autonomously, Roslyn code navigation, and Test Explorer integration. Source: https://github.com/firish/claude_code_vs

## Bug Fixes & Performance

- **Critical proxy/gateway fix (v2.1.276, Sep 18)**: All requests were failing with `400 … Input tag 'advisor_20260301'` when `ANTHROPIC_BASE_URL` pointed at a proxy or gateway. This regression blocked enterprise deployments and was resolved in an emergency patch. Source: https://code.claude.com/docs/en/changelog

- **Crash on API request retries fixed (v2.1.281, Sep 23)**: A crash that occurred during automatic API request retries has been resolved, along with prompt cache loss caused by MCP server disconnections. Source: https://code.claude.com/docs/en/changelog

- **Extended thinking no longer dropped during slash commands (v2.1.282, Sep 24)**: Extended thinking state was being discarded when a slash command was invoked mid-session; this is now preserved correctly. Source: https://code.claude.com/docs/en/changelog

- **SDK sessions no longer lose deferred tool calls (v2.1.283, Sep 25)**: A bug causing Agent SDK sessions to silently drop deferred tool calls and their results has been fixed, improving reliability for headless/scripted Claude Code usage. Source: https://code.claude.com/docs/en/changelog

- **Stdio MCP servers cleaned up on session end (v2.1.283, Sep 25)**: Previously, stdio MCP server child processes were left running after a Claude Code session ended. They are now terminated correctly. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
The single most important development of September 28, 2026 is the cumulative effect of **Claude Opus 5.5 becoming the default Opus model in Claude Code** (Sep 22): it delivers frontier-level performance on coding tasks at materially lower cost, while the accompanying shift to a free server-side auto mode classifier means teams can run it at full capability without hidden overhead.

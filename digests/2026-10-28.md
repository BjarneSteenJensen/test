# Claude Code News Digest — 2026-10-28

## Overview
October 28, 2026 caps a busy release week for Claude Code: yesterday's v2.1.312 added OIDC customisation for the gateway, a Bash editor for cloud setup scripts, and an effort picker for cloud routines, while the week also saw MCP Tasks & Elicitations land in a narrow CLI launch and Code Review reach general availability for Team and Enterprise customers. The pace of daily point-releases (v2.1.299 through v2.1.312 in 14 days) reflects a product in rapid iteration across cloud sessions, IDE integration, and agent infrastructure.

## New Features & Releases

- **v2.1.312 (Oct 27) — OIDC claim config, effort picker, Bash editor for cloud routines**: The latest release adds `oidc.user_id_claim` for the Claude apps gateway (enabling Entra ID `oid` mapping), a per-routine effort picker in cloud sessions, a Bash editor for cloud setup scripts, click-to-send in fullscreen, and renames "session limit" to the clearer "5-hour limit". Bedrock, Vertex, Foundry, and Mantle now use a shorter system prompt for unrecognised model names (`CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=0` restores the full prompt). 22 bugs fixed. Source: https://code.claude.com/docs/en/changelog

- **v2.1.311 (Oct 26) — `ultrathink` at xhigh effort, signed model catalog, 56 fixes**: `ultrathink` now runs at `xhigh` effort on Opus 5.5, Sonnet 5.5, and Haiku 5.5. Model settings load from a signed catalog file (`CLAUDE_CODE_MODEL_CATALOG=off` disables this), and `DISABLE_COMPACT` is restricted to turning compaction off only. New `--hold-idle-file` and `--max-hold-min` flags for `self-hosted-runner`. 56 bugs fixed, 16 improvements. Source: https://code.claude.com/docs/en/changelog

- **v2.1.310 (Oct 23) — Monitor tool on Bedrock, Vertex, Foundry**: The Monitor tool — which streams background process output — now works on Bedrock, Vertex, and Foundry (previously CLI/web only). Enterprise custom roles also gain fine-grained controls over access to cloud sessions and Remote Control. Source: https://code.claude.com/docs/en/changelog

- **v2.1.309 (Oct 22) — Bypass-mode safety hardening, ultrareview workspace trust**: `rm`/`rmdir` in bypass mode are now denied with a rewrite hint, and `claude ultrareview` requires explicit workspace trust (`--trust-workspace` for scripts). `sed -i` runs as a standard Bash command. 62 bugs fixed. Source: https://code.claude.com/docs/en/changelog

- **v2.1.302 (Oct 16) — Fork subagents on by default, idle compaction, Auto Mode model env var**: Fork-style subagents are now on by default for all sessions. Idle compaction (triggered at 200 K+ tokens) is configurable in `/config`. A new `CLAUDE_CODE_AUTO_MODE_MODEL` env var overrides the model used in Auto Mode. Also: notice added that standalone Claude Design closes December 14, 2026. Source: https://code.claude.com/docs/en/changelog

## Integrations & Extensions

- **VS Code: LaTeX rendering, selection attachment, log warnings for TLS failures**: v2.1.301 (Oct 15) added LaTeX math rendering in VS Code. v2.1.300 (Oct 14) added `claudeCode.attachSelection` for attaching the current editor selection to a prompt. v2.1.312 adds a log warning explaining what to do when the VS Code extension's own requests fail certificate verification (common behind TLS-inspecting proxies). Source: https://code.claude.com/docs/en/changelog

- **Slack Connect support in Claude Tag (v2.1.300, Oct 14)**: Claude Tag now works inside Slack Connect shared channels, expanding cross-organisation use of Claude Tag. Source: https://code.claude.com/docs/en/changelog

- **Agent SDK v0.3.302 (TypeScript, Oct 16) / v0.2.168 (Python, Oct 15) — `autoCompactWindow` for subagents**: The latest SDK releases add `autoCompactWindow` to `AgentDefinition`, letting a subagent trigger context compaction earlier than the parent conversation. Memory use of non-interactive (`-p`, SDK) sessions during compaction is improved in v2.1.310. Source: https://www.gradually.ai/en/changelogs/claude-agent-sdk/

- **MCP Tasks & Elicitations — narrow CLI launch (Oct 22–23)**: Anthropic shipped MCP Tasks and Elicitations in the Claude Code CLI (v2.1.307+). Tasks let MCP tools run as durable, interruptible background jobs: the server returns a task ID immediately, Claude Code keeps working and polls for the result. Elicitations let MCP tools pause to ask the user a question mid-run. VS Code, desktop, Bedrock, and Vertex are on the roadmap. Source: https://www.bighatgroup.com/blog/claude-weekly-2026-10-19/

## Bug Fixes & Performance

- **v2.1.309 (Oct 22) — 62 bugs fixed, biggest single-release fix batch this month**: Fixes span permission-prompt reliability, session handling, agent and cloud-session edge cases, and the new bypass-mode safety changes. Source: https://code.claude.com/docs/en/changelog

- **v2.1.306 (Oct 21) — Fixed `claude -p` "Not logged in" in cloud sessions, many-MCP-tool error**: Two targeted fixes: non-interactive `claude -p` in cloud sessions was incorrectly reporting "Not logged in", and sessions with many MCP tools were replacing real API errors with a misleading "prompt is too long" message. Source: https://code.claude.com/docs/en/changelog

- **v2.1.307 (Oct 21) — HTTP MCP retries restricted to read-only/idempotent tools**: A fix prevents HTTP MCP tool calls from being sent twice when the connection closes mid-call; retries now apply only to read-only or idempotent tools, avoiding unintended duplicate side effects. Source: https://code.claude.com/docs/en/changelog

- **v2.1.311 — VS Code extension install-state fix**: Fixed `/ide` incorrectly reporting the VS Code extension as installed before the install had finished or when it failed. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Code Review is now generally available for Team and Enterprise**: Anthropic's Code Review feature has left research preview. Reviews run automatically on new pull requests once admins enable it and install the GitHub App. Speed improved ~3× (6–10 minutes vs ~20 minutes in preview). Admins can choose Quick, Standard (default), or Deep review per repository. Eligible Enterprise organisations can claim at least $10,000 in Code Review credits before January 15, 2027 (credits expire 30 days after claiming). Source: https://claude.com/resources/articles/code-review-is-now-generally-available

- **OpenTelemetry expanded — safety events and cache-write token splits**: v2.1.307 added a `claude_code.safety_event` OTel event, and v2.1.300 added cache-write token splits in OTel, giving teams more granular observability data for cost attribution and safety auditing. Source: https://code.claude.com/docs/en/changelog

- **Claude Duet announced as research preview (Oct 21)**: Anthropic announced Claude Duet, a proactive agent feature, as a waitlist-only research preview for US Pro and Max subscribers. Details are limited; no official blog post has been confirmed. Source: https://aimaker.substack.com/p/claude-code-updates-october-2026

## Roadmap & Announcements

- **Standalone Claude Design closes December 14, 2026**: Starting with v2.1.302 (Oct 16), Claude Code shows a notice that standalone Claude Design will shut down on December 14, 2026. Users relying on Claude Design should migrate ahead of that date. Source: https://code.claude.com/docs/en/changelog

- **New Anthropic API version: 2026-10-21**: v2.1.307 added `/claude-api api-version` support for the `2026-10-21` API version, signalling a new stable API contract. Source: https://code.claude.com/docs/en/changelog

- **MCP Tasks & Elicitations roadmap**: The CLI-only MCP Tasks & Elicitations launch is explicitly described as a narrow/early release; VS Code extension, desktop app, Bedrock, and Vertex support are on the roadmap. Source: https://www.bighatgroup.com/blog/claude-weekly-2026-10-19/

## Key Takeaway
Code Review reaching general availability — with 3× speed improvement, three configurable review levels, and $10K+ credits for Enterprise — is the most impactful Claude Code development this week, making AI-powered PR review accessible to all Team and Enterprise customers with zero developer setup required.

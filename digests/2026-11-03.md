# Claude Code News Digest — 2026-11-03

## Overview
Today's top Claude Code story is a security incident: a malicious version of the Claude Code extension was briefly distributed through Cursor's marketplace, exposing roughly 5,000 developers to an SSH backdoor. On the product side, Claude Code v2.1.317 shipped today with new hooks and cost-reporting features, while Anthropic's updated usage policy (effective November 12) adds an explicit prohibition on sustained abusive treatment of Claude models.

## New Features & Releases

- **v2.1.317 (November 3)**: Today's release adds a `/schedule` command warning when connectors are requested without explicit user intent, an `onFailure: "block"` option for Agent SDK hooks, a new cost-reporting API endpoint (`GET /v1/organizations/analytics/cost`), and a `CLAUDE_CODE_DISABLE_NESTED_SESSION_ID` env var. The `Read` tool no longer returns a misleading "file unchanged" stub. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.316 (October 31)**: Introduced `CLAUDE_CODE_DISABLE_ULTRATHINK` and `CLAUDE_CODE_SUBAGENT_EFFORT` env vars, and pooled group budgets on the Claude apps gateway. **Fast mode on Opus 4.8 is deprecated** as of October 30 and will be removed November 30 — users should migrate to Opus 5.5 to retain the speed benefit. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.314 (October 30)**: Added `permissions.blockWritesOutsideWorkingDirectories`, which makes `Write`, `Edit`, and `NotebookEdit` refuse paths outside working directories in all permission modes — a useful safety guard for agentic workflows. Idle-session compaction, previously desktop-only, now also applies in VS Code and the Desktop Code tab. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Claude Agent SDK v0.3.316**: The npm package for the Claude Agent SDK (formerly Claude Code SDK) was updated approximately two days ago, tracking the bundled Claude Code binary version. The TypeScript package includes the CLI binary so no separate install is needed. Source: [@anthropic-ai/claude-agent-sdk on npm](https://www.npmjs.com/package/@anthropic-ai/claude-agent-sdk)

## Integrations & Extensions

- **MCP docs updated November 2**: The official MCP integration docs were refreshed yesterday. Claude Code's MCP runtime is built on MCP TypeScript SDK 2.0 implementing protocol revision 2026-07-28, which removed protocol-level session tracking to make the protocol stateless. Elicitation support requires Claude Code v2.1.287 or later. The recommended transport for new remote integrations is HTTP; legacy SSE is kept only for compatibility. Source: [Claude Code MCP Docs](https://code.claude.com/docs/en/mcp)

- **v2.1.310 (October 23)**: Monitor tool and plugin monitors were enabled on Bedrock, Vertex, and Foundry, bringing those cloud-hosted deployment targets to feature parity with the standard CLI for monitoring-based workflows. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **IDE inline tab completions gap persists**: A tracked GitHub issue confirms the VS Code and JetBrains extensions still do not support inline tab completions natively; developers who want that feature must configure a separate API key through a third-party plugin. Source: [GitHub issue #45573](https://github.com/anthropics/claude-code/issues/45573)

## Bug Fixes & Performance

- **v2.1.317**: Fixed `Read` returning a "file unchanged" stub when a file had not changed — a subtle bug that could cause an agent loop to incorrectly believe an edit had failed. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.314**: Fixed `FORCE_HYPERLINK=false` not reliably disabling hyperlinks in terminal output. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Message threads cut TTFT by ~35%**: Anthropic's Messages API added message threads (public beta), now on by default for most Claude Code users. For requests in the 500k–1M token range, median time-to-first-token dropped by approximately 35%. Source: [Claude Code Release Notes via releases.sh](https://releases.sh/anthropic/claude-code)

- **v2.1.309 (October 22)**: Dangerous `rm` commands in bypass mode are now denied outright rather than passed through. `sed -i` is treated as a standard Bash command (previously triggered extra prompts on some platforms). Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Community & Ecosystem

- **Malicious extension in Cursor marketplace (October 29)**: A tampered copy of the `anthropic.claude-code` VS Code extension (versions 2.1.312 and 2.1.313) was distributed through Cursor's extension marketplace for approximately 11 hours. The malicious build was designed to establish a reverse SSH tunnel when modules loaded. Cursor has since removed the affected versions and reports no evidence that other versions or official distribution channels were compromised. Developers who installed version 2.1.313 via Cursor on October 29 should inspect their systems for unauthorized SSH activity. Source: [SecurityWeek](https://www.securityweek.com/malicious-claude-code-extension-served-in-cursor-supply-chain-attack/), [80.lv](https://80.lv/articles/claude-code-blocks-video-game-cloning-some-reverse-engineering-tasks)

- **Game-cloning rules trigger developer friction**: Anthropic added instructions to Claude Code (Opus 5.5) to refuse requests that recreate specific existing games, citing IP infringement concerns. Reports from game developers indicate the filter also catches legitimate projects — such as inspecting crash dumps or implementing mechanics inspired by (but not copying) existing titles. Anthropic says it will continue iterating to strike the right balance. Source: [Heise English](https://www.heise.de/en/news/Claude-Code-Anthropic-tightens-rules-on-game-clones-11508408.html), [GameSpot](https://gamespot.com/articles/claude-code-just-got-a-new-rule-stop-copying-other-people-games)

## Roadmap & Announcements

- **Anthropic 2026 Usage Policy update (effective November 12)**: The updated policy adds a prohibition on "sustained, purposeless cruelty toward Claude," aligning with Claude Code's existing ability to end persistently abusive conversations. The policy also tightens rules on deceptive content networks, weapons-related software, and autonomous physical-action systems — all relevant to long-running agentic Claude Code workflows. Source: [Anthropic](https://www.anthropic.com/news/2026-usage-policy-update)

- **Standalone Claude Design closes December 14, 2026**: The changelog entry in v2.1.302 (October 16) included a notice that standalone Claude Design will shut down on December 14, 2026. Teams using it should plan to migrate before that date. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Fast mode Opus 4.8 removal deadline: November 30**: Users still on Opus 4.8 fast mode have until November 30 to migrate to Opus 5.5. After that date, fast-mode requests on Opus 4.8 will return an error with no fallback. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Key Takeaway
The most urgent item today is the Cursor supply chain attack: anyone who installed the Claude Code extension through Cursor on October 29, 2026 should immediately check their systems for unauthorized SSH tunnels — the malicious versions (2.1.312/2.1.313) were live for roughly 11 hours before removal.

# Claude Code News Digest — 2026-08-08

## Overview
Today marks a busy patch day for Claude Code, with two releases (v2.1.225 and v2.1.226) shipping on August 8 alone, building on yesterday's landmark v2.1.224 that introduced self-hosted runner environments. The week's most significant upcoming change is Anthropic's announced shift to making **auto mode the default permission model** for Pro, Max, and Team users starting August 14, replacing the existing manual approval loop with an AI classifier that screens each tool call for destructive or out-of-bounds actions.

## New Features & Releases

- **v2.1.226 — Bug-fix patch (Aug 8)**: A targeted reliability release with no listed new features, focused on stability improvements following the larger v2.1.225 drop earlier the same day. Source: https://code.claude.com/docs/en/changelog

- **v2.1.225 — Gateway spend-limits, cross-machine SendMessage, and Focus view fixes (Aug 8)**: Added spend-limit support to Claude Code's usage warning so the limit-reached message now names the cap, its reset time, and the operator's message (requires gateway 2.1.225). `SendMessage` can now initiate conversations with Remote Control sessions on other machines by name via `ListAgents`, enabling true cross-machine agent orchestration. The VSCode Focus view received several fixes: folded turns now correctly show pending to-do lists and pending questions, and thinking-only folds display "Thought for Ns" and re-collapse on turn completion. Source: https://code.claude.com/docs/en/changelog

- **v2.1.224 — Self-hosted runner environments, archive plugins, and cross-session messaging (Aug 7)**: The headlining feature is `claude self-hosted-runner`, which lets teams on Team and Enterprise plans turn their own machines or containers into Claude Code session runners — keeping sessions inside the corporate network next to internal services and toolchains. Also introduced: `archive` plugin installs from HTTPS zip files with optional SHA-256 pinning (no git or npm required), advanced sandbox credential-masking options (JWT-aware masking, AWS SigV4 re-signing), and the 200-subagent-per-session spawn cap was removed. Source: https://code.claude.com/docs/en/changelog

- **Auto mode to become the default on August 14**: Anthropic announced that auto mode will become the default permission setting for Pro, Max, and Team users next week. Auto mode replaces repeated approval prompts with a classifier that checks each tool call for irreversible, destructive, or out-of-bounds actions; if it blocks something, Claude can try a safer route or ask permission. Users can opt out or run `claude auto-mode reset` to restore default configuration. Source: https://9to5mac.com/2026/08/07/psa-claude-code-enabling-auto-mode-as-default-next-week-anthropic-says/

## Integrations & Extensions

- **VSCode Focus view (v2.1.221, Aug 4)**: A new Focus view (toggle: `Ctrl+Alt+F` or "Claude Code: Toggle Focus view") hides tool activity behind expandable per-turn summaries with a live running-tool indicator, reducing visual noise during long agentic runs. Today's v2.1.225 fixed several edge-case bugs in the view. Source: https://code.claude.com/docs/en/changelog

- **MCP 2026-07-28 spec support and auto-backgrounding**: Claude Code expanded support for the new MCP spec bringing a stateless core, stronger OAuth/OIDC authorization, and versioned extensions. MCP tool calls running longer than 2 minutes now automatically move to the background to keep the session usable (configurable via `CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS`). MCP monthly SDK downloads surpassed 400 million — a 4× increase in 2026. Source: https://code.claude.com/docs/en/changelog

- **Claude Opus 5 as default Opus model (v2.1.219, Jul 24)**: Claude Opus 5 (`claude-opus-5`) with 1M context window is now the default Opus model in Claude Code. Fast mode pricing is $10/$50 per Mtok. The claude-api skill was updated to default to Opus 5 as well. Source: https://code.claude.com/docs/en/changelog

## Bug Fixes & Performance

- **Headless OAuth token regression fixed (v2.1.225)**: Transient 401 errors caused by Claude Code replacing a long-lived `CLAUDE_CODE_OAUTH_TOKEN` with a short-lived stored-login token were fixed — these had been breaking headless sessions until restart. Source: https://code.claude.com/docs/en/changelog

- **MCP OAuth keychain timeout on macOS fixed (v2.1.225)**: MCP OAuth servers on macOS were intermittently failing with bursts of 401 errors after keychain read timeouts; this is now resolved. Source: https://code.claude.com/docs/en/changelog

- **Security: Bash permission-check bypass patched (v2.1.223, Aug 6)**: A crafted command could hide parts from permission checks using invisible Unicode or tab padding; both vectors were closed. A separate zsh `[[ ]]` regex bypass was patched in v2.1.221. Source: https://code.claude.com/docs/en/changelog

- **Worktree isolation hardened (v2.1.222, Aug 4)**: Worktree-isolated sessions and subagents could previously run destructive git commands against the main checkout; this is now blocked. `PreToolUse` auto-allow hooks bypassing tool restrictions in background agent tasks was also fixed. Source: https://code.claude.com/docs/en/changelog

- **Auto mode safety-filter counting bug fixed (v2.1.225)**: Auto mode was incorrectly counting safety-filter refusals toward the consecutive-block limit, which could cause it to fall back to prompting prematurely. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Self-hosted runner public beta opens new deployment patterns**: The `claude self-hosted-runner` feature (v2.1.224) is generating interest for compliance-heavy enterprises that need Claude Code sessions to run inside their own network perimeter with access to internal APIs and tooling. Fixed and on-demand runner modes are both supported for Team and Enterprise plans. Source: https://code.claude.com/docs/en/changelog

- **MCP ecosystem hits 400M monthly downloads**: The Model Context Protocol surpassed 400 million monthly SDK downloads in 2026 — a 4× year-over-year increase — signaling rapid adoption of the open standard that Claude Code uses to connect to external tools and data sources. Source: https://www.explorium.ai/blog/data-enrichment/mcp-enrichment-setup-time-and-credit-cost-for-claude-code-2026-for-revops-teams/

- **Enterprise inference hooks beta**: Anthropic launched inference hooks in beta for Enterprise, giving compliance teams real-time DLP enforcement across chat, Claude Code, and other surfaces — inspecting prompts and tool calls before they reach the model. Source: https://releasebot.io/updates/anthropic/claude-code

## Roadmap & Announcements

- **Auto mode default rollout — August 14**: The most significant near-term change is auto mode becoming the default for Pro, Max, and Team plans next week. This represents a philosophical shift from explicit per-action approval toward classifier-based autonomy. Enterprise and Bedrock/Vertex deployments can disable it via `disableAutoMode`. Source: https://9to5mac.com/2026/08/07/psa-claude-code-enabling-auto-mode-as-default-next-week-anthropic-says/

- **Subagent depth and orchestration expansion**: Subagents can now spawn nested subagents up to depth 3 (raised from 1 in v2.1.219), and the 200-subagent-per-session cap was removed in v2.1.224 — both moves point toward Anthropic enabling more ambitious multi-agent workflows within a single Claude Code session. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
The single most important development this week is Anthropic's announcement that **auto mode will become the default permission model on August 14** — a fundamental shift that replaces manual tool-call approvals with an AI safety classifier, signaling Anthropic's confidence in autonomous Claude Code operation and setting the stage for less-interrupted, more capable agentic workflows.

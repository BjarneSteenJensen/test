# Claude Code News Digest — 2026-11-21

## Overview
November 2026 has been a busy month for Claude Code, culminating in the release of v2.1.330 on November 20 with the headline **Easel** charting mod and enterprise org sign-in. The month's biggest feature is experimental **Code Mode** (v2.1.323, Nov 12), which lets Claude write JavaScript to chain tool calls autonomously, while a wave of security hardening patches shipped across six releases.

## New Features & Releases

- **Easel — built-in charting mod (v2.1.330, Nov 20)**: Anthropic shipped a new built-in mod called `easel` that automatically draws charts during sessions (available to Pro, Max, and where enabled Team/Enterprise users on macOS and Linux). Automatic charts can be toggled off via `/config`. The same release also allows sign-in to organizations managed in Anthropic's Enterprise Admin Console via `claude auth login`, which then auto-applies org settings and cloud provider/gateway configuration. Source: https://code.claude.com/docs/en/changelog

- **Code Mode — experimental opt-in (v2.1.323, Nov 12)**: The month's headline feature lets Claude write JavaScript to chain multiple tool calls in a single step. Enable it by setting `CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1` in your shell or in the `env` block of `~/.claude/settings.json`. It works with Claude Opus 5.5, Sonnet 5.5, Haiku 5.5, and Fable 5.2, and operates only in interactive terminal sessions. By v2.1.326 (Nov 16), Code Mode can also run alongside agent teams. Source: https://code.claude.com/docs/en/changelog

- **Auto mode on more cloud platforms (v2.1.328, Nov 19)**: Auto mode was added for Claude Opus 4.6 and Sonnet 4.6 on Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry, and the Claude apps gateway. Interactive sessions with no explicit permission mode now start in auto mode. Source: https://code.claude.com/docs/en/changelog

- **Scheduled tasks and /loop extended to 30 days (v2.1.330, Nov 20)**: Recurring scheduled tasks and `/loop` now run for up to 30 days instead of the previous 7-day limit. The same release also makes scheduled tasks, `/loop` wakeups, and forks visible in `/tasks` (added in v2.1.329). Source: https://code.claude.com/docs/en/changelog

- **Fable 5.2 as default Fable model (v2.1.321, Nov 9)**: Version 2.1.321 made Claude Fable 5.2 (with its 1M context window) the default Fable model. The same release added settings-file support for Remote Control. Source: https://claudexia.tech/blog/claude-code-novoe-v-noyabre-2026

## Integrations & Extensions

- **VS Code gains `/fork`, `/workflows`, and new settings (v2.1.330, Nov 20)**: The VS Code panel now exposes `/fork` and `/workflows` commands, plus three new settings: `claudeCode.escapeStopsClaude`, `claudeCode.pinPrompt`, and `claudeCode.contextUsageThreshold`. Earlier in v2.1.327 (Nov 17), an "Add to Chat" option was added to the Explorer's right-click menu. Source: https://code.claude.com/docs/en/changelog

- **`claude mcp add-json` reads server config from stdin (v2.1.327, Nov 17)**: The new `claude mcp add-json <name> -` command reads MCP server JSON from stdin, keeping tokens and secrets off the command line. The `/status` command was also enhanced to list broken agent, skill, and command files, keybinding errors, and unmatched hook matchers. Source: https://code.claude.com/docs/en/changelog

- **MCP tasks run in background (v2.1.319, Nov 6)**: When an MCP server runs a tool call as a task, Claude Code now moves it to the background and reports the result when it finishes. A new `permissions.denyInsteadOfPrompting` setting was also added. The `onFailure: "block"` option for `mcp_tool` hooks was added in v2.1.328. Source: https://code.claude.com/docs/en/changelog

- **Claude Agent SDK updates**: The Agent SDK (formerly Claude Code SDK) shipped Python releases 0.2.181–0.2.184 and TypeScript releases 0.3.323–0.3.327 through November. The TypeScript SDK tracks at parity with the CLI. A breaking change requires that hook options be arrays (checked at runtime). Source: https://www.morphllm.com/claude-agent-sdk

## Bug Fixes & Performance

- **Zstd decoding security fix (v2.1.325, Nov 13)**: A security issue in how zstd-compressed responses are decoded was patched. The same release fixed multiple Bash permission gaps including compound commands running without approval, allow rules that could run a different program than named, and several sandbox issues. Source: https://code.claude.com/docs/en/changelog

- **Code Mode sandbox and permission hardening (v2.1.323, Nov 12)**: The Bash sandbox now ignores write access granted through symlinks that lead elsewhere or to missing paths. `git worktree add`, `move`, and `remove` now fail read-only unless in the session's own worktree. Sign-in tokens and API keys are now excluded from most ripgrep and internal git commands. Source: https://code.claude.com/docs/en/changelog

- **v2.1.329: 91 bug fixes; v2.1.330: 98 bug fixes**: The two most recent releases together shipped 189 bug fixes, including fixes for computer use on macOS (new safety rules), auto mode reducing unnecessary `git status` calls, and VS Code extension issues. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Security warning: Trojanized VS Code extension on Cursor marketplace (Oct 29)**: StepSecurity reported that builds 2.1.312 and 2.1.313 of the Claude Code VS Code extension were published to Cursor's extension marketplace with a malicious loader embedded in `extension.js`. Anyone who installed those versions from Cursor's marketplace should check their machines and reinstall from a trusted source (the official VS Code Marketplace or JetBrains Marketplace). Source: https://www.stepsecurity.io/blog/claude-code-extension-trojanized

- **DEV Community weekly roundups**: Weekly "This week in Claude Code, Codex and Gemini CLI" posts on dev.to have been tracking Claude Code releases alongside competing tools, noting auto mode changes and MCP task handling. Source: https://dev.to/aicoding-guide/this-week-in-claude-code-codex-and-gemini-cli-week-of-november-15-2026-4pmm

- **Anthropic blog: Enabling Claude Code to work more autonomously**: Anthropic published a blog post describing the VS Code extension (beta), Terminal v2.0 with searchable history, the Claude Agent SDK rebranding, Checkpoints/rewind, Subagents, Hooks, and Background tasks as the pillars of increasing autonomy. Source: https://www.anthropic.com/news/enabling-claude-code-to-work-more-autonomously

## Roadmap & Announcements

- **Fast mode for Opus 4.8 deprecation (removal Nov 30)**: Fast mode for Claude Opus 4.8 was deprecated as of October 30, 2026 and is scheduled for permanent removal on November 30, 2026. Users running Opus 4.8 with fast mode should switch models before that date. Source: https://claudexia.tech/blog/claude-code-novoe-v-noyabre-2026

- **Code Mode documentation page**: Anthropic published a dedicated Code Mode documentation page at https://code.claude.com/docs/en/code-mode covering how to enable the feature for users and how to disable it for organizations. Source: https://code.claude.com/docs/en/changelog

- **Privacy prompt for email sharing (v2.1.317, Nov 3)**: Claude Code now asks before a web or shell tool call sends the user's account email address over the network — an early sign of tighter privacy defaults being rolled into more workflows. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
**Code Mode** (v2.1.323) is November's biggest development — an experimental opt-in that lets Claude write JavaScript to chain tool calls autonomously, fundamentally expanding what a single agentic step can accomplish and signaling Anthropic's push toward higher-autonomy workflows within the CLI.

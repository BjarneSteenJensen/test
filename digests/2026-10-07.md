# Claude Code News Digest — 2026-10-07

## Overview
October 2026 is a landmark month for Claude Code, headlined by the launch of **Claude Mods** — a TypeScript plugin system that lets users and teams deeply customize agent behavior, UI, and built-in features. Alongside Mods, Anthropic released a redesigned **Projects** beta enabling parallel threads and shared memory across repos, while six rapid-fire point releases (v2.1.287–2.1.292) shipped between October 1–6, hardening security, fixing regressions, and expanding the plugin/MCP ecosystem.

---

## New Features & Releases

- **Claude Mods (v2.1.287, October 1)**: Anthropic introduced Claude Mods, small TypeScript functions that ship inside plugins and allow deep customization of Claude Code — rewriting prompts, adding custom UI panels, replacing built-in features, or adding entirely new functionality. A built-in "You should know" mod runs a side agent that watches for things the user or Claude might miss. Users can write their own mods or ask Claude Code to generate one. Source: https://code.claude.com/docs/en/changelog

- **Plugin Marketplace Install + Sub-agent Effort Control (v2.1.292, October 6)**: The `claude plugin install` command gained a `--marketplace <source>` flag for direct marketplace integration. The Agent tool gained an `effort` parameter so users can control how hard sub-agents work on delegated tasks. Prompt caching support (`cache: true`) was added to `$.model.complete` for mods. Source: https://code.claude.com/docs/en/changelog

- **serverToolUses Tracking + VS Code Upgrades (v2.1.290, October 5)**: Added `serverToolUses` to `turn.step` hook results, exposing tool calls made by the API advisor layer. Added `agentId` to `tool.check` events to distinguish subagent vs. main session permission checks. Also fixed long sessions with hundreds of images getting stuck on "Request rejected as unprocessable" errors. Source: https://code.claude.com/docs/en/changelog

- **Redesigned Projects Beta (October 1)**: Anthropic launched a new beta Projects experience for Claude Code, allowing one project to coordinate parallel threads, shared memory, and a project library for long-running work across multiple repos and tasks. Available to select Claude Pro and Max subscribers using cloud sessions. Source: https://releasebot.io/updates/anthropic/claude-code

## Integrations & Extensions

- **VS Code Extension surpasses 26M installs**: As of September 26, 2026, the Claude Code VS Code extension reached 26,406,934 installs, with v2.1.283 the then-current version. Requirements are VS Code 1.98.0+ and any paid Claude plan or Console account — no API key needed. Usage of Claude Code among professional developers has grown from ~3% to 18% in the past nine months per JetBrains AI Pulse. Source: https://eesel.ai/blog/claude-code-vs-code-extension

- **MCP Gateway Infrastructure matures**: October 2026 discussions highlight MCP gateways as the production standard for teams using Claude Code, centralizing access control, observability, and routing across all upstream tool servers. The community identified a critical STDIO RCE class vulnerability (disclosed April 15, 2026, affecting Python/TypeScript/Java/Rust SDKs) as a key driver for centralized gateway adoption. Source: https://getmaxim.ai/articles/best-mcp-gateways-for-claude-code-in-2026-2

- **MCP tool name length fix (v2.1.292)**: A bug causing MCP tools with names longer than 128 characters to fail requests was fixed, improving compatibility with verbose tool schemas from third-party MCP servers. Source: https://code.claude.com/docs/en/changelog

## Bug Fixes & Performance

- **Critical regression fixes (v2.1.291, October 6)**: Fixed two regressions from v2.1.290 — cloud sessions were dropping answers to permission prompts, and the last session messages were being lost on quit (a regression from v2.1.288). Source: https://code.claude.com/docs/en/changelog

- **Security hardening (v2.1.289, October 3 & v2.1.292)**: Fixed deny/ask permission rules not applying correctly to nested shell commands, symlink-related security issues in notebook and PDF reads, and PreToolUse hook approvals bypassing permission prompts for network (UNC) paths. Also fixed user mods on managed machines not respecting permission boundaries. Source: https://code.claude.com/docs/en/changelog

- **WebFetch silent truncation fixed (v2.1.290)**: WebFetch was silently dropping text beyond 100,000 characters; this is now fixed. Additionally, `/rewind` was not listing prompts sent while Claude was actively working — also resolved. Source: https://code.claude.com/docs/en/changelog

- **NO_PROXY and HTTPS_PROXY fix (v2.1.292)**: Fixed `NO_PROXY` being ignored when `HTTPS_PROXY` is set, resolving network routing issues in enterprise proxy environments. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Corporate adoption headwinds**: Meta Platforms and Microsoft have reportedly asked employees to scale back Claude Code usage. Meta has reportedly cut usage nearly in half. The move signals ongoing enterprise evaluation of AI coding tools rather than a wholesale shift away. Source: https://seekingalpha.com/news/4650314-meta-microsoft-scale-back-employee-use-of-claude-report

- **Claude Agent SDK adoption guide**: The SDK (renamed from Claude Code SDK in September 2025) continues to see strong adoption for embedding the same agent loop into scripts, servers, and pipelines in Python 3.10+ and TypeScript. Starting June 15, 2026, Agent SDK and `claude -p` usage on subscription plans draw from a dedicated monthly Agent SDK credit separate from interactive usage limits. Source: https://www.morphllm.com/claude-agent-sdk

- **MCP token overhead documented**: Community developers have measured MCP server tool schemas consuming significant context at session start — one developer recorded 15,540 tokens across 84 tools from several connected servers — spurring interest in selective server loading and gateway-level tool filtering. Source: https://getmaxim.ai/articles/best-mcp-gateways-for-claude-code-in-2026-2

## Roadmap & Announcements

- **1M context default on Bedrock, Vertex, Foundry (October 1)**: Opus 4.7 and later, plus Fable models, began using 1M token context by default on Bedrock, Vertex, Foundry, and the Claude apps gateway. This change directly benefits Claude Code cloud sessions handling large codebases. Source: https://releasebot.io/updates/anthropic

- **Managed Agents onboarding added (v2.1.290)**: Claude Code v2.1.290 added managed agents onboarding flows, signaling continued investment in enterprise and team-managed deployment patterns for agentic coding workflows. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
The launch of **Claude Mods** in v2.1.287 is the defining development of the week — it fundamentally extends Claude Code from a powerful coding assistant into a customizable platform where teams can encode their own workflows, UIs, and guardrails directly into the tool, sharing them as plugins across their organization.

# Claude Code News Digest — 2026-07-09

## Overview
Claude Code shipped versions 2.1.202–2.1.205 this week, with the headline addition being a smarter auto-mode that blocks session-transcript tampering and a redesigned agent view that links running sessions directly to their pull requests. Separately, Anthropic launched Claude Cowork on web and mobile for Max subscribers and opened a public beta of Claude Code in its FedRAMP High government desktop environment.

## New Features & Releases

- **v2.1.205 — Auto-mode tamper protection & agent view redesign (July 8)**: Auto mode now blocks any attempt to modify session transcript files and asks before running `rm -rf` on unresolvable variables. The `claude agents` view received a visual overhaul: rows show colored state badges and classifier-written headlines instead of raw tool-call text, and sessions that edit, merge, comment on, or push to a PR now surface a direct PR link. The `/doctor` command was promoted to a full setup checkup that can diagnose and fix issues (aliased as `/checkup`). Binary auto-updates now stream to disk instead of buffering in memory, cutting peak RAM use by ~400 MB. Source: <https://code.claude.com/docs/en/changelog>

- **v2.1.203 — Login expiry warnings & MCP roots improvements (July 7)**: Claude Code now warns you before your login token expires so background sessions aren't interrupted mid-task. A grey ⏸ badge appears in the footer when manual permission mode is active. The session's additional working directories are now included in the MCP `roots/list` response, with `notifications/roots/list_changed` fired when the set changes. Source: <https://code.claude.com/docs/en/changelog>

- **v2.1.202 — Dynamic workflow size & /review speed restored (July 6)**: A new "Dynamic workflow size" setting in `/config` lets you control how many subagents Claude spins up for dynamic workflows. The `/workflows` layout was improved (wider titles, dedicated time column). The `/review <pr>` command was reverted to a fast single-pass flow after feedback that the prior multi-agent approach was too slow for routine use. Source: <https://code.claude.com/docs/en/changelog>

- **Claude Sonnet 5 as default model**: Claude Sonnet 5 is now the default model in Claude Code, bringing a native 1M-token context window at promotional pricing of $2/$10 per MTok through August 31, 2026. Source: <https://releasebot.io/updates/anthropic/claude-code>

## Integrations & Extensions

- **Enterprise-managed MCP connectors via Okta**: Anthropic added enterprise-managed MCP connector access, starting with Okta, so admins can provision connectors once and employees get zero-touch access on first login. The beta unifies centralized authorization across Claude Chat, Claude Code, and Cowork for Team and Enterprise plans. Source: <https://releasebot.io/updates/anthropic/claude-code>

- **VS Code remote control setting**: A dedicated VS Code setting was added to control remote-control behavior, giving teams finer-grained control over which IDE sessions can be steered remotely. Source: <https://code.claude.com/docs/en/changelog>

- **Trusted Devices for Remote Control (Enterprise/Team)**: Admins can now require device verification before members can view or steer local Claude Code sessions via Remote Control, tightening the security posture of collaborative debugging workflows. Source: <https://releasebot.io/updates/anthropic/claude-code>

## Bug Fixes & Performance

- **Background session stability (v2.1.203)**: Fixed a critical bug where background sessions became permanently unresponsive to `attach`, replies, and stop commands when the daemon's session token went stale. Also fixed: returning to `claude agents` silently killing running subagents; worktree-isolated subagents running commands in the parent checkout instead of their own; background agents crash-looping when their working directory was deleted. Source: <https://code.claude.com/docs/en/changelog>

- **Memory & streaming improvements**: Fixed a memory and CPU regression in interactive sessions (v2.1.203). The `--json-schema` flag no longer silently produces unstructured output when the schema is invalid (v2.1.205). Messages sent while Claude was working are no longer silently lost at the `--max-turns` limit. Source: <https://code.claude.com/docs/en/changelog>

- **Windows worktree fix**: Fixed a Windows-specific bug where worktree removal could delete files outside the worktree when NTFS junctions existed — a potentially destructive data-loss issue for Windows users. Source: <https://code.claude.com/docs/en/changelog>

- **SessionStart hook fix (v2.1.204)**: Hook events were not streaming during `SessionStart` hooks in headless sessions, causing remote workers to be idle-reaped mid-hook. This is now corrected. Source: <https://code.claude.com/docs/en/changelog>

## Roadmap & Announcements

- **Claude Code & Cowork in Claude for Government Desktop (public beta)**: Anthropic launched a public beta of both Claude Code and Claude Cowork inside its FedRAMP High authorized government desktop environment. The offering includes tamper-evident audit logs, spend governance controls, and stronger admin permissions — targeting public sector teams modernizing legacy software systems. Source: <https://www.anthropic.com/news>

- **Agent SDK billed separately from June 15**: As of June 15, 2026, Claude Agent SDK and Claude Code GitHub Actions usage is metered separately from interactive Claude Code. This makes agentic pipeline costs more predictable but moves automated workloads onto per-token billing, a significant pricing consideration for teams running large-scale automations. Source: <https://releasebot.io/updates/anthropic/claude-code>

- **Higher usage limits + SpaceX compute deal**: Anthropic announced higher usage limits for Claude plans alongside a compute infrastructure deal with SpaceX, signaling capacity investment to support the growing load from agentic workloads. Source: <https://www.anthropic.com/news/higher-limits-spacex>

## Key Takeaway
The v2.1.205 release's combination of auto-mode safety hardening, a redesigned agent view with direct PR linkage, and a 400 MB memory reduction represents the most operationally significant Claude Code update of the week — making multi-agent sessions both safer and substantially easier to monitor at scale.

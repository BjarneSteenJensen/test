# Claude Code News Digest — 2026-11-28

## Overview
The past week was one of the most active in Claude Code's release history, with five releases (v2.1.328–2.1.332) shipping in nine days. The headline addition is **MCP-server-delivered skills** (now in beta in v2.1.332), which lets any MCP server distribute reusable Claude Code workflows. Alongside that, **Code Mode** — an experimental feature where Claude writes JavaScript to run tools in batch — reached cloud-platform terminal sessions, and the built-in **Easel charts mod** landed for Pro/Max/Enterprise users.

---

## New Features & Releases

- **v2.1.332 — MCP Skills Beta (Nov 25)**: MCP servers can now ship reusable skill workflows to Claude Code, displayed as `server:skill` entries in the `/` menu. A new `PreSkillShellCommand` hook event lets admins refuse inline shell commands before a skill loads. The release also adds OpenTelemetry `assistant_response` events, a Cyber Verification Program tier in the startup header, and VS Code now shows plugin versions. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.331 — Code Mode on Cloud Platforms (Nov 23)**: Code Mode (the experimental mode in which Claude writes JavaScript to call tools in batch) is now available in terminal sessions on Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry, and Claude Platform on AWS. A new `claude doctor` command checks API connectivity. A new env var `CLAUDE_CODE_DISABLE_RESPONSE_COMPRESSION` helps users behind proxies that truncate compressed responses. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.330 — Charts, 30-Day Tasks & Enterprise Sign-In (Nov 20)**: The **Easel built-in mod** adds charts to the conversation for Pro, Max, and Team/Enterprise users on macOS and Linux (disable in `/config`). `claude auth login` now applies full Enterprise Admin Console organization settings. Scheduled tasks and `/loop` can now run up to **30 days** (up from 7). VS Code gains `/fork`, `/workflows`, and several new settings. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.328–2.1.329 — Auto Mode Expands & /code-review Refined (Nov 19)**: Auto mode is now available for Claude Opus 4.6 and Sonnet 4.6 on Bedrock, Agent Platform, Foundry, and Claude apps gateway. `/code-review` was narrowed to report only bugs and CLAUDE.md violations (use `/simplify` for cleanup). `/tasks` now surfaces scheduled tasks, `/loop` wakeups, goals, and forks in one view. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Integrations & Extensions

- **Skills over MCP Beta**: Anthropic launched a public beta (shipping as v2.1.332) allowing MCP servers to distribute skills alongside their tool definitions. Claude Code ignores certain settings — tool-permission and hook settings — that an MCP skill may try to declare, as a safety guardrail. This is part of a broader move to make the skill/MCP/plugin ecosystem more composable. Source: [Dataconomy (Nov 26)](https://dataconomy.com/2026/11/26/anthropic-adds-skills-over-mcp-to-claude-and-claude-code/) — *note: this domain is blocked in the current network policy; check the article directly*

- **VS Code Extension Updates**: v2.1.327 adds "Add to Chat" to the Explorer right-click menu. v2.1.330 adds `/fork` and `/workflows` commands and three new settings: `claudeCode.escapeStopsClaude`, `claudeCode.pinPrompt`, and `claudeCode.contextUsageThreshold`. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **MCP stdin JSON config (v2.1.327)**: `claude mcp add-json <name> -` now reads server config JSON from stdin, keeping API tokens off the command line in scripts and CI pipelines. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

## Bug Fixes & Performance

- **v2.1.332**: `claude auth login` now exits with code 1 when credentials can't be saved (instead of silently succeeding). A `Read` on a named pipe with no writer now times out after 20 seconds rather than hanging indefinitely. Several session freezes caused by large hook output or long `@` mention strings are resolved. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.330 freeze fix**: A bug causing Claude Code to freeze for up to several minutes immediately after compacting a very long conversation was fixed. The automatic `max_tokens` retry that was accidentally removed in v2.1.329 was also restored. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.332 overall scope**: Third-party sources report around 70 bug fixes across the v2.1.332 release cycle, along with 10-minute voice dictation support. Source: [PaidFreeDroid](https://paidfreedroid.com/2026/11/claude-code-v2-1-332-update-mcp-skills-sonnet-5-5-bug-fixes.html)

- **Security — "Don't Ask Again" file exposes secrets**: Security firm Apiiro found that Claude Code's approved-command file (the file that stores "don't ask again" decisions for shell commands) has been committed publicly by developers, with 1,122 public GitHub copies containing plaintext passwords and API keys. Users are advised to add `.claude/settings.local.json` to `.gitignore`. Source: [The Hacker News](https://thehackernews.com/2026/11/claude-codes-dont-ask-again-file.html) — *note: domain blocked in current network policy*

## Roadmap & Announcements

- **Plugin marketplace auto-update default change (Nov 30)**: On or after 2026-11-30, the `plugin marketplace` auto-update setting will default to `true` for `extraKnownMarketplaces` entries in managed settings. Organizations that want to opt out must set `"autoUpdate": false` explicitly before that date. Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)

- **Opus 4.8 Fast Mode removal (Nov 30)**: Fast mode for the Opus 4.8 model is being removed on 2026-11-30 and will error with no fallback. Anthropic recommends migrating to Opus 5.5 to retain fast-mode behavior. Source: [DEV Community weekly roundup](https://dev.to/aicoding-guide/this-week-in-claude-code-codex-and-gemini-cli-week-of-november-22-2026-1ofi)

- **Claude Fable 5.2 & Mythos 5.2 (Nov 9)**: Anthropic released two new models on November 9. The announcement is tagged with Claude Code on Anthropic's blog, suggesting possible Claude Code integration in upcoming releases. Source: [Anthropic announcements](https://claude.com/blog-category/announcements)

## Key Takeaway
The launch of **MCP-delivered skills in v2.1.332** marks a structural shift in how Claude Code capabilities can be distributed — MCP servers can now bundle both tools and reusable workflows together, reducing the need for users to separately install skills and configure servers. With the **plugin marketplace auto-update change on November 30**, enterprise administrators should audit their managed settings before the end of this weekend.

# Claude Code News Digest — 2026-09-20

## Overview
The biggest story of the day is v2.1.278 (shipped September 19), which changes the auto mode classifier to run server-side by default for Claude API and Enterprise users — eliminating classifier overhead charges and surfacing the classifier location in `/status`. Also notable: AGENTS.md is now a first-class alternative to CLAUDE.md, and Anthropic raised standard weekly limits by 25% for Pro, Max, Team, and seat-based Enterprise plans starting September 14.

## New Features & Releases

- **v2.1.278 — Server-side auto mode classifier (Sep 19)**: Auto mode for Claude API and Enterprise users now defaults to the server-side classifier, which no longer charges for classifier overhead. A new `Auto mode server` row in `/status` shows where the classifier is running. The release also bundles 40+ bug fixes covering session crashes, plugin handling, and UI regressions. Source: https://code.claude.com/docs/en/changelog

- **AGENTS.md support (v2.1.277–v2.1.278)**: Claude Code now reads `AGENTS.md` as a project-instructions file when no `CLAUDE.md` is present, aligning with the broader Agent SDK's conventions and improving cross-tool compatibility for teams that share agent configurations. Source: https://code.claude.com/docs/en/changelog

- **v2.1.275 — Ctrl+Enter send-now key & skills sync (Sep 17)**: A new `Ctrl+Enter` binding interrupts the current turn and immediately sends queued messages. Skills and plugins defined on claude.ai now sync automatically to terminal sessions, and `/plugin install <plugin> --marketplace <source>` lets you install from custom marketplaces. This release also shipped 60+ bug fixes. Source: https://code.claude.com/docs/en/changelog

- **Weekly limits raised 25% (Sep 14)**: Anthropic permanently raised standard weekly limits in Claude Code by 25% for Pro, Max, Team, and seat-based Enterprise plans, effective September 14, 2026. Source: https://www.digitalapplied.com/blog/claude-code-weekly-limit-reduction-september-14

## Integrations & Extensions

- **Fast mode in Remote sessions (v2.1.271, Sep 14)**: Fast mode is now available in Claude Code Remote sessions (both cloud and self-hosted runners), enabling lower-latency completions in CI/CD and headless environments. The release also introduced per-command `allowed_domains` for Bash/PowerShell in auto mode and an `omitClaudeMd` flag for agent frontmatter. Source: https://code.claude.com/docs/en/changelog

- **VSCode: Hooks dialog, Agent map, memory editing (Week 37)**: The VS Code extension added a Hooks dialog for managing hooks visually, an agent map view, the ability to view/edit/delete saved memories inside the Memory dialog, and image attachment support without requiring typed text. Source: https://code.claude.com/docs/en/whats-new

- **Claude Mods announced (Sep 14)**: Boris Cherny of the Claude Code team announced "Claude Mods are landing now," pointing to GitHub as the coordination thread — signalling an extensibility layer for modifying Claude Code's behavior beyond plugins. Source: https://releasebot.io/updates/anthropic/claude-code

- **Gateway hint headers & Remote Control session forking (v2.1.273, Sep 15)**: New opt-in request headers (`x-claude-code-request-class`, `x-claude-code-agent-type`, etc.) help LLM gateway operators route and instrument traffic. Remote Control sessions can now be forked server-side for parallel work. Source: https://code.claude.com/docs/en/changelog

## Bug Fixes & Performance

- **Critical proxy regression fixed (v2.1.276, Sep 18)**: Every request was failing with `400 … Input tag 'advisor_20260301'` when `ANTHROPIC_BASE_URL` pointed at a proxy or gateway. A hotfix was shipped same-day. Source: https://code.claude.com/docs/en/changelog

- **MCP reliability: disconnect notifications & startup wait (v2.1.273–v2.1.274)**: Claude Code now shows a visible notification when an MCP server disconnects mid-session and automatic reconnection fails, with a link to `/mcp`. A new `CLAUDE_CODE_MCP_STARTUP_WAIT_MS` env var bounds how long non-interactive sessions wait for MCP servers to connect (`0` = don't wait). Source: https://code.claude.com/docs/en/changelog

- **WebFetch 5-minute timeout & idle CPU fix (v2.1.268, Sep 10)**: Pages that haven't finished downloading within 300 seconds now fail with a clear error instead of hanging indefinitely. A separate fix addressed excessive CPU use in idle sessions. Source: https://code.claude.com/docs/en/changelog

- **Critical memory warning (v2.1.274, Sep 17)**: A visible warning now appears when memory usage is critical, with guided steps to free memory or restart safely before the session is lost. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **`claude plugin eval` launched (v2.1.269 / Week 37, Sep 11)**: The new `claude plugin eval` command runs a plugin against a suite of test cases, scores results, and compares against a no-plugin baseline. `claude plugin eval init` auto-drafts the test cases and graders. This gives plugin authors a repeatable quality gate. Source: https://code.claude.com/docs/en/whats-new

- **Claude Code for startups — September 2026 roundup**: Community coverage notes that Claude Code now spans terminals, IDEs, desktop, web, Slack, and CI/CD and is increasingly used by founders for rapid prototyping — repo mapping, bug fixes, tests, and docs — with the recommendation to keep Claude's access scoped and review every diff. Source: https://blog.mean.ceo/claude-code-news-september-2026/

- **Claude Code Projects beta — parallel threads & shared memory**: Anthropic rolled out a beta experience for Claude Code Projects that lets a single project coordinate parallel threads, maintain shared memory, and use a project library to manage long-running work across repos and tasks with reduced context hand-off. Source: https://www.gradually.ai/en/changelogs/claude-code/

## Roadmap & Announcements

- **Claude Fable 5.1 now default in Claude Code (v2.1.257, Week 36)**: Anthropic released Claude Fable 5.1 (and the identical-but-differently-safeguarded Claude Mythos 5.1) on September 1, 2026. Fable 5.1 brings a 1M-token context window and became the default Fable model in Claude Code as of v2.1.257. Source: https://code.claude.com/docs/en/whats-new

- **`/output-style` command (v2.1.269)**: A new `/output-style` command lets users switch Claude's response style (e.g., to Concise mode, which leads with results and skips preamble). This joins the broader effort to give users finer control over verbosity across sessions. Source: https://code.claude.com/docs/en/changelog

- **`maxEffortLevel` setting (Week 37)**: A new `maxEffortLevel` setting caps the effort level on every provider, giving enterprise deployments a way to bound compute costs without relying on per-session configuration. Source: https://code.claude.com/docs/en/whats-new

## Key Takeaway
The most impactful change landing today is v2.1.278's shift to a server-side auto mode classifier for API and Enterprise users, which eliminates classifier token overhead and makes auto mode more cost-effective at scale — a significant signal that Anthropic is hardening auto mode as the default operating posture for production Claude Code deployments.

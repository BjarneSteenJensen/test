# Claude Code News Digest — 2026-10-24

## Overview
October 2026 has been an exceptionally active month for Claude Code, with ten point releases shipped between October 14–23 alone (v2.1.299 through v2.1.310). The headline event is Code Review reaching general availability for Team and Enterprise customers on October 15, delivering 3× faster automated PR reviews. Simultaneously, the team has been hardening the sandbox security model and expanding cloud/enterprise capabilities, culminating in the v2.1.310 release on October 23 that brought Monitor tools to Bedrock, Vertex, and Foundry.

---

## New Features & Releases

- **Code Review Now Generally Available**: Anthropic's automated pull-request reviewer graduated from research preview on October 15, 2026, and is now available to all Claude Team and Enterprise organizations. Reviews now complete in 6–10 minutes (down from ~20 minutes), admins can choose Quick, Standard, or Deep review depth per repository, and eligible Enterprise orgs can claim at least $10,000 in Code Review credits through January 15, 2027. Source: [claude.com/resources/articles/code-review-is-now-generally-available](https://claude.com/resources/articles/code-review-is-now-generally-available)

- **v2.1.310 — Monitor Tools on Cloud Providers**: Released October 23, this build adds the Monitor tool and plugin monitors to Bedrock, Vertex, and Foundry-hosted sessions, and introduces Enterprise custom role support for Cloud sessions and Remote Control permissions. A new "Choose file" button simplifies cloud environment setup scripts. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.307 — Safety Telemetry & API Version Command**: Released October 21, this version adds the `claude_code.safety_event` OpenTelemetry event (emitted when a permission rule, auto mode, safety check, hook, or sandbox stops or flags a tool call) and a `/claude-api api-version` command to help users migrate API code to the `2026-10-21` version. It also adds `@claude review stop` to cancel an in-progress Code Review. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **v2.1.304 — Guided Auto-Mode Setup**: Released October 19, this build adds `/auto-mode-setup` for step-by-step auto mode configuration, and makes fork subagents the default outside the terminal. Also adds `/claude-api managed-agents-secure` and a `decider: "person"` option for mod `tool.check` answers. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

## Integrations & Extensions

- **LaTeX Math Rendering in VS Code (v2.1.301)**: The October 15 release added LaTeX math rendering support in the VS Code extension, improving the display of mathematical content directly in the IDE. Also added in this build: `%` motion in vim mode and multi-row support for mod `Input` fields. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Slack Connect Support for Claude Tag (v2.1.300)**: The October 14 release added Slack Connect support for Claude Tag, expanding the Slack integration to cross-workspace channels. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Agent SDK — Fork Subagents by Default**: The Claude Agent SDK (TypeScript 0.3.302 / Python 0.2.168, mid-October) now runs fork subagents by default and agents' own `Agent` calls in the foreground. Also added: per-subagent auto-compact windows. Claude Max and Team plans now include monthly API credits covering Agent SDK usage. Source: [gradually.ai/en/changelogs/claude-agent-sdk/](https://www.gradually.ai/en/changelogs/claude-agent-sdk/)

- **VS Code TLS Warning for Proxy Environments (v2.1.309)**: Released October 22, the VS Code extension now logs a clear warning with remediation steps when dictation or extension requests fail certificate verification, helping users behind TLS-inspecting proxies. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

## Bug Fixes & Performance

- **Sandbox Security Hardening (v2.1.309)**: The October 22 release fixed two sandbox escape vectors: shell startup files running outside the sandbox and MCP config files being writable by sandboxed commands. Also addressed multiple Bash permission-check gaps, several VS Code bugs, and Cloud session issues. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **MCP Reliability Improvements (v2.1.307 / v2.1.306)**: Fixed macOS keychain-locked auth prompts breaking headless runs, servers being wrongly marked as timed out after sleep, and HTTP tool calls being sent twice on dropped connections (retries are now limited to read-only/idempotent tools). Separately, v2.1.306 fixed API errors being masked by a misleading "prompt is too long" message in sessions with many MCP tools. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Gzip Request Bodies by Default (v2.1.300)**: All requests to `api.anthropic.com` are now gzip-compressed by default, reducing bandwidth and latency. Can be disabled with `CLAUDE_CODE_GZIP_REQUEST_BODIES=0`. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Idle Compaction for Long Sessions (v2.1.299)**: Conversations over 200 K tokens that sit idle for ~54 minutes are now automatically compacted before the one-hour prompt cache expires, preventing expensive re-processing on the next message. Configurable via `CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS` or disabled with `"idleCompaction": false`. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

- **Gateway Compatibility Fix (v2.1.310)**: Fixed requests failing behind gateways that reject the `effort-2025-11-24` beta header value. Source: [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

## Community & Ecosystem

- **Claude Code Misused in Data Exfiltration Campaign**: Cybersecurity researchers disclosed that a threat actor (CyberXero) used Claude Code as part of a campaign that accessed 429 WordPress admin panels and exfiltrated over 628,000 records from four Ukrainian organizations. The report underscores AI-assisted attack tooling as a growing concern. Source: [thehackernews.com/2026/10/cyberxero-uses-claude-code-in-campaign.html](https://thehackernews.com/2026/10/cyberxero-uses-claude-code-in-campaign.html)

- **Community IDE Extensions Expanding**: Unofficial extensions now cover Eclipse IDE and Visual Studio 2026 (bringing native diff accept/reject, autonomous debugger control, and Roslyn code navigation). A community JetBrains "Claude Code with GUI" plugin (v0.34.6, October 20) also updated. These are not affiliated with Anthropic. Sources: [marketplace.eclipse.org](https://marketplace.eclipse.org/content/claude-code-eclipse-ide), [github.com/firish/claude\_code\_vs](https://github.com/firish/claude_code_vs)

- **Claude Security Available as MCP Connector**: Claude Security (Anthropic's security findings product) is now available as an MCP connector in Claude.ai and Claude Code, letting users review a finding, start a fix, and mark it resolved in a single session. Source: [code.claude.com/docs/en/mcp](https://code.claude.com/docs/en/mcp)

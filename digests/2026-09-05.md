# Claude Code News Digest — 2026-09-05

## Overview
The first week of September 2026 brought a flurry of Claude Code releases (v2.1.257–v2.1.261), headlined by the launch of Claude Fable 5.1 with a 1M-token context window. Organizations gained the ability to push MCP servers to all users centrally, and a new visual diff panel landed in the UI. Anthropic also announced a permanent 25% usage limit increase effective September 14.

---

## New Features & Releases

- **Claude Fable 5.1 ships as the new default Fable model (v2.1.257 — Sep 1)**: `claude-fable-5-1` brings a 1M-token context window at $10/$50 per MTok with $0.25/MTok cache reads. The release also added `CLAUDE_CODE_SUBAGENT_MODEL_FORCE`, the `permissions.blockReadsOutsideWorkingDirectories` setting, a `Containment Escape` rule for auto mode, and `timeFormat`/`timeZone` settings. Over 100 bug fixes shipped alongside it. Source: https://code.claude.com/docs/en/changelog

- **Fullscreen diff panel via `/diff` (v2.1.260 — Sep 3)**: A new diff panel opens beside the conversation in fullscreen mode and shows your uncommitted changes as Claude edits in real time. The release also adds `/reload-plugins` for headless sessions and a text form of `/advisor` for desktop, Remote Control, and headless sessions. Source: https://code.claude.com/docs/en/changelog

- **Output and task size limits raised (v2.1.261 — Sep 4)**: `bashOutputMaxChars` and `taskOutputMaxChars` settings (configurable up to 128K characters) let teams handle larger tool outputs without truncation. The new `/skill-doctor` command shows unused skills and their context cost. Source: https://code.claude.com/docs/en/changelog

- **Permanent 25% usage limit increase from September 14**: Anthropic is permanently raising standard baseline limits for Claude Code by 25% across Pro, Max, Team, and seat-based Enterprise tiers — following the temporary +50% promo extended through September 13. Source: https://aicatchup.com/news/claude-code-weekly-limits-permanent-25-percent-september-2026

## Integrations & Extensions

- **`managedMcpServers` setting for Enterprise (v2.1.259 — Sep 2)**: Organizations can now push HTTP/SSE MCP servers to every user in the same format as `.mcp.json` — centralizing MCP configuration without requiring per-user setup. Also added: `--permission-prompts none` for unattended headless CI/CD hosts, which auto-denies anything that would normally prompt. Source: https://code.claude.com/docs/en/changelog

- **Apple Xcode 26.3 gains native Claude Agent SDK integration**: Xcode 26.3 ships a built-in integration with the Claude Agent SDK, bringing subagents, background tasks, and plugins directly into Xcode without leaving the IDE. This follows the pattern of VS Code and JetBrains integrations. Source: https://www.anthropic.com/news/apple-xcode-claude-agent-sdk

- **GitLab merge request support (v2.1.259 — Sep 2)**: Added `glab mr create/merge/close/reopen/note/update` recognition so GitLab merge requests display as `MR !N` in the collapsed tool summary, bringing GitLab to parity with GitHub PR display. Source: https://code.claude.com/docs/en/changelog

- **VS Code extension additions (v2.1.261 — Sep 4)**: The VS Code extension gained a "Build a custom style" walkthrough in the Output styles menu, Add/Remove actions in the MCP servers dialog, a fold button on permission and question prompts, and an "Archive session" option in the session list right-click menu. Source: https://code.claude.com/docs/en/changelog

## Bug Fixes & Performance

- **Concurrent session state corruption fixed (v2.1.259 — Sep 2)**: A critical bug where concurrent sessions silently reverted each other's `~/.claude.json` changes has been resolved — workspace trust no longer resets and MCP/project state is no longer lost when running many sessions simultaneously. Source: https://code.claude.com/docs/en/changelog

- **macOS Monterey launch regression fixed (v2.1.258 — Sep 1)**: Claude Code was failing to launch on macOS 12 (Monterey) due to a regression introduced in v2.1.255; this was patched in the v2.1.258 hotfix. Source: https://code.claude.com/docs/en/changelog

- **MCP disconnect error reporting fixed (v2.1.259 — Sep 2)**: MCP servers that disconnect while their tools are being listed at startup now report the error correctly instead of appearing as connected with no tools. Source: https://code.claude.com/docs/en/changelog

- **Fable 5.1 prompt caching fixed (v2.1.260 — Sep 3)**: Fixed prompt caching on Fable 5.1 not covering context after tool results, and fixed `/effort` invalidating the prompt cache on Fable 5.1. Also fixed the `/model` picker not showing Fable 5.1 as an option. Source: https://code.claude.com/docs/en/changelog

## Community & Ecosystem

- **Commerce agent blueprint released**: Anthropic launched a reference commerce agent blueprint with working shopping and merchant agent implementations buildable via the Messages API, Agent SDK, or Claude Managed Agents (beta), along with a Claude Code plugin to help teams build AI-powered shopping experiences. Source: https://releasebot.io/updates/anthropic/claude

- **Claude Mythos 5 added to Claude Security for Enterprise**: Enterprise customers gained access to Claude Mythos 5 for frontier cyber defense, including codebase scans, vulnerability findings, and suggested patches. Source: https://releasebot.io/updates/anthropic/claude

- **`/skill-doctor` for context cost visibility (v2.1.261 — Sep 4)**: The new `/skill-doctor` command helps developers identify unused skills and understand how much context cost each skill is consuming — useful for optimizing large plugin setups. Source: https://code.claude.com/docs/en/changelog

## Roadmap & Announcements

- **Enterprise Frontier Safeguards (EFS) announced**: Anthropic announced EFS, combining zero data retention with state-of-the-art misuse detection while storing data in cloud infrastructure controlled by the customer — targeting security-sensitive enterprise deployments. Source: https://releasebot.io/updates/anthropic

- **Self-hosted Claude Code environments in public beta**: Team and Enterprise organizations can now run Claude Code cloud sessions on their own infrastructure, in public beta — extending the self-hosted option announced in Week 32 (August 3–7). Source: https://code.claude.com/docs/en/whats-new

- **`--append-subagent-system-prompt-file` for large orchestration prompts (v2.1.261 — Sep 4)**: A new flag lets teams inject large system prompts into subagents from a file, enabling more sophisticated multi-agent orchestration patterns without hitting inline prompt size constraints. Source: https://code.claude.com/docs/en/changelog

## Key Takeaway
The launch of **Claude Fable 5.1** on September 1 is the week's defining event, delivering a 1M-token context window at competitive pricing, while the upcoming **permanent 25% usage limit increase on September 14** gives Claude Code subscribers materially more headroom starting next week.
